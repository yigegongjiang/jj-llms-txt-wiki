# Product descriptions

Last updated Aug 20, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/style-guide/documentation-content-strategy/component-attributes/product-descriptions/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

## Definition

Statements about the product and its benefits for customers.

## When to use it

Use product descriptions in the [Overview (or Landing page)](https://developers.cloudflare.com/style-guide/documentation-content-strategy/content-types/overview/), the Support home page, and the Cloudflare Docs home page.

## Structure

There are two product descriptions, short and long. Both appear in the Overview (or Landing page) as part of the introduction to the product.

### Short description

A short summary statement about the product. This does not need to be, and ideally should not be, a complete sentence.

### Long description

A summary of the product and the value or benefits it brings customers. It makes two main assertions: what the product does, and how that benefits the customer.

* **Intent**: show what a customer could use the product for. It should not sell like marketing content, but you can draw on marketing statements for good summaries and adjust the tone to be product appropriate.
* **Length**: two to four sentences, kept readable at around a 7th grade reading level.

## Example

Short description:

```txt
Cloudflare Registrar: Cloudflare's domain registrar
```

Long description:

```txt
Manage your domain with Cloudflare Registrar and add an additional layer of security to your DNS records for free.
```
