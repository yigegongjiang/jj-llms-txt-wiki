Use the glossary definition shortcode to render the defined glossary definition. Additionally, you can include a [prepend value](https://developers.cloudflare.com/style-guide/build-the-page/components/glossary-definition/) to add words to the start of the definition.

Create the glossary entries in a file dedicated to your product. These YAML files live in `/src/content/glossary/<YOUR-PRODUCT>.yaml`

## Component

```mdx
import { Glossary } from "~/components"

<Glossary />
```

## Glossary

```yaml
productName: Style Guide
entries:
  - term: example
    general_definition: |-
      Hello, world! You can use **Markdown** features inside of your `tooltips`.
```
