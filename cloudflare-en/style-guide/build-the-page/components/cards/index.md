**Partials**

Cards are a built-in component provided by [Nimbus ↗](https://nimbus-docs.com/components/card/).

## Cards

```mdx
import { Card } from "~/components";

<Card title="Check this out" icon="ph:puzzle-piece">
	Interesting content you want to highlight.
</Card>
```

## List cards

```mdx
import { ListCard } from "~/components";

<ListCard title="Links" icon="ph:puzzle-piece">

- foo
- bar
- baz

</ListCard>
```

## Link title cards

```mdx
import { LinkTitleCard } from "~/components";

<LinkTitleCard
	title="Check this out"
	icon="ph:puzzle-piece"
	href="/style-guide/build-the-page/components/cards/"
>
	Interesting content you want to highlight.
</LinkTitleCard>
```

Optionally, you can choose a corresponding icon from Starlight’s [Icons ↗](https://starlight.astro.build/reference/icons/#all-icons) for cards.
