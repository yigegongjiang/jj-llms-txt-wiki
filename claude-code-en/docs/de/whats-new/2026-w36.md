    <span className="digest-feature-pill">v2.1.260</span>
  </div>

  <p className="digest-feature-lede">In der Vollbilddarstellung öffnet <code>/diff</code> jetzt ein Panel neben der Konversation, anstatt einen Viewer zu öffnen, den Sie schließen müssen. Das Panel listet die geänderten Dateien mit ihren hinzugefügten und entfernten Zeilenzahlen auf und wird jedes Mal aktualisiert, wenn Claude eine Datei bearbeitet oder einen Shell-Befehl ausführt. Wählen Sie Zeilen im Panel mit der Maus aus, um sie an Ihre nächste Eingabeaufforderung anzuhängen.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/diff-panel.mp4?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=9d7553c19e7f227891cd95f1f59d796d" data-path="images/whats-new/diff-panel.mp4" />

  <p className="digest-feature-try">Mit aktivierter Vollbilddarstellung, in einem Git-Repository und in einem Terminal mit mindestens 110 Spalten Breite, schalten Sie das Panel um:</p>

  ```text Claude Code theme={null}
  > /diff
  ```

  <p className="digest-feature-try">Führen Sie <code>/diff</code> erneut aus oder klicken Sie auf das <code>✕</code> in seiner Kopfzeile, um es zu schließen.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Ungenutzte Skills mit /skill-doctor finden</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede"><code>/skill-doctor</code> zeigt, was jeder Ihrer Skills im Kontext kostet und wie oft er verwendet wird, damit Sie entscheiden können, welche Sie ausschalten möchten. Jeder Skill in der <a href="/docs/de/skills#skill-descriptions-are-cut-short">Skill-Auflistung</a> trägt zu Ihrem Kontext bei jedem Zug bei, unabhängig davon, ob Claude ihn jemals verwendet oder nicht. Erfordert v2.1.252 oder später und ist nicht in Sitzungen verfügbar, die das <a href="/docs/de/env-vars#features-that-need-feature-flag-fetching">Abrufen von Feature-Flags</a> überspringen.</p>

  <p className="digest-feature-try">Führen Sie es in einer interaktiven Sitzung aus, um den Bericht in der Registerkarte <strong>Stats</strong> des <code>/plugin</code>-Managers zu öffnen:</p>

  ```text Claude Code theme={null}
  > /skill-doctor
  ```

  <p className="digest-feature-try">Im nicht-interaktiven Modus mit <code>-p</code> gibt Claude Code den Bericht stattdessen als Text aus.</p>

  <a className="digest-feature-link" href="/docs/de/skills#find-unused-skills">Ungenutzte Skills finden</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div>Ein <a href="/docs/de/hooks#premodelswitch"><code>PreModelSwitch</code></a> Hook kann einen angeforderten Modellwechsel blockieren, und ein <a href="/docs/de/hooks#postmodelswitch"><code>PostModelSwitch</code></a> Hook kann Kontext für Claude hinzufügen, nachdem sich das Modell der Sitzung ändert</div>
    <div><a href="/docs/de/costs#prompt-cache-statistics"><code>/cost</code></a> fügt eine Zeile <code>Prompt cache (main)</code> hinzu: der Anteil der Input-Token, die aus dem Cache bereitgestellt werden, die Cache-Misses, ob der Cache warm ist, und eine wahrscheinliche Ursache für den letzten Miss, wenn Claude Code eine benennen kann. Status-Zeilen-Skripte erhalten ein entsprechendes <code>prompt\_cache</code> Objekt</div>
    <div>Organisationen können HTTP- und SSE-MCP-Server unter der verwalteten Einstellung <a href="/docs/de/managed-mcp#provide-servers-through-managed-settings"><code>managedMcpServers</code></a> auflisten, um sie jedem Benutzer zur Verfügung zu stellen, zusätzlich zu den Servern, die Benutzer selbst hinzufügen</div>
    <div><code>/effort</code> und die <code>/model</code> Auswahl speichern jetzt <a href="/docs/de/model-config#adjust-effort-level">eine separate Anstrengungsstufe für jedes Modell</a>; drücken Sie <code>s</code> statt <code>Enter</code>, um eine Stufe nur auf die aktuelle Sitzung anzuwenden</div>
    <div>Standardmäßig <a href="/docs/de/permission-modes#what-the-classifier-blocks-by-default">blockiert der Auto-Modus-Klassifizierer jetzt auch</a> Aktionen wie das Anfordern von Anmeldedaten vom Cloud-Instance-Metadaten-Endpunkt oder das Verbinden mit Geschwister-Containern, die Claude nicht gestartet hat</div>
    <div>Im Auto-Modus fragt Claude Code Sie, bevor Claude <a href="/docs/de/permission-modes#first-read-outside-the-working-directories">zum ersten Mal eine Datei außerhalb Ihrer Arbeitsverzeichnisse liest</a>, mit einer Option, solche Lesevorgänge von da an zu blockieren</div>
    <div>Erhöhen Sie <a href="/docs/de/settings-reference#bashoutputmaxchars"><code>bashOutputMaxChars</code></a> und <a href="/docs/de/settings-reference#taskoutputmaxchars"><code>taskOutputMaxChars</code></a> auf bis zu 128.000 Zeichen, damit Claude mehr der Ausgabe eines erfolgreichen Befehls oder einer Hintergrundaufgabe inline erhält</div>
    <div>Die Tastenkombinationen zur Wortbearbeitung in der Eingabeaufforderung <a href="/docs/de/interactive-mode#make-ctrl-w-delete-back-to-whitespace">folgen readline</a> für alle, und die Einstellung <code>keybindingFlavor</code> hat keine Auswirkung mehr. <code>Ctrl+W</code> löscht bis zum vorherigen Leerzeichen, und <code>Alt+B</code>, <code>Alt+F</code> und <code>Alt+D</code> behandeln Satzzeichen wie <code>/</code> und <code>.</code> als Wortgrenzen</div>
    <div>Wenn Sie <code>defaultMode</code> in der <code>.claude/settings.json</code> oder <code>.claude/settings.local.json</code> eines Projekts auf <code>"bypassPermissions"</code> setzen, <a href="/docs/de/permission-modes#which-mode-a-session-starts-in">hat dies keine Auswirkung mehr</a> und die Sitzung startet im Manuellen Modus; setzen Sie stattdessen <code>"bypassPermissions"</code> in Benutzer- oder verwalteten Einstellungen oder übergeben Sie `--permission-mode`</div>
    <div>Seat-basierte Enterprise-Pläne <a href="/docs/de/model-config#default-model-setting">verwenden jetzt standardmäßig Opus 5</a></div>
    <div>In der VS Code-Erweiterung klicken Sie auf den Modellnamen am unteren Rand des Eingabefelds, um <a href="/docs/de/vs-code#use-the-prompt-box">die Modellauswahl zu öffnen</a></div>
    <div>In der VS Code-Erweiterung wählen Sie <strong>Output styles</strong> im Abschnitt „Anpassen" des Befehlsmenüs, um <a href="/docs/de/vs-code#use-the-prompt-box">einen Ausgabestil auszuwählen</a>, einschließlich Ihrer benutzerdefinierten</div>
  </div>
