<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude-Sicherheits-Plugin</span>
    <span className="digest-feature-pill">Plugin</span>
  </div>

  <p className="digest-feature-lede">Das Claude-Sicherheits-Plugin führt einen Multi-Agent-Sicherheitslücken-Scan Ihrer Codebasis innerhalb einer Claude-Code-Sitzung durch: Agenten kartografieren Ihre Architektur, erstellen ein Bedrohungsmodell, suchen nach Sicherheitslücken und überprüfen unabhängig jeden Fund, bevor sie den Bericht in ein <code>CLAUDE-SECURITY-\<timestamp>/</code>-Verzeichnis schreiben. Scannen Sie ein ganzes Repository oder nur das Diff eines Branches, einen Pull Request oder einen einzelnen Commit, und wandeln Sie dann die Findings, die Sie auswählen, in überprüfte Patches um, die Sie selbst anwenden.</p>

  <p className="digest-feature-try">Installieren Sie das Plugin aus dem offiziellen Anthropic-Marketplace, führen Sie <code>/reload-plugins</code> aus, und starten Sie dann einen Scan mit <code>/claude-security</code>:</p>

  ```text Claude Code theme={null}
  > /plugin install claude-security@claude-plugins-official
  ```

  <a className="digest-feature-link" href="/docs/de/claude-security#scan-and-fix-your-codebase">Scannen und beheben Sie Ihre Codebasis</a>
</div>

  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/de/code-review#review-a-diff-locally"><code>/code-review</code></a> läuft jetzt als Hintergrund-Subagent mit eigenem Kontextfenster, sodass die Überprüfungsarbeit aus Ihrer Konversation bleibt und die Findings ankommen, wenn sie abgeschlossen ist</div>
    <div><code>/verify</code>, <code>/code-review</code> und <code>/deep-research</code> laufen nur, wenn Sie sie aufrufen; Claude startet sie nicht mehr von selbst</div>
    <div><a href="/docs/de/interactive-mode#emoji-shortcodes">Emoji-Shortcodes</a> werden in der Eingabeaufforderung automatisch vervollständigt: Geben Sie <code>:heart:</code> ein, um ein Emoji einzufügen, oder zwei oder mehr Zeichen nach <code>:</code> für Vorschläge; deaktivieren Sie dies mit <code>emojiCompletionEnabled</code></div>
    <div>Skills mit <code>context: fork</code> <a href="/docs/de/skills#run-skills-in-a-subagent">laufen standardmäßig im Hintergrund</a>, und <code>background: false</code> in der Frontmatter des Skills wartet auf das Ergebnis in derselben Runde</div>
    <div>Eine Sitzung führt standardmäßig bis zu 20 Subagenten gleichzeitig aus; ändern Sie das <a href="/docs/de/sub-agents#concurrent-subagent-limit">Limit</a> mit <code>CLAUDE\_CODE\_MAX\_CONCURRENT\_SUBAGENTS</code></div>
    <div>`--max-budget-usd` erzwingt jetzt die Obergrenze für Subagenten: Sobald die Ausgaben sie erreichen, kann Claude keine neuen starten und laufende Hintergrund-Subagenten stoppen</div>
    <div>Neue <a href="/docs/de/sandboxing#disable-filesystem-isolation"><code>sandbox.filesystem.disabled</code></a>-Einstellung überspringt die Dateisystem-Isolation, während die Kontrolle des Netzwerk-Egress erhalten bleibt</div>
    <div>Im Auto-Modus öffnen die Überprüfungen für gefährliche <code>rm</code>-Befehle, Hintergrund-Jobs und verdächtige Windows-Pfade keine Berechtigungsdialoge mehr; der Auto-Modus-Klassifizierer entscheidet stattdessen</div>
    <div>Bash-Berechtigungsprüfungen schlagen bei mehr Shell-Formen fehl, einschließlich Dateideskriptor-Umleitungen, Zsh-Variablen-Subscripts in <code>\[\[]]</code>-Vergleichen, <code>help</code>- und <code>man</code>-Aufrufe, die unsichere Optionen ausführen könnten, und Befehle über 10.000 Zeichen</div>
    <div><a href="/docs/de/fast-mode">Schnellmodus</a> unterstützt Opus 4.7 nicht mehr: <code>/fast</code> gilt jetzt für Opus 5 und Opus 4.8</div>
    <div>Langfristig laufende Tool-Aufrufe geben einen periodischen Fortschritts-Heartbeat aus, anstatt stumm zu bleiben</div>
  </div>
</div>
