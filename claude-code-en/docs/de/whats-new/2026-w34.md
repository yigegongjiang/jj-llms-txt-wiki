  <p className="digest-feature-lede">Der <code>/design</code>-Skill bringt den Artboard-Workflow von Claude Design in die CLI und Claude Code Desktop, basierend auf Artefakten. Führen Sie ihn mit einer kurzen Beschreibung aus und Claude veröffentlicht eine Canvas mit bearbeitbaren Artboards für Ihre UI. Wählen Sie einen aus, passen Sie ihn an und lassen Sie Claude ihn dann implementieren. Verfügbar für Pro, Max, Team und Enterprise. Erfordert v2.1.234 oder später.</p>

    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/2SnAdpL4dJ18nKb3/images/whats-new/design-skill.mp4?fit=max&auto=format&n=2SnAdpL4dJ18nKb3&q=85&s=0b376a94227c14a4204af89c4c9fd7ac" data-path="images/whats-new/design-skill.mp4" />
  </Frame>

  <p className="digest-feature-try">Beschreiben Sie, was Sie entworfen haben möchten, und lassen Sie Claude die Optionen entwerfen:</p>

  ```text Claude Code theme={null}
  > /design redesign the composer based on what people actually use it for
  ```

  <p className="digest-feature-try">Claude gibt einen Link zur veröffentlichten Canvas aus. Öffnen Sie ihn, wählen Sie ein Artboard aus und teilen Sie Claude mit, welche Option implementiert werden soll.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Concise-Ausgabestil</span>
    <span className="digest-feature-pill">v2.1.237</span>
  </div>

  <p className="digest-feature-lede">Concise ist ein neuer integrierter Ausgabestil. Claude führt mit dem Ergebnis an und überspringt Präambel und Erzählung, während die Arbeit genauso gründlich wie im Standard-Stil erledigt wird. Wenn Sie um eine Erklärung oder mehr Details bitten, antwortet Claude vollständig. Fehlerberichte, Sicherheitswarnungen und Bestätigungen für destruktive Aktionen behalten ihren vollständigen Inhalt.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/2SnAdpL4dJ18nKb3/images/whats-new/concise-output-style.mp4?fit=max&auto=format&n=2SnAdpL4dJ18nKb3&q=85&s=dfb40ec8921ed1bc82eb629042a8ec17" data-path="images/whats-new/concise-output-style.mp4" />
  </Frame>

  <p className="digest-feature-try">Aktivieren Sie es unter <strong>Output style</strong> in <code>/config</code>, oder stellen Sie es in Ihrer Einstellungsdatei ein:</p>

  ```json ~/.claude/settings.json {2} theme={null}
  {
    "outputStyle": "Concise"
  }
  ```

  <p className="digest-feature-try">Führen Sie <code>/clear</code> aus oder starten Sie eine neue Sitzung, und Claudes Antworten führen mit dem Ergebnis an.</p>

  <a className="digest-feature-link" href="/docs/de/output-styles#built-in-output-styles">Integrierte Ausgabestile</a>
</div>

  <div className="digest-feature-header">
    <span className="digest-feature-title">Starten Sie eine Sitzung auf Ihrem Computer von Ihrem Telefon aus</span>
    <span className="digest-feature-pill">mobile</span>
  </div>

  <p className="digest-feature-lede">Jeder Computer, auf dem <code>claude remote-control</code> ausgeführt wird, wird jetzt als Gerätekarte oben auf der Registerkarte Code in der Claude-App angezeigt. Remote Control ist auch aus der Forschungsvorschau heraus.</p>

  <Frame>
    <img className="w-full" src="https://mintcdn.com/claude-code/2SnAdpL4dJ18nKb3/images/whats-new/remote-control-phone-start.jpg?fit=max&auto=format&n=2SnAdpL4dJ18nKb3&q=85&s=9f0ebedab23aa0e1732cc37782573907" alt="Die Registerkarte Code in der Claude-Mobile-App mit einem Abschnitt „Geräte&#x22;, der einen verbundenen MacBook als Gerätekarte über der Sitzungsliste anzeigt" width="1206" height="895" data-path="images/whats-new/remote-control-phone-start.jpg" />
  </Frame>

  <p className="digest-feature-try">Starten Sie Remote Control auf dem Computer, den Sie erreichen möchten, und öffnen Sie dann die Registerkarte Code auf Ihrem Telefon:</p>

  ```bash terminal theme={null}
  claude remote-control
  ```

  <p className="digest-feature-try">Ihr Computer wird als Gerätekarte oben auf der Registerkarte Code angezeigt. Tippen Sie darauf, um ein Verzeichnis auszuwählen und dort eine Sitzung zu starten.</p>

  <a className="digest-feature-link" href="/docs/de/remote-control#start-a-remote-control-session">Starten Sie eine Remote Control-Sitzung</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div>Claude Code setzt Ihre Sitzung jetzt automatisch fort, wenn ein claude.ai-Nutzungslimit zurückgesetzt wird. Deaktivieren Sie dies in der Zeile <strong>Continue automatically at usage limit</strong> in <code>/config</code></div>
    <div>Die optionale <a href="/docs/de/interactive-mode#check-spelling-as-you-type"><code>spellcheck</code>-Einstellung</a> unterstreicht falsch geschriebene Wörter in der Eingabeaufforderung während der Eingabe mit Ihrem installierten <code>aspell</code>, <code>hunspell</code> oder <code>ispell</code></div>
    <div>In einem Branch mit einer offenen GitLab-Merge-Request, wobei die <code>glab</code>-CLI über <code>glab auth login</code> authentifiziert ist, zeigt die Fußzeile ein <a href="/docs/de/interactive-mode#gitlab-merge-requests"><code>MR !N</code>-Badge</a> an, das je nachdem farbig gekennzeichnet ist, ob die Merge-Request ein Entwurf, offen oder zusammenführbar ist</div>
    <div>Ändern Sie die Aufwandsstufe von Ihrem Telefon oder claude.ai/code aus und sie <a href="/docs/de/remote-control#what-connected-devices-see">wird auf die Sitzung auf Ihrem Computer angewendet</a>. Remote Control-Sitzungen, die von Desktop oder VS Code gehostet werden, zeigen verbundenen Geräten auch den aktuellen Berechtigungsmodus der Sitzung an</div>
    <div>Sie können <a href="/docs/de/permissions#manage-permissions"><code>/permissions</code></a> öffnen oder <code>/add-dir \<path></code> ausführen, während Claude arbeitet. Änderungen an Berechtigungsregeln gelten für den Rest des aktuellen Zuges</div>
    <div>Wenn Hintergrundaufgaben ein <a href="/docs/de/goal#background-work-defers-evaluation"><code>/goal</code></a> warten lassen, überprüft Claude sie nach 30 Minuten, anstatt unbegrenzt zu warten, und überprüft sie weiterhin in längeren Intervallen, während die Sitzung untätig ist. Setzen Sie <code>CLAUDE\_CODE\_GOAL\_CHECKIN\_MINUTES=0</code>, um dies zu deaktivieren</div>
    <div>Ihre eigenen Eingabeaufforderungen werden jetzt im Transkript als Markdown gerendert, mit hervorgehobenen Codeblöcken, Inline-Code und Listen, genauso wie Antworten</div>
    <div>Die neue <a href="/docs/de/model-config#set-a-default-model-for-new-sessions"><code>ANTHROPIC\_DEFAULT\_MODEL</code></a>-Umgebungsvariable legt das Modell fest, mit dem neue Sitzungen starten. Eine <code>/model</code>-Auswahl überschreibt sie immer noch und bleibt über Neustarts hinweg erhalten</div>
    <div>Mit der <code>notify\_when\_idle</code>-Eingabe auf <code>SendMessage</code> kann Claude eine andere Claude Code-Sitzung auf demselben Computer bitten, <a href="/docs/de/cross-session-messaging#get-a-notice-when-another-session-goes-idle">eine Benachrichtigung zu senden, wenn sie das nächste Mal untätig wird</a></div>
    <div>Stellen Sie <a href="/docs/de/interactive-mode#make-ctrl-w-delete-back-to-whitespace"><code>keybindingFlavor</code></a> auf <code>"readline"</code> ein, um <code>Ctrl+W</code> in der Eingabeaufforderung zum Löschen bis zum vorherigen Leerzeichen zu machen, wie Bash es tut, anstatt bei Satzzeichen wie <code>/</code> zu stoppen</div>
    <div>Unter nativem Windows können Ihre Claude Code-Sitzungen jetzt <a href="/docs/de/cross-session-messaging#availability">miteinander kommunizieren</a> mit <code>SendMessage</code> und sich gegenseitig mit <code>ListAgents</code> finden, wie auf macOS und Linux</div>
    <div>Self-Hosted-Runner akzeptieren `--defer-shutdown-max-min`, das <a href="/docs/de/self-hosted-environments-deploy#defer-the-drain-past-the-first-signal">angehängte Sitzungen</a> für eine festgelegte Anzahl von Minuten nach SIGTERM weiter bedient</div>
    <div>Self-Hosted-Runner akzeptieren `--proxy-authorization-command` oder `--proxy-authorization-file`, um einen frischen `Proxy-Authorization`-Header für <a href="/docs/de/self-hosted-environments-deploy#authenticate-to-an-egress-proxy">Egress-Proxys bereitzustellen, die einen benötigen</a></div>
  </div>
</div>
