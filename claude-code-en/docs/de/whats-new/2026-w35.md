Durchsuchen Sie Ihre Sitzungen nach Titel, Ordner oder Branch und zeigen Sie eine Vorschau an, wo Sie aufgehört haben, bevor Sie fortfahren.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Von Claude entworfenes Feedback</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">Wenn ein Tool immer wieder fehlschlägt, Claude bei einer Anfrage nicht helfen kann oder Sie auf einen Fehler hinweisen, entwirft Claude jetzt mit dem <code>SendFeedback</code>-Tool einen Feedback-Bericht für Sie. Eine Karte über Ihrer Eingabeaufforderung zeigt den Entwurf an, und Sie können ihn von dort aus überprüfen, senden oder verwerfen. Nichts erreicht Anthropic, bis Sie es senden. Erfordert v2.1.238 oder später.</p>

  <p className="digest-feature-try">Führen Sie <code>/feedback</code> ohne Argument aus, um Ihre Warteschlange mit Entwürfen aus jeder Sitzung zu öffnen:</p>

  ```text Claude Code theme={null}
  > /feedback
  ```

  <p className="digest-feature-try">Wählen Sie einen Entwurf aus und bearbeiten, senden oder verwerfen Sie ihn. Um das Entwerfen auszuschalten, setzen Sie <strong>Von Claude entworfenes Feedback</strong> in <code>/config</code> auf <code>off</code>.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Eingeschränkter Modus</span>
    <span className="digest-feature-pill">v2.1.248</span>
  </div>

  <p className="digest-feature-lede">Der eingeschränkte Modus startet Claude Code ohne die integrierten Tools, die Befehle oder Code ausführen. Verwenden Sie ihn, wenn ein Evaluierungs-Harness <code>claude</code> auf einem gemeinsamen Computer steuert. Starten Sie ihn mit `--restricted` oder setzen Sie <code>CLAUDE\_CODE\_RESTRICTED=1</code>. Claude Code entfernt auch <code>WebFetch</code>, beschränkt die Datei-Tools auf die Arbeitsverzeichnisse, lädt nur verwaltete Einstellungen und `--settings`, und lehnt den <code>bypassPermissions</code>-Berechtigungsmodus ab.</p>

  <p className="digest-feature-try">Führen Sie eine nicht-interaktive Abfrage ohne die befehlsausführenden Tools aus:</p>

  ```bash terminal theme={null}
  claude --restricted -p "review src/ for SQL injection risks"
  ```

  <p className="digest-feature-try">Um Claude eines der entfernten Tools zurückzugeben, listen Sie es in `--tools` zusammen mit den anderen integrierten Tools auf, die Sie möchten, zum Beispiel `--tools "Bash,Read,Edit"`. `--tools` ist eine Zulassungsliste, und seine <code>default</code>-Voreinstellung stellt die entfernten Tools nicht wieder her.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div>Setzen Sie die neue <a href="/docs/de/settings-reference#modelpicker"><code>modelPicker</code></a>-Einstellung, um die integrierte Liste des <code>/model</code>-Pickers mit Ihren eigenen geordneten, beschrifteten Einträgen zu erweitern oder zu ersetzen, einschließlich Amazon Bedrock oder Google Cloud Agent Platform-Modell-IDs</div>
    <div>Setzen Sie <a href="/docs/de/prompt-caching#choose-the-ttl-yourself"><code>promptCacheTtl</code></a> auf <code>1h</code>, um einen einstündigen Prompt-Cache in der Hauptkonversation zu behalten, wenn Sie einen API-Schlüssel oder einen Cloud-Provider verwenden; <code>subagentPromptCacheTtl</code> setzt die TTL für Subagenten und alle anderen Anfragen außerhalb der Hauptkonversation</div>
    <div>Bei Pro-, Max-, Team- und Enterprise-Plänen fügt <a href="/docs/de/costs#plan-usage-breakdown"><code>/usage</code></a> eine Loops-Aufschlüsselung hinzu: Ausführungsanzahl, Gesamttoken, Token pro Ausführung und letzte Ausführung für die <code>/loop</code> und geplanten Aufgaben, die die meisten Token verbrauchten</div>
    <div>Organisationen mit vertraglich vereinbarten Sätzen können die <a href="/docs/de/costs#report-spend-at-your-contracted-rates"><code>modelPricing</code></a>-verwaltete Einstellung setzen, damit <code>/usage</code>, die Statuszeile und OpenTelemetry Kosten zu diesen Sätzen statt zum Listenpreis melden</div>
    <div><code>/login</code> bietet <strong>Mit Ihrem Console-Konto anmelden</strong> unter der Option <strong>Anthropic Console-Konto</strong>, damit Mitglieder von Console-Organisationen, die keine API-Schlüssel zulassen, sich anmelden können, ohne einen zu erstellen</div>
    <div>Führen Sie <code>/permissions</code> aus und öffnen Sie die neue <a href="/docs/de/auto-mode-config#edit-rules-from-permissions"><strong>Auto-Modus</strong>-Registerkarte</a>, um Auto-Modus-Klassifiziererregeln anzuzeigen und zu bearbeiten, ohne eine Einstellungsdatei zu öffnen</div>
    <div>Wenn der Auto-Modus verfügbar ist, bieten Bash-Berechtigungsaufforderungen im Manual- und <code>acceptEdits</code>-Berechtigungsmodus eine <a href="/docs/de/permission-modes#switch-permission-modes"><strong>Ja, und zum Auto-Modus wechseln</strong></a>-Option; wählen Sie diese aus, um den Befehl zu genehmigen und die Sitzung zum Auto-Modus zu wechseln</div>
    <div>Nachdem Sie <a href="/docs/de/permissions#move-the-session-to-another-directory">eine Sitzung mit <code>/cd</code> verschoben haben</a>, werden die Projekteinstellungen, Hooks, <code>.mcp.json</code>-Server, Skills und Subagenten des neuen Verzeichnisses sofort wirksam, anstatt beim nächsten `--resume`</div>
    <div>In nicht-interaktiven Sitzungen, einschließlich <code>-p</code>-Ausführungen, Agent SDK-Ausführungen und Cloud-Sitzungen, <a href="/docs/de/errors#the-response-above-may-be-incomplete">setzt Claude Code eine Antwort fort</a>, die ein Serverfehler, eine unterbrochene Verbindung oder ein Stall mitten im Stream unterbrochen hat, wenn die Teilantwort Text und keine Tool-Aufrufe enthält</div>
    <div>Ein Subagent, der bei seinem <code>maxTurns</code>-Limit stoppt, gibt seine Ausgabe als teilweise markiert zurück, mit einem Hinweis, dass Claude sie <a href="/docs/de/sub-agents#resume-subagents">mit <code>SendMessage</code> fortsetzen kann</a>, anstatt fertig zu erscheinen</div>
    <div>Bei Amazon Bedrock, Google Cloud Agent Platform und Microsoft Foundry können Sitzungen auf demselben Computer jetzt <a href="/docs/de/cross-session-messaging#availability">miteinander kommunizieren</a>, <code>/loop</code> kann <a href="/docs/de/scheduled-tasks#let-claude-choose-the-interval">sein eigenes Intervall wählen</a>, und <code>/model</code> und <code>/effort</code> werden sofort angewendet, anstatt nach dem Ende des Zuges</div>
    <div>Das native Installationsprogramm und der Auto-Updater laden einen zstd-komprimierten Build herunter, etwa 75 MB statt 340 MB auf Linux x64, und native Builds laden Code bei Bedarf, wobei etwa 40 bis 70 MB weniger Speicher pro Sitzung verwendet wird</div>
  </div>
