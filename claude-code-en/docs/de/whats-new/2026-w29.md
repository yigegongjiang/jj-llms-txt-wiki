    <span className="digest-feature-pill">web</span>

  <p className="digest-feature-lede">Ein veröffentlichtes Artefakt kann jetzt MCP-Konnektoren aufrufen, jedes Mal wenn jemand es anzeigt, sodass ein Dashboard Live-Daten anzeigt und Aktionen bei Bedarf ausführen kann, anstatt einen Schnappschuss aus der Sitzung zu zeigen, die es erstellt hat. Jeder Aufruf wird über die eigenen Verbindungen des anzeigenden Kontos ausgeführt, und Betrachter genehmigen den Zugriff, bevor der erste Konnektor-Aufruf der Seite erfolgt. Diese Woche fügt auch öffentliche Freigabelinks, Editor-Rollen für gemeinsames Bearbeiten in Team- und Enterprise-Plänen sowie Artefakte hinzu, die aus Claude Tag-Sitzungen erstellt wurden.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Bildschirmleser-Modus</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">Der Bildschirmleser-Modus ersetzt die visuelle Terminal-Schnittstelle durch einfachen, linearen Text: Anstelle von Feldern, Spinnern und Neuzeichnungen an Ort und Stelle druckt Claude Code beschriftete Zeilen, die ein Bildschirmleser wie VoiceOver oder NVDA der Reihe nach liest, sodass Sie Berechtigungen genehmigen und die Ausgabe von Anfang bis Ende überprüfen können. Aktivieren Sie es pro Sitzung mit einem Flag, pro Shell mit der Umgebungsvariablen <code>CLAUDE\_AX\_SCREEN\_READER</code> oder überall mit der Einstellung <code>axScreenReader</code>.</p>

  <p className="digest-feature-try">Starten Sie eine Sitzung im Bildschirmleser-Modus:</p>

  ```bash terminal theme={null}
  claude --ax-screen-reader
  ```

  <a className="digest-feature-link" href="/docs/de/accessibility#turn-on-screen-reader-mode">Bildschirmleser-Modus aktivieren</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div><code>/fork</code> kopiert jetzt Ihre Konversation in eine neue Hintergrund-Sitzung mit ihrer eigenen Zeile in <code>claude agents</code>, während Sie weiterarbeiten; der in-session-Subagent, den es früher gestartet hat, ist jetzt <code>/subtask</code></div>
    <div><a href="/docs/de/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">Auto-Modus</a> benötigt nicht mehr die <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE</code> Opt-in auf Amazon Bedrock, Google Clouds Agent Platform und Microsoft Foundry; Administratoren können ihn mit <code>disableAutoMode</code> deaktivieren</div>
    <div>MCP-Tool-Aufrufe, die länger als zwei Minuten laufen, werden jetzt automatisch in den Hintergrund verschoben, sodass die Sitzung nutzbar bleibt; passen Sie den Schwellenwert mit <code>CLAUDE\_CODE\_MCP\_AUTO\_BACKGROUND\_MS</code> an oder deaktivieren Sie ihn</div>
    <div>Neuer <code>claude auto-mode reset</code> stellt die Standard-Auto-Modus-Konfiguration wieder her, und `--yes` überspringt die Bestätigungsaufforderung</div>
    <div>Neue <a href="/docs/de/corporate-launcher">Corporate Launcher</a> Unterstützung: <code>CLAUDE\_CODE\_PROCESS\_WRAPPER</code> oder die Einstellung <code>processWrapper</code> führt die Prozesse, die Claude Code von seiner eigenen Binärdatei aus startet, wie den Hintergrund-Service und Agent-View-Sitzungen, durch eine erforderliche Wrapper-Ausführungsdatei aus</div>
    <div><code>vimInsertModeRemaps</code> Einstellung ordnet zwei-Tasten-Insert-Modus-Sequenzen wie <code>jj</code> zu Escape im Vim-Modus zu</div>
    <div>`--forward-subagent-text` und <code>CLAUDE\_CODE\_FORWARD\_SUBAGENT\_TEXT</code> enthalten Subagent-Text und Thinking-Blöcke in <a href="/docs/de/headless#stream-json-output">stream-json-Ausgabe</a></div>
    <div>Sitzungsweite Obergrenzen stoppen Endlosschleifen: WebSearch-Aufrufe und Subagent-Spawns haben jeweils einen Standard von 200, anpassbar mit <code>CLAUDE\_CODE\_MAX\_WEB\_SEARCHES\_PER\_SESSION</code> und <code>CLAUDE\_CODE\_MAX\_SUBAGENTS\_PER\_SESSION</code></div>
    <div>„Immer zulassen" Berechtigungsregeln werden im Repository-Root gespeichert, sodass Genehmigungen, die in einem Git-Worktree gewährt werden, über Sitzungen und Worktrees hinweg bestehen bleiben</div>
    <div>Amazon Bedrock, Google Clouds Agent Platform und Claude Platform auf AWS verwenden jetzt standardmäßig Claude Opus 4.8</div>
    <div>Die eingeklappte Tool-Zusammenfassungszeile zeigt einen Live-Verstrichene-Zeit-Zähler, sodass lange laufende Tool-Aufrufe sichtbar ticken, anstatt stecken zu bleiben</div>
  </div>
</div>
