# Woche 27 · 29. Juni – 3. Juli 2026

> Claude Sonnet 5 wird zum Standard-Modell, Claude in Chrome erreicht allgemeine Verfügbarkeit, Subagenten laufen standardmäßig im Hintergrund, Claude Desktop kommt in Beta auf Linux an, und /radio stimmt sich auf Claude FM ein.

    <span className="digest-feature-title">Claude Sonnet 5</span>
    <span className="digest-feature-pill">neues Modell</span>
  </div>

  <p className="digest-feature-lede">Sonnet 5 ist das neue Standard-Modell für Pro-, Team Standard- und Enterprise-Abonnement-Plätze: erstklassige Codierung und Tool-Nutzung zum Sonnet-Preis, mit einem nativen 1-Million-Token-Kontextfenster und adaptivem Denken standardmäßig aktiviert. Die API-Preisgestaltung ist bis zum 31. August zu Aktionstarife von \$2/\$10 pro MTok. Erfordert v2.1.197 oder später.</p>

  <p className="digest-feature-try">Wechseln Sie zu Sonnet 5 nach Name, oder wählen Sie es aus dem Modell-Picker:</p>

  ```text Claude Code theme={null}
  > /model claude-sonnet-5
  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude in Chrome ist allgemein verfügbar</span>
    <span className="digest-feature-pill">v2.1.198</span>
  </div>

  <p className="digest-feature-lede">Die Chrome-Integration ist aus der Vorschau für alle mit einem direkten Anthropic-Plan verfügbar. Claude Code steuert Ihren Browser durch die Claude in Chrome-Erweiterung: Sie öffnet Registerkarten, klickt sich durch Seiten, füllt Formulare aus, liest Konsolenprotokolle und teilt Ihren Anmeldestatus, damit sie die App testen kann, die sie erstellt, ohne dass Sie den Kontext wechseln.</p>

  <a className="digest-feature-link" href="/docs/de/docs/chrome">Claude Code mit Chrome verwenden</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Subagenten laufen standardmäßig im Hintergrund</span>
    <span className="digest-feature-pill">v2.1.198</span>
  </div>

  <p className="digest-feature-lede">Claude arbeitet jetzt weiter, während Subagenten laufen, und nimmt ihre Ergebnisse auf, wenn sie fertig sind, anstatt das Gespräch zu unterbrechen, um zu warten. Claude führt einen Subagenten immer noch im Vordergrund aus, wenn es das Ergebnis benötigt, bevor es fortfährt, und Hintergrund-Subagenten zeigen alle Berechtigungsaufforderungen in Ihrer Hauptsitzung an. Fixieren Sie das Verhalten eines Subagenten mit dem <code>background</code> Frontmatter-Feld.</p>

  <a className="digest-feature-link" href="/docs/de/docs/sub-agents#run-subagents-in-foreground-or-background">Subagenten im Vordergrund oder Hintergrund ausführen</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude Desktop auf Linux</span>
    <span className="digest-feature-pill">Desktop</span>
  </div>

  <p className="digest-feature-lede">Die Claude-Desktop-App ist jetzt auf Ubuntu 22.04+ und Debian 12+ in Beta auf x86\_64 und arm64 verfügbar. Sie erhalten die gleiche Chat-, Cowork- und Claude Code-Erfahrung wie auf macOS und Windows: parallele Sitzungen, visuelle Diff-Überprüfung, ein integriertes Terminal und Editor sowie Live-App-Vorschau. Installiert sich aus dem Anthropic-apt-Repository, sodass Updates durch regelmäßige Paket-Updates ankommen.</p>

  <a className="digest-feature-link" href="/docs/de/docs/desktop-linux">Claude Desktop auf Linux</a>
</div>

  <div className="digest-wins-grid">
    <div><a href="/docs/de/docs/artifacts">Artefakte</a> sind jetzt allgemein verfügbar und in Pro- und Max-Plänen enthalten, zusammen mit Team und Enterprise</div>
    <div>Administratoren können ein <a href="/docs/de/docs/model-config#organization-default-model">Standard-Modell der Organisation</a> in der Org-Konsole festlegen; es wird als „Org-Standard" in <code>/model</code> angezeigt, wenn Sie selbst kein Modell ausgewählt haben</div>
    <div>Gestapelte Skill-Aufrufe wie <code>/skill-a /skill-b do XYZ</code> laden jetzt alle führenden Skills (bis zu 5), nicht nur den ersten</div>
    <div><code>AskUserQuestion</code> Dialoge werden nicht mehr standardmäßig automatisch fortgesetzt; aktivieren Sie ein Leerlauf-Timeout über <code>/config</code></div>
    <div>Der „Standard"-Berechtigungsmodus wird jetzt in der CLI, `--help`, VS Code und JetBrains als „Manuell" bezeichnet; `--permission-mode manual` wird neben `default` akzeptiert</div>
    <div>Neuer <code>/dataviz</code> Skill bietet Anleitung zum Diagramm- und Dashboard-Design mit einem ausführbaren Farbpaletten-Validator</div>
    <div>Der integrierte Explore-Agent erbt jetzt das Modell der Hauptsitzung (begrenzt auf Opus), anstatt auf Haiku zu laufen</div>
    <div>Hintergrund-Agenten, die von <code>claude agents</code> gestartet werden, committen, pushen und öffnen einen Entwurf-PR, wenn sie Codearbeit in einem Worktree beenden, anstatt zu stoppen und zu fragen</div>
    <div>Hook-Matcher mit Bindestrichen in Bezeichnern wie <code>code-reviewer</code> stimmen jetzt exakt überein, anstatt Teilzeichenfolgen zu vergleichen; verwenden Sie <code>mcp\_\_brave-search\_\_.\*</code>, um alle Tools von einem MCP-Server mit Bindestrich zu vergleichen</div>
    <div>Vorübergehende Server-Ratenlimit-Fehler, die nicht mit Ihrem Nutzungslimit zusammenhängen, werden jetzt automatisch mit Backoff für Abonnenten wiederholt, anstatt den Zug zu beenden</div>
    <div>Der Streaming-Leerlauf-Watchdog ist jetzt standardmäßig für alle Anbieter aktiviert: Er bricht ab und versucht es erneut, wenn ein Antwort-Stream 5 Minuten lang keine Ereignisse erzeugt (<code>CLAUDE\_ENABLE\_STREAM\_WATCHDOG=0</code> zum Deaktivieren)</div>
  </div>
</div>
