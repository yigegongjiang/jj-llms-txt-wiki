    <span className="digest-feature-title">/doctor ist eine vollständige Setup-Überprüfung</span>
    <span className="digest-feature-pill">v2.1.205</span>
  </div>

  <p className="digest-feature-lede"><code>/doctor</code> diagnostiziert nun Probleme und kann diese beheben, anstatt einen schreibgeschützten Bericht auszudrucken. Es überprüft die Installationsintegrität, findet ungenutzte Skills, MCP-Server und Plugins im Vergleich zu ihren Kontextkosten, dedupliziert lokale <code>CLAUDE.md</code>-Dateien gegen eingecheckte Dateien, schlägt vor, <code>CLAUDE.md</code>-Inhalte zu kürzen, die Claude aus der Codebasis ableiten könnte, und kennzeichnet langsame Hooks. Es meldet Ergebnisse zuerst und fragt um Bestätigung, bevor etwas geändert wird. <code>/checkup</code> ist sein Alias.</p>

  <p className="digest-feature-try">Führen Sie eine Überprüfung aus einer beliebigen Sitzung aus:</p>

  ```text Claude Code theme={null}
  > /doctor
  ```

<div className="digest-wins">
  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div>Der Auto-Modus blockiert nun Manipulationen an Sitzungstranskriptdateien und fragt nach, bevor <code>rm -rf</code> auf eine Variable ausgeführt wird, die nicht aus dem Kontext aufgelöst werden kann</div>
    <div><code>/cd</code> schlägt nun Verzeichnispfade vor, während Sie eingeben, und entspricht <code>/add-dir</code></div>
    <div><code>/commit-push-pr</code> erlaubt automatisch <code>git push</code> zum konfigurierten Push-Remote des Repositorys zusätzlich zu <code>origin</code></div>
    <div>Gateway: <code>/login</code> unterstützt nun von Anthropic betriebene öffentliche Gateway-Endpunkte</div>
    <div><code>EnterWorktree</code> fragt um Bestätigung, bevor ein Git-Worktree außerhalb des Verzeichnisses <code>.claude/worktrees/</code> des Projekts betreten wird</div>
    <div>Hintergrund-Agenten werden direkt nach einem Claude-Code-Update im Hintergrund auf eine neue Version aktualisiert, anstatt eine langsame Upgrade-Verzögerung bei veralteten Sitzungen zu zahlen, wenn Sie sich verbinden</div>
    <div>Agent-View-Zeilen zeigen nun ein farbiges Statuswort und eine von einem Klassifizierer geschriebene Überschrift anstelle von rohem Tool-Call-Text, und Sitzungen, die einen vorhandenen PR bearbeiten, zusammenführen, kommentieren oder pushen, verlinken ihn in <code>claude agents</code></div>
    <div>Auto-Update-Binär-Downloads werden nun auf die Festplatte gestreamt, anstatt im Speicher gepuffert zu werden, wodurch die Spitzenspeichernutzung des Updaters um etwa 400 MB reduziert wird</div>
    <div>Benachrichtigungen für Hintergrundaufgaben geben nun explizit an, dass keine menschliche Eingabe erfolgt ist, um zu verhindern, dass fabrizierte In-Transkript-Genehmigungen ausgeführt werden</div>
    <div>Verbesserte <code>/code-review</code>-Erkennungsqualität auf Opus 4.8 über alle Aufwandsstufen hinweg</div>
  </div>
</div>
