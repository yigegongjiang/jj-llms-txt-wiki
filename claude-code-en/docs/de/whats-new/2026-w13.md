    <span className="digest-feature-title">Auto-Modus</span>
    <span className="digest-feature-pill">Forschungsvorschau</span>
  </div>

  <p className="digest-feature-lede">Der Auto-Modus übergibt Ihre Berechtigungsaufforderungen an einen Klassifizierer. Sichere Bearbeitungen und Befehle werden ohne Unterbrechung ausgeführt; alles Destruktive oder Verdächtige wird blockiert und angezeigt. Es ist der Mittelweg zwischen der Genehmigung jedes Dateischreibvorgangs und dem Ausführen mit <code>--dangerously-skip-permissions</code>.</p>

  </Frame>

  <p className="digest-feature-try">Wechseln Sie mit Umschalt+Tab zum Auto-Modus, oder legen Sie ihn als Standard fest:</p>

  ```json ~/.claude/settings.json {3} theme={null}
  {
    "permissions": {
      "defaultMode": "auto"
    }
  }
  ```

  <p className="digest-feature-lede">Drücken Sie <code>/</code> im Transkriptmodus, um Ihre Konversation zu durchsuchen. <code>n</code> und <code>N</code> durchlaufen die Treffer. Endlich eine Möglichkeit, diesen einen Bash-Befehl zu finden, den Claude vor 400 Nachrichten ausgeführt hat.</p>

  <p className="digest-feature-try">Öffnen Sie den Transkriptmodus und suchen Sie:</p>

  ```text Claude Code theme={null}
  Ctrl+O    # open transcript
  /migrate  # search for "migrate"
  n         # next match
  N         # previous match
  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Bedingte Hooks</span>
    <span className="digest-feature-pill">v2.1.85</span>
  </div>

  <p className="digest-feature-lede">Hooks können jetzt ein <code>if</code>-Feld mit Berechtigungsregelsyntax deklarieren. Ihre Pre-Commit-Prüfung wird nur für <code>Bash(git commit \*)</code> ausgelöst, anstatt für jeden Bash-Aufruf, was den Prozess-Overhead bei aktiven Sitzungen reduziert.</p>

  <p className="digest-feature-try">Beschränken Sie einen Hook nur auf Git-Commits:</p>

  ```json .claude/settings.json {5} theme={null}
  {
    "hooks": {
      "PreToolUse": [{
        "hooks": [{
          "if": "Bash(git commit *)",
          "type": "command",
          "command": ".claude/hooks/lint-staged.sh"
        }]
      }]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/de/docs/hooks">Hooks-Referenz</a>
</div>
