<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Plugins mit claude plugin eval testen</span>
    <span className="digest-feature-pill">v2.1.269</span>
  </div>

  <p className="digest-feature-lede"><code>claude plugin eval</code> führt Ihr Plugin gegen eine Reihe von Testfällen aus, bewertet die Ergebnisse und führt standardmäßig jeden Fall erneut ohne das Plugin aus, damit Sie sehen können, welchen Beitrag es leistet. <code>claude plugin eval init</code> fragt Sie, wie ein gutes Ergebnis aussieht, schlägt dann Testfälle und die Überprüfungen vor, die sie bewerten, versucht die Suite einmal und schreibt die Dateien. Jede Ausführung und jede Überprüfung, bei der ein zweites Modell die Antwort bewertet, ist ein echter Modellaufruf auf Ihrem Konto.</p>

  <Frame>
    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/plugin-eval.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=913066f6d4a2a15426e98a627802f47f" alt="Terminalausgabe von claude plugin eval: eine Tabelle mit sieben Fällen, wobei jeder Fall seine Bewertung mit und ohne Plugin, die Differenz zwischen ihnen, die Ausführungsanzahl und die Kosten zeigt, gefolgt von einer Zusammenfassungszeile mit dem mittleren Delta, der Gesamtdauer und den Gesamtkosten" width="1600" height="900" data-path="images/whats-new/plugin-eval.jpg" />
  </Frame>

  <p className="digest-feature-try">Lassen Sie Claude aus dem Stammverzeichnis Ihres Plugins die Suite entwerfen:</p>

  ```bash terminal theme={null}
  claude plugin eval init
  ```

  <p className="digest-feature-try">Wenn Claude Ihnen mitteilt, dass die Suite bereit ist, beenden Sie die Sitzung, die <code>claude plugin eval init</code> geöffnet hat, und führen Sie <code>claude plugin eval .</code> aus, um jeden Fall zu bewerten. Die Zusammenfassungstabelle wird in Ihrem Terminal gedruckt, und <code>report.html</code> unter <code>evals/results/</code> enthält die Details pro Ausführung.</p>
