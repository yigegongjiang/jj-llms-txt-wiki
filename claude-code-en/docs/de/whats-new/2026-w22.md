    <span className="digest-feature-pill">Forschungsvorschau</span>
  </div>

  <p className="digest-feature-lede">Ein Workflow ist ein Orchestrierungsskript, das Claude für Ihre Aufgabe schreibt und im Hintergrund über viele Subagenten hinweg ausführt. Verwenden Sie einen, wenn eine Aufgabe zu groß für eine Konversation ist, um sie zu koordinieren: eine codebase-weite Überprüfung, eine große Migration, eine Forschungsfrage, die einer Gegenprüfung bedarf. Verwalten Sie Läufe mit <code>/workflows</code>.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Security-guidance-Plugin</span>
    <span className="digest-feature-pill">Plugin</span>
  </div>

  <p className="digest-feature-lede">Das security-guidance-Plugin überprüft Claudes Code-Änderungen auf Sicherheitslücken und behebt sie in derselben Sitzung. Es führt eine schnelle Musterprüfung bei jeder Bearbeitung durch, eine Modellüberprüfung am Ende jedes Durchgangs und eine tiefere agentengestützte Überprüfung beim Commit oder Push. Fügen Sie Projektregeln in <code>.claude/claude-security-guidance.md</code> hinzu.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div>In <code>claude agents</code> können Sie einem Shell-Befehl <code>!</code> voranstellen, um ihn als Hintergrund-Job auszuführen, an den Sie sich anschließen und von dem Sie sich trennen können; auch verfügbar als <code>claude --bg --exec 'pytest -x'</code></div>
    <div>Plugins in <code>.claude/skills</code>-Verzeichnissen werden jetzt automatisch geladen, kein Marketplace erforderlich, und <code>claude plugin init \<name></code> erstellt ein neues Plugin</div>
    <div>Der neue <code>/reload-skills</code>-Befehl scannt Skill-Verzeichnisse erneut, ohne neu zu starten, und <code>SessionStart</code>-Hooks können <code>reloadSkills: true</code> zurückgeben, um Skills, die sie installieren, in derselben Sitzung verfügbar zu machen</div>
    <div>Skills und Befehle können <code>disallowed-tools</code> in der Frontmatter setzen, um Tools aus dem Modell zu entfernen, während der Skill aktiv ist</div>
    <div>Das neue <code>MessageDisplay</code>-Hook-Ereignis ermöglicht es Hooks, Assistenten-Nachrichtentext beim Anzeigen zu transformieren oder auszublenden</div>
    <div>Claude Code wechselt jetzt zu Ihrem konfigurierten <code>--fallback-model</code> für den Rest der Sitzung, wenn das primäre Modell nicht gefunden wird, anstatt jede Anfrage fehlschlagen zu lassen</div>
    <div>Plugins können <code>defaultEnabled: false</code> in <code>plugin.json</code> oder einem Marketplace-Eintrag deklarieren, sodass sie installiert werden, ohne sich einzuschalten, bis Sie sie aktivieren</div>
    <div>Vim-Modus: <code>/</code> im NORMAL-Modus öffnet die umgekehrte Verlaufssuche, passend zu Bash und Zsh vi-mode</div>
    <div>Die Streaming-Tool-Ausführung ist jetzt immer aktiviert, auch mit deaktivierter Telemetrie und auf Amazon Bedrock, Google Cloud's Agent Platform und Microsoft Foundry</div>
    <div><code>←←</code> zum Öffnen der Agents-Ansicht funktioniert jetzt auf Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry und mit deaktivierter Telemetrie</div>
    <div>Claude in Chrome: Wählen Sie, welcher verbundene Browser verwendet werden soll, über <code>/chrome</code> → „Browser auswählen…" oder im Chat, wenn eine Browser-Aktion mit mehreren verbundenen ausgeführt wird</div>
    <div><code>claude mcp list</code> und <code>claude mcp get</code> zeigen jetzt nicht genehmigte <code>.mcp.json</code>-Server als ausstehende Genehmigung an, anstatt sie automatisch zu genehmigen und zu verbinden, wenn die Ausgabe weitergeleitet wird</div>
  </div>
</div>
