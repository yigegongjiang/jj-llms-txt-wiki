<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Automatische Fortsetzung nach einem Nutzungslimit auf Desktop</span>
    <span className="digest-feature-pill">Desktop</span>
  </div>

  <p className="digest-feature-lede">Wenn Sie Ihr Sitzungslimit in der Registerkarte „Code" von Claude Code Desktop erreichen, bietet die Limit-Karte nun ein Kontrollkästchen <strong>Automatisch fortsetzen, wenn Limits zurückgesetzt werden</strong>. Aktivieren Sie es, und die Desktop-App wiederholt den unterbrochenen Zug nach dem Zurücksetzen. Die Karte zeigt die Wiederholungszeit an. Die Karte für das wöchentliche Limit bietet diese Option nicht.</p>

  <p className="digest-feature-try">Wenn die nächste Sitzungslimit-Karte angezeigt wird, aktivieren Sie <strong>Automatisch fortsetzen, wenn Limits zurückgesetzt werden</strong> und lassen Sie die Sitzung offen. Die Karte zeigt <code>Automatische Wiederaufnahme um</code> gefolgt von der Zurücksetzen-Zeit an, und der Zug wird automatisch fortgesetzt, sobald das Limit zurückgesetzt wird.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Fork-Modus standardmäßig aktiviert</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">Der Fork-Modus ist jetzt standardmäßig in interaktiven Sitzungen aktiviert. Claude kann den Subagent-Typ <code>fork</code> anfordern, der die vollständige Konversation und den Prompt-Cache erbt, anstatt von vorne zu beginnen, sodass Sie den Kontext für eine Nebenaufgabe nicht erneut erklären müssen. Subagenten, die Claude in interaktiven Sitzungen spawnt, mit Ausnahme derjenigen, die ein Agent-Team-Teamkollege spawnt, laufen auch standardmäßig im Hintergrund.</p>

  <p className="digest-feature-try">Starten Sie selbst einen Fork mit einer Aufgabe, die alles erfordert, das Sie bisher besprochen haben:</p>

  ```text Claude Code theme={null}
  > /subtask draft unit tests for the parser changes so far
  ```

  <p className="digest-feature-try">Der Fork wird in der Leiste unter Ihrer Eingabeaufforderung angezeigt und sein Ergebnis kommt in Ihre Konversation, wenn er fertig ist. Um den Fork-Modus auszuschalten, setzen Sie <code>CLAUDE\_CODE\_FORK\_SUBAGENT=0</code>.</p>

  <a className="digest-feature-link" href="/docs/de/sub-agents#turn-fork-mode-on-or-off">Fork-Modus aktivieren oder deaktivieren</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">GitLab-Merge-Requests und Marktplätze</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">Plugin-Marktplätze klonen nackte <code>gitlab.com</code>-URLs, einschließlich verschachtelter Untergruppen. Auf v2.1.233 oder später können Sie eine GitLab-Merge-Request-URL an <code>--worktree</code> übergeben, um von ihr zu branchen, und die Ansicht <code>claude agents</code> kennzeichnet Sitzungen, die mit einem Merge-Request verknüpft sind, als <code>!N</code>. Claude Code reduziert auch GitLab-Token-Familien wie <code>glpat-</code> und <code>glrt-</code> und schützt den Konfigurationsspeicher der <code>glab</code>-CLI auf die gleiche Weise wie <code>gh</code>.</p>

  <p className="digest-feature-try">Starten Sie eine Sitzung in einem Worktree, das von einem Merge-Request verzweigt ist:</p>

  ```bash terminal theme={null}
  claude --worktree https://gitlab.com/group/project/-/merge_requests/42
  ```

  <p className="digest-feature-try">Wenn <code>origin</code> auf gitlab.com ist, ruft Claude Code <code>merge-requests/42/head</code> ab und öffnet die Sitzung auf diesem Branch in seinem eigenen Worktree.</p>

  <a className="digest-feature-link" href="/docs/de/worktrees#branch-from-a-pull-request">Einen Worktree von einem Pull- oder Merge-Request verzweigen</a>
</div>
