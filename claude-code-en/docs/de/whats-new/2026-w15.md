<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Ultraplan</span>
    <span className="digest-feature-pill">research preview</span>
  </div>

  <p className="digest-feature-lede">Starten Sie den Plan Mode in der Cloud von Ihrem Terminal aus, überprüfen Sie dann das Ergebnis in Ihrem Browser. Claude erstellt den Plan in einer Claude Code-Sitzung im Web, während Ihr Terminal frei bleibt. Wenn es fertig ist, kommentieren Sie einzelne Abschnitte, fordern Überarbeitungen an und wählen, ob Sie es remote ausführen oder zurück zu Ihrer CLI senden möchten. Ab v2.1.101 erstellt der erste Durchlauf automatisch eine Standard-Cloud-Umgebung, sodass es keinen Web-Setup-Schritt gibt, bevor Sie es ausprobieren können.</p>

    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/ultraplan.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=e8f2f23730c6a5c289dbf3e7b13eadf6" data-path="images/whats-new/ultraplan.mp4" />
  </Frame>

  <p className="digest-feature-try">Führen Sie den Befehl aus oder fügen Sie das Schlüsselwort einfach in einen beliebigen Prompt ein:</p>

  ```text Claude Code theme={null}
  > /ultraplan migrate the auth service from sessions to JWTs
  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Monitor-Tool</span>
    <span className="digest-feature-pill">v2.1.98</span>
  </div>

  <p className="digest-feature-lede">Ein neues integriertes Tool, das einen Hintergrund-Watcher spawnt und seine Ereignisse in das Gespräch streamt: Jedes Ereignis landet als neue Transkript-Nachricht, auf die Claude sofort reagiert. Verfolgen Sie einen Trainings-Durchlauf, beaufsichtigen Sie die CI eines PR oder beheben Sie automatisch einen Dev-Server-Absturz in dem Moment, in dem er auftritt – alles ohne eine Bash-Sleep-Loop, die den Turn offen hält.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/monitor-tool.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=f4156c15a0999de5c5157f54a3117c89" data-path="images/whats-new/monitor-tool.mp4" />
  </Frame>

  <p className="digest-feature-try">Bitten Sie Claude, etwas zu beobachten, während Sie weiterarbeiten:</p>

  ```text Claude Code theme={null}
  > Tail server.log in the background and tell me the moment a 5xx shows up
  ```

  <p className="digest-feature-try">Dies funktioniert mit <code>/loop</code>, das sich jetzt selbst steuert: Lassen Sie das Intervall weg und Claude plant den nächsten Tick basierend auf der Aufgabe, oder greift auf das Monitor-Tool zurück, um das Polling ganz zu überspringen.</p>

  ```text Claude Code theme={null}
  > /loop check CI on my PR
  ```

  <a className="digest-feature-link" href="/docs/de/docs/tools-reference#monitor-tool">Monitor-Tool-Referenz</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">/autofix-pr</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">PR-Auto-Fix landete in Woche 13 im Web. Jetzt können Sie es aktivieren, ohne Ihr Terminal zu verlassen: <code>/autofix-pr</code> leitet den offenen PR für Ihren aktuellen Branch ab und aktiviert Auto-Fix dafür auf Claude Code im Web in einem Schritt. Pushen Sie Ihren Branch, führen Sie den Befehl aus, gehen Sie weg; Claude beobachtet CI und Review-Kommentare und pusht Fixes, bis es grün ist.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/autofix-pr.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=95f191eb4711130a128aec3f6b720527" data-path="images/whats-new/autofix-pr.mp4" />
  </Frame>

  <p className="digest-feature-try">Führen Sie es vom Branch des PR aus:</p>

  ```text Claude Code theme={null}
  > /autofix-pr
  ```

  <a className="digest-feature-link" href="/docs/de/docs/claude-code-on-the-web#auto-fix-pull-requests">Auto-Fix für Pull Requests</a>

<div className="digest-wins">
  <p className="digest-wins-title">Weitere Verbesserungen</p>

  <div className="digest-wins-grid">
    <div>Fokus-Ansicht: Drücken Sie <code>Ctrl+O</code> im flimmerfreien Modus, um die Ansicht auf Ihren letzten Prompt, eine einzeilige Tool-Zusammenfassung mit Diffstats und Claudes endgültige Antwort zu reduzieren</div>
    <div>Geführte <a href="/docs/de/docs/amazon-bedrock">Amazon Bedrock</a>- und <a href="/docs/de/docs/google-vertex-ai">Google Cloud's Agent Platform</a>-Setup-Assistenten auf dem Anmeldebildschirm: Wählen Sie „3rd-party platform" für schrittweise Authentifizierung, Region, Anmeldedaten-Überprüfung und Modell-Pinning</div>
    <div><code>/agents</code> erhält ein Tabbed-Layout: Ein Running-Tab zeigt Live-Subagents mit einer <code>● N running</code>-Anzeige sowie Run agent und View running instance-Aktionen im Library-Tab</div>
    <div>Die Standard-Anstrengungsstufe ist jetzt <code>high</code> für API-Key-, Amazon Bedrock-, Google Cloud's Agent Platform-, Microsoft Foundry-, Team- und Enterprise-Benutzer (steuern Sie mit <code>/effort</code>)</div>
    <div><code>/cost</code> zeigt eine Pro-Modell- und Cache-Hit-Aufschlüsselung für Abonnement-Benutzer</div>
    <div><code>/release-notes</code> ist jetzt ein interaktiver Versions-Picker</div>
    <div>Statuszeile: neue <code>refreshInterval</code>-Einstellung führt den Befehl alle N Sekunden erneut aus, und <code>workspace.git\_worktree</code> in der JSON-Eingabe</div>
    <div><code>CLAUDE\_CODE\_PERFORCE\_MODE</code>: Edit/Write schlagen bei schreibgeschützten Dateien mit einem <code>p4 edit</code>-Hinweis fehl, anstatt stillschweigend zu überschreiben</div>
    <div>Der OS-CA-Zertifikatspeicher wird jetzt standardmäßig vertraut, sodass Enterprise-TLS-Proxys ohne zusätzliches Setup funktionieren (<code>CLAUDE\_CODE\_CERT\_STORE=bundled</code> zum Deaktivieren)</div>
    <div>Amazon Bedrock powered by Mantle: Setzen Sie <code>CLAUDE\_CODE\_USE\_MANTLE=1</code></div>
    <div>Gehärtete Bash-Tool-Berechtigungen: Backslash-escaped Flags, Env-Var-Präfixe, <code>/dev/tcp</code>-Umleitungen und zusammengesetzte Befehle werden jetzt korrekt abgefragt</div>
    <div><code>UserPromptSubmit</code>-Hooks können den Sitzungstitel über <code>hookSpecificOutput.sessionTitle</code> setzen</div>
  </div>
</div>
