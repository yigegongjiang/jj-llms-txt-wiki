# Beispiele

> Finden Sie ein vollständiges, ausführbares Agent SDK-Projekt oder ein geführtes Rezept aus dem Claude Cookbook, das zu dem passt, was Sie erstellen möchten.

Diese Seite leitet Sie zu vollständigen, ausführbaren Agent SDK-Projekten und geführten Claude Cookbook-Rezepten weiter. TypeScript-Anwendungen befinden sich im Repository [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos), und Python-Rezepte befinden sich im [Claude Cookbook](https://platform.claude.com/cookbook).

<h2 id="run-a-minimal-agent-first">
  Führen Sie zuerst einen minimalen Agent aus
</h2>

Wenn Sie noch nichts mit dem SDK erstellt haben, beginnen Sie mit einem dieser Projekte, bevor Sie eine vollständige Anwendung erstellen:

* [Agent SDK-Schnellstart](/docs/de/agent-sdk/quickstart): Erstellen Sie Ihren ersten funktionierenden Agent in TypeScript oder Python mit Einrichtungsschritten. Der Agent findet und behebt Fehler in einer Beispieldatei.

* [Hello World](https://github.com/anthropics/claude-agent-sdk-demos/tree/main/hello-world): ein minimales TypeScript-Projekt zum Klonen, wenn Sie von Repository-Code aus starten möchten

<h2 id="explore-a-typescript-application">
  Erkunden Sie eine TypeScript-Anwendung
</h2>

Die TypeScript-Anwendungen in [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos) sind Demos für die lokale Entwicklung, von einem E-Mail-Client bis zu einem Multi-Agent-Forschungssystem. Klonen Sie die Demo, deren Struktur dem entspricht, was Sie erstellen.

<h2 id="work-through-a-python-recipe">
  Arbeiten Sie ein Python-Rezept durch
</h2>

Die Agent SDK-Serie des Claude Cookbook ist eine Abfolge von Rezepten, jeweils ein Python-Notebook, die von einem einfachen Forschungsagent zu ausgefeilten Multi-Agent-Systemen fortschreitet. Jedes Notebook baut auf dem vorherigen auf und führt neue Konzepte und Funktionen ein. Beginnen Sie mit [dem One-Liner-Forschungsagent](https://platform.claude.com/cookbook/claude-agent-sdk-00-the-one-liner-research-agent) und arbeiten Sie sich vorwärts.

Für Rezepte über Claude-Produkte hinweg siehe das vollständige [Claude Cookbook](https://platform.claude.com/cookbook).
