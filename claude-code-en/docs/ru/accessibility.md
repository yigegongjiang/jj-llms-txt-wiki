# Использование Claude Code с программой чтения с экрана

> Настройте Claude Code для программ чтения с экрана, таких как VoiceOver и NVDA, а также параметры для увеличения экрана, уменьшения движения и тем, удобных для дальтоников.

Claude Code имеет режим программы чтения с экрана, который заменяет его визуальный интерфейс терминала простым линейным текстом. Вместо прямоугольников, анимаций прогресса и перерисовок на месте режим выводит помеченные строки, которые программа чтения с экрана, такая как VoiceOver или NVDA, читает по порядку, чтобы вы могли вести полный диалог, одобрять разрешения инструментов и просматривать выходные данные от начала до конца.

Режим программы чтения с экрана является дополнительным. Если вы используете увеличитель экрана, уменьшение движения или тему, удобную для дальтоников, вместо программы чтения с экрана, см. [Параметры доступности за пределами режима программы чтения с экрана](#accessibility-settings-beyond-screen-reader-mode).

<Note>
  Режим программы чтения с экрана требует Claude Code v2.1.181 или более поздней версии. Более ранние версии отклоняют флаг `--ax-screen-reader` с ошибкой `error: unknown option '--ax-screen-reader'`.
</Note>

<h2 id="turn-on-screen-reader-mode">
  Включение режима программы чтения с экрана
</h2>

Выберите метод, который соответствует тому, как часто вы используете программу чтения с экрана:

* Для одного сеанса: запустите `claude --ax-screen-reader`.
* Для сеансов, запущенных из одной оболочки: установите переменную окружения `CLAUDE_AX_SCREEN_READER` на `1`. В Bash или Zsh запустите `export CLAUDE_AX_SCREEN_READER=1`; в PowerShell запустите `$env:CLAUDE_AX_SCREEN_READER = "1"`. Добавьте строку в профиль оболочки, чтобы охватить каждую оболочку.
* Для каждого сеанса на машине: добавьте `"axScreenReader": true` в ваш пользовательский [файл параметров](/docs/ru/settings). Это охватывает любой терминал, включая интегрированный терминал VS Code.

<Note>
  Методы перечислены в порядке приоритета: флаг [`--ax-screen-reader`](/docs/ru/cli-reference#cli-flags) переопределяет переменную окружения [`CLAUDE_AX_SCREEN_READER`](/docs/ru/env-vars), которая переопределяет параметр [`axScreenReader`](/docs/ru/settings#available-settings).
</Note>

Если вы используете Claude Code через SSH, установите переменную окружения или параметр на удаленной машине, где работает Claude Code.

Когда режим включен, первое, что выводит Claude Code, это строка подтверждения, называющая метод, который его включил: `[Screen Reader Mode: on via flag]`, `[Screen Reader Mode: on via env]` или `[Screen Reader Mode: on via settings]`. Формат именования метода требует Claude Code v2.1.206 или более поздней версии. Когда Claude Code перезапускается, например для завершения установки обновления, новый процесс наследует режим через переменную окружения `CLAUDE_AX_SCREEN_READER`, поэтому его строка подтверждения читается как `[Screen Reader Mode: on via env]` независимо от того, какой метод вы использовали.
Более ранние версии выводят `[Accessible screen reader mode: on]`.

<h2 id="turn-off-screen-reader-mode">
  Отключение режима программы чтения с экрана
</h2>

Отмените любой метод, который включил режим: запустите без флага, отмените установку переменной окружения или установите `axScreenReader` на `false`. Установка `CLAUDE_AX_SCREEN_READER=0` сохраняет режим отключенным даже когда параметр имеет значение `true`.

<h2 id="what-your-screen-reader-hears">
  Что слышит ваша программа чтения с экрана
</h2>

В режиме программы чтения с экрана Claude Code выводит плоский текст:

* нет символов рисования прямоугольников для интерфейса
* нет подсказок только по цвету
* нет перерисовок содержимого, которое не изменилось; спиннеры прогресса отображаются как статический текст
* таблицы в ответах Claude читаются как предложения `Header: value` вместо сетки с символами прямоугольников. Требует Claude Code v2.1.198 или более поздней версии; более ранние версии рисуют таблицы как сетки даже в режиме программы чтения с экрана.

Результаты накапливаются в буфере прокрутки вашего терминала, поэтому вы можете перечитать более ранние ходы с помощью команд просмотра вашей программы чтения с экрана или поиска вашего терминала.

Режим программы чтения с экрана отображается как простой прокручиваемый текст, даже если вы включили [полноэкранный режим](/docs/ru/fullscreen) с помощью [параметра `tui`](/docs/ru/settings#available-settings); параметр не имеет эффекта, пока режим активен. Присоединенные фоновые сеансы по-прежнему отображаются в полноэкранном режиме; см. [Известные ограничения](#known-limitations).

Каждое сообщение в стенограмме начинается с метки, которую объявляет ваша программа чтения с экрана, называющей, что это: ваши сообщения, ответы Claude, активность инструментов, ошибки и подсказки. Метки также доступны для поиска, поэтому вы можете переходить между разделами стенограммы, выполняя поиск в буфере прокрутки вашего терминала:

| Метка                  | Значение                                                                                                 |
| :--------------------- | :------------------------------------------------------------------------------------------------------- |
| `you:`                 | Ваши сообщения                                                                                           |
| `claude:`              | Ответы Claude                                                                                            |
| `tool:`                | Активность инструмента, такая как редактирование файла или запуск команды                                |
| `tool error:`          | Инструмент, который не удался                                                                            |
| `error:`               | Ошибка в диалоге, такая как неудачный запрос API                                                         |
| `Permission Required:` | Подсказка разрешения, ожидающая вашего ответа                                                            |
| `Cost:`                | Сводка стоимости сеанса при выходе Claude Code, если ваша учетная запись [показывает затраты](/docs/ru/costs) |

Курсор терминала следует за кареткой ввода, поэтому команда чтения текущей строки программы чтения с экрана отвечает на вопрос "где я" с подсказкой, которую вы редактируете.

<h3 id="jump-between-turns">
  Переход между ходами
</h3>

Claude Code выводит маркеры интеграции оболочки OSC 133 на границах ходов, поэтому клавиша перехода к предыдущей подсказке вашего терминала перемещается между ходами без чтения всей стенограммы:

* iTerm2: Cmd+Shift+Up
* Терминал VS Code: Ctrl+Up в Windows, Cmd+Up в macOS
* Windows Terminal: нет клавиши по умолчанию; привяжите действие `scrollToMark` в его параметрах
* Kitty и Ghostty: проверьте документацию терминала для его клавиши перехода к подсказке

macOS Terminal не действует на маркеры, и Claude Code не выводит их в WezTerm. В этих терминалах вместо этого выполните поиск в буфере прокрутки по метке `you:`.

<h2 id="answer-menus-and-prompts">
  Ответ на меню и подсказки
</h2>

В режиме программы чтения с экрана меню, которыми вы обычно навигируете с помощью клавиш со стрелками, включая подсказки разрешения, становятся нумерованными списками. Каждый вариант объявляется как нумерованная строка, за которой следует подсказка `Enter selection`, которая называет допустимый диапазон. Введите номер нужного варианта и нажмите Enter.

* Чтобы отменить отклоняемое меню: нажмите Escape. Его подсказка заканчивается на `or Escape to cancel`.
* Если вы введете номер, которого нет в списке: Claude Code объявляет допустимый диапазон и позволяет вам попробовать снова.

Подсказки да-или-нет запрашивают введенный ответ вместо меню с двумя вариантами. Ответьте `y` или `n` и нажмите Enter. `yes` и `no` также работают.

<h2 id="hear-when-claude-code-needs-you">
  Услышьте, когда Claude Code нуждается в вас
</h2>

В режиме программы чтения с экрана Claude Code звонит в звонок терминала, когда ему нужно ваше внимание, поэтому вам не нужно постоянно проверять стенограмму. Звонок звонит, когда:

* Claude завершает ответ
* появляется подсказка разрешения
* инструмент, который работал дольше 5 секунд, завершается

Звонок - это стандартный сигнал тревоги вашего терминала. Чтобы отключить его, измените параметр звонка в приложении вашего терминала. Звонок не требует режима программы чтения с экрана: вне режима установите [`preferredNotifChannel`](/docs/ru/settings#available-settings) на `"terminal_bell"` для аналогичных оповещений, когда Claude ждет вас. См. [Получить звонок терминала или уведомление](/docs/ru/terminal-config#get-a-terminal-bell-or-notification).

<h2 id="accessibility-settings-beyond-screen-reader-mode">
  Параметры доступности за пределами режима программы чтения с экрана
</h2>

Эти параметры решают проблемы доступности вне режима программы чтения с экрана. Все они работают вместе с ним.

* Переменная окружения `CLAUDE_CODE_ACCESSIBILITY` [environment variable](/docs/ru/env-vars) предназначена для увеличителей экрана. Установите `CLAUDE_CODE_ACCESSIBILITY=1`, чтобы сохранить видимый собственный курсор терминала, чтобы увеличители, такие как macOS Zoom, могли отслеживать положение курсора.
* Параметр `prefersReducedMotion` [setting](/docs/ru/settings#available-settings) уменьшает или отключает спиннеры, мерцание и другие анимации без изменения остальной части интерфейса.
* Параметр `theme` [setting](/docs/ru/settings#available-settings) выбирает цвета интерфейса, включая удобные для дальтоников темы `dark-daltonized` и `light-daltonized`.

<h2 id="known-limitations">
  Известные ограничения
</h2>

Некоторые поведения не адаптированы для режима программы чтения с экрана:

* Режим программы чтения с экрана не включается автоматически при запуске программы чтения с экрана.
* Изменения режима, такие как вход в [режим плана](/docs/ru/permission-modes#analyze-before-you-edit-with-plan-mode), еще не объявляются.
* Присоединение к [фоновому сеансу](/docs/ru/agent-view) с помощью `claude attach` или из представления агента входит в альтернативный экран терминала, который не имеет собственного буфера прокрутки. Это [то же поведение, что и для других присоединенных сеансов](/docs/ru/fullscreen). Чтобы выйти, нажмите Left Arrow на пустой подсказке или Ctrl+Z, если диалог имеет фокус.
* Claude Code объявляет затраты в сводке, которую он выводит при выходе, а не за ход.
* Режим программы чтения с экрана не изменяет [неинтерактивный режим](/docs/ru/headless) с флагом `-p`. Неинтерактивный режим уже выводит простой текст и остается альтернативой для написания скриптов.

<h2 id="report-an-issue">
  Сообщить о проблеме
</h2>

Если что-то не работает с вашей программой чтения с экрана, увеличителем или терминалом, откройте проблему на [трекере проблем Claude Code](https://github.com/anthropics/claude-code/issues) и упомяните вашу вспомогательную технологию в заголовке. Включите вашу операционную систему, приложение терминала и имя и версию вспомогательной технологии в отчет.
