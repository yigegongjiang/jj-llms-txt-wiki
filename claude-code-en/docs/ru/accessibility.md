# Использование Claude Code с программой чтения с экрана

> Настройте Claude Code для программ чтения с экрана, таких как VoiceOver и NVDA, а также параметры для увеличения экрана, уменьшения движения и тем, удобных для дальтоников.

Claude Code имеет режим программы чтения с экрана, который заменяет его визуальный интерфейс терминала простым линейным текстом. Вместо прямоугольников, анимаций прогресса и перерисовок на месте Claude Code выводит помеченные строки, которые программа чтения с экрана, такая как VoiceOver или NVDA, читает по порядку. Вы можете вести полный диалог, одобрять разрешения инструментов и просматривать выходные данные от начала до конца.

Режим программы чтения с экрана является дополнительным. Если вы используете увеличитель экрана, уменьшение движения или тему, удобную для дальтоников, вместо программы чтения с экрана, установите `CLAUDE_CODE_ACCESSIBILITY`, `prefersReducedMotion` или `theme` из таблицы [Параметры доступности](#accessibility-settings). Режим программы чтения с экрана адаптирует только интерфейс терминала, поэтому вам не нужен он в панели чата расширения VS Code. В Claude Code v2.1.236 или более поздней версии расширение [объявляет активность диалога вашей программе чтения с экрана](/docs/ru/vs-code#use-a-screen-reader) там без каких-либо параметров.

<h2 id="turn-on-screen-reader-mode">
  Включение режима программы чтения с экрана
</h2>

Выберите метод, который соответствует тому, как часто вы используете программу чтения с экрана:

* Для одного сеанса: запустите `claude --ax-screen-reader`.
* Для сеансов, запущенных из одной оболочки: установите переменную окружения `CLAUDE_AX_SCREEN_READER` на `1`. В Bash или Zsh запустите `export CLAUDE_AX_SCREEN_READER=1`. В PowerShell запустите `$env:CLAUDE_AX_SCREEN_READER = "1"`. Добавьте эту строку в профиль оболочки, чтобы сохранить её для будущих оболочек.
* Для каждого сеанса на машине: добавьте `"axScreenReader": true` в ваш пользовательский [файл параметров](/docs/ru/settings). Параметр применяется в любом терминале, включая интегрированный терминал VS Code.

Если вы комбинируете методы, Claude Code применяет флаг [`--ax-screen-reader`](/docs/ru/cli-reference#cli-flags) над переменной окружения [`CLAUDE_AX_SCREEN_READER`](/docs/ru/env-vars#variables), и переменную над параметром [`axScreenReader`](/docs/ru/settings-reference#axscreenreader).

Если вы используете Claude Code через SSH, установите переменную окружения или параметр на удаленной машине, где работает Claude Code.

Первая строка, которую выводит Claude Code, подтверждает режим: `[Screen Reader Mode: on via flag]`, `[Screen Reader Mode: on via env]` или `[Screen Reader Mode: on via settings]`.

<h2 id="turn-off-screen-reader-mode">
  Отключение режима программы чтения с экрана
</h2>

Отмените любой метод, который включил режим: запустите без флага, отмените установку переменной окружения или установите `axScreenReader` на `false`. Если вы установите `CLAUDE_AX_SCREEN_READER` на `0`, Claude Code сохраняет режим отключенным даже когда параметр имеет значение `true`.

<h2 id="accessibility-settings">
  Параметры доступности
</h2>

Таблица перечисляет каждый параметр доступности, устанавливаете ли вы его как флаг, переменную окружения или параметр, и что он изменяет.

| Параметр                                                                | Тип                  | Что он изменяет                                                                                                                                                                                                                                                                         |
| :---------------------------------------------------------------------- | :------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`--ax-screen-reader`](/docs/ru/cli-reference#cli-flags)                     | Флаг                 | Режим программы чтения с экрана для одного сеанса.                                                                                                                                                                                                                                      |
| [`CLAUDE_AX_SCREEN_READER`](/docs/ru/env-vars#variables)                     | Переменная окружения | Режим программы чтения с экрана для сеансов, запущенных из оболочки, где вы его установили.                                                                                                                                                                                             |
| [`axScreenReader`](/docs/ru/settings-reference#axscreenreader)               | Параметр             | Режим программы чтения с экрана для каждого сеанса, когда `true`.                                                                                                                                                                                                                       |
| [`CLAUDE_AX_STARTUP_QUIET_MS`](/docs/ru/env-vars#variables)                  | Переменная окружения | Как долго Claude Code ждёт после строки подтверждения перед тем, как нарисовать первую подсказку в режиме программы чтения с экрана. Требует Claude Code v2.1.217 или более поздней версии.                                                                                             |
| [`CLAUDE_AX_PREPARK_MS`](/docs/ru/env-vars#variables)                        | Переменная окружения | Как долго Claude Code ждёт, с курсором в начале строки, перед тем, как написать новую или изменённую строку в режиме программы чтения с экрана. Требует Claude Code v2.1.233 или более поздней версии.                                                                                  |
| [`CLAUDE_CODE_ACCESSIBILITY`](/docs/ru/env-vars#variables)                   | Переменная окружения | Курсор терминала, который остаётся видимым для увеличителей экрана, таких как macOS Zoom, когда вы установите его на `1`. Курсор следует за кареткой ввода и, в Claude Code v2.1.218 или более поздней версии, за выделённой строкой в меню и панелях, таких как `/config` и `/plugin`. |
| [`prefersReducedMotion`](/docs/ru/settings-reference#prefersreducedmotion)   | Параметр             | Уменьшенные или отсутствующие спиннеры, мерцание и другие анимации, когда `true`.                                                                                                                                                                                                       |
| [`theme`](/docs/ru/settings-reference#theme)                                 | Параметр             | Цвета интерфейса, включая удобные для дальтоников темы `dark-daltonized` и `light-daltonized`. Вы также можете выбрать одну с помощью [`/theme`](/docs/ru/commands#all-commands).                                                                                                            |
| [`preferredNotifChannel`](/docs/ru/settings-reference#preferrednotifchannel) | Параметр             | С значением `"terminal_bell"`, звонок терминала вне режима программы чтения с экрана, когда Claude ждёт вас.                                                                                                                                                                            |

<h2 id="what-your-screen-reader-hears">
  Что слышит ваша программа чтения с экрана
</h2>

В режиме программы чтения с экрана Claude Code выводит плоский текст:

* Нет символов рисования прямоугольников для интерфейса
* Нет подсказок только по цвету
* Нет перерисовок содержимого, которое не изменилось. Спиннеры прогресса отображаются как статический текст
* Таблицы в ответах Claude читаются как предложения `Header: value` вместо сетки с символами рисования прямоугольников

Claude Code оставляет всё, что он выводит, в буфере прокрутки вашего терминала, поэтому вы можете перечитать более ранние ходы с помощью команд просмотра вашей программы чтения с экрана или поиска вашего терминала. Claude Code игнорирует параметр [`tui`](/docs/ru/settings-reference#tui) в режиме программы чтения с экрана. Кроме присоединённых фоновых сеансов, перечисленных в разделе [Известные ограничения](#known-limitations), он выводит прокручиваемый текст вместо [полноэкранного отображения](/docs/ru/fullscreen).

Claude Code также ждёт в двух местах, чтобы ваша программа чтения с экрана могла поспеть:

* После того, как Claude Code выводит строку подтверждения, он ждёт 3 секунды перед тем, как нарисовать подсказку, чтобы ваша программа чтения с экрана могла закончить строку. Нажмите любую клавишу, чтобы завершить ожидание. Чтобы изменить длину ожидания, установите [`CLAUDE_AX_STARTUP_QUIET_MS`](/docs/ru/env-vars#variables).
* Перед тем, как Claude Code напишет новую или изменённую строку, такую как подсказка или больше ответа Claude, он перемещает курсор в начало строки и ждёт 50 миллисекунд. Ваша программа чтения с экрана затем читает строку с её первого символа. Символы, которые вы вводите или удаляете в конце строки ввода, появляются немедленно. Чтобы изменить длину ожидания, установите [`CLAUDE_AX_PREPARK_MS`](/docs/ru/env-vars#variables).

Каждое сообщение в стенограмме начинается с метки, которую объявляет ваша программа чтения с экрана, называющей, что это: ваши сообщения, ответы Claude и размышления, активность инструментов, ошибки и предупреждения, и подсказки. Метки также доступны для поиска, поэтому вы можете переходить между разделами стенограммы, выполняя поиск в буфере прокрутки вашего терминала:

| Метка                  | Значение                                                                                                 |
| :--------------------- | :------------------------------------------------------------------------------------------------------- |
| `you:`                 | Ваши сообщения                                                                                           |
| `claude:`              | Ответы Claude                                                                                            |
| `thinking:`            | Размышления Claude                                                                                       |
| `tool:`                | Активность инструмента, такая как редактирование файла или запуск команды                                |
| `tool error:`          | Инструмент, который не удался                                                                            |
| `error:`               | Ошибка в диалоге, такая как неудачный запрос API                                                         |
| `warning:`             | Предупреждение от Claude Code, такое как переключение на резервную модель                                |
| `Permission Required:` | Подсказка разрешения, ожидающая вашего ответа                                                            |
| `Cost:`                | Сводка стоимости сеанса при выходе Claude Code, если ваша учётная запись [показывает затраты](/docs/ru/costs) |

Claude Code сохраняет курсор терминала на кареткой ввода, поэтому команда чтения текущей строки вашей программы чтения с экрана читает подсказку, которую вы редактируете.

Когда вы вводите текст в конце строки ввода, или нажимаете `Backspace` там, Claude Code выводит только символы, которые изменились. Ваша программа чтения с экрана повторяет только эти символы.

Когда вы удаляете слово или строку с помощью одного из [сочетаний клавиш редактирования текста](/docs/ru/interactive-mode#text-editing), Claude Code объявляет удалённый текст:

* Удаление слов с помощью `Ctrl+W` или `Alt+D`, или с помощью `Option+Delete` на macOS или `Ctrl+Backspace` на Windows
* Удаление в начало строки с помощью `Ctrl+U` или `Cmd+Backspace`
* Удаление в конец строки с помощью `Ctrl+K`

Когда вы циклируете [режимы разрешения](/docs/ru/permission-modes) с помощью `Shift+Tab`, Claude Code объявляет режим разрешения, на который вы приземлились, такой как `[plan mode on]` или `[accept edits on]`. Claude Code выводит объявление один раз и не повторяет его при более поздних перерисовках.

<h3 id="jump-between-turns">
  Переход между ходами
</h3>

Claude Code выводит маркеры интеграции оболочки OSC 133 на границах ходов, поэтому клавиша перехода к предыдущей подсказке вашего терминала перемещается между ходами без чтения всей стенограммы:

* iTerm2: Cmd+Shift+Up
* Терминал VS Code: Ctrl+Up на Windows, Cmd+Up на macOS
* Windows Terminal: нет клавиши по умолчанию; привяжите действие `scrollToMark` в его параметрах
* Kitty и Ghostty: проверьте документацию терминала для его клавиши перехода к подсказке

macOS Terminal не действует на маркеры, и Claude Code не выводит их в WezTerm. В этих терминалах вместо этого выполните поиск в буфере прокрутки по метке `you:`.

<h2 id="answer-menus-and-prompts">
  Ответ на меню и подсказки
</h2>

В режиме программы чтения с экрана меню, которыми вы обычно навигируете с помощью клавиш со стрелками, включая подсказки разрешения, становятся нумерованными списками. Claude Code объявляет каждый параметр как нумерованную строку, затем подсказку `Enter selection`, которая называет допустимый диапазон. Введите номер нужного параметра и нажмите Enter.

* Нажмите Escape, чтобы отменить меню, чья подсказка заканчивается на `or Escape to cancel`.
* Если вы введёте номер, которого нет в списке, Claude Code объявляет допустимый диапазон и позволяет вам попробовать снова.

Селектор [`/effort`](/docs/ru/model-config#adjust-effort-level), который является ползунком вне режима программы чтения с экрана, становится тем же видом нумерованного списка.

Подсказки да-или-нет запрашивают введённый ответ вместо меню с двумя параметрами. Ответьте `y` или `n` и нажмите Enter. `yes` и `no` также работают.

<h2 id="hear-when-claude-code-needs-you">
  Услышьте, когда Claude Code нуждается в вас
</h2>

В режиме программы чтения с экрана Claude Code звонит в звонок терминала, когда ему нужно ваше внимание, поэтому вам не нужно постоянно проверять стенограмму. Звонок звонит, когда:

* Claude завершает ответ
* Подсказка или диалог нуждается в вашем ответе, такой как подсказка разрешения
* Инструмент, который работал дольше 5 секунд, завершается

Звонок - это стандартный сигнал тревоги вашего терминала. Чтобы отключить его, измените параметр звонка в приложении вашего терминала. Вне режима программы чтения с экрана установите [`preferredNotifChannel`](/docs/ru/settings-reference#preferrednotifchannel) на `"terminal_bell"`, чтобы получить [аналогичный звонок](/docs/ru/terminal-config#get-a-terminal-bell-or-notification), когда Claude ждёт вас.

<h2 id="known-limitations">
  Известные ограничения
</h2>

Некоторые поведения не адаптированы для режима программы чтения с экрана:

* Режим программы чтения с экрана не включается автоматически при запуске программы чтения с экрана.
* Claude Code не объявляет изменение режима разрешения, сделанное любым способом, кроме циклирования с помощью `Shift+Tab`, такое как вход в [режим плана](/docs/ru/permission-modes#analyze-before-you-edit-with-plan-mode) из команды.
* Присоединение к [фоновому сеансу](/docs/ru/agent-view) с помощью `claude attach` или из представления агента входит в альтернативный экран терминала, который не имеет собственного буфера прокрутки. Это [то же поведение, что и для других присоединённых сеансов](/docs/ru/fullscreen). Чтобы выйти, нажмите Left Arrow на пустой подсказке или Ctrl+Z, если диалог имеет фокус.
* Claude Code объявляет затраты в сводке, которую он выводит при выходе, а не за ход.
* Режим программы чтения с экрана не изменяет [неинтерактивный режим](/docs/ru/headless) с флагом `-p`. Неинтерактивный режим уже выводит простой текст и остаётся альтернативой для написания скриптов.

<h2 id="report-an-issue">
  Сообщить о проблеме
</h2>

Если что-то не работает с вашей программой чтения с экрана, увеличителем или терминалом, откройте проблему на [трекере проблем Claude Code](https://github.com/anthropics/claude-code/issues) и упомяните вашу вспомогательную технологию в заголовке. Включите вашу операционную систему, приложение терминала и имя и версию вспомогательной технологии в отчёт.
