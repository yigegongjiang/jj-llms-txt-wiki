# Примеры

> Найдите полный, готовый к запуску проект Agent SDK или пошаговый рецепт из Claude Cookbook, который соответствует тому, что вы хотите создать.

Эта страница направляет вас к полным, готовым к запуску проектам Agent SDK и пошаговым рецептам Claude Cookbook. Приложения TypeScript находятся в репозитории [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos), а рецепты Python находятся в [Claude Cookbook](https://platform.claude.com/cookbook).

<h2 id="run-a-minimal-agent-first">
  Сначала запустите минимальный агент
</h2>

Если вы еще ничего не создавали с помощью SDK, начните с одного из этих вариантов перед полным приложением:

* [Agent SDK quickstart](/docs/ru/agent-sdk/quickstart): создайте свой первый работающий агент на TypeScript или Python с включенными шагами настройки. Агент находит и исправляет ошибки в примере файла.

* [Hello World](https://github.com/anthropics/claude-agent-sdk-demos/tree/main/hello-world): минимальный проект TypeScript для клонирования, когда вы хотите начать с кода репозитория

<h2 id="explore-a-typescript-application">
  Изучите приложение TypeScript
</h2>

Приложения TypeScript в [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos) — это демонстрации для локальной разработки, от почтового клиента до многоагентной системы исследований. Клонируйте демонстрацию, структура которой соответствует тому, что вы создаете.

<h2 id="work-through-a-python-recipe">
  Работайте с рецептом Python
</h2>

Серия Agent SDK в Claude Cookbook — это последовательность рецептов, каждый из которых представляет собой записную книжку Python, которая развивается от простого агента исследований к сложным многоагентным системам. Каждая записная книжка основывается на предыдущей, вводя новые концепции и возможности. Начните с [однострочного агента исследований](https://platform.claude.com/cookbook/claude-agent-sdk-00-the-one-liner-research-agent) и двигайтесь дальше.

Для рецептов по всем продуктам Claude см. полный [Claude Cookbook](https://platform.claude.com/cookbook).
