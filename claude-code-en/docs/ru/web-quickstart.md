# Начало работы с Claude Code в веб-версии

> Запустите Claude Code в облаке из браузера или мобильного приложения. Подключите репозиторий GitHub, отправьте задачу и просмотрите PR без локальной настройки.

<Note>
  Claude Code в веб-версии находится в исследовательском предпросмотре для пользователей Pro, Max и Team, а также для пользователей Enterprise с премиум-местами или местами Chat + Claude Code.
</Note>

Claude Code в веб-версии работает на облачной инфраструктуре, управляемой Anthropic, вместо вашей машины. Отправляйте задачи с [claude.ai/code](https://claude.ai/code) из браузера или мобильного приложения Claude.

Вам потребуется репозиторий GitHub для [начала работы](#connect-github-and-create-an-environment). Claude клонирует его в изолированную виртуальную машину, вносит изменения и отправляет ветку для вашего просмотра. Сеансы сохраняются на всех устройствах, поэтому задача, которую вы начали на ноутбуке, готова к просмотру с телефона позже.

Claude Code в веб-версии хорошо подходит для:

* **Параллельные задачи**: запускайте несколько независимых задач одновременно, каждую в своем сеансе и ветке, без управления несколькими worktrees
* **Репозитории, которые у вас нет локально**: Claude клонирует репозиторий заново в каждом сеансе, поэтому вам не нужно его проверять
* **Задачи, которые не требуют частого управления**: отправьте четко определенную задачу, займитесь чем-то другим и просмотрите результат, когда Claude закончит
* **Вопросы о коде и исследование**: поймите кодовую базу или проследите, как реализована функция, без локального клона

Для работы, которая требует вашей локальной конфигурации, инструментов или окружения, запуск Claude Code локально или использование [Remote Control](/docs/ru/remote-control) — лучший вариант.

<h2 id="how-sessions-run">
  Как работают сеансы
</h2>

Когда вы отправляете задачу:

1. **Клонирование и подготовка**: ваш репозиторий клонируется на управляемую Anthropic ВМ, и ваш [скрипт настройки](/docs/ru/claude-code-on-the-web#setup-scripts) запускается, если он настроен.
2. **Настройка сети**: доступ в интернет устанавливается на основе [уровня доступа](/docs/ru/claude-code-on-the-web#access-levels) вашего окружения.
3. **Работа**: Claude анализирует код, вносит изменения, запускает тесты и проверяет свою работу. Вы можете наблюдать и управлять на протяжении всего процесса или отойти и вернуться, когда это будет сделано.
4. **Отправка ветки**: когда Claude достигает точки остановки, он отправляет свою ветку на GitHub. Вы просматриваете diff, оставляете встроенные комментарии, создаете PR или отправляете еще одно сообщение, чтобы продолжить.

Сеанс не закрывается при отправке ветки. Создание PR и дальнейшие правки происходят в одном и том же разговоре.

<h2 id="compare-ways-to-run-claude-code">
  Сравнение способов запуска Claude Code
</h2>

Claude Code ведет себя одинаково везде. Что меняется, так это место выполнения кода и доступность вашей локальной конфигурации. Приложение Desktop предлагает как локальные, так и облачные сеансы, поэтому ответы ниже зависят от того, что вы выберете:

|                                               | В веб-версии                                                                                                                 | Remote Control                                 | Terminal CLI      | Приложение Desktop                   |
| :-------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------- | :---------------- | :----------------------------------- |
| **Код выполняется на**                        | Облачной ВМ Anthropic                                                                                                        | Вашей машине                                   | Вашей машине      | Вашей машине или облачной ВМ         |
| **Вы общаетесь с**                            | claude.ai или мобильного приложения                                                                                          | claude.ai или мобильного приложения            | Вашего терминала  | Интерфейса Desktop                   |
| **Использует вашу локальную конфигурацию**    | Нет, только репозиторий                                                                                                      | Да                                             | Да                | Да для локального, нет для облачного |
| **Требует GitHub**                            | Да, или [отправьте локальный репозиторий](/docs/ru/claude-code-on-the-web#send-local-repositories-without-github) через `--cloud` | Нет                                            | Нет               | Только для облачных сеансов          |
| **Продолжает работать при отключении**        | Да                                                                                                                           | Пока терминал остается открытым                | Нет               | Зависит от типа сеанса               |
| **[Режимы разрешений](/docs/ru/permission-modes)** | Принять правки, Plan, Auto                                                                                                   | Спросить, Автоматическое принятие правок, Plan | Все режимы        | Зависит от типа сеанса               |
| **Доступ в сеть**                             | Настраивается для каждого окружения                                                                                          | Сеть вашей машины                              | Сеть вашей машины | Зависит от типа сеанса               |

Смотрите документацию [быстрого старта терминала](/docs/ru/quickstart), [приложения Desktop](/docs/ru/desktop) или [Remote Control](/docs/ru/remote-control) для их настройки.

<h2 id="connect-github-and-create-an-environment">
  Подключение GitHub и создание окружения
</h2>

Настройка — это одноразовый процесс. Если вы уже используете GitHub CLI, вы можете [сделать это из терминала](#connect-from-your-terminal) вместо браузера.

<Steps>
  <Step title="Посетите claude.ai/code">
    Перейдите на [claude.ai/code](https://claude.ai/code) и войдите со своей учетной записью Anthropic.
  </Step>

  <Step title="Установите приложение Claude GitHub">
    После входа claude.ai/code предложит вам подключить GitHub. Следуйте подсказке, чтобы установить приложение Claude GitHub и предоставить ему доступ к вашим репозиториям. Облачные сеансы работают с существующими репозиториями GitHub, поэтому для запуска нового проекта сначала [создайте пустой репозиторий на GitHub](https://github.com/new).
  </Step>

  <Step title="Создайте ваше окружение">
    После подключения GitHub вам будет предложено создать облачное окружение. Окружение контролирует, какой доступ в сеть имеет Claude во время сеансов и что запускается при создании нового сеанса. Смотрите [Установленные инструменты](/docs/ru/claude-code-on-the-web#installed-tools) для того, что доступно без какой-либо конфигурации.

    Форма содержит эти поля:

    * **Name**: метка отображения. Полезно, когда у вас есть несколько окружений для разных проектов или уровней доступа.
    * **Network access**: контролирует, что сеанс может достичь в интернете. По умолчанию `Trusted` позволяет подключения к [общим реестрам пакетов](/docs/ru/claude-code-on-the-web#default-allowed-domains) как npm, PyPI и RubyGems, блокируя общий доступ в интернет.
    * **Environment variables**: необязательные переменные, доступные в каждом сеансе, в формате `.env`. Не оборачивайте значения в кавычки, так как кавычки сохраняются как часть значения. Они видны всем, кто может редактировать это окружение.
    * **Setup script**: необязательный Bash скрипт, который запускается перед запуском Claude Code. Используйте его для установки системных инструментов, которые облачная ВМ не включает, например `apt install -y gh`. Результат [кэшируется](/docs/ru/claude-code-on-the-web#environment-caching), поэтому скрипт не переустанавливается в каждом сеансе. Смотрите [Скрипты настройки](/docs/ru/claude-code-on-the-web#setup-scripts) для примеров и советов по отладке.

    Для первого проекта оставьте значения по умолчанию и нажмите **Create environment**. Вы можете [отредактировать его позже или создать дополнительные окружения](/docs/ru/claude-code-on-the-web#configure-your-environment) для разных проектов.
  </Step>
</Steps>

<h3 id="connect-from-your-terminal">
  Подключение из терминала
</h3>

Если вы уже используете GitHub CLI (`gh`), вы можете настроить Claude Code в веб-версии без открытия браузера. Это требует [Claude Code CLI](/docs/ru/quickstart). `/web-setup` читает ваш локальный токен `gh`, связывает его с вашей учетной записью Claude и создает облачное окружение по умолчанию, если у вас его нет.

<Note>
  Организации с включенным [Zero Data Retention](/docs/ru/zero-data-retention) не могут использовать `/web-setup` или другие функции облачных сеансов. Если GitHub CLI не установлен или не аутентифицирован, `/web-setup` открывает поток встроенной настройки браузера.
</Note>

<Steps>
  <Step title="Аутентификация с помощью GitHub CLI">
    В вашей оболочке аутентифицируйте GitHub CLI, если вы еще этого не сделали:

    ```bash theme={null}
    gh auth login
    ```
  </Step>

  <Step title="Войдите в Claude">
    В Claude Code CLI запустите `/login` для входа со своей учетной записью claude.ai. Пропустите этот шаг, если вы уже вошли.
  </Step>

  <Step title="Запустите /web-setup">
    В Claude Code CLI запустите:

    ```text theme={null}
    /web-setup
    ```

    Это синхронизирует ваш токен `gh` с вашей учетной записью Claude. Если у вас еще нет облачного окружения, `/web-setup` создает его с доступом в сеть Trusted и без скрипта настройки. Вы можете [отредактировать окружение или добавить переменные](/docs/ru/claude-code-on-the-web#configure-your-environment) позже. После завершения `/web-setup` вы можете запускать облачные сеансы из терминала с помощью [`--cloud`](/docs/ru/claude-code-on-the-web#from-terminal-to-web) или настроить повторяющиеся задачи с помощью [`/schedule`](/docs/ru/routines).
  </Step>
</Steps>

<h2 id="start-a-task">
  Начните задачу
</h2>

С подключенным GitHub и созданным окружением вы готовы отправлять задачи.

<Steps>
  <Step title="Выберите репозиторий и ветку">
    На [claude.ai/code](https://claude.ai/code) или на вкладке Code в мобильном приложении Claude нажмите селектор репозитория под полем ввода и выберите репозиторий для работы Claude. Каждый репозиторий показывает селектор ветки. Измените его, чтобы запустить Claude с ветки функции вместо ветки по умолчанию. Вы можете добавить несколько репозиториев для работы с ними в одном сеансе.
  </Step>

  <Step title="Выберите режим разрешений">
    Раскрывающееся меню режима рядом с вводом по умолчанию установлено на **Accept edits**, где Claude вносит изменения и отправляет ветку без остановки для одобрения. Переключитесь на **Plan Mode**, если вы хотите, чтобы Claude предложил подход и дождался вашего одобрения перед редактированием файлов. Облачные сеансы не предлагают разрешения Manual или разрешения Bypass. Смотрите [полный список режимов разрешений](/docs/ru/permission-modes#available-modes) для того, что позволяет каждый из них.
  </Step>

  <Step title="Опишите задачу и отправьте">
    Введите описание того, что вы хотите, и нажмите Enter. Будьте конкретны:

    * Назовите файл или функцию: "Add a README with setup instructions" или "Fix the failing auth test in `tests/test_auth.py`" лучше, чем "fix tests"
    * Вставьте вывод ошибки, если у вас он есть
    * Опишите ожидаемое поведение, а не просто симптом

    Claude клонирует репозитории, запускает ваш скрипт настройки, если он настроен, и начинает работать. Каждая задача получает свой сеанс и свою ветку, поэтому вам не нужно ждать, пока одна закончится, прежде чем начать другую.
  </Step>
</Steps>

<h2 id="pre-fill-sessions">
  Предварительное заполнение сеансов
</h2>

Вы можете предварительно заполнить подсказку, репозитории и окружение для нового сеанса, добавив параметры запроса к URL [claude.ai/code](https://claude.ai/code). Используйте это для создания интеграций, таких как кнопка в вашем трекере проблем, которая открывает Claude Code с описанием проблемы в качестве подсказки.

| Параметр       | Описание                                                                                                                                                                                                     |
| :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`       | Текст подсказки для предварительного заполнения в поле ввода. Также принимается псевдоним `q`.                                                                                                               |
| `prompt_url`   | URL для получения текста подсказки, для подсказок, которые слишком длинные для встраивания в строку запроса. URL должен разрешать кросс-источниковые запросы. Игнорируется, когда также установлен `prompt`. |
| `repositories` | Разделенный запятыми список слагов `owner/repo` для предварительного выбора. Также принимается псевдоним `repo`.                                                                                             |
| `environment`  | Имя или ID [окружения](#connect-github-and-create-an-environment) для предварительного выбора.                                                                                                               |

URL-кодируйте каждое значение. Пример ниже открывает форму с уже выбранной подсказкой и репозиторием:

```text theme={null}
https://claude.ai/code?prompt=Fix%20the%20login%20bug&repositories=acme/webapp
```

<h2 id="review-and-iterate">
  Просмотр и итерация
</h2>

Когда Claude закончит, просмотрите изменения, оставьте отзыв на конкретных строках и продолжайте, пока diff не будет выглядеть правильно.

<Steps>
  <Step title="Откройте представление diff">
    Индикатор diff показывает добавленные и удаленные строки во всем сеансе, например `+42 -18`. Выберите его, чтобы открыть представление diff с списком файлов слева и изменениями справа.
  </Step>

  <Step title="Оставляйте встроенные комментарии">
    Выберите любую строку в diff, введите свой отзыв и нажмите Enter. Комментарии накапливаются до тех пор, пока вы не отправите следующее сообщение, затем они объединяются с ним. Claude видит "at `src/auth.ts:47`, don't catch the error here" вместе с вашей основной инструкцией, поэтому вам не нужно описывать, где проблема.
  </Step>

  <Step title="Создайте pull request">
    Когда diff выглядит правильно, выберите **Create PR** в верхней части представления diff. Вы можете открыть его как полный PR, черновик или перейти на страницу составления GitHub с сгенерированным названием и описанием.
  </Step>

  <Step title="Продолжайте итерацию после PR">
    Сеанс остается активным после создания PR. Вставьте вывод ошибки CI или комментарии рецензента в чат и попросите Claude их решить. Чтобы Claude автоматически отслеживал PR, смотрите [Auto-fix pull requests](/docs/ru/claude-code-on-the-web#auto-fix-pull-requests).
  </Step>
</Steps>

<h2 id="troubleshoot-setup">
  Устранение неполадок при настройке
</h2>

<h3 id="no-repositories-appear-after-connecting-github">
  После подключения GitHub не появляются репозитории
</h3>

Облачный сеанс может использовать любой репозиторий, который подключенная учетная запись GitHub может видеть, независимо от того, на каких репозиториях установлено приложение Claude GitHub. Если репозиторий отсутствует, убедитесь, что подключенная учетная запись GitHub имеет доступ к нему на GitHub. Если вы также хотите [Auto-fix](/docs/ru/claude-code-on-the-web#auto-fix-pull-requests) для репозитория, установите приложение на него: на github.com откройте **Settings → Applications → Claude → Configure** и убедитесь, что репозиторий указан в **Repository access**. Приватные репозитории требуют такой же авторизации, как и публичные.

<h3 id="the-page-only-shows-a-github-login-button">
  На странице отображается только кнопка входа GitHub
</h3>

Облачные сеансы требуют подключенной учетной записи GitHub. Подключитесь через поток браузера выше или запустите `/web-setup` из терминала, если вы используете GitHub CLI. Если вы предпочитаете вообще не подключать GitHub, смотрите [Remote Control](/docs/ru/remote-control) для запуска Claude Code на вашей машине и мониторинга его из веб-версии.

<h3 id="not-available-for-the-selected-organization">
  "Not available for the selected organization"
</h3>

Организациям Enterprise может потребоваться администратор для включения Claude Code в веб-версии. Свяжитесь с вашей командой учетных записей Anthropic.

<h3 id="/web-setup-shows-no-commands-match-or-unknown-command">
  `/web-setup` показывает "No commands match" или "Unknown command"
</h3>

`/web-setup` работает внутри Claude Code CLI, а не в вашей оболочке. Сначала запустите `claude`, затем введите `/web-setup` в подсказке.

Если вы ввели его внутри Claude Code и меню команд показывает `No commands match "/web-setup"`, или отправка возвращает `Unknown command: /web-setup`, команда скрыта, потому что требование не выполнено. Причина обычно в том, что вы аутентифицированы с помощью ключа API или поставщика третьей стороны вместо подписки claude.ai. Запустите `/login` для входа со своей учетной записью claude.ai.

<h3 id="could-not-create-a-cloud-environment-or-no-cloud-environment-available-when-using-cloud-or-ultraplan">
  "Could not create a cloud environment" или "No cloud environment available" при использовании `--cloud` или ultraplan
</h3>

Функции удаленного сеанса автоматически создают облачное окружение по умолчанию, если у вас его нет. Если вы видите "Could not create a cloud environment", автоматическое создание не удалось. Если вы видите "No cloud environment available", ваш CLI предшествует автоматическому созданию. В любом случае запустите `/web-setup` в Claude Code CLI для создания вручную или посетите [claude.ai/code](https://claude.ai/code) и следуйте шагу **Create your environment** выше.

<h3 id="setup-script-failed">
  Скрипт настройки не удался
</h3>

Скрипт настройки завершился с ненулевым статусом, что блокирует запуск сеанса. Распространенные причины:

* Установка пакета не удалась, потому что реестр не находится на вашем [уровне доступа в сеть](/docs/ru/claude-code-on-the-web#access-levels). `Trusted` охватывает большинство менеджеров пакетов; `None` блокирует их все.
* Скрипт ссылается на файл или путь, который не существует в свежем клоне.
* Команда, которая работает локально, требует другого вызова на Ubuntu.

Для отладки добавьте `set -x` в начало скрипта, чтобы увидеть, какая команда не удалась. Для некритических команд добавьте `|| true`, чтобы они не блокировали запуск сеанса.

<h3 id="new-sessions-hang-or-time-out-during-setup">
  Новые сеансы зависают или истекает время ожидания во время настройки
</h3>

Если новые сеансы зависают на шаге скрипта настройки или не удаются с общей ошибкой контейнера перед завершением скрипта, скрипт, вероятно, превышает примерно пятиминутный бюджет времени для построения [кэша окружения](/docs/ru/claude-code-on-the-web#environment-caching). Тяжелые шаги, такие как извлечение больших образов Docker, синхронизация полных деревьев зависимостей или загрузка весов модели, часто превышают лимит, особенно когда они выполняются один за другим.

Чтобы исправить это, обрежьте скрипт так, чтобы он надежно завершался менее чем за пять минут:

* Запускайте независимые установки параллельно с `&` и финальным `wait` вместо их последовательного выполнения.
* Переместите самые большие загрузки из скрипта настройки в [SessionStart hook](/docs/ru/claude-code-on-the-web#setup-scripts-vs-sessionstart-hooks), который запускает их в фоновом режиме, чтобы сеанс стал пригодным для использования, пока они завершаются.
* Удалите длинные повторные попытки сна из скрипта настройки, так как зависший цикл повторных попыток учитывается в бюджете.

<h3 id="session-keeps-running-after-closing-the-tab">
  Сеанс продолжает работать после закрытия вкладки
</h3>

Это сделано специально. Закрытие вкладки или навигация не останавливает сеанс. Он продолжает работать в фоновом режиме до тех пор, пока Claude не закончит текущую задачу, затем переходит в режим ожидания. На боковой панели вы можете [архивировать сеанс](/docs/ru/claude-code-on-the-web#archive-sessions), чтобы скрыть его из списка, или [удалить его](/docs/ru/claude-code-on-the-web#delete-sessions), чтобы удалить его навсегда.
