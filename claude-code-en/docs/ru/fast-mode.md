# Ускорьте ответы с помощью быстрого режима

> Получайте более быстрые ответы Opus в Claude Code, включив быстрый режим.

<Note>
  Быстрый режим находится в [исследовательском превью](#research-preview). Функция, цены и доступность могут измениться на основе отзывов.
</Note>

Быстрый режим — это высокоскоростная конфигурация для Claude Opus, которая делает модель в 2,5 раза быстрее при более высокой стоимости за токен. Включайте его с помощью `/fast`, когда вам нужна скорость для интерактивной работы, такой как быстрая итерация или живая отладка, и отключайте, когда стоимость важнее, чем задержка.

Быстрый режим — это не другая модель. Он использует Claude Opus с другой конфигурацией API, которая приоритизирует скорость над экономичностью. Вы получаете идентичное качество и возможности с более быстрыми ответами. Быстрый режим поддерживается на Opus 5.5, Opus 5 и Opus 4.8. Он недоступен на Sonnet, Haiku или других моделях.

Opus 4.7 не поддерживает быстрый режим, поэтому переключение на него отключает быстрый режим. Быстрый режим для Opus 4.7 был объявлен устаревшим 25 июня 2026 года и удален 24 июля 2026 года.

Что нужно знать:

* Используйте `/fast` для включения быстрого режима в Claude Code CLI. Расширение [VS Code](/docs/ru/vs-code) предлагает команду **Toggle fast mode** при выборе модели, которая поддерживает быстрый режим. Claude Code сохраняет этот переключатель в вашей настройке [`fastMode`](#toggle-fast-mode).
* Цены на быстрый режим составляют \$8/\$40 за MTok входа/выхода на Opus 5.5 и \$10/\$50 на Opus 5 и Opus 4.8.
* Доступно пользователям Claude Code на планах подписки (Pro/Max/Team/Enterprise) и на Claude Console. Организациям Team и Enterprise требуется, чтобы Owner сначала это включил, а организациям Console требуется сначала предоставить доступ, оба варианта описаны в разделе [Requirements](#requirements).
* Для пользователей Claude Code на планах подписки (Pro/Max/Team/Enterprise) быстрый режим доступен только через кредиты использования и не включен в лимиты скорости подписки.

<h2 id="toggle-fast-mode">
  Включение быстрого режима
</h2>

В CLI включайте быстрый режим одним из следующих способов:

* Запустите `/fast`, нажмите Space для включения или отключения, затем нажмите Enter для подтверждения
* Установите `"fastMode": true` в вашем [файле пользовательских настроек](/docs/ru/settings)

По умолчанию быстрый режим, который вы включаете в интерактивном сеансе, сохраняется между сеансами. Вы можете настроить быстрый режим на сброс каждого сеанса. Подробности см. в разделе [обязательное согласие за сеанс](#require-per-session-opt-in).

Вне [облачного сеанса](#use-fast-mode-in-cloud-sessions), в [неинтерактивном режиме](/docs/ru/headless) с флагом `-p` команда `/fast` работает только в сеансе, запущенном с быстрым режимом в его значении [`--settings`](/docs/ru/cli-reference#cli-flags), например `claude -p --settings '{"fastMode": true}'`; переключение затем применяется только к этому сеансу и не сохраняется как ваше значение по умолчанию. Форма `-p` требует Claude Code v2.1.205 или более поздней версии. В остальных случаях в неинтерактивном режиме команда сообщает, что быстрый режим недоступен.

Вы можете запустить `/fast` во время работы Claude, и Claude Code переключает быстрый режим без ожидания завершения хода. Claude Code завершает текущий ход с его исходной скоростью, поэтому изменение скорости вступает в силу со следующего хода. Если ваша текущая модель не поддерживает быстрый режим, его включение также переключает вашу модель, и Claude Code использует новую модель со следующего запроса в этом ходе.

Для лучшей экономичности включайте быстрый режим в начале сеанса, а не переключайтесь в середине разговора. Подробности см. в разделе [понимание компромисса стоимости](#understand-the-cost-tradeoff).

Когда вы включаете быстрый режим:

* Если ваша текущая модель не поддерживает быстрый режим, Claude Code переключается на Opus
* Вы увидите сообщение подтверждения: "Fast mode ON"
* Рядом с приглашением появляется небольшой значок `↯` во время активного быстрого режима
* Запустите `/fast` снова в любое время, чтобы проверить, включен или отключен быстрый режим

Opus 5.5 является стандартным режимом быстрого режима в Claude Code v2.1.280 и позже. До версии v2.1.280 быстрый режим по умолчанию использовал Opus 5 с версии v2.1.219, Opus 4.8 на версиях v2.1.154 по v2.1.218 и Opus 4.7 на версиях v2.1.142 по v2.1.153.

Когда вы отключаете быстрый режим с помощью `/fast` снова, вы остаетесь на Opus. Чтобы переключиться на другую модель, используйте `/model`.

<h3 id="switch-models-while-fast-mode-is-on">
  Переключение моделей во время активного быстрого режима
</h3>

Быстрый режим следует вашим переключениям моделей в обоих направлениях:

* **Переключение в сторону**: когда вы переключаетесь на модель, которая не поддерживает быстрый режим, Claude Code отключает быстрый режим. Это включает Opus 4.7; до версии v2.1.221 быстрый режим оставался включенным после переключения на Opus 4.7 и API отклонял запросы.
* **Переключение обратно**: переключение обратно на поддерживаемую модель Opus включает быстрый режим снова, когда ваше сохраненное предпочтение быстрого режима включено, то же самое предпочтение, с которого новый сеанс начинается по умолчанию. Переключение модели никогда не включает быстрый режим для сеанса, чье сохраненное предпочтение отключено, и с настроенным [обязательным согласием за сеанс](#require-per-session-opt-in) переключение обратно также не включает его; запустите `/fast` для его повторного включения.

Всякий раз, когда переключение модели включает или отключает быстрый режим, Claude Code показывает подтверждение `Fast mode ON` или `Fast mode OFF`, и значок `↯` появляется во время активного быстрого режима. Это применяется независимо от того, переключаетесь ли вы с помощью `/model`, с помощью [`/config model=<model>`](/docs/ru/settings) или с устройства, подключенного через [Remote Control](/docs/ru/remote-control).

Claude Code повторно отправляет статус быстрого режима сеанса на устройства, подключенные через Remote Control, после переключения модели, переподключения или неудачной [проверки доступности](#use-fast-mode-behind-proxies-and-llm-gateways).

<h3 id="use-fast-mode-in-cloud-sessions">
  Использование быстрого режима в облачных сеансах
</h3>

Быстрый режим работает в [облачных сеансах](/docs/ru/claude-code-on-the-web), когда он доступен на вашей учетной записи, независимо от того, работает ли сеанс на инфраструктуре, управляемой Anthropic, или на [самостоятельно размещенном runner](/docs/ru/self-hosted-environments). Требует Claude Code v2.1.271 или более поздней версии в окружении сеанса.

Введите `/fast on` в сеансе, чтобы включить быстрый режим. Он остается включенным только для этого сеанса и не сохраняется как ваше значение по умолчанию. [Требования](#requirements) применяются и в облачных сеансах.

<h2 id="understand-the-cost-tradeoff">
  Понимание компромисса стоимости
</h2>

Быстрый режим имеет более высокую цену за токен, чем стандартный Opus:

| Модель   | Входные данные (MTok) | Выходные данные (MTok) |
| -------- | --------------------- | ---------------------- |
| Opus 5.5 | \$8                   | \$40                   |
| Opus 5   | \$10                  | \$50                   |
| Opus 4.8 | \$10                  | \$50                   |

Цены на быстрый режим одинаковы по всему контекстному окну из 1M токенов. Для сравнения со стандартной ставкой Opus см. [справочник по ценам Claude](https://platform.claude.com/docs/ru/about-claude/pricing).

Первый раз, когда вы включаете быстрый режим в разговоре, вы платите полную цену быстрого режима без кэша за входные токены для всего контекста разговора. Чем глубже вы находитесь в разговоре, тем больше это стоит, поэтому включение быстрого режима с самого начала дешевле. Стоимость применяется один раз за разговор, поэтому отключение и повторное включение быстрого режима позже не повторяет её. Для механизма см. [как быстрый режим взаимодействует с кэшем подсказок](/docs/ru/prompt-caching#turning-on-fast-mode).

<h3 id="see-where-fast-mode-spend-appears">
  Посмотрите, где появляются расходы быстрого режима
</h3>

Вы видите расходы быстрого режима в разном месте в зависимости от того, как вы вошли, поэтому сначала запустите [`/status`](/docs/ru/commands) для проверки. Если это показывает строку `Login method` такую как `Claude Max account`, вы вошли с подпиской Claude. Если вместо этого это показывает строку `API key`, ваши запросы выставляются в счёт организации Claude Console.

* **Pro и Max**: вы платите за быстрый режим из своих кредитов использования. Перейдите на [**Settings > Usage**](https://claude.ai/settings/usage) на claude.ai, где раздел **Usage credits** показывает, сколько вы потратили в кредитах использования в этом месяце. Эта цифра включает быстрый режим, но не разбивает его отдельно.
* **Team и Enterprise**: ваша организация платит за использование быстрого режима из своих кредитов использования. Чтобы увидеть свои расходы в кредитах использования, запустите [`/usage`](/docs/ru/costs#check-your-usage-credits-spend). Для того, где ваша организация видит эти расходы, см. [Claude для Teams и Enterprise](/docs/ru/costs#claude-for-teams-and-enterprise).
* **Claude Console**: ваша организация платит за быстрый режим вместе с остальным использованием API. На страницах Console [Usage](https://platform.claude.com/usage) и [Cost](https://platform.claude.com/cost) выберите **Speed (Research Preview)** в меню **Group by** для отделения быстрого режима от использования стандартной скорости. Вы видите эту опцию только когда выбранный диапазон дат включает использование быстрого режима.

<h2 id="decide-when-to-use-fast-mode">
  Решение о том, когда использовать быстрый режим
</h2>

Быстрый режим лучше всего подходит для интерактивной работы, где задержка ответа важнее стоимости:

* Быстрая итерация изменений кода
* Сеансы живой отладки
* Работа, чувствительная ко времени, с жесткими сроками

Стандартный режим лучше для:

* Долгих автономных задач, где скорость менее важна
* Пакетной обработки или конвейеров CI/CD
* Рабочих нагрузок, чувствительных к стоимости

<h3 id="fast-mode-vs-effort-level">
  Быстрый режим в сравнении с уровнем усилий
</h3>

Быстрый режим и уровень усилий оба влияют на скорость ответа, но по-разному:

| Параметр                        | Эффект                                                                                                     |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Быстрый режим**               | Одинаковое качество модели, меньшая задержка, более высокая стоимость                                      |
| **Более низкий уровень усилий** | Меньше времени на размышление, более быстрые ответы, потенциально более низкое качество на сложных задачах |

Вы можете комбинировать оба: используйте быстрый режим с более низким [уровнем усилий](/docs/ru/model-config#adjust-effort-level) для максимальной скорости на простых задачах.

<h2 id="requirements">
  Требования
</h2>

Быстрый режим требует всех следующих условий:

* **Только Anthropic API или подписка**: быстрый режим доступен через Anthropic Console API и для планов подписки Claude с использованием кредитов. Он недоступен на Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry или Claude Platform на AWS. Организации Console также должны иметь [доступ к быстрому режиму](#enable-fast-mode-for-your-organization).
* **Кредиты использования включены для планов подписки**: на плане Pro, Max, Team или Enterprise ваша учетная запись должна иметь [кредиты использования](/docs/ru/costs#add-usage-credits-to-your-subscription) включенными, что позволяет выставлять счета сверх включенного использования вашего плана. До их включения `/fast` сообщает "Fast mode requires usage credits". Способ их включения зависит от вашего плана:
  * На Pro и Max включите их в разделе **Usage credits** на странице [**Settings > Usage**](https://claude.ai/settings/usage) на claude.ai или запустите `/usage-credits` для открытия этой страницы.
  * На Team и Enterprise член с доступом к выставлению счетов включает их для организации в [**Admin settings > Usage**](https://claude.ai/admin-settings/usage), а член без доступа запускает `/usage-credits` для отправки запроса администраторам организации.

<Note>
  Использование быстрого режима берет кредиты непосредственно из кредитов использования, даже если у вас остается использование в вашем плане.
</Note>

* **Платная организация Console**: учетные записи Claude Console не используют кредиты использования, и ваша организация платит за быстрый режим за токен вместе с остальным использованием API. На бесплатном плане Evaluation Console `/fast` показывает "Fast mode unavailable during evaluation. Please purchase credits." Чтобы это исправить, приобретите кредиты в [параметрах выставления счетов Console](https://platform.claude.com/settings/billing).
* **Включение владельцем для Team и Enterprise**: быстрый режим отключен по умолчанию для организаций Team и Enterprise. Владелец должен явно [включить быстрый режим](#enable-fast-mode-for-your-organization) перед тем, как пользователи смогут получить к нему доступ.

<Note>
  Четыре параметра организации могут заблокировать включение быстрого режима с помощью `/fast`:

  * **Быстрый режим не включен**: если быстрый режим не был включен для вашей организации, включение быстрого режима с помощью `/fast` показывает "Fast mode has been disabled by your organization."
  * **Быстрый режим отключен управляемыми параметрами**: если ваша организация развертывает [управляемые параметры](/docs/ru/managed-settings), которые устанавливают [`fastMode: false`](/docs/ru/settings-reference#fastmode), включение быстрого режима с помощью `/fast` показывает то же сообщение "Fast mode has been disabled by your organization".
  * **Требуется явное согласие для каждого сеанса**: управляемые параметры, которые устанавливают [`fastModePerSessionOptIn: true`](#require-per-session-opt-in), отклоняют `/fast on` с тем же сообщением везде, кроме интерактивного сеанса терминала.
  * **Модель быстрого режима не разрешена**: если список разрешений [`availableModels`](/docs/ru/model-config#restrict-model-selection) вашей организации исключает модель Opus быстрого режима, включение отклоняется с "is not in your organization's allowed models". В сеансе, уже работающем на разрешенной модели Opus, поддерживающей быстрый режим, `/fast` вместо этого включает быстрый режим на вашей текущей модели без переключения моделей.
</Note>

<h3 id="enable-fast-mode-for-your-organization">
  Включение быстрого режима для вашей организации
</h3>

Место, где вы включаете быстрый режим, зависит от того, какой продукт использует ваша организация:

* **Console** (клиенты API): администратор включает его в [Claude Code preferences](https://platform.claude.com/claude-code/preferences). Быстрый режим находится в [исследовательском предпросмотре](#research-preview), поэтому ваша организация также должна иметь доступ к быстрому режиму, предоставленный перед тем, как запросы быстрого режима будут успешными. Чтобы получить доступ, свяжитесь с вашим менеджером по работе с клиентами или присоединитесь к списку ожидания, как описано в [быстром режиме на Claude API](https://platform.claude.com/docs/en/build-with-claude/fast-mode).

  Без предоставленного доступа API отклоняет каждый запрос быстрого режима с кодом 429, и Claude Code рассматривает каждое отклонение как [ограничение скорости быстрого режима](#handle-rate-limits). В отличие от периода ожидания ограничения скорости, отклонения продолжаются до тех пор, пока доступ не будет предоставлен.
* **Claude AI** (Team и Enterprise): владелец включает его в [Admin Settings > Claude Code](https://claude.ai/admin-settings/claude-code)

Другой вариант полного отключения быстрого режима — установить `CLAUDE_CODE_DISABLE_FAST_MODE=1`. См. [Переменные окружения](/docs/ru/env-vars).

<h3 id="use-fast-mode-behind-proxies-and-llm-gateways">
  Использование быстрого режима за прокси и шлюзами LLM
</h3>

Перед предложением быстрого режима Claude Code проверяет доступность быстрого режима вашей организации с помощью запроса непосредственно к `api.anthropic.com`. Проверка не следует [`ANTHROPIC_BASE_URL`](/docs/ru/llm-gateway-connect#set-the-base-url-and-credential), поэтому в сети, которая маршрутизирует трафик Claude через [шлюз LLM](/docs/ru/llm-gateway) и блокирует прямой исходящий трафик к `api.anthropic.com`, проверка не удается, даже если запросы вывода работают. Проверка использует настроенный [HTTP прокси](/docs/ru/network-config#proxy-configuration), поэтому блокировка сети не удается проверке только там, где `api.anthropic.com` недостижим даже через прокси.

Когда проверка не удается, `/fast` сообщает "Fast mode unavailable due to network connectivity issues", и запросы выполняются на стандартной скорости, даже если ваша организация имеет включенный быстрый режим. Проверка, которая была успешной в прошлом, продолжает работать из своего кэшированного результата, поэтому заблокированная проверка в основном влияет на новые установки.

То же сообщение о подключении появляется в открытой сети, когда проверка достигает `api.anthropic.com`, но представляет учетные данные, которые Anthropic отклоняет. Сеанс, чей разрешенный ключ является учетными данными, выданными шлюзом, хранящимися в [`ANTHROPIC_API_KEY`](/docs/ru/llm-gateway-connect#set-the-base-url-and-credential) или созданными [`apiKeyHelper`](/docs/ru/settings-reference#apikeyhelper), отправляет проверку с этим ключом, и отклоненный запрос сообщается как сбой подключения.

Чтобы восстановить быстрый режим, разрешите прямой исходящий трафик к `api.anthropic.com`, где причина — блокировка сети, или установите переменную, которая соответствует тому, как проверка не удается:

* `CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS=1` рассматривает неудачную проверку как доступную и все еще соблюдает ответ "disabled by your organization". Используйте его, когда ваша сеть отказывает в соединении или когда Anthropic отклоняет учетные данные шлюза; разрешение не помогает в случае учетных данных, так как ничего не блокируется.
* `CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK=1` пропускает проверку полностью. Используйте его, когда ваша сеть перехватывает запрос вместо того, чтобы отказать в нем.

Две конфигурации шлюза сообщают "Fast mode has been disabled by your organization" вместо сообщения о подключении, даже если ваша организация имеет включенный быстрый режим:

* Сеанс, который аутентифицируется только с помощью [`ANTHROPIC_AUTH_TOKEN`](/docs/ru/llm-gateway-connect#set-the-base-url-and-credential), пропускает проверку: без входа в claude.ai или ключа Anthropic API и без кэшированной успешной проверки, Claude Code рассматривает быстрый режим как отключенный вашей организацией без отправки запроса.
* Прокси, который перехватывает проверку и отвечает своей собственной страницей, например TLS-инспектирующий прокси, возвращающий страницу блокировки HTTP 200, читается как ответ, говорящий, что ваша организация отключила быстрый режим.

В обоих случаях установите `CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK=1` для восстановления быстрого режима. `CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS` не применяется ни к одному из этих случаев, так как он только обходит неудачные проверки, а оба эти случая производят ответ об отключении. Разрешение прямого исходящего трафика не помогает в случае токена-носителя, который никогда не отправляет запрос.

Переменные влияют только на проверку на стороне клиента. Когда ваша организация имеет отключенный быстрый режим, API отклоняет запросы быстрого режима независимо от того, установлены ли они. Отклонение от API остается в силе даже с установленной переменной пропуска. Claude Code повторяет отклоненный запрос на стандартной скорости, отключает быстрый режим и `/fast` сообщает, что ваша организация отключила быстрый режим.

Установка `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` также подавляет проверку доступности. Без ранее кэшированной успешной проверки `/fast` сообщает "Fast mode is currently unavailable"; обе переменные пропуска восстанавливают быстрый режим в этой конфигурации также.

<h3 id="require-per-session-opt-in">
  Требование явного согласия для каждого сеанса
</h3>

По умолчанию быстрый режим, который пользователь включает в интерактивном сеансе, сохраняется между сеансами. Чтобы изменить это, установите `fastModePerSessionOptIn` на `true` в любом [файле параметров](/docs/ru/settings#where-settings-live), что приводит к тому, что каждый сеанс начинается с отключенным быстрым режимом и требует от пользователей явного включения его с помощью `/fast`. Владельцы на планах [Team](https://claude.com/pricing?utm_source=claude_code\&utm_medium=docs\&utm_content=fast_mode_teams#team-&-enterprise) или [Enterprise](https://anthropic.com/contact-sales?utm_source=claude_code\&utm_medium=docs\&utm_content=fast_mode_enterprise) могут развернуть его на уровне организации через [параметры, управляемые сервером](/docs/ru/server-managed-settings).

```json theme={null}
{
  "fastModePerSessionOptIn": true
}
```

Это полезно для контроля затрат в организациях, где пользователи запускают несколько одновременных сеансов. Предпочтение быстрого режима пользователя все еще сохраняется, поэтому удаление этого параметра восстанавливает поведение по умолчанию с сохранением.

Когда управляемые параметры устанавливают ключ, `/fast on` работает только в интерактивном сеансе терминала. Везде еще, включая [неинтерактивный режим](/docs/ru/headless), [расширение VS Code](/docs/ru/vs-code) и [облачные сеансы](#use-fast-mode-in-cloud-sessions), это отклоняется с сообщением, что ваша организация отключила быстрый режим.

<h2 id="handle-rate-limits">
  Обработка лимитов скорости
</h2>

Быстрый режим имеет отдельные лимиты скорости от стандартного Opus. Все поддерживаемые модели Opus используют один пул лимитов быстрого режима: использование на любой из них берет из одних и тех же лимитов. Когда вы достигаете лимита скорости быстрого режима:

1. Быстрый режим автоматически переключается на стандартную скорость
2. Значок `↯` становится серым, указывая на охлаждение
3. Вы продолжаете работать со стандартной скоростью и ценами
4. Когда охлаждение истекает, быстрый режим автоматически повторно включается

Чтобы вместо этого отключить быстрый режим вручную, запустите `/fast` снова.

Если вы исчерпаете кредиты использования во время сеанса, Claude Code повторно пытается выполнить каждый отклоненный запрос быстрого режима со стандартной скоростью и ценами, поэтому вы продолжаете работать, и охлаждение отсутствует. То, как вы видите отклонение, зависит от типа сеанса:

* В интерактивном сеансе Claude Code показывает уведомление "Fast mode disabled · usage credits exhausted" и отключает быстрый режим на оставшуюся часть сеанса. Ваше сохраненное предпочтение быстрого режима не изменяется; запустите `/fast`, чтобы снова включить быстрый режим.
* В [неинтерактивном режиме](/docs/ru/headless) с `--output-format stream-json` и через Agent SDK Claude Code выдает тот же текст в потоке сообщений как `system` сообщение с подтипом `notification`, один раз за ход, пока у вас закончились кредиты использования. Быстрый режим остается включенным. Требуется Claude Code v2.1.221 или позже.

Быстрый режим — это функция исследовательского превью. Это означает:

* Доступность и цены могут измениться
* Базовая конфигурация API может развиваться
