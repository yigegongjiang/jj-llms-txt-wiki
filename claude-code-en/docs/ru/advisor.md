# Эскалация сложных решений с помощью инструмента advisor

> Объедините вашу основную модель с более мощной моделью-советником, которую Claude консультирует в ключевые моменты выполнения задачи.

<Note>
  Инструмент advisor является экспериментальным и требует API Anthropic. Он недоступен на Amazon Bedrock, Claude Platform on AWS, Google Cloud's Agent Platform или Microsoft Foundry. Поведение, цены и доступность могут измениться.
</Note>

Инструмент advisor позволяет Claude консультироваться со второй, обычно более мощной моделью в ключевые моменты выполнения задачи, например перед принятием подхода, когда возникает повторяющаяся ошибка, или перед объявлением задачи завершённой. Советник получает полный диалог, включая каждый вызов инструмента и результат, и возвращает рекомендации, которые Claude применяет перед продолжением.

Советник работает на стороне сервера на инфраструктуре Anthropic как [server tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool), доступный как для подписных, так и для счётных по API аккаунтов. Вы выбираете, какая модель действует в качестве советника, а Claude решает, когда его вызывать.

На этой странице рассказывается, как включить советника, какие пары моделей приняты, что Claude показывает во время консультации и как выставляется счёт за использование советника.

<h2 id="when-to-use-the-advisor">
  Когда использовать советника
</h2>

Советник подходит для длительных многошаговых задач, где большинство ходов рутинны, но качество плана определяет результат. Примеры включают крупные рефакторинги, сеансы отладки, где ошибка повторяется, и задачи, которые вы хотите независимо проверить перед тем, как Claude объявит их завершёнными.

Он добавляет меньше ценности для коротких задач, где мало что нужно планировать, или для работы, где каждый ход требует самой мощной модели. Для этого [переключите основную модель](/docs/ru/model-config#setting-your-model) или см. [как советник сравнивается с opusplan и subagents](#compare-with-related-features) для других способов получить второе мнение.

<h2 id="enable-the-advisor">
  Включение советника
</h2>

Вы можете установить модель советника тремя способами:

* **Команда `/advisor`**: установите или измените советника во время сеанса и сохраните его как стандартный
* **Параметр `advisorModel`**: настройте постоянное значение по умолчанию в вашем [файле параметров](/docs/ru/settings)
* **Флаг `--advisor`**: установите советника для одного сеанса при запуске

Каждый из этих способов включает советника для сеансов, основная модель которых [его поддерживает](#choose-an-advisor-model). После запуска сеанса Claude Code показывает уведомление `Advisor Tool (experimental) is on and may use more tokens · /advisor`. Чтобы перестать использовать советника, см. [Отключение советника](#turn-the-advisor-off).

На некоторых планах использование Fable в качестве советника также требует вашего одноразового [согласия на выставление счёта за использование Fable на основе кредитов использования](/docs/ru/model-config#fable-and-usage-credits). О том, что происходит до того, как вы дали это согласие, см. [Советник Fable и кредиты использования](#fable-advisor-and-usage-credits).

<h3 id="use-the-/advisor-command">
  Использование команды `/advisor`
</h3>

Запустите `/advisor` без аргументов, чтобы открыть средство выбора со списком доступных моделей советника, или передайте модель напрямую:

```
/advisor opus
```

Команда подтверждает выбор сообщением `Advisor set to`, за которым следует имя модели советника. Ваш выбор сохраняется в `advisorModel` в параметрах пользователя и сохраняется между сеансами, за исключением случаев, которые указаны в записи [`advisorModel`](/docs/ru/settings-reference#advisormodel) как применяемые только к текущему сеансу.

Команда также работает там, где нет средства выбора терминала: в [неинтерактивном режиме](/docs/ru/headless) с флагом `-p`, в Agent SDK, в настольном приложении и через [Remote Control](/docs/ru/remote-control). Это требует Claude Code v2.1.260 или более поздней версии. На этих поверхностях:

* Запустите `/advisor` без аргумента, чтобы вывести текущую модель советника и псевдонимы, которые она принимает.
* Запустите `/advisor` с моделью, например `/advisor opus`, чтобы установить её.
* Запустите `/advisor off`, чтобы отключить его.

Claude Code не вызывает сохранённого советника, которого исключает список разрешённых моделей [`availableModels`](/docs/ru/model-config#restrict-model-selection) вашей организации. Чтобы использовать советника, выберите разрешённую модель с помощью `/advisor`.

Claude Code по-прежнему сохраняет советника, которого не поддерживает ваша текущая основная модель. Этот советник активируется после переключения на [совместимую основную модель](#choose-an-advisor-model) с помощью [`/model`](/docs/ru/model-config#setting-your-model). Если API уже отклонил сохранённого советника в текущем разговоре, он остаётся отключённым до `/clear` или `/compact`, даже после переключения моделей.

На некоторых планах использование Fable в качестве советника также требует вашего одноразового [согласия на выставление счёта за использование Fable на основе кредитов использования](/docs/ru/model-config#fable-and-usage-credits). О том, что делает `/advisor fable` до того, как вы дали это согласие, см. [Советник Fable и кредиты использования](#fable-advisor-and-usage-credits).

<h3 id="set-advisormodel-in-settings">
  Установка `advisorModel` в параметрах
</h3>

Чтобы настроить советника по умолчанию без открытия сеанса, установите его в файле параметров:

```json theme={null}
{
  "advisorModel": "opus"
}
```

<h3 id="use-the-advisor-flag">
  Использование флага `--advisor`
</h3>

Чтобы установить советника для одного сеанса без изменения сохранённого параметра, запустите с флагом:

```bash theme={null}
claude --advisor opus
```

Claude Code использует флаг вместо параметра `advisorModel` для этого сеанса. Он не указывает `--advisor` в `claude --help`. Claude Code завершается с ошибкой при запуске, если:

* Основная модель сеанса не поддерживает советника
* Запрошенная модель, например Haiku, не может действовать в качестве советника
* Список разрешённых моделей [`availableModels`](/docs/ru/model-config#restrict-model-selection) вашей организации исключает запрошенную модель
* Вы запросили Fable, и ваша учётная запись по-прежнему требует [согласия на кредиты использования](#fable-advisor-and-usage-credits)

Если вы запустите [фоновый сеанс](/docs/ru/agent-view) с флагом `--advisor` и применимо одно из этих условий, Claude Code запустит сеанс без советника вместо выхода с ошибкой.

<h2 id="choose-an-advisor-model">
  Выбор модели советника
</h2>

Советник должен быть по крайней мере такой же способной, как основная модель. Принятые советники для каждой основной модели:

| Основная модель       | Принятые советники                  | Примечания                                                                                |
| --------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------- |
| Haiku 4.5             | Fable, Opus, Sonnet                 | Haiku может вызывать советника, но не может быть им                                       |
| Sonnet 4.6            | Fable, Opus, Sonnet                 |                                                                                           |
| Sonnet 5              | Fable, Opus 4.7 или позже, Sonnet 5 | Советник Sonnet 4.6 отклоняется, и API отклоняет советника Opus 4.6                       |
| Opus 4.6              | Fable, Opus, Sonnet 5               | Советник Sonnet 4.6 отклоняется                                                           |
| Opus 4.7 или Opus 4.8 | Fable и Opus 4.7 или позже          | Советник Opus 4.6 или Sonnet отклоняется                                                  |
| Opus 5.5 или Opus 5   | Fable и Opus 5 или позже            | Советник Opus 4.6 или Sonnet отклоняется, и API отклоняет советника Opus 4.7 или Opus 4.8 |
| Fable 5               | Fable 5.1 или Fable 5               | Советник Opus или Sonnet отклоняется                                                      |
| Fable 5.1             | Fable 5.1                           | Советник Opus или Sonnet отклоняется, и API отклоняет советника Fable 5                   |

Fable 5.1 требует Claude Code v2.1.257 или более поздней версии. Обе модели Fable требуют [доступ к Fable](/docs/ru/model-config#work-with-fable).

Установите советника как `fable`, `opus` или `sonnet`. Эти псевдонимы разрешаются в встроенную версию Claude Code по умолчанию для каждого семейства моделей, которая обновляется с новыми выпусками Claude Code. Вы также можете передать полный ID модели, например `claude-opus-5-5`.

Подагенты наследуют настроенного советника и применяют ту же проверку пары к своей собственной модели.

Claude Code проверяет пару перед отправкой запроса, и API проверяет её снова:

* Для советника, который таблица указывает как отклоняемый, Claude Code не присоединяет его к запросам основной модели. Вывод команды `/advisor` и уведомление показывают это. Подагенты, чья собственная модель удовлетворяет требованиям пары, могут по-прежнему использовать советника.
* Для советника, который таблица указывает как отклоняемый API, Claude Code присоединяет его, и API отклоняет его. Claude Code затем повторно отправляет этот запрос без советника, и остальная часть разговора выполняется без него, поэтому вы не видите ошибку и не получаете вызовы советника. Выберите принятого советника с помощью `/advisor`; изменение вступает в силу после `/clear` или `/compact` и в новых сессиях.
* Если основная модель или советник — это модель, которую Claude Code не распознает, советник не присоединяется.

<h3 id="fable-advisor-and-usage-credits">
  Советник Fable и кредиты использования
</h3>

На некоторых планах использование Fable выставляется в счёт кредитов использования, и Fable в качестве советника выставляется в счёт так же. Если ваша учётная запись требует [одноразового согласия на выставление счёта за использование Fable в кредиты использования](/docs/ru/model-config#fable-and-usage-credits), Claude Code запрашивает его, когда вы выбираете модель Fable с помощью `/model`, и не применяет Fable в качестве советника до тех пор, пока вы не примете это согласие.

До того как вы примете его, Claude Code не сохраняет Fable в качестве советника, когда вы вводите `/advisor fable` или выбираете Fable в средстве выбора `/advisor`. Вместо этого он указывает вам на `/model fable`. С помощью `claude --advisor fable` Claude Code выходит при запуске с сообщением, которое указывает на `/model fable`. В [фоновой сессии](#use-the-advisor-flag) он запускает сессию без советника вместо выхода. Если Fable уже сохранён как ваша `advisorModel`, Claude Code отправляет запросы без советника. В интерактивной сессии, основная модель которой поддерживает советника, он также показывает уведомление, которое указывает на `/model fable`.

Чтобы принять согласие, запустите `/model fable` и выберите продолжить на Fable. Claude Code записывает согласие и [сохраняет Fable как вашу выбранную модель](/docs/ru/model-config#default-model-setting). Затем выберите Fable в качестве советника.

<h3 id="common-model-pairings">
  Распространённые пары моделей
</h3>

Любая принятая пара работает. Эти комбинации балансируют стоимость и возможности по-разному:

| Пара                              | Когда использовать                                                                                                                                                     |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sonnet основная + Opus советник   | Sonnet обрабатывает рутинную работу и эскалирует планирование, неоднозначные сбои и проверки завершения на Opus                                                        |
| Sonnet основная + Fable советник  | Рекомендации Fable в точках принятия решений без запуска Fable на протяжении всего процесса. Требует доступ к Fable                                                    |
| Haiku основная + Opus советник    | Самая дешёвая основная модель с мощным планированием. Ожидайте более высокую стоимость, чем только Haiku, но ниже, чем переключение основной модели на Sonnet или Opus |
| Opus основная + Opus советник     | Второй Opus проверяет первый. Полезно для высокорисковых задач, где независимая проверка важнее стоимости                                                              |
| Fable основная + Fable советник   | Пара с наивысшей возможностью, когда Fable доступна. Claude Code не применяет советника Opus или Sonnet к основной модели Fable                                        |
| Sonnet основная + Sonnet советник | Более дешёвое второе мнение для выявления рутинных упущений                                                                                                            |

<h2 id="when-claude-consults-the-advisor">
  Когда Claude консультируется с советником
</h2>

Claude решает, когда вызывать советника. Он имеет тенденцию консультироваться перед принятием подхода, когда ошибка повторяется, и перед объявлением задачи завершённой, но время определяется моделью, а не правилами.

Вы можете попросить консультацию в своём приглашении так же, как вы запросили бы любой инструмент, например `consult the advisor before you continue`. Нет параметра для ограничения или принудительного вызова советника; если вы хотите, чтобы Claude консультировался чаще или реже во время задачи, скажите об этом в своих инструкциях.

<h2 id="what-you-see-during-a-session">
  Что вы видите во время сеанса
</h2>

Когда Claude вызывает советника, стенограмма показывает строку `Advising` с именем модели советника во время выполнения вызова. Когда результат возвращается, строка сообщает, дал ли советник рекомендации:

* **Reviewed**: строка подтверждает, что советник проверил диалог. Когда советник вернул читаемые рекомендации, нажмите `Ctrl+O`, чтобы прочитать их.
* **Declined**: строка читается как `Advisor declined to advise on this request`. Если советник дал причину, нажмите `Ctrl+O`, чтобы прочитать её.

Claude обычно следует рекомендациям советника, но адаптируется, когда его собственные доказательства противоречат конкретному утверждению: если рекомендуемый шаг не удаётся при попытке или содержимое файла противоречит совету, Claude выявляет конфликт, а не следует рекомендации безусловно.

Советник всегда получает полный диалог, и Claude контролирует время. Для большего контроля или другой конфигурации см. [как советник сравнивается с subagents и opusplan](#compare-with-related-features).

<h2 id="cost">
  Стоимость
</h2>

Когда Claude вызывает советника, модель советника читает диалог, поэтому каждый вызов потребляет токены по ставкам модели советника в дополнение к использованию вашей основной модели. То, как эти токены советника выставляются в счёт, зависит от способа оплаты:

* **Выставление счёта по API**: вы платите по входным и выходным ставкам модели советника за токены советника
* **Планы подписки**: использование советника учитывается в пределах лимитов использования вашего плана, за исключением того, что советник Fable выставляет счёт на [кредиты использования](/docs/ru/model-config#fable-and-usage-credits) на планах, где это применяется

Если ваша учётная запись требует согласия на использование кредитов, советник Fable не выставляет счёт до тех пор, пока вы его не дадите, потому что Claude Code [не применяет выбор](#fable-advisor-and-usage-credits) до этого момента.

Claude вызывает советника в точках принятия решений, а не на каждом ходу, поэтому объединение более быстрой основной модели с более мощным советником обычно стоит меньше, чем запуск более мощной модели на протяжении всего процесса. Использование советника учитывается в итогах сеанса, показанных [`/usage`](/docs/ru/costs#track-your-costs).

Для информации о том, как токены советника сообщаются в ответах API, см. [Usage and billing](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool#usage-and-billing) в документации Claude API.

<h2 id="impact-on-prompt-caching">
  Влияние на кэширование приглашений
</h2>

Включение или отключение советника во время сеанса не делает недействительным [кэш приглашений](/docs/ru/prompt-caching) вашей основной модели. В отличие от [переключения моделей](/docs/ru/prompt-caching#switching-models), переключение `/advisor` сохраняет кэшированный префикс нетронутым, и возвращённые рекомендации советника кэшируются как часть стенограммы при последующих ходах.

Собственное чтение советником диалога не кэшируется. Каждый вызов советника обрабатывает полную стенограмму заново, без повторного использования между вызовами.

<h2 id="requirements">
  Требования
</h2>

Инструмент advisor требует всё следующее:

* **Только API Anthropic**: советник является инструментом, выполняемым на сервере. Он недоступен на Amazon Bedrock, Claude Platform on AWS, Google Cloud's Agent Platform или Microsoft Foundry. Через [LLM gateway](/docs/ru/llm-gateway), настроенный с `ANTHROPIC_BASE_URL`, доступность зависит от того, пересылает ли шлюз запрос в целости на API Anthropic. Если шлюз или его вышестоящий источник не распознают инструмент advisor, см. [Автоматический повтор и пересылка ошибок](/docs/ru/llm-gateway-protocol#automatic-retry-and-error-forwarding) для информации о том, как Claude Code реагирует.
* **Поддерживаемая основная модель**: Fable, Opus 4.6 или позже, Sonnet 4.6 или позже, или Haiku 4.5. См. [Выбор модели advisor](#choose-an-advisor-model) для информации о том, какие советники принимает каждая модель.
* **Получение флага функции**: Claude Code включает советника через флаг функции, который он получает от Anthropic. В сеансе, где установлена переменная, отключающая получение флага, такая как `DISABLE_TELEMETRY`, советник остаётся отключённым. См. [Функции, требующие получения флага функции](/docs/ru/env-vars#features-that-need-feature-flag-fetching).

<h2 id="turn-the-advisor-off">
  Отключение советника
</h2>

Чтобы перестать использовать советника, запустите `/advisor off` или выберите **No advisor** в средстве выбора `/advisor`:

```
/advisor off
```

Чтобы полностью отключить инструмент advisor, установите `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1`. Команда `/advisor` становится недоступной и любой настроенный `advisorModel` игнорируется. Флаг `--advisor` принимается, но не имеет эффекта. См. [Environment variables](/docs/ru/env-vars).

<h2 id="compare-with-related-features">
  Сравнение со связанными функциями
</h2>

Советник — это один из нескольких способов объединить сильные стороны моделей. Выбирайте в зависимости от того, когда вы хотите, чтобы вторая модель была задействована.

| Подход                                                             | Когда работает более мощная модель                                                                                                                  | Как это начинается                                |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Инструмент advisor                                                 | В точках принятия решений во время задачи                                                                                                           | Claude вызывает его, когда ему нужна рекомендация |
| [`opusplan`](/docs/ru/model-config#opusplan-model-setting)              | Во время режима плана, когда [разрешено `availableModels`](/docs/ru/model-config#restrict-model-selection), затем переключается на Sonnet для выполнения | Вы входите в режим плана                          |
| [Subagents](/docs/ru/sub-agents#choose-a-model) с установленным `model` | Для всей делегированной подзадачи                                                                                                                   | Claude делегирует или вы вызываете subagent       |
| [`/model`](/docs/ru/model-config#setting-your-model)                    | Для всех последующих ходов                                                                                                                          | Вы переключаете модели                            |
