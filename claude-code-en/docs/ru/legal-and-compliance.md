<h3 id="can-customers-offer-claude-code-in-their-products">
  Могут ли клиенты предлагать Claude Code в своих продуктах?
</h3>

Если мы не договорились об ином, предустановка или запуск Claude Code в ваших продуктах или услугах (например, в размещённых песочницах или другой инфраструктуре агентов) требует согласия с нашими [Коммерческими условиями обслуживания](https://www.anthropic.com/legal/commercial-terms) и соблюдения приведённых ниже условий:

* **Двоичный файл Claude Code не должен быть изменён.** Claude Code должен быть установлен и запущен так, как опубликовано компанией Anthropic, и клиенты не могут удалять, отключать или ограничивать какой-либо встроенный метод аутентификации (включая методы, которые позволяют входить с помощью учётной записи Claude или собственного ключа API пользователя).
* **Клиенты не могут платить, перепродавать или выступать посредником при использовании Claude от имени своих конечных пользователей.** Каждый конечный пользователь должен пройти аутентификацию со своим собственным ключом API Anthropic, учётными данными плана подписки Claude или учётными данными поставщика вывода 3P (Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry). Это использование выставляется в счёт конечному пользователю в соответствии с его собственным соглашением с Anthropic или, для поставщиков вывода третьих сторон, с применимым поставщиком.

**Использование имени и логотипа Claude Code.** Вы можете точно сказать, простым текстом, что ваш продукт имеет предустановленный Claude Code или что он запускает Claude Code. Но вы не можете использовать имена или логотипы Claude Code или Anthropic как часть названия вашего собственного продукта, функции или компании, в своём логотипе или способом, который предполагает, что Anthropic создала, одобрила или является партнёром вашего продукта. Любое другое использование имён или логотипов Anthropic регулируется нашими [Рекомендациями по товарным знакам](https://www.anthropic.com/legal/trademark-guidelines) и требует нашего письменного разрешения.

Claude Code остаётся управляемым стандартными условиями Anthropic (см. разделы «Лицензия» и «Коммерческие соглашения» выше) независимо от платформы, через которую к нему осуществляется доступ.

<h3 id="authentication-and-credential-use">
  Аутентификация и использование учетных данных
</h3>

Claude Code аутентифицируется на серверах Anthropic с использованием токенов OAuth или ключей API. Эти методы аутентификации служат разным целям:

* **Аутентификация OAuth** предназначена исключительно для покупателей планов Claude Free, Pro, Max, Team и Enterprise и разработана для поддержки обычного использования Claude Code и других встроенных приложений Anthropic. Инструкции по входу см. в разделе [Вход в вашу учетную запись Claude](https://support.claude.com/en/articles/13189465-logging-in-to-your-claude-account); информацию о том, как Claude Code выполняет аутентификацию OAuth, см. в разделе [Authentication](/docs/ru/authentication).
* **Разработчики**, создающие продукты или сервисы, которые взаимодействуют с возможностями Claude, включая те, которые используют [Agent SDK](/docs/ru/agent-sdk/overview), должны использовать аутентификацию по ключу API через [Claude Console](https://platform.claude.com/) или поддерживаемого облачного провайдера. Anthropic не разрешает сторонним разработчикам предлагать вход Claude.ai в их собственные приложения или маршрутизировать запросы через учетные данные планов Free, Pro или Max от имени своих пользователей. Кроме того, разработчики не могут собирать, хранить или посредничать в учетных данных Claude.ai или токенах сеанса — вход в учетную запись Claude должен осуществляться через собственный поток Anthropic.

Это не ограничивает способ, которым клиенты предоставляют и управляют своими собственными ключами API или учетными данными поставщика услуг вывода третьих сторон — например, настройку ключа API в среде разработки, менеджере секретов или образе машины для использования авторизованными пользователями клиента — при условии, что полученное использование выставляется владельцу ключа в соответствии с его соглашением с Anthropic (или применимым поставщиком) и не перепродается или не посредничается, как описано выше. Это также не препятствует конечному пользователю входить в неизмененный бинарный файл Claude Code со своей собственной подпиской Claude, включая случаи, когда платформа размещает Claude Code, как описано выше.

Anthropic оставляет за собой право принимать меры для обеспечения соблюдения этих ограничений и может делать это без предварительного уведомления.

По вопросам о разрешенных методах аутентификации для вашего случая использования, пожалуйста, [свяжитесь с отделом продаж](https://www.anthropic.com/contact-sales?utm_source=claude_code\&utm_medium=docs\&utm_content=legal_compliance_contact_sales).
