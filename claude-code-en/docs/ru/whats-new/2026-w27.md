# Неделя 27 · 29 июня – 3 июля 2026

> Claude Sonnet 5 становится моделью по умолчанию, Claude в Chrome достигает общей доступности, подагенты работают в фоновом режиме по умолчанию, Claude Desktop появляется на Linux в бета-версии, и /radio настраивается на Claude FM.

  <p className="digest-feature-lede">Claude теперь продолжает работать, пока работают подагенты, и получает их результаты по завершении, вместо того чтобы приостанавливать разговор в ожидании. Claude по-прежнему запускает подагента на переднем плане, когда ему нужен результат перед продолжением, и фоновые подагенты выводят каждый запрос разрешения в вашу основную сессию. Закрепите поведение подагента с помощью поля frontmatter <code>background</code>.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Другие достижения</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/ru/docs/artifacts">Artifacts</a> теперь общедоступны и включены в планы Pro и Max, присоединяясь к Team и Enterprise</div>
    <div>Администраторы могут установить <a href="/docs/ru/docs/model-config#organization-default-model">модель по умолчанию организации</a> в консоли организации; она отображается как "Org default" в <code>/model</code>, когда вы сами не выбрали модель</div>
    <div>Стекированные вызовы навыков, такие как <code>/skill-a /skill-b do XYZ</code>, теперь загружают все ведущие навыки (до 5), а не только первый</div>
    <div>Диалоги <code>AskUserQuestion</code> больше не продолжаются автоматически по умолчанию; выберите timeout неактивности через <code>/config</code></div>
    <div>Режим разрешения "default" теперь называется "Manual" во всём CLI, `--help`, VS Code и JetBrains; `--permission-mode manual` принимается наряду с `default`</div>
    <div>Новый навык <code>/dataviz</code> предоставляет рекомендации по дизайну диаграмм и панелей управления с валидатором палитры цветов, который можно запустить</div>
    <div>Встроенный агент Explore теперь наследует модель основной сессии (ограничена Opus) вместо работы на Haiku</div>
    <div>Фоновые агенты, запущенные из <code>claude agents</code>, теперь фиксируют, отправляют и открывают черновик PR по завершении работы с кодом в worktree, вместо того чтобы останавливаться и спрашивать</div>
    <div>Матчеры hooks с дефисными идентификаторами, такие как <code>code-reviewer</code>, теперь точно совпадают вместо частичного совпадения; используйте <code>mcp\_\_brave-search\_\_.\*</code> для совпадения всех инструментов с дефисного сервера MCP</div>
    <div>Временные ошибки ограничения скорости сервера, не связанные с вашим лимитом использования, теперь автоматически повторяются с отступом для подписчиков вместо отказа в ходе</div>
    <div>Watchdog неактивности потока теперь включён по умолчанию для всех поставщиков: он прерывает и повторяет попытку, когда поток ответа не производит событий в течение 5 минут (<code>CLAUDE\_ENABLE\_STREAM\_WATCHDOG=0</code> для отключения)</div>
  </div>
</div>
