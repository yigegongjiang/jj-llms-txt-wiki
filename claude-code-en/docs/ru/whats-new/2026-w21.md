<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/ru/costs#track-your-costs"><code>/usage</code></a> теперь показывает разбивку по категориям того, что влияет на ограничения вашего плана, приписывая недавнее использование skills, subagents, plugins и отдельным MCP servers</div>
    <div>"Extra usage" переименовано в "usage credits" по всему CLI, и <code>/extra-usage</code> теперь <code>/usage-credits</code>. Старое имя по-прежнему работает.</div>
    <div>Новая команда <a href="/docs/ru/code-review"><code>/code-review</code></a> сообщает об ошибках корректности на выбранном уровне усилий, таком как <code>/code-review high</code>, и <code>--comment</code> публикует результаты как встроенные комментарии GitHub PR. <code>/simplify</code> остается отдельной проверкой только для очистки.</div>
    <div>Фоновые сеансы теперь появляются в <code>/resume</code> наряду с интерактивными, отмеченные <code>bg</code>, и сеансы, закрепленные с помощью <code>Ctrl+T</code> в <code>claude agents</code>, остаются активными при неактивности</div>
    <div><code>claude agents --json</code> выводит список активных сеансов в формате JSON для написания скриптов, таких как строки состояния и средства выбора сеансов</div>
    <div>Инструмент PowerShell теперь включен по умолчанию на Windows для пользователей Amazon Bedrock, Google Cloud's Agent Platform и Microsoft Foundry; отключите с помощью <code>CLAUDE\_CODE\_USE\_POWERSHELL\_TOOL=0</code></div>
    <div><code>claude plugin disable</code> теперь отказывает, когда другой включенный plugin зависит от целевого, и <code>claude plugin enable</code> принудительно включает переходные зависимости</div>
    <div>Панель просмотра marketplace <code>/plugin</code> показывает прогнозируемую стоимость контекста, а экраны Discover и Browse выводят список команд, agents, skills, hooks и MCP/LSP servers плагина перед установкой</div>
    <div>Новый параметр <code>worktree.bgIsolation: "none"</code> позволяет фоновым сеансам редактировать рабочую копию напрямую без <code>EnterWorktree</code>, для репозиториев, где worktrees непрактичны</div>
    <div>Вывод Markdown отображает флажки списка задач GFM, и представление деталей <code>/diff</code> прокручивается с помощью клавиатуры</div>
    <div>Входные данные JSON строки состояния теперь включают информацию о репозитории GitHub и PR при обнаружении</div>
    <div>Enterprise: управляемый параметр <code>allowAllClaudeAiMcps</code> загружает соединители облачных MCP claude.ai наряду с <code>managed-mcp.json</code></div>
  </div>
</div>
