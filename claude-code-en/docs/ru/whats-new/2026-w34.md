Запустите его с кратким описанием, и Claude опубликует холст с редактируемыми артбордами для вашего UI. Выберите один, отредактируйте его, а затем попросите Claude реализовать его. Доступно для Pro, Max, Team и Enterprise. Требуется v2.1.234 или позже.</p>


  <p className="digest-feature-try">Claude выводит ссылку на опубликованный холст. Откройте его, выберите артборд и скажите Claude, какой вариант реализовать.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Стиль вывода Concise</span>
    <span className="digest-feature-pill">v2.1.237</span>
  </div>

  <p className="digest-feature-lede">Concise — это новый встроенный стиль вывода. Claude начинает с результата и пропускает преамбулу и повествование, при этом выполняя работу так же тщательно, как в стиле Default. Когда вы просите объяснение или больше деталей, Claude отвечает полностью. Отчеты об ошибках, предупреждения безопасности и подтверждения для деструктивных действий сохраняют свое полное содержание.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/2SnAdpL4dJ18nKb3/images/whats-new/concise-output-style.mp4?fit=max&auto=format&n=2SnAdpL4dJ18nKb3&q=85&s=dfb40ec8921ed1bc82eb629042a8ec17" data-path="images/whats-new/concise-output-style.mp4" />
  </Frame>

  <p className="digest-feature-try">Включите его в разделе <strong>Output style</strong> в <code>/config</code> или установите в файле параметров:</p>

  ```json ~/.claude/settings.json {2} theme={null}
  {
    "outputStyle": "Concise"
  }
  ```

  <p className="digest-feature-try">Запустите <code>/clear</code> или начните новый сеанс, и ответы Claude будут начинаться с результата.</p>

  <a className="digest-feature-link" href="/docs/ru/output-styles#built-in-output-styles">Встроенные стили вывода</a>

<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div>Claude Code теперь автоматически продолжает ваш сеанс, когда сбрасывается лимит использования claude.ai; отключите это из строки <strong>Continue automatically at usage limit</strong> в <code>/config</code></div>
    <div>Дополнительный параметр <a href="/docs/ru/interactive-mode#check-spelling-as-you-type"><code>spellcheck</code></a> подчеркивает неправильно написанные слова в поле ввода подсказки по мере ввода, используя установленный <code>aspell</code>, <code>hunspell</code> или <code>ispell</code></div>
    <div>На ветке с открытым запросом на слияние GitLab, с аутентифицированным CLI <code>glab</code> через <code>glab auth login</code>, нижний колонтитул показывает значок <a href="/docs/ru/interactive-mode#gitlab-merge-requests"><code>MR !N</code></a>, окрашенный в зависимости от того, является ли запрос на слияние черновиком, открытым или готовым к слиянию</div>
    <div>Измените уровень усилий со своего телефона или claude.ai/code, и он <a href="/docs/ru/remote-control#what-connected-devices-see">применится к сеансу на вашей машине</a>; сеансы Remote Control, размещенные на Desktop или VS Code, также показывают подключенным устройствам текущий режим разрешений сеанса</div>
    <div>Вы можете открыть <a href="/docs/ru/permissions#manage-permissions"><code>/permissions</code></a> или запустить <code>/add-dir \<path></code>, пока Claude работает; изменения правил разрешений применяются к остальной части текущего хода</div>
    <div>Когда фоновые задачи держат <a href="/docs/ru/goal#background-work-defers-evaluation"><code>/goal</code></a> в ожидании, Claude проверяет их через 30 минут вместо неопределенного ожидания и продолжает проверять с более длительными интервалами, пока сеанс неактивен; установите <code>CLAUDE\_CODE\_GOAL\_CHECKIN\_MINUTES=0</code>, чтобы отказаться</div>
    <div>Ваши собственные подсказки теперь отображают markdown в стенограмме с выделенными блоками кода, встроенным кодом и списками, так же как и ответы</div>
    <div>Новая переменная окружения <a href="/docs/ru/model-config#set-a-default-model-for-new-sessions"><code>ANTHROPIC\_DEFAULT\_MODEL</code></a> устанавливает модель, на которой начинаются новые сеансы; выбор <code>/model</code> по-прежнему переопределяет его и сохраняется при перезагрузке</div>
    <div>С входом <code>notify\_when\_idle</code> на <code>SendMessage</code>, Claude может попросить другой сеанс Claude Code на той же машине <a href="/docs/ru/cross-session-messaging#get-a-notice-when-another-session-goes-idle">отправить одно уведомление, когда он в следующий раз перейдет в режим ожидания</a></div>
    <div>Установите <a href="/docs/ru/interactive-mode#make-ctrl-w-delete-back-to-whitespace"><code>keybindingFlavor</code></a> на <code>"readline"</code>, чтобы сделать <code>Ctrl+W</code> в подсказке удаляющим до предыдущего пробела, как это делает Bash, вместо остановки на пунктуации, такой как <code>/</code></div>
    <div>На собственном Windows ваши сеансы Claude Code теперь могут <a href="/docs/ru/cross-session-messaging#availability">обмениваться сообщениями друг с другом</a> с помощью <code>SendMessage</code> и находить друг друга с помощью <code>ListAgents</code>, как на macOS и Linux</div>
    <div>Самостоятельно размещаемые средства выполнения принимают `--defer-shutdown-max-min`, который <a href="/docs/ru/self-hosted-environments-deploy#defer-the-drain-past-the-first-signal">продолжает обслуживать подключенные сеансы</a> в течение установленного количества минут после SIGTERM</div>
    <div>Самостоятельно размещаемые средства выполнения принимают `--proxy-authorization-command` или `--proxy-authorization-file` для предоставления свежего заголовка `Proxy-Authorization` для <a href="/docs/ru/self-hosted-environments-deploy#authenticate-to-an-egress-proxy">прокси-серверов исходящего трафика, которые требуют его</a></div>
  </div>
</div>
