  <p className="digest-feature-lede"><code>/doctor</code> теперь диагностирует проблемы и может их исправить вместо вывода отчета только для чтения. Он проверяет здоровье установки, находит неиспользуемые skills, MCP серверы и plugins в сравнении с их стоимостью контекста, дедублирует локальные файлы <code>CLAUDE.md</code> в сравнении с зафиксированными, предлагает сокращение содержимого <code>CLAUDE.md</code>, которое Claude может вывести из кодовой базы, и отмечает медленные hooks. Он сначала сообщает о результатах и просит подтверждение перед внесением каких-либо изменений. <code>/checkup</code> — это его псевдоним.</p>

  <p className="digest-feature-try">Запустите проверку из любого сеанса:</p>

  ```text Claude Code theme={null}
  > /doctor
  ```
