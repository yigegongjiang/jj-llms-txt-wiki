  <p className="digest-feature-lede">Опубликованный артефакт теперь может вызывать MCP коннекторы каждый раз, когда кто-то его просматривает, поэтому панель управления показывает живые данные и может выполнять действия по требованию, а не снимок из сеанса, который её создал. Каждый вызов выполняется через собственные подключения учётной записи зрителя, и зрители одобряют доступ перед первым вызовом коннектора на странице. На этой неделе также добавлены ссылки для публичного общего доступа, роли редактора для совместного редактирования в планах Team и Enterprise, а также артефакты, созданные из сеансов Claude Tag.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Режим чтения с экрана</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">Режим чтения с экрана заменяет визуальный интерфейс терминала простым линейным текстом: вместо прямоугольников, спиннеров и перерисовок на месте, Claude Code выводит помеченные строки, которые программа чтения с экрана, такая как VoiceOver или NVDA, читает по порядку, поэтому вы можете одобрить разрешения и просмотреть вывод от начала до конца. Включите его для каждого сеанса с флагом, для каждой оболочки с переменной окружения <code>CLAUDE\_AX\_SCREEN\_READER</code> или везде с параметром <code>axScreenReader</code>.</p>

  <p className="digest-feature-try">Запустите сеанс в режиме чтения с экрана:</p>

  ```bash terminal theme={null}
  claude --ax-screen-reader
  ```

  <a className="digest-feature-link" href="/docs/ru/accessibility#turn-on-screen-reader-mode">Включите режим чтения с экрана</a>
</div>

  <div className="digest-wins-grid">
    <div><code>/fork</code> теперь копирует вашу беседу в новый фоновый сеанс с собственной строкой в <code>claude agents</code>, пока вы продолжаете работать; запущенный в сеансе разветвлённый подагент, который он использовал, теперь называется <code>/subtask</code></div>
    <div><a href="/docs/ru/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">Автоматический режим</a> больше не требует согласия <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE</code> на Amazon Bedrock, Agent Platform Google Cloud и Microsoft Foundry; администраторы могут отключить его с помощью <code>disableAutoMode</code></div>
    <div>Вызовы инструментов MCP, которые выполняются дольше двух минут, теперь автоматически переходят в фоновый режим, чтобы сеанс оставался пригодным для использования; настройте или отключите порог с помощью <code>CLAUDE\_CODE\_MCP\_AUTO\_BACKGROUND\_MS</code></div>
    <div>Новая команда <code>claude auto-mode reset</code> восстанавливает конфигурацию автоматического режима по умолчанию, а <code>--yes</code> пропускает запрос подтверждения</div>
    <div>Новая поддержка <a href="/docs/ru/corporate-launcher">корпоративного средства запуска</a>: <code>CLAUDE\_CODE\_PROCESS\_WRAPPER</code> или параметр <code>processWrapper</code> запускает процессы, которые Claude Code запускает из собственного двоичного файла, такие как фоновая служба и сеансы просмотра агента, через требуемый исполняемый файл-обёртка</div>
    <div>Параметр <code>vimInsertModeRemaps</code> отображает двухклавишные последовательности режима вставки, такие как <code>jj</code>, на Escape в режиме vim</div>
    <div><code>--forward-subagent-text</code> и <code>CLAUDE\_CODE\_FORWARD\_SUBAGENT\_TEXT</code> включают текст подагента и блоки размышлений в <a href="/docs/ru/headless">вывод stream-json</a></div>
    <div>Ограничения на уровне сеанса останавливают бесконечные циклы: вызовы WebSearch и порождение подагентов по умолчанию составляют 200, настраиваются с помощью <code>CLAUDE\_CODE\_MAX\_WEB\_SEARCHES\_PER\_SESSION</code> и <code>CLAUDE\_CODE\_MAX\_SUBAGENTS\_PER\_SESSION</code></div>
    <div>Правила разрешений «Всегда разрешить» сохраняются в корне репозитория, поэтому одобрения, предоставленные в git worktree, сохраняются в сеансах и worktrees</div>
    <div>Amazon Bedrock, Agent Platform Google Cloud и Claude Platform на AWS теперь по умолчанию используют Claude Opus 4.8</div>
    <div>Свёрнутая строка сводки инструмента показывает счётчик прошедшего времени в реальном времени, поэтому долгие вызовы инструментов видимо отсчитываются, а не выглядят зависшими</div>
  </div>
