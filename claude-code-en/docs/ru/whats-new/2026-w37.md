    <span className="digest-feature-pill">v2.1.269</span>

  <p className="digest-feature-lede"><code>claude plugin eval</code> запускает ваш плагин на наборе тестовых случаев, оценивает результаты и по умолчанию запускает каждый случай снова без плагина, чтобы вы могли увидеть, что он добавляет. <code>claude plugin eval init</code> спрашивает вас, как должен выглядеть хороший результат, затем предлагает тестовые случаи и проверки, которые их оценивают, пробует набор один раз и записывает файлы. Каждый запуск и каждая проверка, которая имеет второго судью модели для ответа, — это реальный вызов модели на вашем счёте.</p>

    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/plugin-eval.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=913066f6d4a2a15426e98a627802f47f" alt="Вывод терминала claude plugin eval: таблица из семи случаев с оценкой каждого случая с плагином и без плагина, разницей между ними, количеством запусков и стоимостью, за которой следует строка сводки со средней разницей, общей продолжительностью и общей стоимостью" width="1600" height="900" data-path="images/whats-new/plugin-eval.jpg" />
  </Frame>

  <p className="digest-feature-try">Из корневого каталога вашего плагина попросите Claude составить набор:</p>

  ```bash terminal theme={null}
  claude plugin eval init
  ```

  <p className="digest-feature-try">Когда Claude скажет вам, что набор готов, выйдите из сеанса, который открыл <code>claude plugin eval init</code>, и запустите <code>claude plugin eval .</code> для оценки каждого случая. Таблица сводки выводится в ваш терминал, а <code>report.html</code> в <code>evals/results/</code> содержит детали каждого запуска.</p>

  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div>Установите <a href="/docs/ru/settings-reference#maxeffortlevel"><code>maxEffortLevel</code></a> на верхнем уровне или для каждой модели в <code>modelSettings</code>, чтобы ограничить уровень усилий на каждом поставщике, включая Amazon Bedrock, Google Cloud's Agent Platform и Microsoft Foundry; любой более высокий уровень работает на пределе</div>
    <div>Укажите `--plugin-dir` на папку плагинов, чтобы <a href="/docs/ru/plugins/create#load-a-directory-or-archive-for-one-session">загрузить каждую непосредственную подпапку, которая имеет манифест</a></div>
    <div>Если WebFetch не завершил загрузку страницы в течение пяти минут, <a href="/docs/ru/tools-reference#webfetch-tool-behavior">загрузка завершается с ошибкой истечения срока</a> вместо зависания; установите <code>CLAUDE\_CODE\_WEBFETCH\_DEADLINE\_MS</code> для изменения срока или на <code>0</code> для удаления ограничения</div>
    <div>Передайте `--json` в <code>claude plugin install</code>, <code>uninstall</code>, <code>update</code>, <code>enable</code> или <code>disable</code>, чтобы вывести результат как <a href="/docs/ru/plugins/cli-reference#plugin-json-result">один объект JSON в последней строке stdout</a></div>
    <div>Когда классификатор автоматического режима блокирует действие, причина, которую получает Claude, <a href="/docs/ru/auto-mode-config#fix-a-denial-with-an-allow-rule-an-environment-entry-or-a-retry">обычно называет правило, которое совпало</a>, например <code>\[Data Exfiltration]</code></div>
    <div>Когда вы вводите <code>/</code> в середине подсказки, вы теперь можете выбрать из <a href="/docs/ru/interactive-mode#complete-a-command-mid-prompt">списка соответствующих команд</a> вместо одного предложения. Список открывается по мере ввода в полноэкранном режиме. Навык плагина также совпадает по его имени без префикса плагина</div>
    <div>В расширении VS Code нажмите на количество агентов в нижней части поля подсказки, чтобы открыть <a href="/docs/ru/vs-code#use-the-prompt-box">карту агентов</a>, где вы можете открыть транскрипт подагента только для чтения или остановить его</div>
    <div>В расширении VS Code выберите <strong>Hooks</strong> или <strong>Permissions</strong> в разделе Customize меню команд, чтобы <a href="/docs/ru/vs-code#use-the-prompt-box">добавить или удалить hooks и правила разрешений</a> в ваших пользовательских, проектных и локальных параметрах</div>
    <div>Claude может выбрать <a href="/docs/ru/artifacts#create-an-artifact">значок вкладки браузера</a> для соответствия каждому артефакту, который он публикует</div>
    <div>В Claude Code в веб-версии отозвите поставленное в очередь сообщение в облачном сеансе до того, как Claude его прочитает: удалите его из очереди или нажмите <code>Esc</code> или <code>Up</code>, и текст вернётся в поле сообщения</div>
  </div>
</div>
