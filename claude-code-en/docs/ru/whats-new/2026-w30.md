> Opus 5 становится моделью Opus по умолчанию, Claude Code Desktop добавляет панель iOS Simulator, а плагин Claude Security сканирует ваш код на уязвимости.

Fast mode переходит на Opus 5 по цене \$10/\$50 за MTok. Требуется v2.1.219 или позже.</p>

Когда Claude собирает, запускает или проверяет ваше приложение в симуляторе, панель открывается рядом с беседой и транслирует экран устройства в реальном времени, так что вы можете наблюдать, как Claude нажимает на приложение для проверки его изменений, или управлять устройством самостоятельно. Требуется Xcode с установленной платформой iOS и Claude Desktop v1.24012.0 или позже.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Плагин Claude Security</span>
    <span className="digest-feature-pill">плагин</span>
  </div>

  <p className="digest-feature-lede">Плагин Claude Security запускает многоагентное сканирование уязвимостей вашей кодовой базы внутри сеанса Claude Code: агенты отображают вашу архитектуру, создают модель угроз, ищут уязвимости и независимо проверяют каждый результат перед написанием отчета в директорию <code>CLAUDE-SECURITY-\<timestamp>/</code>. Сканируйте весь репозиторий или только diff ветки, pull request или отдельный коммит, затем превратите выбранные вами результаты в проверенные патчи, которые вы применяете самостоятельно.</p>

  <p className="digest-feature-try">Установите плагин из официального маркетплейса Anthropic, запустите <code>/reload-plugins</code>, затем начните сканирование с помощью <code>/claude-security</code>:</p>

  ```text Claude Code theme={null}
  > /plugin install claude-security@claude-plugins-official
  ```

  <a className="digest-feature-link" href="/docs/ru/claude-security#scan-and-fix-your-codebase">Сканируйте и исправляйте вашу кодовую базу</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/ru/code-review#review-a-diff-locally"><code>/code-review</code></a> теперь работает как фоновый подагент с собственным окном контекста, поэтому работа по проверке остаётся вне вашей беседы и результаты приходят при завершении</div>
    <div><code>/verify</code>, <code>/code-review</code> и <code>/deep-research</code> запускаются только при их вызове; Claude больше не запускает их самостоятельно</div>
    <div><a href="/docs/ru/interactive-mode#emoji-shortcodes">Сокращённые коды эмодзи</a> автодополняются в поле ввода подсказки: введите <code>:heart:</code> для вставки эмодзи или два или более символов после <code>:</code> для предложений; отключите с помощью <code>emojiCompletionEnabled</code></div>
    <div>Skills с <code>context: fork</code> <a href="/docs/ru/skills#run-skills-in-a-subagent">работают в фоне</a> по умолчанию, и <code>background: false</code> в frontmatter skill ждёт результата в том же ходу</div>
    <div>Сеанс запускает до 20 подагентов одновременно по умолчанию; измените <a href="/docs/ru/sub-agents#concurrent-subagent-limit">лимит</a> с помощью <code>CLAUDE\_CODE\_MAX\_CONCURRENT\_SUBAGENTS</code></div>
    <div>`--max-budget-usd` теперь применяет ограничение на подагентов: как только расходы достигают его, Claude не может запустить больше и работающие фоновые подагенты останавливаются</div>
    <div>Новая настройка <a href="/docs/ru/sandboxing#disable-filesystem-isolation"><code>sandbox.filesystem.disabled</code></a> пропускает изоляцию файловой системы, сохраняя контроль исходящего сетевого трафика</div>
    <div>В режиме auto проверки опасных команд <code>rm</code>, фоновых заданий и подозрительных путей Windows больше не открывают диалоги разрешений; вместо этого их рассматривает классификатор режима auto</div>
    <div>Проверки разрешений Bash завершаются неудачей на большем количестве форм оболочки, включая перенаправления дескрипторов файлов, подписки переменных Zsh в сравнениях <code>\[\[ ]]</code>, вызовы <code>help</code> и <code>man</code>, которые могут запустить небезопасные опции, и команды длиной более 10 000 символов</div>
    <div><a href="/docs/ru/fast-mode">Fast mode</a> больше не поддерживает Opus 4.7: <code>/fast</code> теперь применяется к Opus 5 и Opus 4.8</div>
    <div>Долгоживущие вызовы инструментов выдают периодический импульс прогресса вместо молчания</div>
  </div>
</div>
