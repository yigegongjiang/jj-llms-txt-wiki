<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div>В <code>claude agents</code> добавьте префикс команды оболочки с помощью <code>!</code>, чтобы запустить её как фоновое задание, к которому вы можете подключаться и отключаться; также доступно как <code>claude --bg --exec 'pytest -x'</code></div>
    <div>Плагины в директориях <code>.claude/skills</code> теперь загружаются автоматически, без необходимости в marketplace, и <code>claude plugin init \<name></code> создаёт каркас нового плагина</div>
    <div>Новая команда <code>/reload-skills</code> повторно сканирует директории skills без перезагрузки, и hooks <code>SessionStart</code> могут возвращать <code>reloadSkills: true</code>, чтобы сделать skills, которые они устанавливают, доступными в том же сеансе</div>
    <div>Skills и команды могут устанавливать <code>disallowed-tools</code> в frontmatter, чтобы удалить инструменты из модели, пока skill активен</div>
    <div>Новое событие hook <code>MessageDisplay</code> позволяет hooks преобразовывать или скрывать текст сообщения помощника при его отображении</div>
    <div>Claude Code теперь переключается на ваш настроенный <code>--fallback-model</code> для остальной части сеанса, когда основная модель не найдена, вместо того чтобы не выполнять каждый запрос</div>
    <div>Плагины могут объявлять <code>defaultEnabled: false</code> в <code>plugin.json</code> или записи marketplace, поэтому они устанавливаются без включения, пока вы их не включите</div>
    <div>Режим Vim: <code>/</code> в режиме NORMAL открывает поиск истории в обратном направлении, соответствуя Bash и Zsh vi-mode</div>
    <div>Потоковое выполнение инструментов теперь всегда включено, включая с отключённой телеметрией и на Amazon Bedrock, Google Cloud's Agent Platform и Microsoft Foundry</div>
    <div><code>←←</code> для открытия представления agents теперь работает на Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry и с отключённой телеметрией</div>
    <div>Claude в Chrome: выберите, какой подключённый браузер использовать через <code>/chrome</code> → "Select browser…", или в чате, когда действие браузера выполняется с несколькими подключёнными</div>
    <div><code>claude mcp list</code> и <code>claude mcp get</code> теперь показывают неодобренные серверы <code>.mcp.json</code> как ожидающие одобрения вместо автоматического одобрения и подключения, когда вывод передаётся по конвейеру</div>
  </div>
</div>
