Теперь вы можете включить его, не покидая терминал: <code>/autofix-pr</code> определяет открытый PR для вашей текущей ветки и включает автоисправление для него в Claude Code в веб-версии за один шаг.     <div><code>/agents</code> получает макет с вкладками: вкладка Running показывает активные подагенты с подсчётом <code>● N running</code>, плюс действия Run agent и View running instance на вкладке Library</div>

    <div><code>/cost</code> показывает разбивку по моделям и попаданиям в кэш для пользователей подписки</div>

    <div><code>CLAUDE\_CODE\_PERFORCE\_MODE</code>: Edit/Write завершаются ошибкой на файлах только для чтения с подсказкой <code>p4 edit</code> вместо молчаливого перезаписывания</div>

    <div>Усиленные разрешения инструмента Bash: флаги с обратной косой чертой, префиксы переменных окружения, перенаправления <code>/dev/tcp</code> и составные команды теперь правильно запрашивают подтверждение</div>
