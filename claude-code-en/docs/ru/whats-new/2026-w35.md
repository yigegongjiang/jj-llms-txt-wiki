    <span className="digest-feature-pill">CLI</span>

  <p className="digest-feature-lede">Когда инструмент продолжает давать сбой, Claude не может помочь с запросом или вы указываете на ошибку, Claude теперь подготавливает отчет об обратной связи для вас с помощью инструмента <code>SendFeedback</code>. Карточка над вашей подсказкой показывает черновик, и вы можете просмотреть, отправить или отклонить его оттуда. Ничего не достигает Anthropic, пока вы это не отправите. Требуется v2.1.238 или позже.</p>

    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/claude-drafted-feedback.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=5cacb3be0dffd1cbd417381f3721637e" alt="Сеанс Claude Code, где Claude подготовил отчет об ошибке под названием Sandbox image pull fails behind proxy, показанный как карточка над подсказкой с опциями для просмотра, отправки или отклонения" width="1440" height="756" data-path="images/whats-new/claude-drafted-feedback.jpg" />

  <p className="digest-feature-try">Выполните <code>/feedback</code> без аргумента, чтобы открыть вашу очередь черновиков из каждого сеанса:</p>

  ```text Claude Code theme={null}
  > /feedback
  ```

  <p className="digest-feature-try">Выберите черновик, затем отредактируйте, отправьте или отклоните его. Чтобы отключить подготовку, установите <strong>Claude-drafted feedback</strong> на <code>off</code> в <code>/config</code>.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Режим ограничений</span>
    <span className="digest-feature-pill">v2.1.248</span>
  </div>

  <p className="digest-feature-lede">Режим ограничений запускает Claude Code без встроенных инструментов, которые выполняют команды или код. Используйте его, когда оценочная система управляет <code>claude</code> на общем компьютере. Запустите его с помощью `--restricted` или установите <code>CLAUDE\_CODE\_RESTRICTED=1</code>. Claude Code также удаляет <code>WebFetch</code>, ограничивает инструменты файлов рабочими каталогами, загружает только управляемые параметры и `--settings`, и отказывает в режиме разрешения <code>bypassPermissions</code>.</p>

  <p className="digest-feature-try">Выполните неинтерактивный запрос без инструментов для выполнения команд:</p>

  ```bash terminal theme={null}
  claude --restricted -p "review src/ for SQL injection risks"
  ```

  <p className="digest-feature-try">Чтобы вернуть Claude один из удаленных инструментов, перечислите его в `--tools` вместе с другими встроенными инструментами, которые вы хотите, например `--tools "Bash,Read,Edit"`. `--tools` — это список разрешений, и его предустановка <code>default</code> не восстанавливает удаленные инструменты.</p>

  <a className="digest-feature-link" href="/docs/ru/cli-reference#cli-flags">Флаги CLI</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div>Установите новый параметр <a href="/docs/ru/settings-reference#modelpicker"><code>modelPicker</code></a>, чтобы расширить или заменить встроенный список средства выбора <code>/model</code> вашими собственными упорядоченными, помеченными записями, включая идентификаторы моделей Amazon Bedrock или Google Cloud's Agent Platform</div>
    <div>Установите <a href="/docs/ru/prompt-caching#choose-the-ttl-yourself"><code>promptCacheTtl</code></a> на <code>1h</code>, чтобы сохранить кэш подсказок на один час в основной беседе при использовании ключа API или поставщика облачных услуг; <code>subagentPromptCacheTtl</code> устанавливает TTL для подагентов и всех других запросов вне основной беседы</div>
    <div>В планах Pro, Max, Team и Enterprise <a href="/docs/ru/costs#plan-usage-breakdown"><code>/usage</code></a> добавляет разбивку Loops: количество запусков, общее количество токенов, токены на запуск и последний запуск для <code>/loop</code> и запланированных задач, которые использовали наибольшее количество токенов</div>
    <div>Организации с договорными ставками могут установить управляемый параметр <a href="/docs/ru/costs#report-spend-at-your-contracted-rates"><code>modelPricing</code></a>, чтобы <code>/usage</code>, строка состояния и OpenTelemetry сообщали стоимость по этим ставкам вместо прейскурантной цены</div>
    <div><code>/login</code> предлагает <strong>Войти с помощью учетной записи Console</strong> в разделе опции <strong>Учетная запись Anthropic Console</strong>, поэтому члены организаций Console, которые не разрешают ключи API, могут войти без создания одного</div>
    <div>Выполните <code>/permissions</code> и откройте новую <a href="/docs/ru/auto-mode-config#edit-rules-from-permissions"><strong>вкладку Auto mode</strong></a>, чтобы просмотреть и отредактировать правила классификатора автоматического режима без открытия файла параметров</div>
    <div>Когда автоматический режим доступен, подсказки разрешения Bash в режимах Manual и <code>acceptEdits</code> предлагают опцию <a href="/docs/ru/permission-modes#switch-permission-modes"><strong>Да, и переключиться на автоматический режим</strong></a>; выберите ее, чтобы одобрить команду и переключить сеанс на автоматический режим</div>
    <div>После того как вы <a href="/docs/ru/permissions#move-the-session-to-another-directory">переместите сеанс с помощью <code>/cd</code></a>, параметры проекта нового каталога, hooks, серверы <code>.mcp.json</code>, skills и подагенты вступают в силу немедленно вместо следующего `--resume`</div>
    <div>В неинтерактивных сеансах, включая запуски `-p`, запуски Agent SDK и облачные сеансы, Claude Code <a href="/docs/ru/errors#the-response-above-may-be-incomplete">продолжает ответ</a>, который ошибка сервера, разорванное соединение или зависание прервали в середине потока, когда частичный ответ содержит текст и не содержит вызовов инструментов</div>
    <div>Подагент, который останавливается на пределе <code>maxTurns</code>, возвращает свой вывод, отмеченный как частичный, с подсказкой о том, что Claude может <a href="/docs/ru/sub-agents#resume-subagents">продолжить его с помощью <code>SendMessage</code></a>, вместо того чтобы казаться завершенным</div>
    <div>На Amazon Bedrock, Google Cloud's Agent Platform и Microsoft Foundry сеансы на одном компьютере теперь могут <a href="/docs/ru/cross-session-messaging#availability">обмениваться сообщениями друг с другом</a>, <code>/loop</code> может <a href="/docs/ru/scheduled-tasks#let-claude-choose-the-interval">выбрать свой собственный интервал</a>, и <code>/model</code> и <code>/effort</code> применяются немедленно вместо после завершения хода</div>
    <div>Встроенный установщик и автоматический обновитель загружают сборку, сжатую с помощью zstd, примерно 75 МБ вместо 340 МБ на Linux x64, и встроенные сборки загружают код по требованию, используя примерно на 40–70 МБ меньше памяти на сеанс</div>
  </div>
