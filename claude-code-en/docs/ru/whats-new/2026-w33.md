  <p className="digest-feature-lede">Когда вы достигаете лимита сеанса на вкладке Code в Claude Code Desktop, карточка лимита теперь предлагает флажок <strong>Автоматически продолжить при сбросе лимитов</strong>. Установите его, и приложение Desktop повторит прерванный ход после сброса. Карточка показывает время повтора. Карточка еженедельного лимита такой опции не предлагает.</p>

  <p className="digest-feature-try">В следующий раз, когда появится карточка лимита сеанса, установите флажок <strong>Автоматически продолжить при сбросе лимитов</strong> и оставьте сеанс открытым. Карточка показывает <code>Auto-resuming at</code> с указанием времени сброса, и ход продолжится автоматически после сброса лимита.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Режим fork включен по умолчанию</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">Режим fork теперь включен по умолчанию в интерактивных сеансах. Claude может запросить тип подагента <code>fork</code>, который наследует полный разговор и кэш подсказок вместо начала с нуля, поэтому вам не нужно переобъяснять контекст для побочной задачи. Подагенты, которые Claude создает в интерактивных сеансах, кроме тех, которых создают товарищи по команде агентов, также работают в фоновом режиме по умолчанию.</p>

  <p className="digest-feature-try">Запустите fork самостоятельно с задачей, которая требует всего, что вы обсуждали до сих пор:</p>

  ```text Claude Code theme={null}
  > /subtask draft unit tests for the parser changes so far
  ```

  <p className="digest-feature-try">Fork появляется на панели ниже вашей подсказки, и его результат поступает в ваш разговор после завершения. Чтобы отключить режим fork, установите <code>CLAUDE\_CODE\_FORK\_SUBAGENT=0</code>.</p>

  <a className="digest-feature-link" href="/docs/ru/sub-agents#turn-fork-mode-on-or-off">Включение или отключение режима fork</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Запросы на слияние GitLab и маркетплейсы</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">Маркетплейсы плагинов клонируют простые URL-адреса <code>gitlab.com</code>, включая вложенные подгруппы. На v2.1.233 или позже передайте URL запроса на слияние GitLab в <code>--worktree</code> для ветвления от него, и представление <code>claude agents</code> помечает сеансы, связанные с запросом на слияние, как <code>!N</code>. Claude Code также скрывает семейства токенов GitLab, такие как <code>glpat-</code> и <code>glrt-</code>, и защищает хранилище конфигурации CLI <code>glab</code> так же, как защищает <code>gh</code>.</p>

  <p className="digest-feature-try">Запустите сеанс в worktree, ветвленном от запроса на слияние:</p>

  ```bash terminal theme={null}
  claude --worktree https://gitlab.com/group/project/-/merge_requests/42
  ```

  <p className="digest-feature-try">Когда <code>origin</code> находится на gitlab.com, Claude Code получает <code>merge-requests/42/head</code> и открывает сеанс на этой ветви в собственном worktree.</p>

  <a className="digest-feature-link" href="/docs/ru/worktrees#branch-from-a-pull-request">Ветвление worktree от запроса на слияние или pull request</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div>Введите <code>@</code> в подсказку, чтобы <a href="/docs/ru/cross-session-messaging#message-another-session">упомянуть другой сеанс Claude</a> по имени, и Claude отправит ему сообщение напрямую с помощью <code>SendMessage</code>; простое имя, которое точно совпадает с одним активным сеансом, теперь доставляется без шага подтверждения</div>
    <div>Интерактивные сеансы на одной машине сохраняют <a href="/docs/ru/cross-session-messaging#see-which-sessions-claude-can-reach">уникальные имена</a>: если вы запустите или переименуете сеанс с именем, которое уже использует другой активный сеанс, Claude Code присвоит вашему сеансу вариант <code>name-word-word</code> и сообщит вам об этом</div>
    <div>Маркетплейсы плагинов принимают <a href="/docs/ru/plugins/marketplace-reference#command-plugin-source">источники <code>command</code></a>: локальная команда выводит каталог плагина, который Claude Code повторно разрешает каждый сеанс и применяет без перезагрузки</div>
    <div>На Linux и WSL установите <a href="/docs/ru/tools-reference#memory-limit-on-linux-and-wsl"><code>CLAUDE\_CODE\_TOOL\_MEMORY\_LIMIT</code></a> на размер, например <code>4G</code>, чтобы ограничить память, которую могут использовать команды инструментов Bash и PowerShell</div>
    <div>Инструменты отслеживания задач, такие как <code>TaskCreate</code>, <code>TaskUpdate</code> и <code>TodoWrite</code>, <a href="/docs/ru/tools-reference#task-tool-availability">больше не доступны на Opus 4.8, Sonnet 5, Fable 5, Mythos 5 и более поздних моделях в этих семействах</a>; установите <code>CLAUDE\_CODE\_ENABLE\_TODO\_TOOLS=1</code> для их повторного включения</div>
    <div><a href="/docs/ru/code-review#review-a-diff-locally"><code>/code-review</code></a> при высоком, очень высоком и максимальном уровне усилий теперь работает в фоновом агенте, как и другие уровни</div>
    <div><a href="/docs/ru/plugins/install#install-a-plugin"><code>/plugin install plugin\@marketplace</code></a> сначала обновляет маркетплейс, поэтому недавно опубликованные плагины устанавливаются без ручного обновления маркетплейса</div>
    <div>Параметры принимают <a href="/docs/ru/settings-reference#marketplace-key-aliases"><code>additionalMarketplaces</code> и <code>allowedMarketplaces</code></a> как псевдонимы для <code>extraKnownMarketplaces</code> и <code>strictKnownMarketplaces</code></div>
    <div>На более новых моделях Claude может <a href="/docs/ru/tools-reference#write-tool-behavior">перезаписать существующий файл с помощью инструмента Write</a> без его предварительного чтения в этом сеансе, что соответствует правилам инструмента Edit; более старые модели требуют чтение</div>
    <div>Расширение VS Code может <a href="/docs/ru/vs-code#organize-sessions-into-groups">организовать список сеансов в группы</a>: щелкните правой кнопкой мыши, чтобы создать, переименовать или удалить группу, и используйте Cmd/Ctrl- или Shift-click для одновременного перемещения нескольких сеансов</div>
    <div>Если ваша организация маршрутизирует Claude Code через <a href="/docs/ru/claude-apps-gateway-spend-limits">шлюз приложений Claude с лимитами расходов</a>, Claude Code показывает период лимита, время его сброса и сообщение оператора при достижении лимита</div>
  </div>
