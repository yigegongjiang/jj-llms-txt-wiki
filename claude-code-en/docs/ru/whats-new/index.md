# Что нового

> Еженедельный дайджест заметных функций Claude Code с примерами кода, демонстрациями и контекстом о том, почему они важны.

Еженедельный дайджест для разработчиков выделяет функции, которые с наибольшей вероятностью изменят способ вашей работы. Каждая запись включает исполняемый код, краткую демонстрацию и ссылку на полную документацию. Для каждого исправления ошибок и незначительного улучшения см. [журнал изменений](/docs/ru/changelog).

  Также на этой неделе: **`/doctor`** — это полная проверка настройки, которая диагностирует проблемы и может их исправить, с `/checkup` в качестве его псевдонима; **режим auto** блокирует подделку стенограмм и запрашивает разрешение перед `rm -rf` на неразрешенных переменных; и **строки представления агента** показывают цветное слово состояния и заголовок, написанный классификатором.
