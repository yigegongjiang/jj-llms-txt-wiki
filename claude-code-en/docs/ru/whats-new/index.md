# Что нового

> Еженедельный дайджест примечательных функций Claude Code с примерами кода, демонстрациями и контекстом о том, почему они важны.

Еженедельный дайджест для разработчиков выделяет функции, которые с наибольшей вероятностью изменят ваш способ работы. Каждая запись включает исполняемый код, краткую демонстрацию и ссылку на полную документацию. Для каждого исправления ошибок и незначительного улучшения см. [журнал изменений](/docs/en/changelog).
