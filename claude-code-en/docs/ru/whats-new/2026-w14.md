<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Переопределение размера результатов MCP</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Авторы MCP-серверов теперь могут повысить лимит усечения для конкретного инструмента, установив <code>anthropic/maxResultSizeChars</code> в записи <code>tools/list</code> инструмента, вплоть до жёсткого потолка в 500K символов. Раньше лимит был глобальным, поэтому инструменты, которые иногда возвращали по своей природе большие полезные нагрузки, такие как схемы баз данных или полные деревья файлов, попадали на лимит по умолчанию и сохранялись на диск со ссылкой на файл. Переопределения для каждого инструмента сохраняют эти результаты встроенными, когда инструмент действительно в них нуждается.</p>

  <p className="digest-feature-try">Аннотируйте инструмент в ответе <code>tools/list</code> вашего сервера:</p>

  ```json highlight={5} theme={null}
  {
    "name": "get_schema",
    "description": "Returns the full database schema",
    "_meta": {
      "anthropic/maxResultSizeChars": 500000
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/ru/docs/mcp#raise-the-limit-for-a-specific-tool">Справочник MCP</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Исполняемые файлы плагинов в PATH</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Поместите исполняемый файл в директорию <code>bin/</code> в корне вашего плагина, и Claude Code добавит эту директорию в <code>PATH</code> инструмента Bash, пока плагин включён. Claude может затем вызвать двоичный файл как простую команду из любого вызова инструмента Bash, без необходимости в абсолютном пути или скрипте-обёртке. Удобно для упаковки помощников CLI рядом с командами, агентами и hooks, которые их вызывают.</p>

  <p className="digest-feature-try">Добавьте директорию <code>bin/</code> в корень плагина:</p>

  ```text highlight={4, 5} theme={null}
  my-plugin/
  ├── .claude-plugin/
  │   └── plugin.json
  └── bin/
      └── my-tool
  ```

  <a className="digest-feature-link" href="/docs/ru/docs/plugins-reference#file-locations-reference">Справочник плагинов</a>
</div>

    <div>Продолжения в режиме Auto: новый hook <code>PermissionDenied</code> срабатывает при отказах классификатора (верните <code>retry: true</code>, чтобы позволить Claude попробовать другой подход), и <code>/permissions</code> → Recently denied позволяет вам повторить попытку вручную с помощью <code>r</code></div>

    <div><code>/buddy</code>: вылупите маленькое существо, которое наблюдает за вами во время кодирования. Шутка 1 апреля, больше недоступна</div>

    <div>Инструмент Edit теперь работает на файлах, просмотренных через <code>cat</code> или <code>sed -n</code> без отдельного Read</div>
    <div>Вывод Hook свыше 50K сохраняется на диск с путём и предпросмотром вместо внедрения в контекст</div>
    <div>Резюме Thinking отключены по умолчанию в интерактивных сессиях (<code>showThinkingSummaries: true</code> для восстановления)</div>
