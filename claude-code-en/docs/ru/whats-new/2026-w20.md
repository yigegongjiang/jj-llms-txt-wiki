  <p className="digest-feature-lede">Установите условие завершения и Claude продолжает работать над его достижением на протяжении нескольких ходов без вашего запроса на каждом шаге. После каждого хода быстрая модель проверяет, выполняется ли условие; если нет, Claude начинает ещё один ход вместо того, чтобы вернуть управление. Полезно для существенной работы с проверяемым конечным состоянием, например миграция модуля до тех пор, пока каждый сайт вызова компилируется и тесты проходят. Цель очищается после выполнения условия и работает в интерактивном режиме, <code>-p</code> и Remote Control.</p>

  <p className="digest-feature-lede"><code>/fast</code> теперь запускается на Opus 4.7 по умолчанию вместо Opus 4.6. Fast mode — это высокоскоростная конфигурация Opus: то же качество модели примерно в 2,5 раза быстрее с более высокой стоимостью за токен, полезно для быстрой итерации и живой отладки. Цены остаются неизменными на уровне $30/$150 за MTok, то же самое, что и для Opus 4.6 fast mode. Чтобы закрепить fast mode на Opus 4.6, установите <code>CLAUDE\_CODE\_OPUS\_4\_6\_FAST\_MODE\_OVERRIDE=1</code>.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code> получил флаги отправки (<code>--add-dir</code>, <code>--settings</code>, <code>--mcp-config</code>, <code>--plugin-dir</code>, <code>--permission-mode</code>, <code>--model</code>, <code>--effort</code>, <code>--dangerously-skip-permissions</code>) для настройки фоновых сессий, и <code>claude agents --cwd \<path></code> ограничивает список сессий директорией</div>
    <div>Новый hook <code>args: string\[]</code> форма exec порождает команду напрямую без оболочки, поэтому заполнители пути никогда не нуждаются в кавычках</div>
    <div>Новый параметр конфигурации <code>continueOnBlock</code> для hooks <code>PostToolUse</code> передаёт причину отклонения hook обратно Claude и продолжает ход вместо его завершения</div>
    <div>Новое поле <code>terminalSequence</code> в выводе JSON hook позволяет hooks отправлять уведомления рабочего стола, заголовки окон и звонки без управляющего терминала</div>
    <div>Меню Rewind добавило "Summarize up to here" для сжатия более ранней информации при сохранении недавних ходов</div>
    <div>Remote Control, <code>/schedule</code>, соединители Claude.ai MCP и предпочтения уведомлений теперь отключены когда установлены <code>ANTHROPIC\_API\_KEY</code>, <code>apiKeyHelper</code> или <code>ANTHROPIC\_AUTH\_TOKEN</code>, даже наряду с входом Claude.ai; отмените установку ключа API для использования этих функций</div>
    <div>Серверы MCP stdio теперь получают <code>CLAUDE\_PROJECT\_DIR</code> в своей среде, соответствуя hooks, и конфигурации плагинов могут ссылаться на <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code> в командах</div>
    <div><code>claude plugin details \<name></code> показывает инвентарь компонентов плагина и прогнозируемую стоимость токена за сессию, и панель деталей <code>/plugin</code> теперь также перечисляет серверы LSP, которые предоставляет плагин</div>
    <div>Плагины с корневым уровнем <code>SKILL.md</code> и без подпапки <code>skills/</code> теперь отображаются как skill</div>
    <div><code>/feedback</code> теперь может включать недавние сессии из последних 24 часов или 7 дней для проблем, охватывающих более чем текущую сессию</div>
    <div>Инструмент агента <code>subagent\_type</code> теперь совпадает без учёта регистра и разделителя, поэтому <code>"Code Reviewer"</code> разрешается в <code>code-reviewer</code></div>
  </div>
