  <p className="digest-feature-lede">В полноэкранном режиме <code>/diff</code> теперь открывает панель рядом с беседой вместо средства просмотра, которое нужно закрывать. Панель отображает изменённые файлы с количеством добавленных и удалённых строк и обновляется каждый раз, когда Claude редактирует файл или запускает команду shell. Выбирайте строки в панели мышью, чтобы прикрепить их к следующему запросу.</p>

  <p className="digest-feature-lede"><code>/skill-doctor</code> показывает, сколько контекста стоит каждый из ваших skills и как часто он используется, чтобы вы могли решить, какие из них отключить. Каждый skill в <a href="/docs/ru/skills#skill-descriptions-are-cut-short">списке skills</a> добавляет к вашему контексту на каждом ходу, используется ли Claude его или нет. Требуется v2.1.252 или позже и недоступен в сеансах, которые пропускают <a href="/docs/ru/env-vars#features-that-need-feature-flag-fetching">получение флагов функций</a>.</p>

  <p className="digest-feature-try">Запустите его в интерактивном сеансе, чтобы открыть отчёт на вкладке <strong>Stats</strong> менеджера <code>/plugin</code>:</p>

  ```text Claude Code theme={null}
  > /skill-doctor
  ```

  <p className="digest-feature-try">В неинтерактивном режиме с <code>-p</code> Claude Code выводит отчёт как текст.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Другие улучшения</p>

  <div className="digest-wins-grid">
    <div>Hook <a href="/docs/ru/hooks#premodelswitch"><code>PreModelSwitch</code></a> может заблокировать переключение модели, которое вы запросили, и hook <a href="/docs/ru/hooks#postmodelswitch"><code>PostModelSwitch</code></a> может добавить контекст для Claude после изменения модели сеанса</div>
    <div><a href="/docs/ru/costs#prompt-cache-statistics"><code>/cost</code></a> добавляет строку <code>Prompt cache (main)</code>: доля входных токенов, поданных из кэша, промахи кэша, прогрет ли кэш и вероятная причина последнего промаха, когда Claude Code может назвать одну. Скрипты строки состояния получают соответствующий объект <code>prompt\_cache</code></div>
    <div>Организации могут перечислять HTTP и SSE MCP серверы в управляемой настройке <a href="/docs/ru/managed-mcp#provide-servers-through-managed-settings"><code>managedMcpServers</code></a>, чтобы предоставить их каждому пользователю в дополнение к серверам, которые пользователи добавляют самостоятельно</div>
    <div><code>/effort</code> и средство выбора <code>/model</code> теперь <a href="/docs/ru/model-config#adjust-effort-level">сохраняют отдельный уровень усилий для каждой модели</a>; нажмите <code>s</code> вместо <code>Enter</code>, чтобы применить уровень только к текущему сеансу</div>
    <div>По умолчанию классификатор автоматического режима теперь также <a href="/docs/ru/permission-modes#what-the-classifier-blocks-by-default">блокирует</a> действия, такие как запрос учётных данных из облачной конечной точки метаданных экземпляра или подключение к дочерним контейнерам, которые Claude не запустил</div>
    <div>В автоматическом режиме Claude Code спрашивает вас перед тем, как Claude <a href="/docs/ru/permission-modes#first-read-outside-the-working-directories">впервые прочитает файл вне ваших рабочих каталогов</a>, с опцией блокировать такие чтения с этого момента</div>
    <div>Увеличьте <a href="/docs/ru/settings-reference#bashoutputmaxchars"><code>bashOutputMaxChars</code></a> и <a href="/docs/ru/settings-reference#taskoutputmaxchars"><code>taskOutputMaxChars</code></a> до 128 000 символов, чтобы Claude получал больше вывода из успешной команды или фоновой задачи встроенным образом</div>
    <div>Сочетания клавиш редактирования слов в подсказке <a href="/docs/ru/interactive-mode#make-ctrl-w-delete-back-to-whitespace">следуют readline</a> для всех, и настройка <code>keybindingFlavor</code> больше не имеет никакого эффекта. <code>Ctrl+W</code> удаляет до предыдущего пробела, а <code>Alt+B</code>, <code>Alt+F</code> и <code>Alt+D</code> рассматривают пунктуацию, такую как <code>/</code> и <code>.</code>, как разделители слов</div>
    <div>Если вы установите <code>defaultMode</code> на <code>"bypassPermissions"</code> в <code>.claude/settings.json</code> или <code>.claude/settings.local.json</code> проекта, это <a href="/docs/ru/permission-modes#which-mode-a-session-starts-in">больше не вступает в силу</a> и сеанс начинается в режиме Manual; установите <code>"bypassPermissions"</code> в пользовательских или управляемых настройках вместо этого или передайте `--permission-mode`</div>
    <div>Планы Enterprise на основе мест теперь <a href="/docs/ru/model-config#default-model-setting">по умолчанию используют Opus 5</a></div>
    <div>В расширении VS Code нажмите на имя модели в нижней части поля подсказки, чтобы <a href="/docs/ru/vs-code#use-the-prompt-box">открыть средство выбора модели</a></div>
    <div>В расширении VS Code выберите <strong>Output styles</strong> в разделе Customize меню команд, чтобы <a href="/docs/ru/vs-code#use-the-prompt-box">выбрать стиль вывода</a>, включая ваши пользовательские</div>
  </div>
</div>
