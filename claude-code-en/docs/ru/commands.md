# Команды

> Полный справочник команд, доступных в Claude Code, включая встроенные команды и встроенные skills.

Команды управляют Claude Code внутри сеанса. Они предоставляют быстрый способ переключения моделей, управления разрешениями, очистки контекста, запуска рабочего процесса и многого другого.

Введите `/` для просмотра всех доступных вам команд или введите `/` с последующими буквами для фильтрации.

Команда распознается только в начале вашего сообщения. Текст, который следует за названием команды, передается ей в качестве аргументов. Начиная с версии 2.1.199, [skills](/docs/ru/skills#pass-arguments-to-skills) являются исключением: вызов skill, за которым следуют другие skills, такие как `/skill-a /skill-b do XYZ`, загружает каждый skill, указанный в начале, и передает завершающий текст каждому в качестве аргументов. Можно объединить до шести skills.

Если вы отправите команду, пока Claude отвечает, она встанет в очередь и выполнится после завершения текущего хода. Некоторые команды, такие как `/status`, `/tasks` и `/usage`, выполняются немедленно без прерывания ответа.

<h2 id="commands-across-a-typical-workflow">
  Команды в типичном рабочем процессе
</h2>

Большинство команд полезны в определенной точке сеанса, от настройки проекта до отправки изменения.

**Первый сеанс в репозитории.** Запустите `/init` для создания стартового `CLAUDE.md`, затем `/memory` для его уточнения. Используйте `/mcp` для настройки любых серверов, которые нужны проекту, попросите Claude создать любых [subagents](/docs/ru/sub-agents), которые вам нужны, и запустите `/permissions` для установки правил одобрения.

**Во время задачи.** `/plan` переключает в режим плана перед крупным изменением. `/model` и `/effort` регулируют, какую модель вы используете и сколько рассуждений она применяет. Когда беседа становится длинной, `/context` показывает, что заполняет окно, и `/compact` сжимает его для освобождения места. Используйте `/btw` для быстрого замечания, которое не должно добавляться в историю беседы.

**Параллельное выполнение работы.** Claude делегирует побочные задачи [subagents](/docs/ru/sub-agents), и `/tasks` выводит список того, что выполняется в фоне текущего сеанса, включая subagents, которые завершили работу. `/background` отделяет весь сеанс, чтобы он продолжал работать как [фоновый агент](/docs/ru/agent-view), и освобождает ваш терминал. Для крупного изменения, охватывающего всю кодовую базу, `/batch` разбивает его на независимые единицы и запускает каждую в своем собственном [worktree](/docs/ru/worktrees). Смотрите [Запуск агентов параллельно](/docs/ru/agents), чтобы понять, как эти подходы связаны между собой.

**Перед отправкой.** `/diff` показывает, что изменилось, `/code-review` проверяет diff на наличие ошибок корректности и очистки и может применить результаты с помощью `--fix`, `/review` запускает быструю однопроходную проверку только для чтения GitHub pull request, `/code-review <level> <pr#>` запускает многоагентный обзор одного, а `/security-review` проверяет diff на наличие уязвимостей безопасности. `/code-review ultra` запускает многоагентный обзор в облаке.

**Между сеансами.** `/clear` начинает заново с новой задачей, сохраняя память проекта. `/resume` и `/branch` позволяют вернуться к более ранней беседе или создать ветвь. `/teleport` переносит веб-сеанс в этот терминал, а `/remote-control` позволяет продолжить этот локальный сеанс с другого устройства.

**Когда что-то не так.** `/rewind` откатывает код и беседу к контрольной точке или суммирует часть беседы. `/doctor` запускает проверку настройки, которая диагностирует проблемы установки и конфигурации и может их исправить, `/debug` диагностирует проблемы выполнения, а `/feedback` сообщает об ошибке с контекстом сеанса.

<h2 id="all-commands">
  Все команды
</h2>

В таблице ниже перечислены все команды, включенные в Claude Code. Большинство из них — встроенные команды, поведение которых закодировано в CLI. Отмечены два вида записей:

* **[Skill](/docs/ru/skills#bundled-skills)**: встроенный skill. Он работает как skills, которые вы пишете сами: подсказка, переданная Claude, которую Claude также может автоматически вызывать при необходимости.
* **[Workflow](/docs/ru/workflows#bundled-workflows)**: встроенный [динамический workflow](/docs/ru/workflows), который распределяет работу между множеством подагентов и выполняется в фоновом режиме.

Чтобы добавить свои собственные команды, см. [skills](/docs/ru/skills).

В таблице ниже `<arg>` указывает на обязательный аргумент, а `[arg]` указывает на необязательный.

<Note>
  Не каждая команда отображается для каждого пользователя. Доступность зависит от вашей платформы, плана и окружения. Например, `/desktop` отображается только на macOS и Windows при входе с подпиской Claude, а `/upgrade` отображается только на планах Pro и Max.
</Note>

<h2 id="mcp-prompts">
  MCP prompts

MCP servers могут предоставлять подсказки, которые появляются как команды. Они используют формат `/mcp__<server>__<prompt>` и динамически обнаруживаются из подключенных серверов. См. [MCP prompts](/docs/ru/mcp#use-mcp-prompts-as-commands) для деталей.
