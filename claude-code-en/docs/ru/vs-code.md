# Использование Claude Code в VS Code

> Установите и настройте расширение Claude Code для VS Code. Получите помощь AI при кодировании с встроенными diff, @-упоминаниями, проверкой плана и сочетаниями клавиш.

<img src="https://mintcdn.com/claude-code/-YhHHmtSxwr7W8gy/images/vs-code-extension-interface.jpg?fit=max&auto=format&n=-YhHHmtSxwr7W8gy&q=85&s=300652d5678c63905e6b0ea9e50835f8" alt="Редактор VS Code с открытой панелью расширения Claude Code справа, показывающей беседу с Claude" width="2500" height="1155" data-path="images/vs-code-extension-interface.jpg" />

Расширение VS Code предоставляет собственный графический интерфейс для Claude Code, интегрированный непосредственно в вашу IDE. Это рекомендуемый способ использования Claude Code в VS Code.

С расширением вы можете просматривать и редактировать планы Claude перед их принятием, автоматически принимать правки по мере их внесения, использовать @-упоминания файлов с определёнными диапазонами строк из вашего выделения, получать доступ к истории беседы и открывать несколько бесед в отдельных вкладках или окнах.

<h2 id="prerequisites">
  Предварительные требования
</h2>

Перед установкой убедитесь, что у вас есть:

* VS Code версии 1.94.0 или выше
* Учётная запись Anthropic: подойдёт любая платная подписка Claude (Pro, Max, Team или Enterprise) или учётная запись Claude Console, API ключ не требуется. Вы [войдёте](/docs/ru/authentication#log-in-to-claude-code) с помощью этой учётной записи при первом открытии расширения. Если вы получаете доступ к Claude через поставщика услуг третьей стороны, такого как Amazon Bedrock или Google Cloud's Agent Platform, см. [Использование поставщиков третьей стороны](#use-third-party-providers) для инструкций по настройке.

<Tip>
  Расширение включает собственную копию CLI (интерфейс командной строки) для панели чата. Чтобы запустить `claude` во встроенном терминале VS Code, вам также нужна [автономная установка CLI](/docs/ru/setup). Подробности см. в разделе [Расширение VS Code и Claude Code CLI](#vs-code-extension-vs-claude-code-cli).
</Tip>

<h2 id="install-the-extension">
  Установка расширения
</h2>

Нажмите на ссылку для вашей IDE, чтобы установить напрямую:

* [Установить для VS Code](vscode:extension/anthropic.claude-code)
* [Установить для Cursor](cursor:extension/anthropic.claude-code)

Или в VS Code нажмите `Cmd+Shift+X` (Mac) или `Ctrl+Shift+X` (Windows/Linux), чтобы открыть представление расширений, найдите "Claude Code" и нажмите **Установить**.

Расширение также устанавливается в других форках VS Code, таких как Devin Desktop или Kiro. Найдите "Claude Code" в представлении расширений вашего редактора или установите из [реестра Open VSX](https://open-vsx.org/extension/Anthropic/claude-code). Если ваш редактор не может установить расширение, [установите CLI](/docs/ru/quickstart) и запустите `claude` в его встроенном терминале. CLI работает в любом терминале.

<Note>Если расширение не появляется после установки, перезагрузите VS Code или выполните "Developer: Reload Window" из палитры команд.</Note>

<h2 id="get-started">
  Начало работы
</h2>

После установки вы можете начать использовать Claude Code через интерфейс VS Code:

<Steps>
  <Step title="Откройте панель Claude Code">
    По всему VS Code значок Spark указывает на Claude Code: <img src="https://mintcdn.com/claude-code/c5r9_6tjPMzFdDDT/images/vs-code-spark-icon.svg?fit=max&auto=format&n=c5r9_6tjPMzFdDDT&q=85&s=3ca45e00deadec8c8f4b4f807da94505" alt="Spark icon" style={{display: "inline", height: "0.85em", verticalAlign: "middle"}} width="16" height="16" data-path="images/vs-code-spark-icon.svg" />

    Самый быстрый способ открыть Claude — нажать значок Spark на **панели инструментов редактора** (верхний правый угол редактора). Значок появляется только при открытом файле.

    <img src="https://mintcdn.com/claude-code/mfM-EyoZGnQv8JTc/images/vs-code-editor-icon.png?fit=max&auto=format&n=mfM-EyoZGnQv8JTc&q=85&s=eb4540325d94664c51776dbbfec4cf02" alt="VS Code editor showing the Spark icon in the Editor Toolbar" width="2796" height="734" data-path="images/vs-code-editor-icon.png" />

    Другие способы открыть Claude Code:

    * **Activity Bar**: нажмите значок Spark на левой боковой панели, чтобы открыть список сеансов. Нажмите на любой сеанс, чтобы открыть его в вашем [предпочитаемом месте](#extension-settings), или начните новый. Этот значок всегда виден на Activity Bar.
    * **Command Palette**: `Cmd+Shift+P` (Mac) или `Ctrl+Shift+P` (Windows/Linux), введите "Claude Code" и выберите опцию, например "Open in New Tab"
    * **Status Bar**: если вы установили [`preferredLocation`](#extension-settings) на `sidebar` или открыли Claude с помощью **Claude Code: Open in Side Bar**, нажмите **✻ Claude Code** в нижнем правом углу окна. Это работает даже при отсутствии открытого файла.

    Вы можете перетащить панель Claude в любое место VS Code. Подробнее см. в разделе [Настройка вашего рабочего процесса](#customize-your-workflow).
  </Step>

  <Step title="Войдите в систему">
    При первом открытии панели появляется экран входа. Нажмите **Sign in** и завершите авторизацию в браузере.

    Если позже вы увидите **Not logged in · Please run /login**, расширение автоматически откроет экран входа. Если это не произойдет, перезагрузите окно из Command Palette с помощью **Developer: Reload Window**.

    Если у вас установлена переменная `ANTHROPIC_API_KEY` в оболочке, но вы все еще видите приглашение входа, VS Code может не унаследовать переменные окружения вашей оболочки. Запустите VS Code из терминала с помощью `code .`, чтобы он унаследовал переменные окружения, или вместо этого войдите с помощью своей учетной записи Claude.

    После входа появляется контрольный список **Learn Claude Code**. Пройдите каждый пункт, нажав **Show me**, или закройте его с помощью X. Чтобы открыть его позже, снимите флажок **Hide Onboarding** в параметрах VS Code в разделе Extensions → Claude Code.
  </Step>

  <Step title="Отправьте запрос">
    Попросите Claude помочь с вашим кодом или файлами, будь то объяснение того, как что-то работает, отладка проблемы или внесение изменений.

    <Tip>Claude автоматически видит выделенный текст. Нажмите `Option+K` (Mac) / `Alt+K` (Windows/Linux), чтобы также вставить ссылку @-mention (например `@file.ts#5-10`) в ваш запрос.</Tip>

    Вот пример вопроса о конкретной строке в файле:

    <img src="https://mintcdn.com/claude-code/FVYz38sRY-VuoGHA/images/vs-code-send-prompt.png?fit=max&auto=format&n=FVYz38sRY-VuoGHA&q=85&s=ede3ed8d8d5f940e01c5de636d009cfd" alt="VS Code editor with lines 2-3 selected in a Python file, and the Claude Code panel showing a question about those lines with an @-mention reference" width="3288" height="1876" data-path="images/vs-code-send-prompt.png" />
  </Step>

  <Step title="Проверьте изменения">
    То, что вы видите, зависит от [режима разрешений](/docs/ru/permission-modes#which-mode-a-session-starts-in), показанного в нижней части поля запроса:

    * В режиме Auto или Edit automatically Claude редактирует большинство файлов в вашем рабочем пространстве без запроса.
    * В режиме Manual, когда Claude хочет отредактировать файл, он показывает сравнение исходного и предложенного изменений рядом, а затем запрашивает разрешение. Вы можете принять, отклонить или сказать Claude, что делать вместо этого. Если вы отредактируете предложенное содержимое непосредственно в представлении diff перед принятием, Claude будет уведомлен, что вы его изменили, поэтому он не будет предполагать, что файл соответствует его исходному предложению.

          <img src="https://mintcdn.com/claude-code/FVYz38sRY-VuoGHA/images/vs-code-edits.png?fit=max&auto=format&n=FVYz38sRY-VuoGHA&q=85&s=e005f9b41c541c5c7c59c082f7c4841c" alt="VS Code showing a diff of Claude's proposed changes with a permission prompt asking whether to make the edit" width="3292" height="1876" data-path="images/vs-code-edits.png" />

    Чтобы проверить предложенное редактирование по одному изменению за раз, используйте кнопки **Accept this change** и **Reject this change** под каждым изменением в diff. Отклонение изменения отменяет его в предложенном содержимом; принятие отмечает его как проверенное. Принятие или отклонение всего файла все равно завершает проверку. Diff с более чем 100 изменениями открывается без кнопок для каждого изменения, поэтому проверьте его как целый файл. Проверка по изменениям требует Claude Code v2.1.275 или более поздней версии.

    Те же действия доступны в курсоре из контекстного меню редактора и из Command Palette как **Claude Code: Accept Change at Cursor** и **Claude Code: Reject Change at Cursor**.
  </Step>
</Steps>

Для получения дополнительных идей о том, что вы можете делать с Claude Code, см. [Распространенные рабочие процессы](/docs/ru/common-workflows).

<Tip>
  Запустите "Claude Code: Open Walkthrough" из Command Palette для пошагового руководства по основам.
</Tip>

<h2 id="use-the-prompt-box">
  Использование поля ввода подсказки
</h2>

Поле ввода подсказки поддерживает несколько функций:

* **Режимы разрешений**: нажмите на индикатор режима в нижней части поля ввода подсказки, чтобы переключать режимы разрешений. В планах Pro, Max и Team режим Auto является встроенным начальным режимом разрешений. Смотрите [как расширение выбирает начальный режим разрешений](/docs/ru/permission-modes#switch-permission-modes), чтобы узнать, что это меняет, и все режимы разрешений, которые предлагает индикатор.
  * **Auto**: классификатор проверяет большинство действий вместо того, чтобы просить вас. Смотрите [режим auto](/docs/ru/permission-modes#eliminate-prompts-with-auto-mode), чтобы узнать, что он проверяет и блокирует.
  * **Manual**: Claude запрашивает разрешение перед редактированием файлов и большинством команд оболочки.
  * **Plan**: Claude описывает, что он будет делать, и ждет одобрения перед внесением изменений. VS Code автоматически открывает план как полный документ Markdown, где вы можете добавлять встроенные комментарии, чтобы дать обратную связь перед началом работы Claude.

    Вы также можете ввести `/plan` в поле ввода подсказки. Требует Claude Code v2.1.280 или позже.

    * `/plan`: переключается в режим плана. Если вы уже находитесь в режиме плана, показывает текущий план вместо этого.
    * `/plan` с задачей, такой как `/plan fix the auth bug`: переключается в режим плана и начинает планирование этой задачи.
    * `/plan open`: когда вы уже находитесь в режиме плана, открывает файл плана в редакторе.
  * **Edit automatically**: Claude вносит изменения без запроса.
* **Model**: выберите **Switch model…** из меню команд, чтобы изменить модель во время сеанса. Вы также можете нажать на имя модели в нижней части поля ввода подсказки, чтобы открыть тот же выбор.

  Когда текущая модель поддерживает [уровни усилий](/docs/ru/model-config#adjust-effort-level), выбор также показывает строку **Effort** и кнопка имени модели показывает выбранный уровень. Когда вы выбираете уровень, отличный от `max`, Claude Code сохраняет его для текущей модели как ваше значение по умолчанию в разделе [`modelSettings`](/docs/ru/settings-reference#modelsettings) в ваших пользовательских параметрах; `max` применяется только к текущему сеансу. Кнопка имени модели и строка **Effort** требуют Claude Code v2.1.257 или позже.
* **Command menu**: нажмите `/` или введите `/`, чтобы открыть меню команд. Опции включают присоединение файлов, переключение моделей и переключение расширенного мышления.

  Раздел Customize предоставляет доступ к серверам MCP, commands, стилям вывода, hooks, памяти, инструкциям, разрешениям и плагинам. Элементы со значком терминала открываются в интегрированном терминале.

  * Для просмотра команд, таких как `/usage` или [`/remote-control`](/docs/ru/remote-control), выберите **Slash commands** в разделе Customize. Диалог отображает их с полем фильтра. Выберите один для его запуска. Ввод `/` в поле ввода подсказки по-прежнему предлагает команды встроенным образом. Требует Claude Code v2.1.257 или позже.

    Ввод `/skills` также открывает этот диалог. Каждая строка [skill](/docs/ru/skills) показывает его [видимость](/docs/ru/skills#override-skill-visibility-from-settings), такую как **On** или **Name only**. Нажмите на видимость, чтобы изменить ее, кроме строк, отмеченных как **locked**, таких как skills плагинов. Ярлык `/skills` и элементы управления видимостью требуют Claude Code v2.1.280 или позже.
  * Выберите **Output styles** в разделе Customize, чтобы выбрать [стиль вывода](/docs/ru/output-styles), включая ваши пользовательские стили. Требует Claude Code v2.1.257 или позже.

    Чтобы создать пользовательский стиль, выберите **Build a custom style** из меню **Output styles**. Claude Code записывает [файл стиля](/docs/ru/output-styles#create-a-custom-output-style) для вас на уровне проекта или пользователя. Требует Claude Code v2.1.261 или позже.
  * Выберите **Hooks** в разделе Customize, чтобы просмотреть [hooks](/docs/ru/hooks), загруженные в сеанс, сгруппированные по событиям. Вы можете добавлять, редактировать или удалять hooks, сохраненные в ваших файлах пользовательских, проектных и локальных параметров. Hooks из других источников, таких как управляемые параметры или плагины, доступны только для чтения. Требует Claude Code v2.1.269 или позже.
  * Выберите **Permissions** в разделе Customize, чтобы просмотреть [правила разрешений](/docs/ru/permissions) сеанса, сгруппированные в Allow, Ask и Deny. Вы можете добавлять правила в ваши пользовательские, проектные или локальные параметры и удалять правила, сохраненные там. Правила из других источников, таких как управляемые параметры или одобрения, сделанные только для этого сеанса, доступны только для чтения. Требует Claude Code v2.1.269 или позже.
  * Выберите **Memory** в разделе Customize, чтобы включить или отключить [автоматическую память](/docs/ru/memory#auto-memory). Пока она включена, вы также можете просматривать воспоминания, которые Claude сохранил, и открывать папки, в которых они хранятся, в вашем файловом менеджере. Требует Claude Code v2.1.274 или позже.

    Нажмите на сохраненное воспоминание, чтобы прочитать его в диалоге, где вы можете редактировать текст, удалить воспоминание или открыть его файл в редакторе. Просмотр, редактирование и удаление воспоминания в диалоге требуют Claude Code v2.1.275 или позже.
  * Выберите **Instructions** в разделе Customize, чтобы отредактировать [файлы CLAUDE.md](/docs/ru/memory#claude-md-files), которые читает Claude. Выберите файл, чтобы открыть его в редакторе. Если файл еще не существует, Claude Code создает его сначала. Требует Claude Code v2.1.274 или позже.
  * Выберите **Status** в разделе Customize, или введите `/status`, чтобы проверить версию Claude Code сеанса, учетную запись, модель и детали сервера MCP. Требует Claude Code v2.1.280 или позже.
  * Выберите **Sandbox** в разделе Customize, или введите `/sandbox`, чтобы увидеть, работают ли команды Bash Claude [в изолированной среде](/docs/ru/sandboxing). Вы можете переключить режим sandbox и добавить [исключенные команды](/docs/ru/settings-reference#sandbox-excludedcommands) там. Требует Claude Code v2.1.280 или позже.
  * Выберите **Claude in Chrome** в разделе Customize, или введите `/chrome`, чтобы проверить и управлять подключением [Claude in Chrome](/docs/ru/chrome). Оба требуют входа с учетной записью claude.ai. Требует Claude Code v2.1.280 или позже.
  * Выберите **Export conversation** в разделе Context, или введите `/export`, чтобы скопировать разговор как простой текст или сохранить его в файл. Добавьте имя файла, такое как `/export notes.txt`, чтобы пропустить диалог и выбрать, где сохранить файл. Требует Claude Code v2.1.280 или позже.
  * Раздел Settings включает **Enable Remote Control for all sessions**, который устанавливает [`remoteControlAtStartup`](/docs/ru/settings-reference#remotecontrolatstartup) для управления тем, [подключаются ли новые интерактивные сеансы к Remote Control автоматически](/docs/ru/remote-control#enable-remote-control-for-all-sessions). Требует Claude Code v2.1.203 или позже.

    Когда вы включаете или выключаете переключатель в окне VS Code, изменение применяется к сеансам, уже открытым в этом окне VS Code, а не только к сеансам, которые вы запускаете позже. Если вы его выключите, открытые сеансы отключатся. С Claude Code v2.1.261 или позже изменение также достигает сеансов, открытых в ваших других окнах VS Code.
  * Раздел Settings также включает **Focus view**, который скрывает вызовы инструментов, результаты инструментов и мышление за расширяемыми строками, оставляя ваши подсказки и ответы Claude. Переключайте его там, с `Ctrl+Option+F` (Mac) / `Ctrl+Alt+F` (Windows/Linux), или из Command Palette с **Claude Code: Toggle Focus view**. Изменение применяется к каждому открытому сеансу и сохраняется между сеансами. Требует Claude Code v2.1.221 или позже.

    Последний список дел Claude остается видимым, как и текст, о котором задает вопрос ожидающий вопрос от Claude; это требует Claude Code v2.1.225 или позже. Пока Claude запускает [подагентов](/docs/ru/sub-agents), строки прямого прогресса с их последней активностью появляются под группой вызовов инструментов, которая их запустила. Это требует Claude Code v2.1.269 или позже.
  * Чтобы выйти из своей учетной записи Anthropic, выберите **Sign out** в разделе Settings, или введите `/logout`. На [поставщике третьей стороны](#use-third-party-providers) меню не предлагает ни того, ни другого. Требует Claude Code v2.1.277 или позже.
  * Чтобы сообщить об ошибке, нажмите **Report a problem** в нижней части меню, или введите `/bug` или `/feedback` с необязательным описанием, которое предварительно заполняет отчет. Когда вы отправляете отчет и вы вошли в Anthropic на подключении первой стороны, Claude Code отправляет его в Anthropic. У поставщика третьей стороны или без учетных данных Anthropic диалог все еще открывается, но отправка показывает ошибку и ничего не отправляет: в отличие от `/bug` CLI, расширение не записывает локальный архив. Требует Claude Code v2.1.229 или позже.

    Если политика вашей организации отключает отзывы о продукте, **Report a problem** не появляется в меню, и `/bug` и `/feedback` показывают уведомление `Feedback is turned off by your organization's policy or this environment's settings.` вместо открытия отчета.
* **Side questions**: введите `/btw` с последующим вопросом, чтобы задать вопрос о вашем сеансе [без добавления в разговор](/docs/ru/interactive-mode#side-questions-with-%2Fbtw). Ответ открывается в панели рядом с чатом, где вы можете задавать дополнительные вопросы. Поток сохраняется при перезагрузке окна. Claude Code сохраняет новейшие 20 обменов и истекает сохраненные потоки по расписанию [`cleanupPeriodDays`](/docs/ru/settings-reference#cleanupperioddays), пока Claude Code может [безопасно определить период хранения](/docs/ru/claude-directory#cleaned-up-automatically). Чтобы очистить поток, нажмите на значок корзины в панели. Требует Claude Code v2.1.227 или позже.
* **Copy a response**: наведите курсор на ответ и нажмите **Copy response**, чтобы скопировать его в буфер обмена, или введите `/copy`, чтобы скопировать последний ответ. `/copy 2` копирует второй с конца. Требует Claude Code v2.1.277 или позже.
* **Context indicator**: поле ввода подсказки показывает, сколько контекстного окна Claude вы используете. Claude автоматически компактирует при необходимости, или вы можете запустить `/compact` вручную.
* **Prompt cache clock**: значок часов рядом с индикатором контекста оценивает, сколько времени осталось у [prompt cache](/docs/ru/prompt-caching) разговора перед его истечением. Он отсчитывает от [времени жизни](/docs/ru/prompt-caching#cache-lifetime) кэша в пять минут или один час, и каждый ответ, который использует кэш, перезапускает обратный отсчет. Помимо компактирования, [действия, которые делают кэш недействительным](/docs/ru/prompt-caching#actions-that-invalidate-the-cache), не сбрасывают часы, поэтому они все еще могут показывать оставшиеся минуты после переключения моделей.
  * До истечения обратного отсчета значок показывает оставшиеся минуты, такие как **12m**.
  * Когда обратный отсчет заканчивается, минуты исчезают и значок становится красным, или цветом ошибки вашей темы, до следующего ответа. Кэш, вероятно, истек, поэтому ожидайте более медленный и дорогостоящий ответ на ваше следующее сообщение, пока кэш перестраивается. Если время жизни в пять минут продолжает истекать между вашими сообщениями, смотрите [Choose the TTL yourself](/docs/ru/prompt-caching#choose-the-ttl-yourself).
  * Сразу после [компактирования](/docs/ru/prompt-caching#compacting-the-conversation) разговора значок также становится красным без минут до следующего ответа, потому что кэш еще не охватывает компактированный разговор.
* **Agent map**: когда разговор включает [подагентов](/docs/ru/sub-agents), счетчик агентов, такой как **2 agents**, появляется в нижней части поля ввода подсказки. Его точка показывает, работает ли какой-либо подагент или ожидает вашего разрешения.

  Нажмите на счетчик агентов, чтобы открыть карту агентов, которая рисует подагентов разговора как дерево под главным агентом, каждый с его статусом, прошедшим временем и счетчиком токенов. Нажмите на подагента, чтобы увидеть его подсказку и вызовы инструментов, открыть его транскрипт только для чтения или остановить его во время работы. Требует Claude Code v2.1.269 или позже.

  Карта также отображает другие [фоновые задачи](/docs/ru/tools-reference#background-commands) сеанса, такие как фоновые команды оболочки и [мониторы](/docs/ru/tools-reference#monitor-tool), ниже агентов. Нажмите на строку, чтобы открыть карточку задачи и остановить ее там.

  Чтобы открыть карту, когда счетчик агентов не отображается, например когда Claude запустил фоновую команду оболочки, но нет подагентов, введите `/tasks` в поле ввода подсказки. Фоновые задачи на карте и введенная `/tasks` требуют Claude Code v2.1.277 или позже.
* **Extended thinking**: позволяет Claude потратить больше времени на рассуждение о сложных проблемах. Переключайте его через меню команд (`/`). Рассуждение Claude появляется в разговоре как свернутые блоки: нажмите на блок, чтобы прочитать его, или нажмите `Ctrl+O`, чтобы развернуть или свернуть каждый блок мышления в сеансе. Смотрите [Extended thinking](/docs/ru/model-config#extended-thinking) для деталей.
* **Multi-line input**: нажмите `Shift+Enter`, чтобы добавить новую строку без отправки. Это также работает в вводе свободного текста "Other" диалогов вопросов.

<h3 id="reference-files-and-folders">
  Справочные файлы и папки
</h3>

Используйте @-упоминания, чтобы дать Claude контекст о конкретных файлах или папках. Когда вы вводите `@` с последующим именем файла или папки, Claude читает это содержимое и может ответить на вопросы о нем или внести в него изменения. Claude Code поддерживает нечеткое совпадение, поэтому вы можете вводить частичные имена, чтобы найти то, что вам нужно:

```text wrap theme={null}
Explain the logic in @auth (fuzzy matches auth.js, AuthService.ts, etc.)
What's in @src/components/ (include a trailing slash for folders)
```

Для больших PDF-файлов вы можете попросить Claude прочитать определенные страницы вместо всего файла: одну страницу, диапазон, например страницы 1-10, или открытый диапазон, например страница 3 и далее.

Когда вы выбираете текст в редакторе, Claude может видеть ваш выделенный код автоматически. Нижняя часть поля ввода подсказки показывает, сколько строк выбрано. Нажмите `Option+K` (Mac) / `Alt+K` (Windows/Linux), чтобы вставить @-упоминание с путем файла и номерами строк (например, `@app.ts#5-10`). Нажмите **X** на индикаторе выделения, чтобы удалить его, чтобы Claude не получал выделение. Индикатор появляется снова, когда вы выбираете другой текст.

Расширение скрывает выбранный текст из некоторых файлов. Когда файл находится внутри вашего рабочего пространства и соответствует вашим параметрам `files.exclude` или `search.exclude`, Claude получает максимум путь файла и не получает текст, который вы выбрали. То же самое применяется к файлу, который игнорирует git, пока параметр `search.useIgnoreFiles` VS Code и параметр [`respectGitIgnore`](#extension-settings) расширения оба включены, что является значением по умолчанию. Этот фильтр охватывает только панель чата: когда Claude Code работает в интегрированном терминале, CLI отправляет ваш выбранный текст независимо от файла, поэтому добавьте [правило отрицания `Read`](#the-built-in-ide-mcp-server), чтобы содержимое файла не попало к Claude там.

Claude также видит, какой файл у вас открыт в редакторе, даже когда ничего не выбрано, и поле ввода подсказки показывает его имя. Чтобы добавить только выбранный текст, отключите [параметр Attach Open File](vscode://settings/claudeCode.attachOpenFile). Параметр требует Claude Code v2.1.271 или позже.

Вы также можете прикреплять изображения и файлы к вашему сообщению:

* Чтобы прикрепить изображение, вставьте его из буфера обмена в поле ввода подсказки.
* Чтобы прикрепить файлы, удерживайте `Shift` при перетаскивании их в поле ввода подсказки.
* Чтобы удалить вложение из контекста, нажмите X на нем.

<h3 id="paste-text">
  Вставка текста
</h3>

Текст, который вы вставляете, остается видимым в поле ввода подсказки, а не сворачивается в заполнитель, как это происходит [в терминале](/docs/ru/terminal-config#paste-large-content). В сеансах, где Claude Code [отмечает вставленный текст](/docs/ru/terminal-config#how-claude-treats-pasted-text), Claude все еще видит большую вставку как текст, который вы вставили, а не набрали.

Claude Code также удаляет [невидимые символы Unicode](/docs/ru/interactive-mode#invisible-characters-in-prompts) из текста, который вы вставляете в поле ввода подсказки, и из всего остального, что вы отправляете:

* Если уведомление, такое как `Removed 3 invisible characters from the pasted text`, появляется при вставке, текст был вставлен без этих символов.
* Если уведомление об удаленных символах появляется при отправке, ничего не было отправлено. Очищенный текст вернулся в поле ввода подсказки. Отправьте снова, чтобы отправить текст как показано.

<h3 id="resume-past-conversations">
  Возобновление прошлых разговоров
</h3>

Нажмите кнопку **Session history** в верхней части панели Claude Code, чтобы получить доступ к истории вашего разговора. Вы можете искать по ключевому слову или просматривать по времени.

Нажмите на любой разговор, чтобы возобновить его с полной историей сообщений. Если разговор уже открыт на другой вкладке текущего окна, нажатие на него переключит вас на эту вкладку. Для получения дополнительной информации о возобновлении сеансов смотрите [Manage sessions](/docs/ru/sessions).

* **Session titles**: новые сеансы получают названия, созданные ИИ, на основе вашего первого сообщения.
* **Rename and archive**: наведите курсор на сеанс, чтобы открыть эти действия. Переименуйте, чтобы дать ему описательное название, или архивируйте, чтобы переместить его в группу **Archived sessions** в нижней части списка.

По умолчанию сеанс без активности в течение 14 дней переходит в **Archived sessions** автоматически, если только он не открыт, не прочитан или не находится в [группе](#organize-sessions-into-groups). Автоматическое архивирование требует Claude Code v2.1.265 или позже. Чтобы изменить период или отключить его, откройте [Archive Inactive Sessions setting](vscode://settings/claudeCode.archiveInactiveSessions) и выберите количество дней или **Never**.

Чтобы восстановить архивированный сеанс, разверните **Archived sessions** и нажмите **Unarchive session**. Чтобы восстановить каждый архивированный сеанс сразу, наведите курсор на заголовок **Archived sessions** в списке сеансов в Activity Bar и нажмите его значок разархивирования, что требует Claude Code v2.1.277 или позже. До v2.1.257 действие было **Delete session**, которое скрывало сеанс без возможности его восстановления. Сеансы, которые вы удалили, появляются в **Archived sessions** после обновления.

Когда разговор, который вы возобновляете, закончился в режиме плана, Claude Code восстанавливает режим плана. Требует Claude Code v2.1.246 или позже. Claude Code не восстанавливает его в двух случаях:

* Расширение [выбирает начальный режим разрешений](/docs/ru/permission-modes#switch-permission-modes) из `claudeCode.initialPermissionMode` или выбора, который переносится из более раннего разговора
* У вас настроен `claudeCode.claudeProcessWrapper`

<h3 id="resume-cloud-sessions-from-claude-ai">
  Возобновление облачных сеансов из Claude.ai
</h3>

Если вы используете [облачные сеансы](/docs/ru/claude-code-on-the-web), вы можете возобновить их прямо в VS Code. Это требует входа с **Claude.ai Subscription**, а не Anthropic Console.

<Steps>
  <Step title="Open session history">
    Нажмите кнопку **Session history** в верхней части панели Claude Code.
  </Step>

  <Step title="Select the Web tab">
    Диалог показывает две вкладки: Local и Web. Нажмите **Web**, чтобы увидеть сеансы из claude.ai.
  </Step>

  <Step title="Select a session to resume">
    Просмотрите или найдите ваши облачные сеансы. Нажмите на любой сеанс, чтобы загрузить его и продолжить разговор локально.
  </Step>
</Steps>

<Note>
  Только облачные сеансы, начатые с репозитория GitHub, появляются на вкладке Web. Возобновление загружает историю разговора локально; изменения не синхронизируются обратно в claude.ai.
</Note>

<h3 id="check-account-and-usage">
  Проверка учетной записи и использования
</h3>

Запустите `/usage`, чтобы открыть диалог Account & usage. Он показывает вашу учетную запись, в которую вы вошли, и использование отличается в зависимости от входа:

* **claude.ai plan**: полосы использования для ограничений вашего плана, таких как текущий сеанс и неделя. Каждая полоса показывает, как долго до сброса ее лимита.

  Диалог также разбивает то, что способствует ограничениям вашего плана. Он отмечает поведение, которое составляет 10% или более недавнего использования, такое как промахи кэша, длинный контекст и сеансы с большим количеством подагентов или высокой параллелизацией, каждый с советом по его снижению. Таблицы атрибуции показывают, сколько использования пришло из каждого skill, подагента, плагина и сервера MCP.

  Используйте переключатель Day и Week для переключения между последними 24 часами и последними 7 днями. Цифры являются приблизительными и вычисляются из локальных сеансов на этой машине, поэтому использование с других устройств или claude.ai не включено.
* **Other sign-ins**: когда ограничения плана не применяются к вашему входу, например на [поставщике третьей стороны](#use-third-party-providers) или с ключом API, раздел Usage показывает стоимость сеанса и использование токенов вместо этого. `/usage` CLI показывает те же итоги в его [Session block](/docs/ru/costs#track-your-costs). Список сеансов в Activity Bar также показывает итоги активного сеанса под его заголовком **Account & usage**. Требует Claude Code v2.1.277 или позже.

Для получения дополнительной информации об отслеживании и снижении использования смотрите [Track your costs](/docs/ru/costs#track-your-costs).

<h2 id="customize-your-workflow">
  Настройте свой рабочий процесс
</h2>

Вы можете переместить панель Claude, запустить несколько разговоров, организовать список сеансов в группы или переключиться в режим терминала.

<h3 id="choose-where-claude-lives">
  Выберите, где находится Claude
</h3>

Вы можете перетащить панель Claude, чтобы переместить её в любое место в VS Code. Возьмитесь за вкладку или заголовок панели и перетащите её в:

* **Вторичная боковая панель**: правая сторона окна. Держит Claude видимым во время кодирования.
* **Основная боковая панель**: левая боковая панель со значками для Explorer, Search и т. д.
* **Область редактора**: открывает Claude как вкладку рядом с вашими файлами. Полезно для дополнительных задач.

Когда Claude открывает вкладку в новой группе редактора, расширение блокирует эту группу, поэтому файлы, которые вы открываете, пока вкладка Claude сфокусирована, переходят в другую группу вместо того, чтобы находиться рядом с ней.

Чтобы остановить блокировку групп расширением, отключите [параметр Lock Editor Groups](vscode://settings/claudeCode.lockEditorGroups). Группы, которые уже заблокированы, остаются заблокированными, пока вы их не разблокируете. Этот параметр требует Claude Code v2.1.274 или позже.

<Tip>
  Используйте боковую панель для вашего основного сеанса Claude и открывайте дополнительные вкладки для дополнительных задач. Claude запоминает ваше предпочтительное местоположение. Значок списка сеансов на панели действий отделён от панели Claude: список сеансов всегда виден на панели действий, а значок панели Claude появляется там только при закреплении панели на левой боковой панели.
</Tip>

После запуска **Developer: Reload Window** или перезагрузки VS Code, возвращение чата с его разговором зависит от того, где он был открыт:

* **Вкладка редактора**: разговор возвращается с его вкладкой.
* **Боковая панель**: разговор возвращается, если вы отправили сообщение или Claude ответил в нём в течение последних 10 минут. Если он не возвращается, возобновите разговор из [истории сеансов](#resume-past-conversations).

Если перезагрузка прервала Claude в середине шага, Claude продолжит этот шаг, когда разговор вернётся, и уведомление в чате отметит продолжение. Требуется Claude Code v2.1.274 или позже. Если шаг был прерван более часа назад или сеанс открыт в другом месте, разговор вернётся в неактивном состоянии.

Чтобы отключить продолжение, откройте [параметр Continue After Reload](vscode://settings/claudeCode.continueAfterReload) и снимите флажок.

<h3 id="run-multiple-conversations">
  Запустите несколько разговоров
</h3>

Используйте **Open in New Tab** или **Open in New Window** из палитры команд, чтобы начать дополнительные разговоры. Каждый разговор сохраняет свою собственную историю и контекст, позволяя вам работать над различными задачами параллельно.

При использовании вкладок небольшая цветная точка на значке искры указывает статус: синий означает, что запрос разрешения ожидает, оранжевый означает, что Claude завершил работу, пока вкладка была скрыта.

<h3 id="organize-sessions-into-groups">
  Организуйте сеансы в группы
</h3>

В списке сеансов на панели действий вы можете собрать связанные сеансы в именованные, сворачиваемые группы. Требуется Claude Code v2.1.229 или позже.

* **Сгруппировать или разгруппировать сеанс**: щёлкните правой кнопкой мыши на сеансе, чтобы создать группу из него, переместить его в существующую группу или удалить его из его группы. Каждый сеанс принадлежит одной группе одновременно, поэтому перемещение его в другую группу удаляет его из первой.
* **Переместить несколько сеансов одновременно**: `Cmd`-щелчок (Mac) / `Ctrl`-щелчок (Windows/Linux) на каждом сеансе или `Shift`-щелчок для выбора диапазона, затем щёлкните правой кнопкой мыши на выборе.
* **Сгруппировать сеанс из его вкладки**: запустите **Claude Code: Add Session Tab to Group** из палитры команд, затем выберите или создайте группу. Требуется Claude Code v2.1.257 или позже.
* **Переименовать или удалить группу**: щёлкните правой кнопкой мыши на заголовке группы. Удаление группы удаляет только группу, и её сеансы возвращаются в список без группировки.

Расширение сохраняет группы для каждой папки рабочего пространства, поэтому они сохраняются при перезагрузке окна и появляются в каждом окне, где вы открываете одну и ту же папку. Когда вы ищете в списке, расширение показывает совпадения в одном плоском списке во всех группах.

<h3 id="switch-to-terminal-mode">
  Переключитесь в режим терминала
</h3>

По умолчанию расширение открывает графическую панель чата. Если вы предпочитаете интерфейс в стиле CLI, откройте [параметр Use Terminal](vscode://settings/claudeCode.useTerminal) и установите флажок.

Вы также можете открыть параметры VS Code (`Cmd+,` на Mac или `Ctrl+,` на Windows/Linux), перейти в Extensions → Claude Code и установить флажок **Use Terminal**.

<h2 id="manage-plugins">
  Управление плагинами
</h2>

Расширение VS Code включает графический интерфейс для установки и управления [плагинами](/docs/ru/plugins/overview). Введите `/plugins` в поле подсказки, чтобы открыть интерфейс **Управление плагинами**.

<h3 id="install-plugins">
  Установка плагинов
</h3>

Диалоговое окно плагина показывает две вкладки: **Плагины** и **Маркетплейсы**.

На вкладке Плагины:

* **Установленные плагины** отображаются в верхней части с переключателями для их включения или отключения
* **Доступные плагины** из ваших настроенных маркетплейсов отображаются ниже
* Используйте поиск для фильтрации плагинов по названию или описанию
* Нажмите **Установить** на любом доступном плагине

При установке плагина выберите область установки:

* **Установить для вас**: доступно во всех ваших проектах (область пользователя)
* **Установить для этого проекта**: общее использование с сотрудниками проекта (область проекта)
* **Установить локально**: только для вас, только в этом репозитории (локальная область)

<h3 id="share-a-plugin-install-link">
  Поделиться ссылкой на установку плагина
</h3>

Чтобы отправить кому-то прямую ссылку на установку конкретного плагина, дайте им URL `install-plugin` расширения. При открытии он запускает или фокусирует VS Code, открывает панель Claude Code и открывает диалоговое окно **Управление плагинами** с выбором области этого плагина. Ничего не устанавливается, пока пользователь не выберет область. Если маркетплейс плагина еще не настроен в Claude Code, диалоговое окно сначала попросит его добавить.

```text theme={null}
vscode://anthropic.claude-code/install-plugin?plugin=code-review&marketplace=anthropics/claude-plugins-official
```

URL принимает два параметра запроса:

| Параметр      | Описание                                                                                                                                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `plugin`      | Имя плагина, как его указывает маркетплейс. Обязательно.                                                                                                                                                      |
| `marketplace` | Источник плагина: репозиторий GitHub `owner/repo`, URL `https://` или git SSH URL, например `git@github.com:owner/repo.git`. По умолчанию используется `anthropics/claude-plugins-official`, если не указано. |

Некоторые значения, которые принимает [вкладка Маркетплейсы](#manage-marketplaces), не работают в ссылке, например локальный путь или адрес `http://`. Для них VS Code показывает сообщение об ошибке и диалоговое окно не открывается.

Два случая заканчиваются сообщением в диалоговом окне вместо выбора области:

* **Маркетплейс не содержит плагин с таким названием**: диалоговое окно сообщает, что плагин не найден. Проверьте значение `plugin` в списке маркетплейса.
* **Плагин уже установлен**: диалоговое окно это указывает, и ничего не меняется.

README на GitHub, проблемы и некоторые другие хосты Markdown удаляют ссылки, схема которых не `http` или `https`, поэтому ссылка `vscode://` там отображается как простой текст. Поместите URL в блок кода на этих хостах, как описано в разделе [Ссылка отображается как простой текст вместо того, чтобы быть кликабельной](/docs/ru/deep-links#the-link-renders-as-plain-text-instead-of-being-clickable) для ссылок `claude-cli://`.

<h3 id="manage-marketplaces">
  Управление маркетплейсами
</h3>

Перейдите на вкладку **Маркетплейсы**, чтобы добавить или удалить источники плагинов:

* Введите репозиторий GitHub, URL или локальный путь для добавления нового маркетплейса
* Нажмите значок обновления, чтобы обновить список плагинов маркетплейса
* Нажмите значок корзины, чтобы удалить маркетплейс

Изменения плагинов, которые вы вносите в диалоговом окне, применяются сразу же к сеансам Claude Code, открытым в этом окне VS Code. Если сеанс, из которого вы открыли диалоговое окно, не может перезагрузить свои плагины, диалоговое окно предлагает повторить попытку или перезагрузить Claude в этом сеансе.

<Note>
  Управление плагинами в VS Code использует те же команды CLI под капотом. Плагины и маркетплейсы, которые вы настраиваете в расширении, также доступны в CLI, и наоборот.
</Note>

Дополнительную информацию о системе плагинов см. в разделах [Плагины](/docs/ru/plugins/overview) и [Маркетплейсы плагинов](/docs/ru/plugins/overview).

<h2 id="automate-browser-tasks-with-chrome">
  Автоматизация задач браузера с помощью Chrome
</h2>

Подключите Claude к вашему браузеру Chrome для тестирования веб-приложений, отладки с помощью логов консоли и автоматизации рабочих процессов браузера, не покидая VS Code. Это требует расширение [Claude in Chrome extension](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn) версии 1.0.36 или выше.

Введите `@browser` в поле подсказки, а затем то, что вы хотите, чтобы Claude сделал:

```text wrap theme={null}
@browser go to localhost:3000 and check the console for errors
```

Вы также можете открыть меню вложений, чтобы выбрать конкретные инструменты браузера, такие как открытие новой вкладки или чтение содержимого страницы.

Claude открывает новые вкладки для задач браузера и делится состоянием входа вашего браузера, поэтому он может получить доступ к любому сайту, на который вы уже вошли.

Инструкции по настройке, полный список возможностей и устранение неполадок см. в разделе [Use Claude Code with Chrome](/docs/ru/chrome).

<h3 id="launch-a-vs-code-tab-from-other-tools">
  Запуск вкладки VS Code из других инструментов
</h3>

Расширение регистрирует обработчик URI по адресу `vscode://anthropic.claude-code/open`. Используйте его для открытия новой вкладки Claude Code из вашего собственного инструмента: псевдонима оболочки, букмарклета браузера или любого скрипта, который может открыть URL. Если VS Code еще не запущен, открытие URL сначала запускает его. Если VS Code уже запущен, URL открывается в окне, которое в данный момент находится в фокусе.

Вызовите обработчик с помощью открывателя URL вашей операционной системы.

<Tabs>
  <Tab title="macOS">
    ```bash theme={null}
    open "vscode://anthropic.claude-code/open"
    ```
  </Tab>

  <Tab title="Linux">
    ```bash theme={null}
    xdg-open "vscode://anthropic.claude-code/open"
    ```

    Команда `xdg-open` поступает из пакета `xdg-utils`. Если оболочка сообщает, что она не найдена, см. [xdg-open is not found on Linux](/docs/ru/deep-links#xdg-open-is-not-found-on-linux).
  </Tab>

  <Tab title="Windows">
    В PowerShell:

    ```powershell theme={null}
    Start-Process "vscode://anthropic.claude-code/open"
    ```

    В `cmd.exe`, `start` рассматривает свой первый аргумент в кавычках как заголовок окна, поэтому передайте пустой заголовок перед URL:

    ```cmd theme={null}
    start "" "vscode://anthropic.claude-code/open"
    ```
  </Tab>
</Tabs>

Обработчик принимает два необязательных параметра запроса:

| Параметр  | Описание                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `prompt`  | Текст для предварительного заполнения в поле подсказки. Должен быть закодирован в URL. Подсказка предварительно заполняется, но не отправляется автоматически.                                                                                                                                                                                                                                               |
| `session` | Идентификатор сеанса для возобновления вместо начала нового разговора. Сеанс должен принадлежать рабочей области, которая в данный момент открыта в VS Code. Если сеанс не найден, вместо этого начинается новый разговор. Если сеанс уже открыт на вкладке, эта вкладка получает фокус. Чтобы программно захватить идентификатор сеанса, см. [Continue conversations](/docs/ru/headless#continue-conversations). |

Например, чтобы открыть вкладку с предварительным заполнением "review my changes":

```text theme={null}
vscode://anthropic.claude-code/open?prompt=review%20my%20changes
```

Расширение также обрабатывает `vscode://anthropic.claude-code/install-plugin`, который [открывает диалог плагина на одном плагине](#share-a-plugin-install-link). Чтобы запустить сеанс терминала вместо вкладки VS Code, используйте обработчик `claude-cli://` CLI. См. [Launch sessions from links](/docs/ru/deep-links).

<h2 id="configure-settings">
  Настройка параметров
</h2>

Расширение имеет два типа параметров:

* **Параметры расширения** в VS Code: управляют поведением расширения в VS Code. Откройте с помощью `Cmd+,` (Mac) или `Ctrl+,` (Windows/Linux), затем перейдите в Extensions → Claude Code. Вы также можете ввести `/` и выбрать **General config…** для открытия параметров.
* **Параметры Claude Code** в `~/.claude/settings.json`: общие для расширения и CLI. Используйте для разрешённых команд, переменных окружения, hooks и MCP серверов. На планах Pro, Max и Team это также один из входных параметров режима разрешений, с которого начинаются беседы. [Switch permission modes](/docs/ru/permission-modes#switch-permission-modes) указывает порядок. Подробнее см. [Settings](/docs/ru/settings).

<Tip>
  Добавьте `"$schema": "https://json.schemastore.org/claude-code-settings.json"` в ваш `settings.json`, чтобы получить автодополнение и встроенную проверку для всех доступных параметров прямо в VS Code.
</Tip>

<h2 id="use-a-screen-reader">
  Использование программы чтения с экрана
</h2>

Панель чата расширения работает с программами чтения с экрана. Вам не нужно ничего включать: расширение объявляет активность разговора для каждого пользователя без визуальных изменений. Это отличается от режима программы чтения с экрана CLI с явным согласием пользователя [screen reader mode](/docs/ru/accessibility), который адаптирует интерфейс терминала.

Поддержка программы чтения с экрана в панели чата требует Claude Code версии 2.1.236 или более поздней.

Во время разговора расширение объявляет:

* **Ответы Claude**: расширение объявляет каждый ответ один раз, когда он завершен, и молчит во время потоковой передачи текста. Ваша программа чтения с экрана читает блоки кода как сводку по количеству строк, читает ссылки по их метке и читает таблицы ячейка за ячейкой; полный ответ остается читаемым в стенограмме.
* **Запросы разрешений и вопросы**: расширение объявляет запрос, когда появляется его диалоговое окно разрешения, называя инструмент, который Claude хочет использовать. Оно объявляет таким же образом, когда Claude задает вам вопрос и когда Claude завершает план и ждет вашего рассмотрения.
* **Изменения статуса**: расширение объявляет, когда Claude начинает работать, когда Claude готов к вашему вводу и когда Claude Code начинает сжимать разговор.
* **Ошибки и подсказки модели**: расширение объявляет об ошибках в разговоре и объявляет, когда появляется [диалоговое окно согласия на использование кредитов](/docs/ru/model-config#fable-and-usage-credits) или [диалоговое окно помеченного запроса](/docs/ru/model-config#ask-before-switching).

Пока Claude работает, ваша программа чтения с экрана читает текстовую метку вместо анимации спиннера прогресса.

Когда вы повторно открываете сеанс или переключаетесь на другой, расширение ничего не объявляет: восстановленная история, ожидающие запросы разрешений и текущий статус остаются молчаливыми до тех пор, пока не произойдет что-то новое.

<h3 id="use-the-chat-panel-from-the-keyboard">
  Использование панели чата с клавиатуры
</h3>

Каждый ход в стенограмме начинается с визуально скрытого заголовка, помеченного подсказкой, которая начала ход, поэтому вы можете переходить между ходами с помощью навигации по заголовкам вашей программы чтения с экрана.

В пределах хода ваша программа чтения с экрана объявляет, чье сообщение вы читаете, когда вы перемещаетесь по нему:

* **Ваши сообщения**: "Вы"
* **Сообщения Claude**: "Claude"
* **Шаги инструмента**: "Claude" плюс имя инструмента, например "Claude, Bash"
* **Блоки размышления**: "Claude, thinking"

Поскольку расширение предоставляет стенограмму как помеченный регион, вы также можете переместить фокус на саму стенограмму с помощью `Tab` и читать ее в своем собственном темпе. Чтобы вместо этого переместить фокус на последнее сообщение или ожидающий запрос разрешения, запустите **Claude Code: Focus last message** из [Command Palette](#vs-code-commands-and-shortcuts).

Когда опция в диалоговом окне разрешения сохраняет правило разрешения или доступ к каталогу, ее метка заканчивается названием места сохранения одобрения, например "все проекты" или "этот сеанс". Когда опция сфокусирована, нажмите клавишу `Left` или `Right` для изменения назначения, и расширение объявляет каждое назначение по мере того, как вы на него переходите. Вы также можете щелкнуть на назначение в метке. Клавиши со стрелками требуют Claude Code версии 2.1.268 или более поздней.

<h3 id="rewind-with-checkpoints">
  Rewind с checkpoints
</h3>

Расширение VS Code поддерживает checkpoints, которые отслеживают редактирование файлов Claude и позволяют вернуться к предыдущему состоянию. Наведите указатель мыши на любое сообщение, чтобы открыть кнопку rewind, затем выберите один из трёх вариантов:

* **Fork conversation from here**: начните новую ветку разговора с этого сообщения, сохраняя все изменения кода
* **Rewind code to here**: отмените изменения файлов до этой точки в разговоре, сохраняя полную историю разговора
* **Fork conversation and rewind code**: начните новую ветку разговора и отмените изменения файлов до этой точки

Полные сведения о том, как работают checkpoints и их ограничения, см. в разделе [Checkpointing](/docs/ru/checkpointing).

<h3 id="run-cli-in-vs-code">
  Запуск CLI в VS Code
</h3>

Чтобы использовать CLI, оставаясь в VS Code, откройте встроенный терминал (`` Ctrl+` `` на Windows/Linux или `` Cmd+` `` на Mac) и запустите `claude`. CLI автоматически интегрируется с вашей IDE для функций, таких как просмотр diff и обмен диагностикой.

Установка расширения не добавляет `claude` в PATH вашей оболочки. Расширение включает приватную копию CLI для своей панели чата, но ввод `claude` в терминал требует [автономной установки CLI](/docs/ru/setup). Запустите установку один раз, и команды на этой странице, включая `claude mcp add` и `claude --resume`, будут работать в любом терминале. Если `claude` всё ещё не найден после установки, [проверьте ваш PATH](/docs/ru/troubleshoot-install#verify-your-path).

Если вы используете внешний терминал, запустите `/ide` внутри Claude Code, чтобы подключить его к VS Code.

<h3 id="connect-to-external-tools-with-mcp">
  Подключение к внешним инструментам с помощью MCP
</h3>

MCP (Model Context Protocol) серверы дают Claude доступ к внешним инструментам, базам данных и API.

Чтобы управлять MCP серверами, не покидая VS Code, введите `/mcp` на панели чата. В открывшемся диалоговом окне вы можете добавлять серверы, удалять серверы, сохранённые в локальной, пользовательской или проектной [области](/docs/ru/mcp#mcp-installation-scopes), включать или отключать серверы, переподключаться к серверу и управлять аутентификацией OAuth. Добавление и удаление серверов в диалоговом окне требует Claude Code v2.1.261 или более поздней версии.

Вы также можете запустить `claude mcp add` во встроенном терминале VS Code (`` Ctrl+` `` или `` Cmd+` ``). Диалоговое окно и команда терминала сохраняют в одну и ту же конфигурацию MCP, и изменения из любого источника вступают в силу в разговорах, которые вы начинаете впоследствии. Пример ниже добавляет удалённый MCP сервер GitHub, который аутентифицируется с помощью [личного токена доступа](https://github.com/settings/personal-access-tokens), переданного в качестве заголовка:

```bash theme={null}
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ \
  --header "Authorization: Bearer YOUR_GITHUB_PAT"
```

Замените `YOUR_GITHUB_PAT` на ваш личный токен доступа. Команда `claude mcp add` сохраняет конфигурацию без проверки учётных данных, поэтому здесь принимается значение-заполнитель, но сервер не подключится позже. Чтобы проверить соединение, начните новый разговор, введите `/mcp` и проверьте, что сервер показывает **Connected**. Сервер с неправильными учётными данными показывает **Failed**.

После настройки попросите Claude использовать инструменты (например, "Review PR #456").

Чтобы найти серверы для подключения, см. [Find and build MCP servers](/docs/ru/mcp#find-and-build-mcp-servers).

<h2 id="security-and-privacy">
  Безопасность и конфиденциальность
</h2>

Ваш код остаётся приватным. Claude Code обрабатывает ваш код для предоставления помощи, но не использует его для обучения моделей. Подробнее о обработке данных и способах отказа от логирования см. [Data and privacy](/docs/ru/data-usage).

Когда включены разрешения на автоматическое редактирование, Claude Code может изменять файлы конфигурации VS Code (такие как `settings.json` или `tasks.json`), которые VS Code может выполнять автоматически. Чтобы снизить риск при работе с ненадёжным кодом:

* Включите [VS Code Restricted Mode](https://code.visualstudio.com/docs/editor/workspace-trust#_restricted-mode) для ненадёжных рабочих пространств
* Используйте Manual mode вместо Edit automatically или Auto для редактирования
* Внимательно проверяйте изменения перед их принятием

<h3 id="the-built-in-ide-mcp-server">
  Встроенный MCP сервер IDE
</h3>

Когда расширение активно, оно запускает локальный MCP сервер, к которому CLI подключается автоматически. Именно так CLI открывает различия в встроенном средстве просмотра различий VS Code, читает ваш текущий выбор для упоминаний `@` и — когда вы работаете в записной книжке Jupyter — просит VS Code выполнить ячейки.

Сервер называется `ide` и скрыт от `/mcp`, потому что нечего настраивать. Однако если ваша организация использует hook `PreToolUse` для создания списка разрешённых MCP инструментов, вам нужно знать, что он существует.

**Выделение и контекст открытого файла.** Во время подключения CLI включает ваш текущий выбор в редакторе и путь активного файла в качестве контекста для каждого отправляемого вами запроса. Стенограмма показывает строку `⧉ Selected N lines from <file>` когда это происходит.

Чтобы исключить конфиденциальный файл, такой как `.env`, добавьте [правило отказа `Read`](/docs/ru/permissions#read-and-edit) для его пути. Соответствующее правило отказа предотвращает как выбранный текст, так и уведомление об открытом файле для этого файла от достижения Claude.

Если вы отключите [параметр Attach Open File](#extension-settings), CLI получит путь активного файла только при наличии выделенного текста в нём.

**Транспорт и аутентификация.** Сервер привязывается к `127.0.0.1` на случайный порт в диапазоне 10000–65535, и порт не настраивается. Транспорт — это незашифрованный `ws://`; поскольку сокет только для обратного пути, любой процесс, который может перехватить трафик, также может прочитать токен из файла блокировки, поэтому TLS не добавит защиту. Каждая активация расширения генерирует свежий случайный токен аутентификации, записывает его в файл блокировки в `~/.claude/ide/<port>.lock`, и CLI должен представить его как заголовок `X-Claude-Code-Ide-Authorization` для подключения. Файл блокировки имеет разрешения `0600` в каталоге `0700`, поэтому только пользователь, запустивший VS Code, может его прочитать. Если установлена переменная `CLAUDE_CONFIG_DIR`, файл блокировки записывается в `$CLAUDE_CONFIG_DIR/ide/` вместо этого.

**Инструменты, предоставляемые модели.** Сервер размещает дюжину инструментов, но только два видны модели. Остальные — это внутренний RPC, который CLI использует для собственного пользовательского интерфейса — открытие различий, чтение выборок, сохранение файлов — и отфильтровываются перед тем, как список инструментов достигает Claude.

| Имя инструмента (как его видят hooks) | Что он делает                                                                                                                         | Только для чтения |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| `mcp__ide__getDiagnostics`            | Возвращает диагностику языкового сервера — ошибки и предупреждения на панели Problems в VS Code. Опционально ограничено одним файлом. | Да                |
| `mcp__ide__executeCode`               | Запускает код Python в ядре активной записной книжки Jupyter. См. поток подтверждения ниже.                                           | Нет               |

**Выполнение Jupyter всегда сначала спрашивает.** `mcp__ide__executeCode` не может ничего запустить молча. При каждом вызове код вставляется как новая ячейка в конце активной записной книжки, VS Code прокручивает её в поле зрения, и встроенное Quick Pick спрашивает вас **Execute** или **Cancel**. Отмена — или закрытие средства выбора с помощью `Esc` — возвращает ошибку Claude и ничего не запускается. Инструмент также отказывает, когда нет активной записной книжки, когда расширение Jupyter (`ms-toolsai.jupyter`) не установлено, или когда ядро не является Python.

<Note>
  Подтверждение Quick Pick отделено от hooks `PreToolUse`. Запись в список разрешений для `mcp__ide__executeCode` позволяет Claude *предложить* запуск ячейки; Quick Pick внутри VS Code — это то, что позволяет ей *фактически* запуститься.
</Note>

<h3 id="extension-won’t-install">
  Расширение не устанавливается
</h3>

* Убедитесь, что у вас установлена совместимая версия VS Code (1.94.0 или выше)
* Проверьте, что VS Code имеет разрешение на установку расширений
* Попробуйте установить напрямую из [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)

<h3 id="spark-icon-not-visible">
  Значок Spark не виден
</h3>

Значок Spark появляется на **панели инструментов редактора** (в верхнем правом углу редактора) при открытом файле. Если вы его не видите:

1. **Откройте файл**: Значок требует открытого файла. Просто открытой папки недостаточно.
2. **Проверьте версию VS Code**: Требуется версия 1.94.0 или выше (Help → About)
3. **Перезагрузите VS Code**: Выполните "Developer: Reload Window" из палитры команд
4. **Отключите конфликтующие расширения**: Временно отключите другие расширения ИИ (Cline, Continue и т. д.)
5. **Проверьте доверие рабочей области**: Расширение не работает в режиме ограниченного доступа

Кроме того, если вы установили [`preferredLocation`](#extension-settings) на `sidebar` или открыли Claude с помощью **Claude Code: Open in Side Bar**, нажмите "✻ Claude Code" на **строке состояния** (в нижнем правом углу). Это работает даже без открытого файла. Вы также можете использовать **палитру команд** (`Cmd+Shift+P` / `Ctrl+Shift+P`) и ввести "Claude Code".

<h3 id="cmd-esc-does-nothing-on-macos">
  Cmd+Esc ничего не делает на macOS
</h3>

На macOS Tahoe и более поздних версиях системный ярлык Game Overlay по умолчанию привязан к `Cmd+Esc` и перехватывает нажатие клавиши до того, как оно достигнет VS Code. Чтобы освободить ярлык:

1. Откройте System Settings
2. Перейдите в Keyboard, затем Keyboard Shortcuts, затем Game Controllers
3. Снимите флажок Game Overlay

Кроме того, вы можете переназначить расширение на другую клавишу: откройте редактор [Keyboard Shortcuts](https://code.visualstudio.com/docs/configure/keybindings) в VS Code (`Cmd+K Cmd+S`), найдите `Claude Code: Focus input` и назначьте новое сочетание клавиш.

<h3 id="claude-code-never-responds">
  Claude Code никогда не отвечает
</h3>

Если Claude Code не отвечает на ваши запросы:

1. **Проверьте подключение к интернету**: Убедитесь, что у вас есть стабильное подключение к интернету
2. **Начните новый разговор**: Попробуйте начать новый разговор, чтобы проверить, сохраняется ли проблема
3. **Попробуйте CLI**: Выполните `claude` из терминала, чтобы увидеть более подробные сообщения об ошибках

Если проблемы сохраняются, [создайте проблему на GitHub](https://github.com/anthropics/claude-code/issues) с подробностями об ошибке.

<h2 id="uninstall-the-extension">
  Удаление расширения
</h2>

Чтобы удалить расширение Claude Code:

1. Откройте представление расширений (`Cmd+Shift+X` на Mac или `Ctrl+Shift+X` на Windows/Linux)
2. Найдите "Claude Code"
3. Нажмите **Uninstall**

Если вы запустите `claude` в интегрированном терминале VS Code, Claude Code автоматически переустановит расширение. Чтобы оно оставалось удалённым, отключите **Auto-install IDE extension** в `/config` или установите [`autoInstallIdeExtension`](/docs/ru/settings-reference#autoinstallideextension) на `false`. Вы также можете установить переменную окружения [`CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL`](/docs/ru/env-vars) на `1`.

Чтобы также удалить данные расширения и сбросить все параметры, удалите каталог хранилища расширения для вашей платформы.

На macOS:

```bash theme={null}
rm -rf ~/Library/"Application Support"/Code/User/globalStorage/anthropic.claude-code
```

На Linux:

```bash theme={null}
rm -rf ~/.config/Code/User/globalStorage/anthropic.claude-code
```

На Windows в PowerShell:

```powershell theme={null}
Remove-Item -Recurse -Force "$env:APPDATA\Code\User\globalStorage\anthropic.claude-code"
```

Для получения дополнительной помощи см. [руководство по устранению неполадок](/docs/ru/troubleshooting).
