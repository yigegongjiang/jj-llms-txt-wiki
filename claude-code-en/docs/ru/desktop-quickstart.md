# Начало работы с настольным приложением

> Установите Claude Code на рабочий стол и начните свой первый сеанс кодирования

Настольное приложение предоставляет вам Claude Code с графическим интерфейсом, созданным для запуска нескольких сеансов рядом: боковая панель для управления параллельной работой, макет с перетаскиванием с интегрированным терминалом и редактором файлов, визуальный просмотр различий, предпросмотр приложения в реальном времени, мониторинг GitHub PR с автоматическим слиянием и запланированные задачи. Терминал не требуется.

На этой странице описывается установка приложения и начало вашего первого сеанса. Если вы уже настроены, см. [Использование Claude Code Desktop](/docs/ru/desktop) для полного справочника.

Настольное приложение имеет три вкладки:

* **Chat**: Общее общение без доступа к файлам, аналогично claude.ai.
* **Cowork**: Автономный фоновый агент, который работает над задачами в изолированной виртуальной машине с собственной средой, работая независимо, пока вы занимаетесь другой работой. Локальные сеансы Cowork запускают виртуальную машину на вашем компьютере; удалённые сеансы Cowork запускают её на управляемой Anthropic виртуальной машине вместо этого.
* **Code**: Интерактивный помощник по кодированию с прямым доступом к вашим локальным файлам. В зависимости от режима разрешений вы одобряете каждое изменение по мере его предложения Claude или просматриваете изменения после того, как Claude их внесёт.

Chat и Cowork рассматриваются в [Центре справки Claude](https://support.claude.com/); установка и развёртывание настольного приложения рассматриваются в [статьях поддержки Claude Desktop](https://support.claude.com/en/collections/16163169-claude-desktop). На этой странице основное внимание уделяется вкладке **Code**.

<h2 id="install">
  Установка
</h2>

<Steps>
  <Step title="Установка и вход в систему">
    На macOS и Windows загрузите установщик по ссылкам выше и запустите его. На Linux следуйте инструкциям по установке в разделе [Claude Desktop на Linux](/docs/ru/desktop-linux). Запустите Claude из папки Applications на macOS, из меню Start на Windows или из средства запуска приложений на Linux, затем войдите со своей учетной записью Anthropic.
  </Step>

  <Step title="Откройте вкладку Code">
    Нажмите на вкладку **Code** в верхнем центре. Если нажатие на Code предлагает вам обновиться, вам необходимо сначала [подписаться на платный план](https://claude.com/pricing?utm_source=claude_code\&utm_medium=docs\&utm_content=desktop_quickstart_upgrade). Если он предлагает вам войти в систему онлайн, завершите вход и перезагрузите приложение. Если вы видите ошибку 403, см. [устранение неполадок аутентификации](/docs/ru/desktop#403-or-authentication-errors-in-the-code-tab).
  </Step>
</Steps>

Настольное приложение включает Claude Code. Вам не нужно устанавливать Node.js или CLI отдельно. Чтобы использовать `claude` из терминала, установите CLI отдельно. См. [Начало работы с CLI](/docs/ru/quickstart).

<h2 id="start-your-first-session">
  Начните свой первый сеанс
</h2>

С открытой вкладкой Code выберите проект и дайте Claude что-нибудь сделать.

<Steps>
  <Step title="Выберите окружение и папку">
    Выберите **Local**, чтобы запустить Claude на вашем компьютере, используя ваши файлы напрямую. Нажмите **Select folder** и выберите директорию вашего проекта.

    <Tip>
      Начните с небольшого проекта, который вы хорошо знаете. Это самый быстрый способ увидеть, что может делать Claude Code.
    </Tip>

    Вы также можете выбрать:

    * **Cloud**: Запускайте сеансы в облаке, которые продолжают работу даже если вы закроете приложение. См. [Use Claude Code in the cloud](/docs/ru/claude-code-on-the-web) для информации о том, как работают облачные сеансы.
    * **SSH**: Подключитесь к удаленной машине через SSH, например к вашим собственным серверам, облачным виртуальным машинам или контейнерам разработки. Desktop автоматически устанавливает Claude Code на удаленную машину при первом подключении.
    * **WSL** (Windows): Запустите сеанс внутри [WSL 2 дистрибутива](/docs/ru/desktop-wsl); Claude Code, инструменты и git выполняются на стороне Linux с собственными путями.
  </Step>

  <Step title="Выберите модель">
    Выберите модель из раскрывающегося списка рядом с кнопкой отправки. См. [models](/docs/ru/model-config#available-models) для сравнения доступных моделей. Вы можете изменить модель позже из того же раскрывающегося списка.
  </Step>

  <Step title="Скажите Claude, что делать">
    Введите, что вы хотите, чтобы Claude сделал:

    * `Find a TODO comment and fix it`
    * `Add tests for the main function`
    * `Create a CLAUDE.md with instructions for this codebase`

    [Сеанс](/docs/ru/desktop#work-in-parallel-with-sessions) — это беседа с Claude о вашем коде. Каждый сеанс отслеживает свой собственный контекст и изменения.
  </Step>

  <Step title="Проверьте и примите изменения">
    То, что произойдет дальше, зависит от [режима разрешений](/docs/ru/desktop#choose-a-permission-mode), показанного в селекторе рядом с кнопкой отправки:

    * **Auto или Accept edits**: Claude применяет изменения файлов, и появляется индикатор, такой как `+12 -1`, чтобы вы могли просмотреть их в представлении diff
    * **Manual**: Claude предлагает каждое изменение и ждет вашего одобрения перед его применением. Ваши файлы не изменяются, пока вы не примете изменение, и если вы отклоните изменение, Claude спросит, как вы хотели бы поступить вместо этого

    В режиме Manual вы увидите:

    1. [Представление diff](/docs/ru/desktop#review-changes-with-diff-view), показывающее точно, что изменится в каждом файле
    2. Кнопки Accept/Reject для одобрения или отклонения каждого изменения
    3. Обновления в реальном времени по мере того, как Claude работает над вашим запросом
  </Step>
</Steps>

<h2 id="now-what">
  Что дальше?
</h2>

Вы сделали первое редактирование. Полный справочник по всем возможностям Desktop см. в разделе [Use Claude Code Desktop](/docs/ru/desktop). Вот несколько вещей, которые стоит попробовать дальше.

**Прерывание и управление.** Вы можете перенаправить Claude в любой момент. Нажмите кнопку остановки, чтобы прервать немедленно, или введите исправление и нажмите **Enter**, чтобы отправить его без остановки выполняемого действия. В любом случае вам не нужно ждать завершения или начинать заново.

**Предоставьте Claude больше контекста.** Введите `@filename` в поле подсказки, чтобы добавить конкретный файл в беседу, прикрепите изображения и PDF-файлы с помощью кнопки вложения или перетащите файлы прямо в подсказку. Чем больше контекста у Claude, тем лучше результаты. См. [Add files and context](/docs/ru/desktop#add-files-and-context-to-prompts).

**Используйте skills для повторяющихся задач.** Введите `/` или нажмите **+** → **Slash commands**, чтобы просмотреть [built-in commands](/docs/ru/commands), [custom skills](/docs/ru/skills) и skills плагинов. Skills — это многократно используемые подсказки, которые вы можете вызывать всякий раз, когда они вам нужны, например контрольные списки проверки кода или этапы развертывания.

**Проверьте изменения перед фиксацией.** После редактирования файлов Claude появляется индикатор `+12 -1`. Нажмите на него, чтобы открыть [diff view](/docs/ru/desktop#review-changes-with-diff-view), просмотрите изменения файл за файлом и оставляйте комментарии к конкретным строкам. Claude читает ваши комментарии и вносит исправления. Нажмите **Review code**, чтобы Claude самостоятельно оценил различия и оставил встроенные предложения.

**Отрегулируйте объем контроля.** Ваш [permission mode](/docs/ru/desktop#choose-a-permission-mode) определяет, сколько Claude может делать без запроса одобрения:

* **Auto**: классификатор проверяет действия в фоновом режиме и блокирует рискованные вместо того, чтобы просить вас.
* **Manual**: Claude запрашивает разрешение перед редактированием файлов или запуском команд.
* **Accept edits**: Claude автоматически принимает редактирование файлов для более быстрой итерации.
* **Plan**: Claude предлагает подход без редактирования каких-либо файлов, что полезно перед крупным рефакторингом.

**Добавьте плагины для дополнительных возможностей.** Нажмите кнопку **+** рядом с полем подсказки и выберите **Plugins**, чтобы просмотреть и установить [plugins](/docs/ru/desktop#install-plugins), которые добавляют skills, агентов, MCP серверы и многое другое.

**Организуйте рабочее пространство.** Перетащите панели чата, diff, терминала, файла и браузера в любой нужный вам макет. Откройте терминал с помощью **Ctrl+\`**, чтобы запускать команды параллельно с вашей сессией, или нажмите на путь файла, чтобы открыть его в панели файлов. См. [Arrange your workspace](/docs/ru/desktop#arrange-your-workspace).

**Предпросмотр вашего приложения.** Когда вы запускаете сервер разработки на рабочем столе, ваше приложение открывается в панели Browser, которая также может [открывать внешние сайты](/docs/ru/desktop#browse-external-sites). Claude может просматривать работающее приложение, тестировать конечные точки, проверять журналы и повторять итерации на основе того, что он видит. См. [Preview your app](/docs/ru/desktop#preview-your-app).

**Отслеживайте ваш pull request.** После открытия PR, Claude Code отслеживает результаты проверок CI и может автоматически исправлять сбои или объединять PR после прохождения всех проверок. См. [Monitor pull request status](/docs/ru/desktop#monitor-pull-request-status).

**Поставьте Claude по расписанию.** Установите [scheduled tasks](/docs/ru/desktop-scheduled-tasks) для автоматического запуска Claude на регулярной основе: ежедневная проверка кода каждое утро, еженедельный аудит зависимостей или брифинг, который извлекает данные из ваших подключенных инструментов.

**Масштабируйте, когда будете готовы.** Откройте [parallel sessions](/docs/ru/desktop#work-in-parallel-with-sessions) на боковой панели, чтобы работать над несколькими задачами одновременно, каждая в своем Git worktree, и откройте [tasks pane](/docs/ru/desktop#watch-background-tasks), чтобы наблюдать за подагентами и фоновыми командами, которые запускает сессия. Откройте [side chat](/docs/ru/desktop#ask-a-side-question-without-derailing-the-session), чтобы задать вопрос без отвлечения основного потока. Отправьте [long-running work to the cloud](/docs/ru/desktop#run-long-running-tasks-in-the-cloud), чтобы он продолжался даже если вы закроете приложение, или [continue a session on the web or in your IDE](/docs/ru/desktop#continue-in-another-surface), если задача займет больше времени, чем ожидалось. [Connect external tools](/docs/ru/desktop#extend-claude-code) такие как GitHub, Slack и Linear, чтобы объединить ваш рабочий процесс.
