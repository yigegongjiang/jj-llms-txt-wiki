# Поделитесь выходом сеанса как артефактами

> Артефакты превращают работу Claude Code в живые интерактивные страницы на claude.ai, которые вы можете хранить в приватном режиме, делиться с вашей организацией или публиковать по общедоступной ссылке.

<Note>
  Артефакты доступны в планах Pro, Max, Team и Enterprise и требуют сеанса, вошедшего в систему с помощью [`/login`](/docs/ru/setup#authenticate). Полный набор требований см. в разделе [Доступность](#availability).
</Note>

[Артефакт](https://claude.com/features/artifacts) — это живая интерактивная веб-страница, которую Claude Code публикует из вашего сеанса на приватный URL на claude.ai. Вы открываете её в браузере, и она обновляется на месте по мере продолжения сеанса. Поделитесь ею из заголовка страницы, когда захотите, чтобы кто-то ещё её увидел.

<h2 id="when-to-use-an-artifact">
  Когда использовать артефакт
</h2>

Используйте артефакт, когда текст терминала — неправильный способ представления того, что создал Claude: вывод, который легче просматривать и с которым легче взаимодействовать, чем читать построчно. Claude создает страницу из всего, что может достичь ваша сессия, включая вашу кодовую базу и данные, которые она получает через ваши [подключенные инструменты](/docs/ru/mcp), поэтому страница может показывать вещи, которые потребовали бы абзацев для описания. Например, попросите Claude:

* Провести рецензента через pull request с аннотированными diff'ами
* Отрендерить панель управления из данных, которые сессия уже получила
* Расположить несколько вариантов дизайна или реализации рядом
* Вести временную шкалу расследования, которая заполняется во время выполнения длительной задачи
* Отправить коллеге ссылку вместо вставки вывода в Slack
* Опубликовать доску статуса, которая [получает свежие данные через MCP connectors](#pull-live-data-with-mcp-connectors) каждый раз, когда кто-то её открывает

См. [Что вы можете создать](#what-you-can-build) для подсказок, которые соответствуют этим задачам, и [Получение живых данных с помощью MCP connectors](#pull-live-data-with-mcp-connectors) для подсказки доски с поддержкой connectors.

<h3 id="what-an-artifact-is-not">
  Что артефакт не является
</h3>

Артефакт — это снимок работы: одна самодостаточная страница без бэкенда, поэтому она не может обслуживать несколько маршрутов. Для размещённого внутреннего инструмента с бэкендом разверните его на собственной инфраструктуре. См. [Ограничения страницы](#page-constraints) для полного набора ограничений.

<h2 id="create-an-artifact">
  Создание артефакта
</h2>

Claude может опубликовать артефакт самостоятельно, когда результат подходит для страницы, или вы можете попросить его напрямую. Чтобы попросить, назовите функцию или опишите желаемый визуальный результат простым языком. Хорошим кандидатом является все, что легче увидеть, чем прочитать как текст, например аннотированный diff, диаграмма или набор вариантов для сравнения. Приведенные ниже подсказки — два примера; см. [Что вы можете создать](#what-you-can-build) для получения дополнительных шаблонов.

```text wrap theme={null}
Make an artifact that walks through this PR with the diff annotated inline.
```

```text wrap theme={null}
Build a dashboard artifact of last week's deploy failures by service and keep it updated as you investigate.
```

Если вы не указали местоположение, Claude записывает страницу в файл HTML или Markdown во временный каталог вне вашего проекта, а затем публикует его. Публикация нового артефакта проходит через [режим разрешений](/docs/ru/permission-modes) вашей сессии:

* **Режим Auto**: классификатор проверяет публикацию вместо того, чтобы вас спрашивать, поэтому Claude может опубликовать страницу без того, чтобы вы видели подсказку. Какой режим используется в начале ваших сессий, зависит от вашего плана; см. [начальный режим разрешений](/docs/ru/permission-modes#eliminate-prompts-with-auto-mode).
* **Режимы Manual и Accept edits**: Claude Code запрашивает разрешение; это может звучать примерно так: `Claude wants to publish deploy-failures.html, uploading it to claude.ai (Anthropic's servers) to host as the page "Deploy failures by service", private to you until you share it`. Выберите **Yes** для публикации.

После того как вы один раз одобрите артефакт, Claude Code переиздает его без вопросов и снова спрашивает в некоторых случаях, включая:

* Claude объявляет возможность выполнения для страницы, такую как [вызовы соединителя](#pull-live-data-with-mcp-connectors) или [загрузки файлов](#offer-a-file-download)
* Вы с тех пор [поделились им публично](#share-an-artifact)
* Вы с тех пор поделились им с конкретными людьми или вашей организацией с последней версией, выбранной как версия, которую видят зрители

После первой публикации Claude выводит URL, и ваш браузер открывает новую страницу. Если вы отправили подсказку через [Remote Control](/docs/ru/remote-control) с claude.ai, Claude Desktop или мобильного приложения Claude, вкладка не открывается на машине, на которой работает сессия. Браузер открывается там в следующий раз, когда Claude публикует артефакт из подсказки, которую вы вводите в терминале. Нажмите `Ctrl+]` в любой момент, чтобы переоткрыть самый последний артефакт сессии.

Claude выбирает название артефакта и эмодзи, и оба появляются в вашей [галерее артефактов](#share-an-artifact) на claude.ai и в общих ссылках. Claude также может выбрать значок вкладки браузера, который соответствует тому, что находится на странице, например диаграмма или календарь. Попросите Claude выбрать конкретное название, эмодзи или значок вкладки, если вы хотите.

Чтобы остановить автоматическое открытие браузера при публикации нового артефакта, установите `CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0` в вашей среде.

Если Claude ответит, что не может опубликовать, или напишет локальный файл HTML без ссылки, инструмент не включен для вашей сессии. Проверьте требования [Доступность](#availability).

<h2 id="update-an-artifact">
  Обновление артефакта
</h2>

Попросите Claude пересмотреть страницу или позвольте долгоживущей задаче переопубликовать её по мере выполнения. Claude редактирует базовый файл и переопубликовывает его на тот же URL.

```text wrap theme={null}
Добавьте разбивку по регионам ниже диаграммы сводки и переопубликуйте.
```

Любой, у кого открыта страница, видит обновление на месте. Каждая публикация становится версией, и из элемента управления **Share** в заголовке страницы вы можете выбрать, какую версию видят зрители.

Чтобы обновить артефакт из другого сеанса, укажите Claude его URL или прикрепите его с помощью [`/artifacts`](#find-an-artifact-again). Без одного из них новый сеанс создаст новый артефакт вместо обновления существующего.

```text wrap theme={null}
Обновите https://claude.ai/code/artifact/5fbea6f3-... с сегодняшними числами.
```

<h2 id="find-an-artifact-again">
  Найти артефакт снова
</h2>

Выполните `/artifacts` в Claude Code, чтобы вывести список всех принадлежащих вам артефактов и артефактов, которые с вами поделились. Выберите один и нажмите `o`, чтобы открыть его в браузере, или `c`, чтобы скопировать его ссылку. Нажмите `Enter`, чтобы прикрепить его к текущему сеансу; в версиях до v2.1.216 `Enter` открывал его в браузере. Claude Code читает список из вашей учетной записи claude.ai, поэтому это работает в новом сеансе и после `/clear`, когда ссылка прокрутилась из терминала. Требуется Claude Code v2.1.208 или более поздняя версия.

<h2 id="share-an-artifact">
  Поделиться артефактом
</h2>

Новый артефакт видна только вам. Чтобы поделиться ею, откройте артефакт в браузере и используйте элемент управления **Share** в заголовке страницы. Заголовок также содержит ссылку на вашу галерею на [claude.ai/code/artifacts](https://claude.ai/code/artifacts), в которой перечислены все созданные вами артефакты.

Зрители в вашей организации могут видеть, кто опубликовал страницу: на артефакте, общем доступе в пределах вашей организации, ваше имя находится в меню заголовка, а на общедоступном артефакте оно находится в заголовке страницы для вошедших в систему зрителей в вашей организации. Зритель, который открывает общедоступную ссылку без входа в систему или из-за пределов вашей организации, видит метку `Content is user-generated and unverified.` вместо вашего имени.

Кого вы можете добавить в общий доступ, зависит от вашего плана:

* **В пределах вашей организации**: в планах Team и Enterprise предоставьте доступ определённым людям в вашей организации или всем в ней. Зрители входят в claude.ai как члены вашей организации, чтобы увидеть страницу.
* **Публично**: поделитесь ссылкой, которую может открыть любой в интернете, без необходимости входа в claude.ai. В планах Pro и Max общедоступная ссылка — единственный способ поделиться артефактом. В планах Team и Enterprise общедоступный доступ отключён до тех пор, пока владелец не [включит его для организации](#control-public-sharing).

<h3 id="let-someone-edit-with-you">
  Позвольте кому-то редактировать вместе с вами
</h3>

Люди, с которыми вы делитесь, по умолчанию являются зрителями: они видят каждую опубликованную вами версию, но не могут изменять страницу. В планах Team и Enterprise вы также можете сделать кого-то редактором. В диалоговом окне общего доступа добавьте человека и измените его роль с **viewer** на **editor**.

Редактор публикует новые версии так же, как вы [обновляете артефакт из другого сеанса](#update-an-artifact): он предоставляет Claude URL артефакта или прикрепляет его из [`/artifacts`](#find-an-artifact-again), и Claude извлекает текущее содержимое и переиздаёт его с его изменениями. Все, у кого открыта страница, видят каждое обновление в реальном времени.

<h2 id="read-an-artifact-shared-with-you">
  Прочитайте артефакт, которым с вами поделились
</h2>

Когда кто-то делится с вами артефактом, вы можете попросить Claude прочитать его: предоставьте Claude его URL или прикрепите его из [`/artifacts`](#find-an-artifact-again).

Claude читает страницу, написанную кем-то другим, так же, как он читает веб-страницу с помощью [WebFetch](/docs/ru/tools-reference#webfetch-tool-behavior): он получает краткое описание того, о чем его попросили, а не исходную страницу, и краткое описание содержит инструкции, написанные на странице, вместо того чтобы их передавать. Claude Code также сохраняет полный исходный код страницы в локальный файл, который Claude может открыть, когда ему нужно точное содержимое, например для повторной публикации артефакта в качестве [редактора](#let-someone-edit-with-you).

<h2 id="collect-comments-on-an-artifact">
  Собирайте комментарии к артефакту
</h2>

Когда вы делитесь артефактом в пределах вашей организации, люди, с которыми вы им делитесь, могут оставлять комментарии на странице, и вы можете попросить Claude прочитать эти комментарии и ответить на них. Вам нужна Claude Code версии 2.1.221 или более поздней и план Team или Enterprise, потому что только артефакт, который вы [делите в пределах вашей организации](#share-an-artifact), получает комментарии. Claude читает комментарии в двух случаях:

* **Вы просите Claude прочитать их**: дайте Claude URL артефакта и попросите комментарии. Claude перечисляет каждый тред и отмечает комментарии, которые отправил ему кто-то, кто может редактировать артефакт.
* **Кто-то, кто может редактировать артефакт, отправляет комментарий Claude**: в треде на странице они отправляют комментарий с помощью **Send to Claude**, или упоминают `@claude` в нём. В любом случае они активируют тред.

Claude может ответить или разрешить только активированный тред. Другие треды остаются открытыми до тех пор, пока человек не разрешит их на странице. Зрители видят каждый ответ, приписываемый Claude, через вас.

Если вы делитесь артефактом публично, зрители не могут комментировать его: на странице написано `Comments aren't available while this Artifact is shared publicly.` Чтобы переключить артефакт, который уже имеет треды комментариев, на публичную ссылку, сначала удалите треды.

Чтобы попросить комментарии самостоятельно, дайте Claude URL:

```text wrap theme={null}
Read the comments on https://claude.ai/code/artifact/5fbea6f3-... and make the changes the commenters ask for.
```

Если Claude говорит вам, что не может читать комментарии, подтвердите вашу версию, вашу сессию и параметр флага функции:

* Вы используете Claude Code версии 2.1.221 или более поздней.
* Вы не находитесь в своей первой сессии после установки Claude Code или обновления с версии до v2.1.221. В этой [первой сессии после установки или обновления](/docs/ru/env-vars#first-session-after-an-install-or-upgrade) Claude может быть не в состоянии читать комментарии; начните новую сессию и попросите снова.
* Вы не отключили получение флагов функций.

<h3 id="let-claude-reply-to-comments-on-its-own">
  Позвольте Claude отвечать на комментарии самостоятельно
</h3>

После того как ваша сессия опубликует артефакт, Claude Code следит за этим артефактом на предмет комментариев столько, сколько работает сессия. Когда кто-то, кто может редактировать артефакт, отправляет комментарий Claude, он сразу же поступает в вашу сессию, и Claude может прочитать тред и ответить без вашего участия.

Вам нужна Claude Code версии 2.1.228 или более поздней. Если вы отключили [получение флагов функций](/docs/ru/env-vars#features-that-need-feature-flag-fetching), Claude Code не следит за комментариями.

Ваш [режим разрешений](/docs/ru/permission-modes) определяет, что делает Claude, когда приходит отправленный комментарий:

* **Claude отвечает самостоятельно**: когда ваш режим разрешений позволяет Claude опубликовать ответ без вашего разрешения, Claude читает тред и отвечает, и редактирует артефакт, когда комментарий просит об изменении. Вы видите `Auto-replied to comment thread on Artifact: <name>` или `Auto-edited Artifact: <name> in response to a comment thread`.
* **Claude ждёт вас**: вне режима плана, когда публикация ответа потребует вашего одобрения, вы видите `Comments are waiting on Artifact: <name>`. Claude затем просит у вас одобрение на чтение треда и снова на публикацию ответа.
* **Claude делает паузу в режиме плана**: вы видите `Comments are waiting on Artifact: <name>`, и Claude не отвечает до тех пор, пока вы не выйдете из режима плана и не попросите его прочитать и ответить.

Claude также прекращает отвечать самостоятельно на артефакт после обработки 60 отправленных комментариев или активаций тредов на этом артефакте в течение часа. Вы видите `Comments are waiting on Artifact: <name>` один раз, и Claude возобновляет работу по мере того, как комментарии этого часа устаревают.

Запустите `/tasks` чтобы увидеть каждый артефакт, за которым следит ваша сессия, указанный как задача с живыми обновлениями. Вы можете остановить Claude от самостоятельного ответа любым из этих способов:

* **Нажмите Ctrl+C один раз на неактивной подсказке**: Claude прекращает отвечать на каждый артефакт, за которым следит ваша сессия. Ответы возобновляются после того, как вы отправите следующее сообщение.
* **Остановите задачу в `/tasks`**: Claude прекращает отвечать на этот артефакт до тех пор, пока вы не попросите его возобновить ответы там. Повторная публикация артефакта не запускает ответы снова, и остановка по-прежнему применяется при возобновлении сессии позже.
* **Нажмите `Ctrl+X Ctrl+K` дважды в течение 3 секунд**: комбинация, которая [останавливает каждого работающего фонового подагента](/docs/ru/interactive-mode#general-controls), также останавливает Claude от ответа на каждый артефакт на оставшуюся часть сессии. Просьба Claude возобновить ответы не отменяет эту остановку.

Если служба, которая доставляет комментарии, становится недоступной или перестаёт отвечать, Claude Code продолжает пытаться переподключиться в течение некоторого времени, а затем прекращает следить за каждым артефактом, за которым следила ваша сессия.

<h2 id="pull-live-data-with-mcp-connectors">
  Получение актуальных данных с помощью коннекторов MCP
</h2>

Артефакт может вызывать [коннекторы MCP](/docs/ru/mcp#use-mcp-servers-from-claude-ai) каждый раз, когда кто-то его просматривает, поэтому страница отображает текущие данные, а не снимок из сеанса, в котором она была создана. Вызовы коннекторов из артефактов доступны в планах Pro, Max, Team и Enterprise и требуют Claude Code версии 2.1.209 или более поздней. В более ранних версиях Claude публикует страницу с теми данными, которые сеанс собрал во время её создания.

Чтобы создать страницу с поддержкой коннектора, назовите коннектор и данные, которые вам нужны, в вашем запросе:

```text wrap theme={null}
Build a dashboard artifact of our open pull requests that pulls the live list through my GitHub connector when the page loads.
```

Claude объявляет, какие коннекторы может вызывать страница, как часть публикации, и страница не может вызывать коннекторы вне этого объявления. Только коннекторы из вашей учётной записи claude.ai подходят: Claude называет их в объявлении, и когда кто-то просматривает страницу, каждый вызов [выполняется через собственное подключение учётной записи просмотра](#how-connector-calls-work-for-viewers) к этому коннектору. Локальные MCP серверы, которые вы настраиваете в Claude Code, такие как серверы из `.mcp.json`, могут предоставлять данные во время создания страницы Claude, но опубликованная страница не может их вызывать.

Страница получает данные при загрузке и может обновляться по расписанию или когда зритель использует элемент управления обновлением на странице. Ответы кэшируются в браузере зрителя, поэтому повторно открытая страница отображается из кэшированных ответов немедленно, а затем обновляется с новыми результатами.

<h3 id="how-connector-calls-work-for-viewers">
  Как работают вызовы коннекторов для зрителей
</h3>

Когда опубликованная страница вызывает коннектор, вызов использует учётную запись человека, просматривающего страницу, а не учётную запись человека, который её опубликовал:

* **Каждый зритель использует свои собственные коннекторы**: вызовы проходят через подключённые инструменты учётной записи просмотра, поэтому два человека, открывающие одну и ту же панель управления, могут видеть разные данные в зависимости от того, к чему имеют доступ их учётные записи. Страница никогда не видит учётные данные никого; claude.ai делает вызовы от имени страницы.
* **Зрители сначала одобряют доступ**: claude.ai просит разрешение у каждого зрителя перед первым вызовом коннектора на странице. Зритель, который отказывает, или у которого нет подключённого коннектора, используемого страницей, всё равно видит страницу без её живых разделов.
* **Действия также используют учётную запись зрителя**: страница может предлагать элементы управления, которые вызывают инструменты коннектора с побочными эффектами, такие как отправка сообщения или обновление проблемы. Действие выполняется через учётную запись того, кто выбирает элемент управления.

Когда вы планируете поделиться страницей с поддержкой коннектора, попросите Claude включить резервное сообщение в каждый живой раздел, который называет коннектор, который ему нужен. Зритель, у которого отсутствует подключение, затем видит, что нужно подключить, вместо пустого раздела.

Артефакт, который вызывает коннекторы, не может быть поделён по общей ссылке ни в одном плане. В планах Team и Enterprise вы можете оставить его приватным или [поделиться им в пределах вашей организации](#share-an-artifact). В планах Pro и Max, где общая ссылка — единственный способ поделиться, артефакт с поддержкой коннектора остаётся приватным для вас.

<h3 id="the-page-shows-no-live-data-for-a-viewer">
  Страница не показывает живые данные для зрителя
</h3>

Когда страница с поддержкой коннектора отображается, но её живые разделы остаются пустыми для кого-то, с кем вы её поделились, проработайте эти причины:

* **Зритель не подключил коннектор**: коннекторы привязаны к учётной записи, поэтому каждому зрителю нужно своё подключение к каждому коннектору, который вызывает страница. Они могут добавить его в **Settings > Connectors** на claude.ai, а затем перезагрузить страницу.
* **Зритель отказал в разрешении**: отказ действует до конца этой загрузки страницы. Перезагрузка страницы возвращает запрос разрешения.
* **Вызовы коннекторов отключены для организации**: владелец управляет переключателем [**Enable artifact connectors**](#control-connector-calls-from-artifacts) в параметрах администратора.
* **Страница вызывает имена инструментов, которые коннектор не предоставляет**: затронутые разделы остаются пустыми для всех, включая вас. Это может произойти, когда страница называет отдельные инструменты за коннектором в стиле шлюза, который предоставляет только несколько собственных инструментов. Попросите Claude исправить имена инструментов, которые вызывает страница, и опубликуйте её снова.

  Когда Claude публикует страницу и инструменты этого коннектора доступны в вашем сеансе, Claude Code проверяет имена инструментов, которые объявляет страница, против них, предупреждает Claude об именах, которые не совпадают, и отказывает в публикации, когда ни один не совпадает. До версии 2.1.265 она публиковала страницу без их проверки.

<h2 id="offer-a-file-download">
  Предложить загрузку файла
</h2>

Артефакт может предложить зрителям файл, который генерирует страница, например CSV-экспорт таблицы или PNG диаграммы. Зритель сохраняет его через элемент управления загрузкой на странице, например кнопку. Загрузки файлов — это возможность во время выполнения, которую claude.ai включает для каждой учетной записи, поэтому Claude проверяет, есть ли у вашей учетной записи эта возможность, прежде чем создавать элемент управления.

Зрители не могут сохранить файл из обычной ссылки для загрузки или скрипта на странице, потому что средство просмотра артефактов на claude.ai блокирует любую загрузку, которую инициирует сама страница, включая ссылки на URL-адреса `data:` или `blob:`. Если на странице есть кнопки загрузки, созданные таким образом, попросите Claude перестроить их с использованием возможности загрузок.

Чтобы предложить файл, запросите элемент управления и формат файла в вашем приглашении:

```text wrap theme={null}
Add a button that downloads this table as a CSV file.
```

Claude объявляет возможность загрузок как часть публикации, так же как это [объявляет connectors](#pull-live-data-with-mcp-connectors).

<h2 id="what-you-can-build">
  What you can build
</h2>

Артефакт — это одна страница HTML, поэтому всё, что вы можете выразить в HTML, CSS и встроенном JavaScript, находится в области действия. Приведённые ниже шаблоны встречаются чаще всего.

<h3 id="walk-through-a-change">
  Walk through a change
</h3>

Попросите страницу, которая отображает diff или изменение дизайна с аннотациями рядом с соответствующими строками, чтобы рецензенты могли прочитать ваше обоснование рядом с кодом вместо того, чтобы восстанавливать его из описания.

```text wrap theme={null}
Make an artifact that walks through this PR. Render the diff with margin annotations and color-code findings by severity.
```

<h3 id="compare-alternatives">
  Compare alternatives
</h3>

Попросите несколько вариантов на одной странице, чтобы вы могли оценить их друг против друга. Это работает для макетов, копии, форм API или планов реализации.

```text wrap theme={null}
Make an artifact with four distinctly different layouts for the settings panel. Vary density and grouping, and lay them out as a grid with a one-line tradeoff under each.
```

<h3 id="tune-with-interactive-controls">
  Tune with interactive controls
</h3>

Попросите ползунки, переключатели или поля ввода, привязанные к тому, что вы настраиваете, чтобы вы могли исследовать значения напрямую вместо их описания.

```text wrap theme={null}
Build an artifact with sliders for the easing curve, duration, and delay so I can try values on this transition. Show the animation live as I move them.
```

<h3 id="bring-the-result-back-to-your-session">
  Bring the result back to your session
</h3>

Артефакт может действовать как лёгкий редактор для решения, которое вы затем передаёте Claude. Попросите элемент управления экспортом, который производит текст, который вы можете вставить в терминал, чтобы результат взаимодействия со страницей вернулся в сеанс вместо того, чтобы остаться на странице.

```text wrap theme={null}
Make a triage board artifact with each open issue as a draggable card across Now, Next, Later, and Cut columns. Add a "Copy as prompt" button that gives me the final ordering to paste back here.
```

<h3 id="track-work-in-progress">
  Track work in progress
</h3>

Попросите Claude держать артефакт в актуальном состоянии во время выполнения длительной задачи, чтобы любой, у кого есть ссылка, мог следить без чтения терминала.

```text wrap theme={null}
Turn this migration plan into a checklist artifact. Check items off as you complete them and add a note for anything you skip.
```

<h2 id="improve-the-visual-design">
  Улучшение визуального дизайна
</h2>

Claude применяет встроенный навык дизайна при создании артефакта, поэтому страницы получают продуманную палитру, типографику и макет без дополнительных подсказок. Этот навык также ищет существующую систему дизайна в вашем проекте перед выбором собственной. Дизайн-токены — это названные значения цвета, типографики и интервалов, которые ваша система дизайна переиспользует. Чтобы сохранить артефакты в соответствии с брендингом вашего продукта, запишите их там, где Claude сможет их найти, например в файле [CLAUDE.md](/docs/ru/memory) вашего проекта или в файле темы в вашем репозитории:

```markdown theme={null}
## Design system

- Colors: primary #1a4d8f, accent #f59e0b, surface #f8fafc
- Typography: Inter for body, JetBrains Mono for code
- Spacing: 8px scale, 6px border radius
```

Claude рассматривает вашу систему дизайна как имеющую более высокий приоритет, чем его собственные выборы, а вашу подсказку как имеющую более высокий приоритет, чем оба. Заголовок и формат выше — это пример; подойдет любой четкий список цветов, шрифтов и интервалов.

Для типографики Claude может загружать шрифт из Google Fonts, единственного внешнего источника шрифтов, из которого может загружаться страница артефакта. Claude встраивает любой другой шрифт как `@font-face` data URI и предоставляет каждому шрифту резервный стек, поэтому страница все еще отображается, если шрифт не загружается. Чтобы использовать определенный шрифт, назовите его в вашей подсказке или в вашей системе дизайна.

<h2 id="draft-a-design-canvas">
  Создание макета дизайна
</h2>

Чтобы создать макет пользовательского интерфейса, потока экранов, целевой страницы или постера вместо создания страницы, запустите `/design` с кратким описанием. Claude создает дизайн в виде артбордов на одном холсте и публикует холст как артефакт Design. В кратком описании указывается, что вы хотите нарисовать:

```text wrap theme={null}
/design a settings screen for a mobile banking app
```

Откройте опубликованный артефакт в браузере рабочего стола для просмотра артбордов. Выберите элемент на артборде и измените его, и ваши правки сохранятся автоматически. Вы можете экспортировать каждый артборд как PNG или PDF.

`/design` требует сеанса, где [артефакты доступны](#availability), и Claude Code версии 2.1.265 или более поздней.

<h2 id="page-constraints">
  Ограничения страницы
</h2>

Каждый артефакт — это одна самостоятельная страница. Claude Code оборачивает опубликованный файл в оболочку HTML-документа и обслуживает его в соответствии со строгой политикой безопасности контента (CSP), которая определяет возможности страницы.

| Ограничение                   | Эффект                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| :---------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Внешние запросы               | Страница может загружать шрифты из Google Fonts и скрипты с [пяти общедоступных хостов CDN](#allowlist-the-viewer-domain): cdnjs, unpkg, Tailwind и jQuery CDN, а также выбранные пути на jsDelivr, такие как `/npm/`. CSP блокирует все внешние изображения и все остальные внешние скрипты, таблицы стилей и шрифты, а также позволяет вызовам `fetch`, XHR и WebSocket достигать только собственного источника страницы и хостов Google Fonts. Claude поэтому загружает любую библиотеку, которая требуется странице, с одного из этих CDN, встраивает все остальные CSS и JavaScript, а также встраивает изображения как data URI. [Вызовы Connector](#pull-live-data-with-mcp-connectors) проходят через claude.ai, который сам выполняет сетевой вызов. |
| Нет бэкенда                   | Артефакт — это статическая страница. Она не может самостоятельно аутентифицировать зрителей.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Загрузки                      | Страница не может самостоятельно инициировать загрузку. Чтобы позволить зрителям сохранить файл, который генерирует страница, Claude объявляет возможность загрузок. См. [Предложить загрузку файла](#offer-a-file-download).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Одна страница                 | Относительные ссылки не разрешаются, потому что ничего не развернуто рядом со страницей. Для многосекционного контента Claude использует якоря на странице, а не отдельные файлы.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Типы исходных файлов          | Опубликованный файл должен быть `.html`, `.htm` или `.md`, и должен декодироваться как UTF-8, или как little-endian UTF-16 по его метке порядка байтов. Файлы Markdown отображаются как стилизованные страницы документов с подсветкой синтаксиса кода. Файл, который не декодируется, или который содержит символ замены `U+FFFD`, [отклоняется с указанием строки и столбца для исправления](/docs/ru/errors#the-source-file-is-not-valid-utf-8-text).                                                                                                                                                                                                                                                                                                           |
| Размер отрендеренной страницы | Отрендеренная страница должна быть размером 16 МиБ или меньше. Большие встроенные изображения — обычная причина, когда публикация не удается из-за размера.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

Создание артефакта использует выходные токены, как и любой другой ответ, а стилизованная страница требует больше токенов, чем тот же контент в виде текста терминала. Встроенный CSS, JavaScript для интерактивных элементов управления и особенно изображения, встроенные как data URI, являются основными факторами. Чтобы снизить стоимость артефакта в токенах:

* Предпочитайте SVG или HTML и CSS для диаграмм вместо встроенных растровых изображений
* Опускайте интерактивность, которая вам не нужна
* Пусть страница суммирует большие наборы данных вместо того, чтобы встраивать их полностью

<h2 id="availability">
  Availability
</h2>

Артефакты требуют каждого условия ниже. Когда одно из них не выполнено, Claude записывает локальный файл HTML или говорит, что не может опубликовать вместо этого.

| Requirement         | Available when                                                                                                                                                                                                                                                                                                                                                                                                                                |
| :------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plan                | Pro, Max, Team или Enterprise. На планах Pro и Max артефакты являются приватными для вас до тех пор, пока вы их не поделитесь, и управление администратором не применяется. На планах Team артефакты включены по умолчанию. На планах Enterprise владелец [включает их](#manage-artifacts-for-your-organization) в параметрах администратора claude.ai.                                                                                       |
| Authentication      | Сеанс поддерживается учётной записью claude.ai: войдите с помощью `/login` в CLI или приложении для рабочего стола. Сеансы Claude Tag вошли через идентификацию агента, поэтому никаких шагов не требуется. Сеансы, использующие ключ API, [токен шлюза](/docs/ru/llm-gateway) или учётные данные поставщика облачных услуг, не могут публиковать.                                                                                                 |
| Model provider      | Anthropic API. Недоступно на [Amazon Bedrock](/docs/ru/amazon-bedrock), [Google Cloud's Agent Platform](/docs/ru/google-vertex-ai) или [Microsoft Foundry](/docs/ru/microsoft-foundry).                                                                                                                                                                                                                                                                      |
| Organization policy | Ключи шифрования, управляемые клиентом (CMEK), HIPAA и [Zero Data Retention](/docs/ru/zero-data-retention) не включены для организации.                                                                                                                                                                                                                                                                                                            |
| Surface             | Claude Code CLI или приложение Claude для рабочего стола версии 1.13576.0 или позже. Сеансы [Claude Tag](https://claude.com/docs/claude-tag/overview) также могут публиковать артефакты, когда оба Claude Tag и артефакты включены для организации. По умолчанию отключено в контекстах [Agent SDK](/docs/ru/agent-sdk/overview), GitHub Action и MCP-server, а также когда установлен [`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`](/docs/ru/env-vars). |

Доступность артефактов для вашей организации определяется политикой вашей организации, которую Claude Code загружает из `api.anthropic.com`. Когда Claude Code не может загрузить политику, артефакты недоступны. Когда вы просите один, Claude объясняет почему.

Если задействован прокси, VPN или веб-фильтр, попросите вашего администратора IT разрешить `api.anthropic.com`. Claude Code продолжает повторять попытки в фоновом режиме, и артефакты становятся доступными после загрузки политики и её разрешения.

<h2 id="disable-artifacts">
  Отключение артефактов
</h2>

Чтобы отключить артефакты для своих сеансов независимо от параметра вашей организации, используйте любой из следующих способов:

| Где                                   | Что делать                                                                                                                                              |
| :------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`/config`](/docs/ru/commands)             | Отключите строку **Artifacts**, которая записывает [`"enableArtifact": false`](/docs/ru/settings-reference#enableartifact) в ваши пользовательские параметры |
| [Файл параметров](/docs/ru/settings)       | Установите `"enableArtifact": false`. Устаревший параметр `"disableArtifact": true` также отключает артефакты                                           |
| [Переменная окружения](/docs/ru/env-vars)  | Установите `CLAUDE_CODE_DISABLE_ARTIFACT=1`                                                                                                             |
| [Правило разрешений](/docs/ru/permissions) | Добавьте `Artifact` в `permissions.deny`                                                                                                                |

После того как вы отключите артефакты в файле [`--settings`](/docs/ru/cli-reference#cli-flags) или с помощью `CLAUDE_CODE_DISABLE_ARTIFACT`, или ваш администратор отключит их в [управляемых параметрах](/docs/ru/server-managed-settings), ни один файл параметров не включит их обратно. До версии v2.1.242 файл, расположенный выше в [стеке приоритетов](/docs/ru/settings#settings-precedence), мог включить артефакты обратно, даже если файл с более низким приоритетом установил `"enableArtifact": false`.

Вы также можете установить `"enableArtifact": false` в файле `.claude/settings.json` или `.claude/settings.local.json` проекта, чтобы отключить артефакты для сеансов в этом проекте. Параметр `"enableArtifact": true` в любом из этих файлов не включит их обратно. Поддержка этого ключа в параметрах проекта и локальных параметрах требует Claude Code версии 2.1.242 или более поздней.

Если вы добавите правило `WebFetch` deny или ask без части `domain:`, оно не отключит артефакты и не заблокирует чтение артефактов. [Правило `WebFetch(domain:claude.ai)` в `deny` или `ask` применяется к чтению артефактов](/docs/ru/permissions#allow-or-deny-every-fetch).

<h2 id="manage-artifacts-for-your-organization">
  Управление артефактами для вашей организации
</h2>

Владельцы планов Team и Enterprise управляют артефактами из [параметров администратора claude.ai](https://claude.ai/admin-settings/claude-code). Содержимое артефактов хранится на инфраструктуре, управляемой Anthropic, и видно только аутентифицированным членам организации-издателя, если только артефакт не [опубликован публично](#control-public-sharing).

<h3 id="enable-or-disable-artifacts">
  Включение или отключение артефактов
</h3>

Чтобы включить или отключить артефакты для всей организации, перейдите в [**Параметры > Claude Code > Возможности**](https://claude.ai/admin-settings/claude-code) и используйте переключатель **Артефакты**. На планах Enterprise с управлением доступом на основе ролей вы можете дополнительно ограничить артефакты определёнными ролями: перейдите в [**Параметры > Роли**](https://claude.ai/admin-settings/roles), отредактируйте роль и установите разрешение **Артефакты** в группе **Claude Code**.

<h3 id="control-connector-calls-from-artifacts">
  Управление вызовами соединителей из артефактов
</h3>

[Вызовы соединителей из артефактов](#pull-live-data-with-mcp-connectors) имеют собственный переключатель, отдельный от переключателя **Артефакты**, который включает или отключает артефакты. Перейдите в [**Параметры > Возможности**](https://claude.ai/admin-settings/capabilities) и используйте переключатель **Включить соединители артефактов**. Один и тот же переключатель управляет вызовами соединителей из артефактов, созданных в беседах claude.ai, поэтому он находится в **Параметры > Возможности**, а не в **Параметры > Claude Code**.

<h3 id="control-public-sharing">
  Управление публичным совместным использованием
</h3>

Публичное совместное использование отключено по умолчанию на планах Team и Enterprise, поэтому члены могут совместно использовать артефакты только внутри организации, пока владелец его не включит. Чтобы позволить членам публиковать артефакты на публичные ссылки, которые может просматривать любой без входа, перейдите в **Параметры > Claude Code > Возможности** и включите **Внешнее совместное использование** под переключателем **Артефакты**. Отключение его обратно блокирует доступ через существующие публичные ссылки без изменения аудитории каждого артефакта; доступ возобновляется, если вы его снова включите.

<h3 id="set-a-retention-policy">
  Установка политики хранения
</h3>

Чтобы установить, как долго артефакты хранятся перед автоматическим удалением, перейдите в [**Параметры > Элементы управления данными и конфиденциальностью**](https://claude.ai/admin-settings/data-privacy-controls). Вы можете установить отдельные периоды хранения для артефактов, которые остаются приватными для их автора, и артефактов, которые были общими.

<h3 id="review-the-audit-log">
  Проверка журнала аудита
</h3>

Публикация, совместное использование и удаление артефакта каждый раз отображаются в журнале аудита вашей организации под типами событий `claude_artifact_*`, семейством, используемым для артефактов, созданных в беседах claude.ai.

<h3 id="allowlist-the-viewer-domain">
  Добавление домена средства просмотра в список разрешений
</h3>

Средство просмотра на claude.ai загружает каждый артефакт из изолированного источника `*.claudeusercontent.com`. Если ваша организация ограничивает исходящий сетевой доступ, добавьте этот домен в список разрешений вместе с `claude.ai`. См. [Требования к сетевому доступу](/docs/ru/network-config#network-access-requirements) для полного списка.

Артефакт, который загружает шрифт из [Google Fonts](#improve-the-visual-design), также запрашивает `fonts.googleapis.com` и `fonts.gstatic.com`. Оба хоста являются необязательными. Если вы их блокируете, артефакты отображаются в резервных шрифтах. Блокируйте с быстрым отклонением, а не с молчаливым отбросом, чтобы запрос шрифта завершился немедленно, а не задержал первый рендер страницы.

Артефакты также могут загружать библиотеки JavaScript, такие как React или пакет для построения диаграмм, из `cdnjs.cloudflare.com`, `cdn.jsdelivr.net`, `cdn.tailwindcss.com`, `code.jquery.com` и `unpkg.com`, и ни откуда больше. Если вы блокируете эти хосты, части артефакта, которые зависят от библиотеки, не работают, и в отличие от заблокированного шрифта, заблокированная библиотека не имеет резервного варианта. Блокируйте с быстрым отклонением и здесь, чтобы заблокированный запрос библиотеки завершился сразу, а не зависал до истечения времени ожидания.

<h3 id="list-and-delete-artifacts-with-the-compliance-api">
  Список и удаление артефактов с помощью API соответствия
</h3>

[API соответствия](https://docs.claude.com/en/api/compliance) предоставляет конечные точки для списка артефактов организации, получения содержимого определённой версии и удаления артефакта:

| Метод    | Конечная точка                                                      |
| :------- | :------------------------------------------------------------------ |
| `GET`    | `/v1/compliance/code/artifacts`                                     |
| `GET`    | `/v1/compliance/code/artifacts/{artifact_id}/versions/{version_id}` |
| `DELETE` | `/v1/compliance/code/artifacts/{artifact_id}`                       |

Для схем запроса и ответа см. [справочник API соответствия](https://docs.claude.com/en/api/compliance/code/artifacts).
