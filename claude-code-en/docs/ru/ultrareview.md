# Поиск ошибок с помощью ultrareview

> Запустите глубокий многоагентный анализ кода в облаке с помощью /code-review ultra, чтобы найти и проверить ошибки перед слиянием.

<Note>
  Ultrareview — это функция исследовательского предпросмотра. Функция, цены и доступность могут измениться на основе отзывов. Команда вызывается как `/code-review ultra`. Когда ultrareview доступен для вашей учетной записи, `/ultrareview` является псевдонимом.
</Note>

Ultrareview — это глубокий анализ кода, который работает как [облачный сеанс](/docs/ru/claude-code-on-the-web) на инфраструктуре Anthropic. Когда вы запускаете `/code-review ultra`, Claude Code запускает флот агентов-рецензентов в облачной изолированной среде для поиска ошибок в вашей ветке или запросе на слияние.

По сравнению с локальным `/code-review`, ultrareview предлагает:

* **Более высокий сигнал**: каждый найденный результат независимо воспроизводится и проверяется, поэтому результаты сосредоточены на реальных ошибках, а не на предложениях по стилю
* **Более широкое покрытие**: более крупный флот агентов-рецензентов исследует изменение параллельно, что выявляет проблемы, которые может пропустить локальный анализ
* **Без использования локальных ресурсов**: анализ работает полностью в облачной изолированной среде, поэтому ваш терминал остается свободным для другой работы во время его выполнения

Ultrareview требует аутентификации с помощью учетной записи claude.ai, так как работает как облачный сеанс на инфраструктуре Anthropic. Если вы вошли только с помощью ключа API, запустите `/login` и сначала аутентифицируйтесь с помощью claude.ai. Ultrareview недоступен при использовании Claude Code с Amazon Bedrock, Google Cloud's Agent Platform или Microsoft Foundry, а также недоступен для организаций, которые включили Zero Data Retention. Когда ultrareview недоступен, `/code-review ultra` запускает локальный анализ в вашем сеансе вместо этого.

<h2 id="run-ultrareview-from-the-cli">
  Запуск ultrareview из CLI
</h2>

Начните анализ из любого репозитория git:

```text theme={null}
/code-review ultra
```

Без аргументов ultrareview анализирует разницу между вашей текущей ветвью и ветвью по умолчанию, включая незафиксированные и подготовленные изменения. Для незафиксированных изменений в файлах, названных как учетные данные или ключи, таких как `.env` и `*.tfvars` файлы, Claude Code следует правилам для [загрузки локального репозитория в облачную сессию](/docs/ru/claude-code-on-the-web#send-local-repositories-without-github).

Для анализа ветки Claude Code упаковывает состояние репозитория и загружает его в удаленную изолированную среду; когда вы [анализируете запрос на слияние](#review-a-pull-request), Claude Code ничего не загружает с вашей машины.

Перед запуском Claude Code показывает диалоговое окно подтверждения с областью анализа, оставшимися бесплатными запусками и предполагаемой стоимостью; для анализа ветки область включает количество файлов и строк. После подтверждения анализ продолжается в фоновом режиме, пока вы продолжаете использовать вашу сессию.

Команда запускается только при вызове с помощью `/code-review ultra`; Claude не запускает ultrareview самостоятельно.

<h3 id="review-against-a-different-base">
  Анализ относительно другой базы
</h3>

Чтобы сравнить с базой, отличной от ветви по умолчанию, передайте имя ветви. Этот пример анализирует вашу текущую ветвь относительно `develop`:

```text theme={null}
/code-review ultra develop
```

Базовая ветвь не должна существовать в вашем локальном клоне; Claude Code получает её из `origin`. Если имя содержит опечатку, Claude Code предлагает ближайшее имя ветви в ошибке.

Идентификатор коммита или тег также работают в качестве базы, и анализ затем охватывает изменения на вашей ветви с момента этого коммита.

<h3 id="review-a-pull-request">
  Анализ запроса на слияние
</h3>

Чтобы анализировать запрос на слияние GitHub вместо локальной ветви, передайте номер PR:

```text theme={null}
/code-review ultra 1234
```

Команда также принимает `#1234`, `PR 1234` и вставленные URL-адреса PR; вставленный URL должен указывать на репозиторий в вашем текущем каталоге.

В режиме PR удаленная изолированная среда клонирует запрос на слияние непосредственно с хоста, а не упаковывает ваше локальное рабочее дерево. Режим PR работает с репозиториями на `github.com` и на экземплярах [GitHub Enterprise Server](/docs/ru/github-enterprise-server), которые администратор подключил к Claude Code.

Для репозиториев на `github.com` изолированная среда клонирует с учетной записью GitHub, подключенной к вашей учетной записи Claude, поэтому учетная запись должна иметь возможность читать репозиторий PR. Claude Code проверяет это перед созданием облачной сессии, если вы не установили [`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`](/docs/ru/env-vars#variables), и отказывает в запуске, когда [нет подключенной учетной записи](/docs/ru/errors#no-github-account-is-connected-to-your-claude-account) или [учетная запись не может видеть репозиторий](/docs/ru/errors#your-connected-github-account-cant-see-the-repository); отказ указывает на исправление. До версии 2.1.248 Claude Code не проверял это перед запуском.

Запустите [`/web-setup`](/docs/ru/web-quickstart#connect-from-your-terminal), чтобы подключить вашу учетную запись GitHub CLI к вашей учетной записи Claude.

<h3 id="post-findings-to-the-pull-request">
  Опубликуйте результаты в запросе на слияние
</h3>

На Claude Code версии 2.1.227 или позже, когда вы анализируете запрос на слияние на `github.com`, вы можете попросить Claude опубликовать готовые результаты в PR как один простой комментарий от вашей собственной учетной записи GitHub. Комментарий не является рецензией или одобрением и заканчивается примечанием "Generated by Claude Code". Когда вы анализируете ветвь или запрос на слияние GitHub Enterprise Server, Claude Code показывает результаты только в вашей сессии.

Claude Code никогда не публикует, если вы не выберете это на этом запуске, и `--no-post` является значением по умолчанию. Публикация — это выбор, который вы делаете для каждого запуска:

* **Интерактивно**: в диалоговом окне запуска выберите **Run and post the findings to the PR as me**. Если вы добавите `--post` к команде, как в `/code-review ultra 1234 --post`, Claude Code предварительно выбирает этот выбор и все еще спрашивает перед запуском.
* **Неинтерактивно**: запустите [подкоманду `claude ultrareview`](#run-ultrareview-non-interactively) с `--post`. Вы даете согласие на публикацию, запустив подкоманду с флагом, поэтому Claude Code публикует без вопросов. В запуске `claude -p '/code-review ultra'` Claude Code выходит перед прибытием результатов, поэтому ничего не публикует; используйте подкоманду вместо этого.

Claude Code не публикует с вашей машины. Он отправляет ID сессии анализа в API Anthropic, который публикует сохраненные результаты анализа как комментарий через учетную запись GitHub, которую вы подключили к Claude. Публикация требует того же входа claude.ai, что и сам анализ, и она недоступна у сторонних поставщиков или когда вы установили [`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`](/docs/ru/env-vars).

В интерактивной сессии Claude Code начинает публикацию, когда результаты прибывают, поэтому держите сессию открытой до завершения анализа. Claude Code сохраняет выбор публикации только в этой сессии. Если сессия заканчивается перед завершением анализа, Claude Code ничего не публикует, даже если вы возобновите разговор позже.

Когда публикация завершается, Claude сообщает вам результат:

* **Опубликовано**: Claude дает вам ссылку на комментарий.
* **Уже опубликовано**: более ранняя публикация того же анализа уже поместила комментарий в PR, поэтому Claude ссылает вас на запрос на слияние вместо повторной публикации.
* **Не удалось**: Claude сообщает вам почему, и результаты остаются в вашем терминале, чтобы вы могли опубликовать их вручную.

<h3 id="pass-a-request-in-plain-words">
  Передайте запрос простыми словами
</h3>

На Claude Code версии 2.1.218 или позже вы также можете описать, над чем вы работаете, простыми словами:

```text theme={null}
/code-review ultra check my auth changes
```

Анализ по-прежнему охватывает вашу текущую ветвь, ту же область, что и запуск без аргумента. Claude сохраняет ваш текст как примечание, показанное в диалоговом окне запуска, и связывает результаты с ним, когда они прибывают.

Claude Code рассматривает ваш текст как примечание только, когда он содержит более одного слова и не является именем ветви или ссылкой на PR. Он читает одно слово как имя ветви или ссылку на PR, поэтому неправильно введенное имя ветви получает ошибку ближайшей ветви из [Анализ относительно другой базы](#review-against-a-different-base) вместо запуска с примечанием. Если ваш текст объединяет ссылку на PR с другими словами, такие как `check PR 123 again`, Claude Code также не запускается; он просит вас повторно запустить только с номером PR для анализа этого PR или без ссылки для анализа вашей текущей ветви.

<Tip>
  Если ваш репозиторий слишком большой для упаковки, Claude Code предложит вам вместо этого использовать режим PR. Отправьте вашу ветвь и откройте черновик PR, затем запустите `/code-review ultra <PR-number>`.
</Tip>

<h3 id="diff-limits-and-fallbacks">
  Ограничения diff и резервные варианты
</h3>

Ultrareview проверяет diff перед началом любой работы по анализу и сообщает вам, когда он не может анализировать его как есть:

* **Diff слишком большой**: анализ ветки может включать до 500 измененных файлов и 8000 измененных строк по умолчанию. Точные значения могут измениться, и [отказ](/docs/ru/errors#diff-is-too-large-for-ultrareview) указывает на действующие значения, размер вашего diff и файлы с наибольшим количеством измененных строк. Claude Code отказывает в анализе слишком большого запроса на слияние таким же образом, указывая количество файлов и строк, но не разбивку по файлам
* **Нечего анализировать**: когда diff относительно базы пуст, ultrareview отказывает и указывает на ветвь или коммит, с которым он сравнивал, и случай, в котором вы находитесь, например, находитесь на самой базовой ветви без ничего незафиксированного, или ветвь, чьи коммиты уже являются частью базы. Он также предлагает способ выхода для этого случая, например переключение на ветвь с вашей работой, подготовка или фиксация локальных правок или передача другой базы
* **Первый коммит**: первый коммит репозитория не имеет ничего более раннего для сравнения, поэтому ultrareview анализирует каждый файл в нем после вашего подтверждения в диалоговом окне запуска. Если у вас есть неотслеживаемые файлы, он отказывает вместо этого и говорит вам `git add` те, которые вы хотите анализировать. Применяются те же ограничения размера.

  Первый коммит анализируется целиком только после этого подтверждения, поэтому подкоманда `claude ultrareview` и `claude -p` отказывают в нем и указывают вам на интерактивную сессию вместо этого. Требует Claude Code версии 2.1.277 или позже
* **Нет базы слияния**: когда ваша ветвь не имеет общей истории с базовой ветвью, или репозиторий не имеет базовой ветви для сравнения, ultrareview анализирует каждый отслеживаемый файл в репозитории вместо этого. Резервный вариант требует полного клона и применяет те же ограничения размера. Он запускается только когда вы подтверждаете в диалоговом окне запуска или запускаете подкоманду `claude ultrareview` самостоятельно. В `claude -p` и везде, где ни то, ни другое не происходит, ultrareview отказывает, говорит, что анализ охватит каждый файл, и указывает вам на интерактивную сессию.

  При проверке без ветвей или других ссылок, такой как отсоединенный HEAD, созданный путем проверки `FETCH_HEAD` после получения URL, Claude Code [отказывает в анализе](/docs/ru/errors#your-checkout-has-no-branches) и предлагает сначала создать ветвь

<h2 id="pricing-and-free-runs">
  Цены и бесплатные запуски
</h2>

Ultrareview — это премиум-функция, которая выставляет счета за дополнительное использование, а не за включенное использование в вашем плане.

| План              | Включено бесплатных запусков | После бесплатных запусков                                                                                                               |
| ----------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Pro               | 3 бесплатных запуска         | выставляется счет как [дополнительное использование](https://support.claude.com/ru/articles/12429409-extra-usage-for-paid-claude-plans) |
| Max               | 3 бесплатных запуска         | выставляется счет как [дополнительное использование](https://support.claude.com/ru/articles/12429409-extra-usage-for-paid-claude-plans) |
| Team и Enterprise | нет                          | выставляется счет как [дополнительное использование](https://support.claude.com/ru/articles/12429409-extra-usage-for-paid-claude-plans) |

* **Бесплатные запуски**: три запуска Pro и Max — это одноразовое выделение на учетную запись и не обновляются.
* **Стоимость одного анализа**: после использования бесплатных запусков обычно от 5 до 25 долларов в дополнительном использовании в зависимости от размера изменения, что соответствует оценке, которую показывает диалоговое окно запуска перед каждым запуском.
* **Когда запуск считается начатым**: после запуска облачной сессии. Анализ, который вы остановили рано или который не завершился, все равно использует бесплатный запуск; платный анализ выставляет счет только за ту часть, которая была выполнена.

Поскольку ultrareview всегда выставляет счет как дополнительное использование вне бесплатных запусков, ваша учетная запись или организация должны иметь включенное дополнительное использование перед запуском платного анализа. Если дополнительное использование не включено, Claude Code блокирует запуск, и способ его включения зависит от вашего доступа к выставлению счетов:

* Если вы можете управлять выставлением счетов для вашей учетной записи, Claude Code ссылает вас на параметры выставления счетов, где вы можете включить дополнительное использование.
* В планах Team и Enterprise члены без доступа к выставлению счетов отправляют запрос из CLI, прося своего администратора включить дополнительное использование.

Вы также можете запустить `/usage-credits` для проверки или изменения параметра дополнительного использования.

Claude Code просит вас подтвердить выставление счетов за дополнительное использование один раз за разговор: когда вы начинаете новый разговор, например с `/clear`, Claude Code показывает подтверждение снова для следующего платного анализа.

<h2 id="track-a-running-review">
  Отслеживание выполняемого анализа
</h2>

Анализ обычно занимает от 5 до 10 минут. Анализ работает как фоновая задача, поэтому вы можете продолжать работать в вашей сессии, запускать другие команды или полностью закрыть терминал. Если вы выбрали [публикацию результатов в запрос на слияние](#post-findings-to-the-pull-request), держите сессию открытой до завершения анализа; если сессия завершится раньше, Claude Code ничего не публикует.

Используйте `/tasks` для просмотра выполняемых и завершенных анализов, открытия подробного представления анализа или остановки выполняемого анализа. Если вы остановите анализ, Claude Code архивирует облачную сессию и не возвращает частичные результаты.

Claude также может сообщить вам, что анализ был остановлен или что его сессия не была найдена:

* Если облачная сессия анализа остановлена или [архивирована](/docs/ru/claude-code-on-the-web#archive-sessions) на claude.ai до завершения анализа, Claude сообщит вам, что она была остановлена.
* Если облачная сессия анализа была удалена, или вы вошли в другой аккаунт Claude или организацию с момента её запуска, Claude сообщит вам, что сессия не была найдена.
* Если вы переключили аккаунты, анализ может всё ещё завершиться под аккаунтом, который его запустил. Если анализ всё ещё выполняется, войдите обратно под этот аккаунт и возобновите разговор с помощью `claude --resume`, чтобы переподключить его.

Когда анализ завершится, Claude Code показывает проверенные результаты как уведомление в вашей сессии. Каждый результат включает расположение файла и объяснение проблемы, чтобы вы могли попросить Claude исправить это напрямую.

<h2 id="run-ultrareview-non-interactively">
  Запуск ultrareview неинтерактивно
</h2>

Используйте подкоманду `claude ultrareview` для запуска ultrareview из CI или скрипта без интерактивной сессии. Подкоманда запускает тот же обзор, что и `/code-review ultra`, блокирует выполнение до завершения удалённого обзора и выводит результаты в stdout.

```bash theme={null}
claude ultrareview
claude ultrareview 1234
claude ultrareview origin/main
```

Без аргументов подкоманда проверяет разницу между вашей текущей веткой и веткой по умолчанию, с тем же [резервным вариантом для всего репозитория](#diff-limits-and-fallbacks), что и `/code-review ultra`, когда база слияния не существует. Передайте номер PR для проверки pull request или базовую ветку для проверки относительно неё; [обработка базовой ветки](#review-against-a-different-base) соответствует интерактивной команде.

Вы даёте согласие на резервный вариант для всего репозитория и на подтверждение выставления счёта и условия при запуске подкоманды, поэтому выполнение начинается без ожидания ввода. Запуск её самостоятельно — это то, что считается согласием. Когда Claude запускает подкоманду для вас, например через инструмент Bash, Claude Code отказывает в проверке всего репозитория.

На Claude Code v2.1.218 или позже вы также можете запустить облачный обзор, выполнив `/code-review ultra` в неинтерактивной сессии, например `claude -p '/code-review ultra'`. Claude Code запускает обзор и выводит ссылку отслеживания без ожидания результатов, в отличие от `claude ultrareview`, который блокирует выполнение до их получения. Когда обзор будет выставлять счёт за использование кредитов, Claude Code останавливается перед запуском и указывает вам на `claude ultrareview`, потому что подтверждение выставления счёта требует интерактивной сессии. До v2.1.218 `/code-review ultra` в неинтерактивной сессии запускал локальный обзор.

Сообщения о ходе выполнения и URL живой сессии идут в stderr, чтобы stdout оставался пригодным для анализа. Используйте эти флаги для управления выводом, тайм-аутом и тем, следует ли публиковать результаты:

| Флаг                  | Описание                                                                                                                                                                                                                                                                                                       |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--json`              | Выведите необработанный payload `bugs.json` вместо отформатированных результатов                                                                                                                                                                                                                               |
| `--timeout <minutes>` | Максимальное количество минут для ожидания завершения обзора. По умолчанию 45                                                                                                                                                                                                                                  |
| `--post`              | [Опубликуйте готовые результаты](#post-findings-to-the-pull-request) в pull request как один простой комментарий с вашего аккаунта GitHub. Работает на целевых pull request на `github.com`; на других целевых объектах Claude Code игнорирует флаг и сообщает об этом. Требует Claude Code v2.1.227 или позже |
| `--no-post`           | Не публикуйте результаты. Это значение по умолчанию, и если вы передадите оба флага, Claude Code не будет публиковать. Требует Claude Code v2.1.227 или позже                                                                                                                                                  |

Запуск `claude ultrareview` требует той же аутентификации и конфигурации кредитов использования, что и `/code-review ultra`.

Подкоманда завершается с одним из трёх кодов:

* **0**: обзор завершился, с результатами или без них
* **1**: обзор не запустился или был остановлен до завершения, облачная сессия ошибилась или истёк тайм-аут
* **130**: вы прервали подкоманду с помощью Ctrl-C

Если вы прервёте подкоманду, удалённый обзор продолжит работу; следуйте по ссылке сессии, выведённой в stderr, чтобы наблюдать за ней в браузере.

С флагом `--post` подкоманда начинает публикацию сразу после вывода результатов и выводит ссылку в stderr.

* Если выполнение не удаётся, остановлено, истекает тайм-аут или вы его прерываете, подкоманда ничего не публикует.
* Если обзор завершится, но комментарий не будет опубликован, Claude Code выведет причину в stderr, а результаты останутся в stdout, чтобы вы могли опубликовать их вручную.

Для автоматических обзоров на pull request GitHub [Code Review](/docs/ru/code-review) интегрируется с вашим репозиторием напрямую и публикует результаты как встроенные комментарии PR без этапа CLI.

<h2 id="how-ultrareview-compares-to-/code-review">
  Как ultrareview сравнивается с /code-review
</h2>

Оба анализа проверяют код, но вы используете их на разных этапах вашего рабочего процесса.

|                   | `/code-review`                                 | `/code-review ultra`                                                                   |
| ----------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------- |
| Цель              | ваш рабочий diff, pull request, ветка или путь | ваш рабочий diff или pull request                                                      |
| Запуск            | локально в вашей сессии                        | в облачной изолированной среде                                                         |
| Глубина           | масштабируется с аргументом effort             | многоагентный флот с независимой проверкой                                             |
| Продолжительность | секунды до нескольких минут                    | примерно 5–10 минут                                                                    |
| Стоимость         | учитывается в обычном использовании            | бесплатные запуски, затем примерно \$5–\$25 за анализ как дополнительное использование |
| Лучше всего для   | быстрая обратная связь при итерации            | уверенность перед слиянием при существенных изменениях                                 |

Используйте `/code-review` для быстрой обратной связи во время работы или передайте номер PR для проверки pull request коллеги перед его одобрением. Используйте `/code-review ultra` перед слиянием существенного изменения, когда вам нужен более глубокий анализ, который поймет проблемы, которые может пропустить локальный анализ.
