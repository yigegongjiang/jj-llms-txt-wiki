# Claude Code в Slack

> Делегируйте задачи кодирования прямо из вашего рабочего пространства Slack. Anthropic снимает с производства эту более раннюю версию для рабочих пространств Team и Enterprise в пользу Claude Tag; она остается путем настройки для планов Pro и Max.

<Warning>
  На этой странице документируется более ранняя версия Claude Code в Slack, которая запускает каждый сеанс под учетной записью отдельного пользователя.

  * **Планы Team и Enterprise:** Anthropic снимает с производства эту версию в пользу [Claude Tag](https://claude.com/product/tag), которая запускает @Claude как общую идентификацию вашей организации с настроенным администратором доступом. Ваше существующее приложение Slack и дескриптор @Claude остаются, и ваша команда учетной записи Anthropic может сообщить вам дату перехода. [Настройте Claude Tag](https://claude.com/docs/claude-tag/overview) для нового рабочего пространства; чтобы переместить то, которое уже использует эту версию, см. [Миграция с более ранней версии Claude в Slack](https://claude.com/docs/claude-tag/admins/migrate-from-earlier).
  * **Планы Pro и Max:** Claude Tag недоступен в индивидуальных планах, поэтому эта страница остается путем настройки.
</Warning>

Claude Code в Slack приносит мощь Claude Code прямо в ваше рабочее пространство Slack. Когда вы упоминаете `@Claude` с задачей кодирования, Claude автоматически определяет намерение и создает сеанс Claude Code в облаке, позволяя вам делегировать работу по разработке, не покидая командные беседы.

Эта интеграция построена на существующем приложении Claude для Slack, но добавляет интеллектуальную маршрутизацию к облачным сеансам Claude Code для запросов, связанных с кодированием. Каждый сеанс работает под вашей собственной учетной записью Claude, используя ваши подключенные репозитории и ограничения вашего плана.

<h2 id="use-cases">
  Варианты использования
</h2>

* **Исследование и исправление ошибок**: Попросите Claude исследовать и исправить ошибки, как только они будут сообщены в каналах Slack.
* **Быстрые проверки кода и модификации**: Пусть Claude реализует небольшие функции или рефакторит код на основе отзывов команды.
* **Совместная отладка**: Когда обсуждения в команде предоставляют важный контекст (например, воспроизведение ошибок или отчеты пользователей), Claude может использовать эту информацию для информирования своего подхода к отладке.
* **Параллельное выполнение задач**: Запустите задачи кодирования в Slack, пока вы продолжаете другую работу, получая уведомления по завершении.

<h2 id="prerequisites">
  Предварительные требования
</h2>

Перед использованием Claude Code в Slack убедитесь, что у вас есть следующее:

| Требование            | Детали                                                                                                         |
| :-------------------- | :------------------------------------------------------------------------------------------------------------- |
| План Claude           | Pro, Max, Team или Enterprise с доступом к Claude Code (премиум-места или места Chat + Claude Code)            |
| Cloud sessions        | [Cloud sessions](/docs/ru/claude-code-on-the-web) включены для вашей учетной записи                                 |
| Учетная запись GitHub | Подключена к [claude.ai/code](https://claude.ai/code) с по крайней мере одним аутентифицированным репозиторием |
| Аутентификация Slack  | Ваша учетная запись Slack связана с вашей учетной записью Claude через приложение Claude                       |

<h2 id="setting-up-claude-code-in-slack">
  Настройка Claude Code в Slack
</h2>

<Steps>
  <Step title="Установите приложение Claude в Slack">
    Администратор рабочего пространства должен установить приложение Claude из Slack App Marketplace. Посетите [Slack App Marketplace](https://slack.com/marketplace/A08SF47R6P4) и нажмите "Add to Slack", чтобы начать процесс установки.
  </Step>

  <Step title="Подключите вашу учетную запись Claude">
    После установки приложения аутентифицируйте вашу индивидуальную учетную запись Claude:

    1. Откройте приложение Claude в Slack, нажав на "Claude" в разделе "Apps"
    2. Перейдите на вкладку App Home
    3. Нажмите "Connect", чтобы связать вашу учетную запись Slack с вашей учетной записью Claude
    4. Завершите процесс аутентификации в вашем браузере
  </Step>

  <Step title="Настройте облачные сеансы">
    Убедитесь, что облачные сеансы правильно настроены для вашей учетной записи:

    * Посетите [claude.ai/code](https://claude.ai/code) и войдите с той же учетной записью, которую вы подключили к Slack
    * Подключите вашу учетную запись GitHub, если она еще не подключена
    * Аутентифицируйте по крайней мере один репозиторий, с которым вы хотите, чтобы Claude работал
  </Step>

  <Step title="Выберите режим маршрутизации">
    После подключения ваших учетных записей настройте, как Claude обрабатывает ваши сообщения в Slack. Откройте App Home Claude в Slack, чтобы найти параметр **Режим маршрутизации**.

    | Режим          | Поведение                                                                                                                                                                                                                                                       |
    | :------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | **Только код** | Claude маршрутизирует все @mentions к сеансам Claude Code. Лучше всего для команд, использующих Claude в Slack исключительно для задач разработки.                                                                                                              |
    | **Код + Чат**  | Claude анализирует каждое сообщение и интеллектуально маршрутизирует между Claude Code (для задач кодирования) и Claude Chat (для написания, анализа и общих вопросов). Лучше всего для команд, которые хотят единую точку входа @Claude для всех типов работы. |

    <Note>
      В режиме "Код + Чат", если Claude маршрутизирует сообщение в Chat, но вы хотели сеанс кодирования, вы можете нажать "Retry as Code", чтобы создать сеанс Claude Code. Аналогично, если он маршрутизирован в Code, но вы хотели сеанс Chat, вы можете выбрать этот вариант в этой цепочке.
    </Note>
  </Step>

  <Step title="Добавьте Claude в каналы">
    Claude не добавляется автоматически ни в какие каналы после установки. Чтобы использовать Claude в канале, пригласите его, введя `/invite @Claude` в этот канал. Claude может отвечать только на @mentions в каналах, где он был добавлен.
  </Step>
</Steps>

<h2 id="how-it-works">
  Как это работает
</h2>

<h3 id="automatic-detection">
  Автоматическое обнаружение
</h3>

В режиме маршрутизации Code + Chat, когда вы упоминаете @Claude в канале или цепочке Slack, Claude автоматически определяет, является ли ваше сообщение задачей кодирования. Задачи кодирования переходят в Claude Code в облачный сеанс. Все остальное получает обычный ответ чата. В режиме только Code каждое упоминание @mention переходит в Claude Code.

Вы также можете явно указать Claude обрабатывать запрос как задачу кодирования, даже если он не обнаружит это автоматически.

<Note>
  Claude Code в Slack работает только в каналах (публичных или приватных). Он не работает в прямых сообщениях (DM).
</Note>

<h3 id="context-gathering">
  Сбор контекста
</h3>

**Из цепочек**: Когда вы упоминаете Claude в цепочке, он собирает контекст из всех сообщений в этой цепочке, чтобы понять полную беседу.

**Из каналов**: Когда упоминается непосредственно в канале, Claude смотрит на недавние сообщения канала для получения соответствующего контекста.

Этот контекст помогает Claude понять проблему, выбрать соответствующий репозиторий и информировать свой подход к задаче.

<Warning>
  Когда @Claude вызывается в Slack, Claude получает доступ к контексту беседы, чтобы лучше понять ваш запрос. Claude может следовать указаниям из других сообщений в контексте, поэтому пользователи должны убедиться, что используют Claude только в доверенных беседах Slack.
</Warning>

<h3 id="session-flow">
  Поток сеанса
</h3>

1. **Инициирование**: Вы упоминаете Claude с запросом кодирования
2. **Обнаружение**: Claude анализирует ваше сообщение и обнаруживает намерение кодирования
3. **Создание сеанса**: Новый сеанс Claude Code создается на claude.ai/code
4. **Обновления прогресса**: Claude публикует обновления статуса в вашу цепочку Slack по мере выполнения работы
5. **Завершение**: По завершении Claude упоминает вас с резюме и кнопками действия
6. **Проверка**: Нажмите "View Session", чтобы увидеть полную стенограмму, или "Create PR", чтобы открыть запрос на слияние

<h2 id="user-interface-elements">
  Элементы пользовательского интерфейса
</h2>

<h3 id="message-actions">
  Действия с сообщениями
</h3>

* **View Session**: Открывает полный сеанс Claude Code в вашем браузере, где вы можете увидеть всю выполненную работу, продолжить сеанс или сделать дополнительные запросы.
* **Create PR**: Создает запрос на слияние прямо из изменений сеанса.
* **Retry as Code**: Если Claude первоначально ответил как помощник чата, но вы хотели сеанс кодирования, нажмите эту кнопку, чтобы повторить запрос как задачу Claude Code.
* **Change Repo**: Позволяет вам выбрать другой репозиторий, если Claude выбрал неправильно.

<h3 id="repository-selection">
  Выбор репозитория
</h3>

Claude автоматически выбирает репозиторий на основе контекста из вашей беседы Slack. Если несколько репозиториев могут применяться, Claude может отобразить раскрывающееся меню, позволяющее вам выбрать правильный.

<h2 id="access-and-permissions">
  Доступ и разрешения
</h2>

<h3 id="user-level-access">
  Доступ на уровне пользователя
</h3>

| Тип доступа                          | Требование                                                                             |
| :----------------------------------- | :------------------------------------------------------------------------------------- |
| Сеансы Claude Code                   | Каждый пользователь запускает сеансы под своей учетной записью Claude                  |
| Использование и ограничения скорости | Сеансы учитываются в отношении ограничений плана отдельного пользователя               |
| Доступ к репозиторию                 | Пользователи могут получать доступ только к репозиториям, которые они лично подключили |
| История сеансов                      | Сеансы отображаются в вашей истории Claude Code на claude.ai/code                      |

<h3 id="workspace-level-access">
  Доступ на уровне рабочего пространства
</h3>

Администраторы рабочего пространства Slack контролируют, доступно ли приложение Claude в их рабочем пространстве:

| Управление                    | Описание                                                                                                                                     |
| :---------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| Установка приложения          | Администраторы рабочего пространства решают, устанавливать ли приложение Claude из Slack App Marketplace                                     |
| Распределение Enterprise Grid | Для организаций Enterprise Grid администраторы организации могут контролировать, какие рабочие пространства имеют доступ к приложению Claude |
| Удаление приложения           | Удаление приложения из рабочего пространства немедленно отзывает доступ для всех пользователей в этом рабочем пространстве                   |

<h3 id="channel-based-access-control">
  Управление доступом на основе канала
</h3>

Установка приложения не добавляет Claude ни в какие каналы. Claude отвечает на @mentions только в каналах, где он был добавлен; пригласите его с помощью `/invite @Claude`. Он работает как в публичных, так и в приватных каналах. Администраторы могут контролировать использование Claude Code, управляя тем, в какие каналы приглашается Claude и кто имеет доступ к этим каналам. Это добавляет дополнительный уровень управления доступом помимо разрешений на уровне рабочего пространства.

<h2 id="what’s-accessible-where">
  Что доступно где
</h2>

**В Slack**: Вы увидите обновления статуса, резюме завершения и кнопки действия. Полная стенограмма сохраняется и всегда доступна.

**На claude.ai/code**: Полный сеанс Claude Code с полной историей беседы, все изменения кода и операции с файлами. Сеансы остаются в истории Claude Code по адресу [claude.ai/code](https://claude.ai/code), где вы можете продолжить прошлые сеансы, ссылаться на них или создавать запросы на слияние.

Для учетных записей Enterprise и Team сеансы, созданные из Claude в Slack, автоматически видны организации. Дополнительные сведения см. в разделе [совместное использование сеансов](/docs/ru/claude-code-on-the-web#share-sessions).

<h2 id="best-practices">
  Лучшие практики
</h2>

<h3 id="writing-effective-requests">
  Написание эффективных запросов
</h3>

* **Будьте конкретны**: Включайте имена файлов, имена функций или сообщения об ошибках, когда это уместно.
* **Предоставьте контекст**: Упомяните репозиторий или проект, если это не ясно из беседы.
* **Определите успех**: Объясните, как выглядит "готово" — должен ли Claude писать тесты? Обновить документацию? Создать PR?
* **Используйте цепочки**: Отвечайте в цепочках при обсуждении ошибок или функций, чтобы Claude мог собрать полный контекст.

<h3 id="when-to-use-slack-vs-web">
  Когда использовать Slack vs. веб-версию
</h3>

**Используйте Slack когда**: Контекст уже существует в обсуждении Slack, вы хотите запустить задачу асинхронно или сотрудничаете с товарищами по команде, которым нужна видимость.

**Используйте веб-версию напрямую когда**: Вам нужно загрузить файлы, вы хотите взаимодействие в реальном времени во время разработки или работаете над более длительными, более сложными задачами.

<h2 id="troubleshooting">
  Устранение неполадок
</h2>

<h3 id="claude-code-is-not-enabled-for-your-account">
  "Claude Code не включен для вашей учетной записи"
</h3>

Эта ошибка означает, что ваша учетная запись Claude еще не имеет облачной среды. Войдите на [claude.ai/code](https://claude.ai/code) один раз с той же учетной записью, которую вы подключили к Slack, и завершите [веб-подготовку](/docs/ru/web-quickstart#connect-github), которая создает вашу облачную среду по умолчанию или просит вас создать ее. Ошибка исчезает при следующем упоминании. Каждый пользователь должен сделать это индивидуально.

<h3 id="sessions-not-starting">
  Сеансы не запускаются
</h3>

1. Убедитесь, что ваша учетная запись Claude подключена в Claude App Home
2. Проверьте, что облачные сеансы включены для вашей учетной записи
3. Убедитесь, что у вас подключен по крайней мере один репозиторий GitHub к Claude Code

<h3 id="sessions-from-a-claude-tag-channel-fail-to-start">
  Сеансы из канала Claude Tag не запускаются
</h3>

Эта запись применяется к рабочим пространствам, использующим [Claude Tag](https://claude.com/docs/claude-tag/overview), где Claude работает в каналах как общая идентификация вашей организации, а не как учетная запись любого члена. Если вы создали облачную среду канала на [claude.ai/code](https://claude.ai/code), она принадлежит вашей личной учетной записи, и Claude не может запустить сеансы канала в личной среде. Claude Code немедленно завершает сеанс с ошибкой, и повторная попытка не помогает.

Если вы являетесь владельцем и среда принадлежит вам, [поделитесь ею с организацией](/docs/ru/cloud-environments#organization-shared-environments) из селектора среды. В противном случае владелец пересоздает ее как организационно-общую среду со страницы **Cloud environments** в [параметрах администратора](https://claude.ai/admin-settings).

Вы можете применить ее двумя способами:

* Установите ее как организационное значение по умолчанию на [claude.ai/admin-settings/claude-code](https://claude.ai/admin-settings/claude-code).
* [Установите ее на канале](https://claude.com/docs/claude-tag/admins/troubleshooting#channel-sessions-use-the-wrong-environment-or-can%E2%80%99t-find-one) в параметрах администратора Claude Tag.

Если вы не являетесь владельцем, отправьте эту запись владельцу.

<h3 id="repository-not-showing">
  Репозиторий не отображается
</h3>

1. Подключите репозиторий на [claude.ai/code](https://claude.ai/code)
2. Проверьте ваши разрешения GitHub для этого репозитория
3. Попробуйте отключить и повторно подключить вашу учетную запись GitHub

<h3 id="wrong-repository-selected">
  Выбран неправильный репозиторий
</h3>

1. Нажмите кнопку "Change Repo", чтобы выбрать другой репозиторий
2. Включите имя репозитория в ваш запрос для более точного выбора

<h3 id="authentication-errors">
  Ошибки аутентификации
</h3>

1. Отключите и повторно подключите вашу учетную запись Claude в App Home
2. Убедитесь, что вы вошли в правильную учетную запись Claude в вашем браузере
3. Проверьте, что ваш план Claude включает доступ к Claude Code

<h2 id="current-limitations">
  Текущие ограничения
</h2>

* **Только GitHub**: репозитории должны находиться на GitHub.
* **Один PR за раз**: каждый сеанс может создать один запрос на слияние.
* **Требуется доступ к облачным сеансам**: пользователи должны иметь доступ к [облачным сеансам](/docs/ru/claude-code-on-the-web); без него Claude отвечает стандартными ответами чата.
