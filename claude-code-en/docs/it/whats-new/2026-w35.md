    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">Quando uno strumento continua a non funzionare, Claude non riesce ad aiutare con una richiesta, o voi segnalate un errore, Claude ora redige un rapporto di feedback per voi con lo strumento <code>SendFeedback</code>. Una scheda sopra il vostro prompt mostra la bozza, e potete esaminarla, inviarla o scartarla da lì. Nulla raggiunge Anthropic finché non la inviate. Richiede v2.1.238 o successiva.</p>

    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/claude-drafted-feedback.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=5cacb3be0dffd1cbd417381f3721637e" alt="Una sessione di Claude Code dove Claude ha redatto un rapporto di bug intitolato Sandbox image pull fails behind proxy, mostrato come una scheda sopra il prompt con opzioni per esaminare, inviare o scartare" width="1440" height="756" data-path="images/whats-new/claude-drafted-feedback.jpg" />

  <p className="digest-feature-try">Eseguite <code>/feedback</code> senza argomenti per aprire la vostra coda di bozze da ogni sessione:</p>

  ```text Claude Code theme={null}
  > /feedback
  ```

  <p className="digest-feature-try">Selezionate una bozza, quindi modificatela, inviatela o scartarla. Per disattivare la redazione, impostate <strong>Claude-drafted feedback</strong> su <code>off</code> in <code>/config</code>.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Modalità limitata</span>
    <span className="digest-feature-pill">v2.1.248</span>
  </div>

  <p className="digest-feature-lede">La modalità limitata avvia Claude Code senza gli strumenti integrati che eseguono comandi o codice. Utilizzatela quando un harness di valutazione guida <code>claude</code> su una macchina condivisa. Avviatela con `--restricted` o impostate <code>CLAUDE\_CODE\_RESTRICTED=1</code>. Claude Code rimuove anche <code>WebFetch</code>, limita gli strumenti di file alle directory di lavoro, carica solo le impostazioni gestite e `--settings`, e rifiuta la modalità di autorizzazione <code>bypassPermissions</code>.</p>

  <p className="digest-feature-try">Eseguite una query non interattiva senza gli strumenti di esecuzione dei comandi:</p>

  ```bash terminal theme={null}
  claude --restricted -p "review src/ for SQL injection risks"
  ```

  <p className="digest-feature-try">Per dare a Claude uno degli strumenti rimossi, elencatelo in `--tools` insieme agli altri strumenti integrati che desiderate, ad esempio `--tools "Bash,Read,Edit"`. `--tools` è una lista di autorizzazione, e il suo preset <code>default</code> non ripristina gli strumenti rimossi.</p>

  <a className="digest-feature-link" href="/docs/it/cli-reference#cli-flags">Flag CLI</a>
</div>

    <div>Eseguite <code>/permissions</code> e aprite la nuova <a href="/docs/it/auto-mode-config#edit-rules-from-permissions">scheda <strong>Auto mode</strong></a> per visualizzare e modificare le regole del classificatore della modalità automatica senza aprire un file di impostazioni</div>

    <div>Un subagent che si ferma al limite <code>maxTurns</code> restituisce il suo output contrassegnato come parziale, con un suggerimento che Claude può <a href="/docs/it/sub-agents#resume-subagents">continuarlo con <code>SendMessage</code></a>, invece di apparire completato</div>
    <div>Su Amazon Bedrock, la piattaforma agente di Google Cloud e Microsoft Foundry, le sessioni sulla stessa macchina possono ora <a href="/docs/it/cross-session-messaging#availability">messaggiarsi l'una con l'altra</a>, <code>/loop</code> può <a href="/docs/it/scheduled-tasks#let-claude-choose-the-interval">scegliere il suo intervallo</a>, e <code>/model</code> e <code>/effort</code> si applicano immediatamente invece che dopo la fine del turno</div>
