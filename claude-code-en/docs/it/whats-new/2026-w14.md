<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Override della dimensione dei risultati MCP</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Gli autori di server MCP possono ora aumentare il limite di troncamento su uno strumento specifico impostando <code>anthropic/maxResultSizeChars</code> nella voce <code>tools/list</code> dello strumento, fino a un limite massimo di 500K caratteri. Il limite era globale, quindi gli strumenti che occasionalmente restituivano payload intrinsecamente grandi come schemi di database o alberi di file completi raggiungevano il limite predefinito e venivano persistiti su disco con un riferimento a file. Gli override per strumento mantengono questi risultati inline quando lo strumento ne ha davvero bisogno.</p>

  <p className="digest-feature-try">Annotate lo strumento nella risposta <code>tools/list</code> del vostro server:</p>

  ```json highlight={5} theme={null}
  {
    "name": "get_schema",
    "description": "Returns the full database schema",
    "_meta": {
      "anthropic/maxResultSizeChars": 500000
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/it/mcp#raise-the-limit-for-a-specific-tool">Riferimento MCP</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Eseguibili plugin su PATH</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Posizionate un eseguibile in una directory <code>bin/</code> alla radice del vostro plugin e Claude Code aggiunge quella directory al <code>PATH</code> dello strumento Bash mentre il plugin è abilitato. Claude può quindi invocare il binario come comando nudo da qualsiasi chiamata dello strumento Bash, senza necessità di percorso assoluto o script wrapper. Utile per pacchettizzare helper CLI accanto ai comandi, agli agenti e agli hook che li chiamano.</p>

  <p className="digest-feature-try">Aggiungete una directory <code>bin/</code> alla radice del plugin:</p>

  ```text highlight={4, 5} theme={null}
  my-plugin/
  ├── .claude-plugin/
  │   └── plugin.json
  └── bin/
      └── my-tool
  ```

  <a className="digest-feature-link" href="/docs/docs/it/plugins-reference#file-locations-reference">Riferimento plugin</a>
