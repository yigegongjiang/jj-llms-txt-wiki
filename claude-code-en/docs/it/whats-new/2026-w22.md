  <div className="digest-wins-grid">
    <div>In <code>claude agents</code>, anteponi un comando shell con <code>!</code> per eseguirlo come processo in background a cui puoi connetterti e disconnetterti; disponibile anche come <code>claude --bg --exec 'pytest -x'</code></div>
    <div>I plugin nelle directory <code>.claude/skills</code> vengono ora caricati automaticamente, senza richiedere il marketplace, e <code>claude plugin init \<name></code> crea lo scaffolding di un nuovo plugin</div>
    <div>Il nuovo comando <code>/reload-skills</code> ripete la scansione delle directory delle skill senza riavviare, e gli hook <code>SessionStart</code> possono restituire <code>reloadSkills: true</code> per rendere disponibili nella stessa sessione le skill che installano</div>
    <div>Le skill e i comandi possono impostare <code>disallowed-tools</code> nel frontmatter per rimuovere gli strumenti dal modello mentre la skill è attiva</div>
    <div>Il nuovo evento hook <code>MessageDisplay</code> consente agli hook di trasformare o nascondere il testo del messaggio dell'assistente mentre viene visualizzato</div>
    <div>Claude Code ora passa al tuo <code>--fallback-model</code> configurato per il resto della sessione quando il modello primario non viene trovato, invece di fallire su ogni richiesta</div>
    <div>I plugin possono dichiarare <code>defaultEnabled: false</code> in <code>plugin.json</code> o in una voce del marketplace, in modo che si installino senza attivarsi finché non li abiliti</div>
    <div>Modalità Vim: <code>/</code> in modalità NORMAL apre la ricerca della cronologia inversa, corrispondendo alla modalità vi di Bash e Zsh</div>
    <div>L'esecuzione dello strumento in streaming è ora sempre abilitata, incluso con telemetria disabilitata e su Amazon Bedrock, Google Cloud's Agent Platform e Microsoft Foundry</div>
    <div><code>←←</code> per aprire la visualizzazione degli agenti ora funziona su Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry e con telemetria disabilitata</div>
    <div>Claude in Chrome: scegli quale browser connesso utilizzare tramite <code>/chrome</code> → "Select browser…", o in chat quando un'azione del browser viene eseguita con più browser connessi</div>
    <div><code>claude mcp list</code> e <code>claude mcp get</code> ora mostrano i server <code>.mcp.json</code> non approvati come in sospeso di approvazione invece di approvarli automaticamente e connettersi quando l'output viene reindirizzato</div>
