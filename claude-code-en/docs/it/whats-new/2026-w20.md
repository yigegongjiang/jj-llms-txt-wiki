  <p className="digest-feature-lede">Imposta una condizione di completamento e Claude continua a lavorare verso di essa tra i turni senza che tu debba richiedere ogni passaggio. Dopo ogni turno, un modello veloce verifica se la condizione è soddisfatta; se non lo è, Claude inizia un altro turno invece di restituire il controllo. Utile per lavori sostanziali con uno stato finale verificabile, come la migrazione di un modulo fino a quando ogni sito di chiamata si compila e i test passano. L'obiettivo si cancella una volta che la condizione è soddisfatta e funziona in modalità interattiva, <code>-p</code> e Remote Control.</p>

<div className="digest-feature">

    <span className="digest-feature-pill">research preview</span>
  </div>

  <p className="digest-feature-lede"><code>/fast</code> ora funziona su Opus 4.7 per impostazione predefinita invece di Opus 4.6. Fast mode è una configurazione Opus ad alta velocità: la stessa qualità del modello a circa 2,5 volte la velocità per un costo per token più elevato, utile per l'iterazione rapida e il debug in tempo reale. I prezzi rimangono invariati a $30/$150 per MTok, gli stessi della modalità veloce Opus 4.6. Per fissare la modalità veloce a Opus 4.6, imposta <code>CLAUDE\_CODE\_OPUS\_4\_6\_FAST\_MODE\_OVERRIDE=1</code>.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Altri vantaggi</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code> ha acquisito flag di dispatch (<code>--add-dir</code>, <code>--settings</code>, <code>--mcp-config</code>, <code>--plugin-dir</code>, <code>--permission-mode</code>, <code>--model</code>, <code>--effort</code>, <code>--dangerously-skip-permissions</code>) per configurare le sessioni in background, e <code>claude agents --cwd \<path></code> limita l'elenco delle sessioni a una directory</div>
    <div>Nuovo hook <code>args: string\[]</code> la forma exec genera il comando direttamente senza una shell, quindi i segnaposti di percorso non hanno mai bisogno di virgolette</div>
    <div>Nuova opzione di configurazione <code>continueOnBlock</code> per gli hook <code>PostToolUse</code> restituisce il motivo del rifiuto dell'hook a Claude e continua il turno invece di terminarlo</div>
    <div>Nuovo campo <code>terminalSequence</code> nell'output JSON dell'hook consente agli hook di emettere notifiche desktop, titoli di finestra e campanelli senza un terminale di controllo</div>
    <div>Il menu Rewind ha aggiunto "Summarize up to here" per comprimere il contesto precedente mantenendo intatti i turni recenti</div>
    <div>Remote Control, <code>/schedule</code>, i connettori Claude.ai MCP e le preferenze di notifica sono ora disabilitati quando <code>ANTHROPIC\_API\_KEY</code>, <code>apiKeyHelper</code> o <code>ANTHROPIC\_AUTH\_TOKEN</code> è impostato, anche insieme a un accesso Claude.ai; annulla l'impostazione della chiave API per utilizzare queste funzionalità</div>
    <div>I server stdio MCP ora ricevono <code>CLAUDE\_PROJECT\_DIR</code> nel loro ambiente, corrispondendo agli hook, e le configurazioni dei plugin possono fare riferimento a <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code> nei comandi</div>
    <div><code>claude plugin details \<name></code> mostra l'inventario dei componenti di un plugin e il costo del token per sessione previsto, e il riquadro dei dettagli <code>/plugin</code> ora elenca anche i server LSP forniti da un plugin</div>
    <div>I plugin con un <code>SKILL.md</code> a livello di root e nessuna sottodirectory <code>skills/</code> sono ora visualizzati come una skill</div>
    <div><code>/feedback</code> può ora includere sessioni recenti degli ultimi 24 ore o 7 giorni per problemi che si estendono oltre la sessione corrente</div>
    <div>Lo strumento agente <code>subagent\_type</code> ora corrisponde senza distinzione tra maiuscole/minuscole e separatori, quindi <code>"Code Reviewer"</code> si risolve in <code>code-reviewer</code></div>
  </div>
