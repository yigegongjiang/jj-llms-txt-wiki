<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Testate i plugin con claude plugin eval</span>
    <span className="digest-feature-pill">v2.1.269</span>
  </div>

  <p className="digest-feature-lede"><code>claude plugin eval</code> esegue il vostro plugin rispetto a una suite di casi di test, valuta i risultati e per impostazione predefinita esegue di nuovo ogni caso senza il plugin in modo che possiate vedere il suo contributo. <code>claude plugin eval init</code> vi chiede come dovrebbe apparire un buon risultato, quindi propone casi di test e i controlli che li valutano, prova la suite una volta e scrive i file. Ogni esecuzione e ogni controllo che ha un secondo giudice modello la risposta è una vera chiamata al modello sul vostro account.</p>

  <Frame>
    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/plugin-eval.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=913066f6d4a2a15426e98a627802f47f" alt="Output del terminale di claude plugin eval: una tabella di sette casi con il punteggio di ogni caso con e senza il plugin, il delta tra loro, il conteggio delle esecuzioni e il costo, seguito da una riga di riepilogo con il delta medio, la durata totale e il costo totale" width="1600" height="900" data-path="images/whats-new/plugin-eval.jpg" />
  </Frame>

  <p className="digest-feature-try">Dalla directory principale del vostro plugin, fate in modo che Claude rediga la suite:</p>

  ```bash terminal theme={null}
  claude plugin eval init
  ```

  <p className="digest-feature-try">Quando Claude vi dice che la suite è pronta, uscite dalla sessione che <code>claude plugin eval init</code> ha aperto ed eseguite <code>claude plugin eval .</code> per valutare ogni caso. La tabella di riepilogo viene stampata nel vostro terminale e <code>report.html</code> sotto <code>evals/results/</code> contiene i dettagli per ogni esecuzione.</p>
