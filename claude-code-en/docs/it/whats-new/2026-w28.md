  <p className="digest-feature-lede"><code>/doctor</code> ora diagnostica i problemi e può risolverli, invece di stampare un rapporto di sola lettura. Controlla l'integrità dell'installazione, trova skills, server MCP e plugin inutilizzati rispetto al loro costo di contesto, deduplica i file locali <code>CLAUDE.md</code> rispetto a quelli archiviati, propone di ridurre il contenuto di <code>CLAUDE.md</code> che Claude potrebbe derivare dalla codebase e segnala gli hook lenti. Riporta i risultati per primo e chiede conferma prima di apportare modifiche. <code>/checkup</code> è il suo alias.</p>

  <p className="digest-feature-try">Esegui un controllo da qualsiasi sessione:</p>

  ```text Claude Code theme={null}
  > /doctor
  ```
