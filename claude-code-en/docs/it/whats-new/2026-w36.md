    <span className="digest-feature-title">Pannello diff dal vivo nel rendering a schermo intero</span>
    <span className="digest-feature-pill">v2.1.260</span>
  </div>

  <p className="digest-feature-lede">Nel rendering a schermo intero, <code>/diff</code> ora apre un pannello accanto alla conversazione invece di un visualizzatore che devi chiudere. Il pannello elenca i file modificati con i conteggi delle righe aggiunte e rimosse e si aggiorna ogni volta che Claude modifica un file o esegue un comando shell. Seleziona le righe nel pannello con il mouse per allegarle al tuo prossimo prompt.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/diff-panel.mp4?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=9d7553c19e7f227891cd95f1f59d796d" data-path="images/whats-new/diff-panel.mp4" />
  </Frame>

  <p className="digest-feature-try">Con il rendering a schermo intero attivato, all'interno di un repository git e in un terminale largo almeno 110 colonne, attiva/disattiva il pannello:</p>

  ```text Claude Code theme={null}
  > /diff
  ```

  <p className="digest-feature-try">Esegui <code>/diff</code> di nuovo o fai clic su <code>✕</code> nell'intestazione per chiuderlo.</p>

    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede"><code>/skill-doctor</code> mostra quanto costa ogni tua skill in contesto e quanto spesso viene utilizzata, così puoi decidere quali disattivare. Ogni skill nell'<a href="/docs/it/skills#skill-descriptions-are-cut-short">elenco delle skill</a> si aggiunge al tuo contesto ad ogni turno, indipendentemente dal fatto che Claude la usi mai. Richiede v2.1.252 o successiva e non è disponibile nelle sessioni che saltano il <a href="/docs/it/env-vars#features-that-need-feature-flag-fetching">recupero dei flag di funzionalità</a>.</p>

  <p className="digest-feature-try">Eseguilo in una sessione interattiva per aprire il report nella scheda <strong>Stats</strong> del gestore <code>/plugin</code>:</p>

  ```text Claude Code theme={null}
  > /skill-doctor
  ```

  <p className="digest-feature-try">In modalità non interattiva con <code>-p</code>, Claude Code stampa il report come testo.</p>

  <div className="digest-wins-grid">
    <div>Un hook <a href="/docs/it/hooks#premodelswitch"><code>PreModelSwitch</code></a> può bloccare un cambio di modello che richiedi, e un hook <a href="/docs/it/hooks#postmodelswitch"><code>PostModelSwitch</code></a> può aggiungere contesto per Claude dopo che il modello della sessione cambia</div>
    <div><a href="/docs/it/costs#prompt-cache-statistics"><code>/cost</code></a> aggiunge una riga <code>Prompt cache (main)</code>: la quota di token di input serviti dalla cache, i miss della cache, se la cache è calda e una probabile causa dell'ultimo miss quando Claude Code riesce a nominarne una. Gli script della riga di stato ricevono un oggetto <code>prompt\_cache</code> corrispondente</div>
    <div>Le organizzazioni possono elencare server MCP HTTP e SSE sotto l'impostazione gestita <a href="/docs/it/managed-mcp#provide-servers-through-managed-settings"><code>managedMcpServers</code></a> per fornirli a ogni utente, oltre ai server che gli utenti aggiungono da soli</div>
    <div><code>/effort</code> e il selettore <code>/model</code> ora <a href="/docs/it/model-config#adjust-effort-level">salvano un livello di sforzo separato per ogni modello</a>; premi <code>s</code> invece di <code>Invio</code> per applicare un livello solo alla sessione corrente</div>
    <div>Per impostazione predefinita, il classificatore della modalità automatica <a href="/docs/it/permission-modes#what-the-classifier-blocks-by-default">ora blocca anche</a> azioni come richiedere credenziali dall'endpoint dei metadati dell'istanza cloud o connettersi a contenitori fratelli che Claude non ha avviato</div>
    <div>In modalità automatica, Claude Code ti chiede prima che Claude <a href="/docs/it/permission-modes#first-read-outside-the-working-directories">legga per la prima volta un file al di fuori delle tue directory di lavoro</a>, con un'opzione per bloccare tali letture da quel momento in poi</div>
    <div>Aumenta <a href="/docs/it/settings-reference#bashoutputmaxchars"><code>bashOutputMaxChars</code></a> e <a href="/docs/it/settings-reference#taskoutputmaxchars"><code>taskOutputMaxChars</code></a>, fino a 128.000 caratteri, in modo che Claude riceva più output da un comando riuscito o da un'attività in background inline</div>
    <div>Le scorciatoie di modifica delle parole del prompt <a href="/docs/it/interactive-mode#make-ctrl-w-delete-back-to-whitespace">seguono readline</a> per tutti, e l'impostazione <code>keybindingFlavor</code> non ha più alcun effetto. <code>Ctrl+W</code> elimina fino allo spazio bianco precedente, e <code>Alt+B</code>, <code>Alt+F</code> e <code>Alt+D</code> trattano la punteggiatura come <code>/</code> e <code>.</code> come interruzioni di parola</div>
    <div>Se imposti <code>defaultMode</code> su <code>"bypassPermissions"</code> nel <code>.claude/settings.json</code> o <code>.claude/settings.local.json</code> di un progetto, <a href="/docs/it/permission-modes#which-mode-a-session-starts-in">non ha più effetto</a> e la sessione inizia in modalità Manuale; imposta <code>"bypassPermissions"</code> nelle impostazioni utente o gestite, oppure passa `--permission-mode`</div>
    <div>I piani Enterprise basati su posti <a href="/docs/it/model-config#default-model-setting">ora predefiniti a Opus 5</a></div>
    <div>Nell'estensione VS Code, fai clic sul nome del modello in fondo alla casella del prompt per <a href="/docs/it/vs-code#use-the-prompt-box">aprire il selettore del modello</a></div>
    <div>Nell'estensione VS Code, seleziona <strong>Output styles</strong> nella sezione Personalizza del menu dei comandi per <a href="/docs/it/vs-code#use-the-prompt-box">scegliere uno stile di output</a>, inclusi i tuoi personalizzati</div>
