    <div>Il nuovo comando <a href="/docs/docs/it/plugin-dependencies#tag-plugin-releases-for-version-resolution"><code>claude plugin tag</code></a> crea tag git di rilascio per i plugin con convalida della versione</div>
    <div>Le sessioni Opus 4.7 ora calcolano rispetto alla finestra di contesto nativa di 1M del modello, correggendo le percentuali <code>/context</code> gonfiate e l'autocompattazione prematura</div>
