<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude Fable 5.1</span>
    <span className="digest-feature-pill">new model</span>
  </div>

  <p className="digest-feature-lede">Claude Fable 5.1 は Claude Code で利用可能で、1M トークンのコンテキストウィンドウを備えており、<code>fable</code> エイリアスはこれを選択するようになりました。Claude apps gateway セッションでは、<code>fable</code> は引き続き Fable 5 を選択します。ゲートウェイが Fable 5.1 を提供している場合は、<code>/model claude-fable-5-1</code> を実行してください。v2.1.257 以降が必要です。</p>

  <p className="digest-feature-try">現在のセッションを Fable 5.1 に切り替えて、デフォルトとして保存します：</p>

  ```text Claude Code theme={null}
  > /model fable
  ```

  <p className="digest-feature-try">Anthropic API では、ピッカーはサーバーが組織で利用可能であると報告した場合にのみ Fable を一度リストアップしますが、<code>/model fable</code> を入力するとサーバーに直接確認します。</p>

  <a className="digest-feature-link" href="/docs/ja/model-config#work-with-fable">Work with Fable</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">フルスクリーンレンダリングのライブ diff パネル</span>
    <span className="digest-feature-pill">v2.1.260</span>
  </div>

  <p className="digest-feature-lede">フルスクリーンレンダリングでは、<code>/diff</code> は閉じる必要があるビューアーではなく、会話の横にパネルを開くようになりました。パネルは変更されたファイルを追加および削除された行数とともにリストアップし、Claude がファイルを編集するか shell コマンドを実行するたびに更新されます。マウスでパネル内の行を選択して、次のプロンプトに添付できます。</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/diff-panel.mp4?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=9d7553c19e7f227891cd95f1f59d796d" data-path="images/whats-new/diff-panel.mp4" />
  </Frame>

  <p className="digest-feature-try">フルスクリーンレンダリングがオンで、git リポジトリ内にあり、ターミナルが少なくとも 110 列幅の場合、パネルを切り替えます：</p>

  ```text Claude Code theme={null}
  > /diff
  ```

  <p className="digest-feature-try"><code>/diff</code> を再度実行するか、ヘッダーの <code>✕</code> をクリックして閉じます。</p>

  <a className="digest-feature-link" href="/docs/ja/interactive-mode#diff-panel">Diff panel</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">/skill-doctor で未使用のスキルを検索</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede"><code>/skill-doctor</code> は各スキルがコンテキストでどのくらいのコストがかかるか、そしてどのくらいの頻度で使用されるかを表示するため、どのスキルをオフにするかを決定できます。<a href="/docs/ja/skills#skill-descriptions-are-cut-short">スキルリスティング</a>内のすべてのスキルは、Claude が使用するかどうかに関わらず、すべてのターンでコンテキストに追加されます。v2.1.252 以降が必要で、<a href="/docs/ja/env-vars#features-that-need-feature-flag-fetching">feature-flag fetching をスキップ</a>するセッションでは利用できません。</p>

  <p className="digest-feature-try">インタラクティブセッションで実行して、<code>/plugin</code> マネージャーの <strong>Stats</strong> タブでレポートを開きます：</p>

  ```text Claude Code theme={null}
  > /skill-doctor
  ```

  <p className="digest-feature-try">非インタラクティブモードで <code>-p</code> を使用すると、Claude Code はレポートをテキストとして出力します。</p>

  <a className="digest-feature-link" href="/docs/ja/skills#find-unused-skills">Find unused skills</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">その他の改善</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/ja/hooks#premodelswitch"><code>PreModelSwitch</code></a> フックはリクエストしたモデル切り替えをブロックでき、<a href="/docs/ja/hooks#postmodelswitch"><code>PostModelSwitch</code></a> フックはセッションのモデルが変更された後に Claude のコンテキストを追加できます</div>
    <div><a href="/docs/ja/costs#prompt-cache-statistics"><code>/cost</code></a> は <code>Prompt cache (main)</code> 行を追加します。キャッシュから提供される入力トークンのシェア、キャッシュミス、キャッシュがウォームであるかどうか、および Claude Code が名前を付けることができる場合の最後のミスの可能な原因。ステータス行スクリプトは一致する <code>prompt\_cache</code> オブジェクトを取得します</div>
    <div>組織は HTTP および SSE MCP サーバーを <a href="/docs/ja/managed-mcp#provide-servers-through-managed-settings"><code>managedMcpServers</code></a> マネージド設定の下にリストアップして、ユーザーが自分で追加するサーバーに加えて、すべてのユーザーに提供できます</div>
    <div><code>/effort</code> と <code>/model</code> ピッカーは <a href="/docs/ja/model-config#adjust-effort-level">各モデルの個別の努力レベルを保存</a>するようになりました。<code>Enter</code> の代わりに <code>s</code> を押して、現在のセッションのみにレベルを適用します</div>
    <div>デフォルトでは、auto モード分類器は <a href="/docs/ja/permission-modes#what-the-classifier-blocks-by-default">クラウドインスタンスメタデータエンドポイントから認証情報をリクエストしたり、Claude が開始しなかった兄弟コンテナに接続したりするなどのアクション</a>もブロックするようになりました</div>
    <div>auto モードでは、Claude Code は Claude が <a href="/docs/ja/permission-modes#first-read-outside-the-working-directories">初めて作業ディレクトリ外のファイルを読み取る</a>前にあなたに確認を求め、その後そのような読み取りをブロックするオプションがあります</div>
    <div><a href="/docs/ja/settings-reference#bashoutputmaxchars"><code>bashOutputMaxChars</code></a> と <a href="/docs/ja/settings-reference#taskoutputmaxchars"><code>taskOutputMaxChars</code></a> を最大 128,000 文字まで引き上げて、Claude が成功したコマンドまたはバックグラウンドタスクからより多くの出力をインラインで受け取るようにします</div>
    <div>プロンプトの <a href="/docs/ja/interactive-mode#make-ctrl-w-delete-back-to-whitespace">単語編集ショートカットはすべての人に対して readline に従う</a>ようになり、<code>keybindingFlavor</code> 設定はもはや効果がありません。<code>Ctrl+W</code> は前の空白文字まで削除し、<code>Alt+B</code>、<code>Alt+F</code>、および <code>Alt+D</code> は <code>/</code> や <code>.</code> などの句読点を単語区切りとして扱います</div>
    <div>プロジェクトの <code>.claude/settings.json</code> または <code>.claude/settings.local.json</code> で <code>defaultMode</code> を <code>"bypassPermissions"</code> に設定した場合、<a href="/docs/ja/permission-modes#which-mode-a-session-starts-in">効果がなくなり</a>、セッションは Manual モードで開始されます。ユーザーまたはマネージド設定で <code>"bypassPermissions"</code> を設定するか、`--permission-mode` を渡してください</div>
    <div>シートベースの Enterprise プランは <a href="/docs/ja/model-config#default-model-setting">Opus 5 にデフォルト設定</a>されるようになりました</div>
    <div>VS Code 拡張機能では、プロンプトボックスの下部のモデル名をクリックして <a href="/docs/ja/vs-code#use-the-prompt-box">モデルピッカーを開く</a>ことができます</div>
    <div>VS Code 拡張機能では、コマンドメニューの Customize セクションで <strong>Output styles</strong> を選択して <a href="/docs/ja/vs-code#use-the-prompt-box">出力スタイルを選択</a>でき、カスタムスタイルも含まれます</div>
  </div>
</div>
