# Contoh

> Temukan proyek Agent SDK yang lengkap dan dapat dijalankan atau resep terpandu di Claude Cookbook yang sesuai dengan apa yang ingin Anda bangun.

Halaman ini mengarahkan Anda ke proyek Agent SDK yang lengkap dan dapat dijalankan serta resep Claude Cookbook yang terpandu. Aplikasi TypeScript berada di repositori [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos), dan resep Python berada di [Claude Cookbook](https://platform.claude.com/cookbook).

<h2 id="run-a-minimal-agent-first">
  Jalankan agen minimal terlebih dahulu
</h2>

Jika Anda belum membangun apa pun dengan SDK, mulai dengan salah satu dari ini sebelum aplikasi lengkap:

* [Agent SDK quickstart](/docs/id/agent-sdk/quickstart): bangun agen kerja pertama Anda dalam TypeScript atau Python, dengan langkah-langkah penyiapan disertakan. Agen menemukan dan memperbaiki bug dalam file sampel.

* [Hello World](https://github.com/anthropics/claude-agent-sdk-demos/tree/main/hello-world): proyek TypeScript minimal untuk diklon ketika Anda ingin memulai dari kode repo

<h2 id="explore-a-typescript-application">
  Jelajahi aplikasi TypeScript
</h2>

Aplikasi TypeScript di [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos) adalah demo untuk pengembangan lokal, dari klien email hingga sistem penelitian multi-agen. Klon demo yang bentuknya sesuai dengan apa yang Anda bangun.

<h2 id="work-through-a-python-recipe">
  Bekerja melalui resep Python
</h2>

Seri Agent SDK Claude Cookbook adalah urutan resep, masing-masing notebook Python, yang berkembang dari agen penelitian sederhana hingga sistem multi-agen yang canggih. Setiap notebook dibangun di atas yang sebelumnya, memperkenalkan konsep dan kemampuan baru. Mulai dengan [agen penelitian satu baris](https://platform.claude.com/cookbook/claude-agent-sdk-00-the-one-liner-research-agent) dan lanjutkan ke depan.

Untuk resep di seluruh produk Claude, lihat [Claude Cookbook](https://platform.claude.com/cookbook) lengkap.
