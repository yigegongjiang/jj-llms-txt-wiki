# Commands

> Referensi lengkap untuk perintah yang tersedia di Claude Code, termasuk perintah bawaan dan skills yang disertakan.

Perintah mengontrol Claude Code dari dalam sesi. Mereka menyediakan cara cepat untuk beralih model, mengelola izin, menghapus konteks, menjalankan alur kerja, dan lainnya.

Ketik `/` untuk melihat perintah yang tersedia untuk Anda, atau ketik `/` diikuti dengan huruf untuk memfilter. [Bagaimana menu perintah cocok dengan apa yang Anda ketik](#how-the-command-menu-matches-what-you-type) mencakup penyorotan, kesalahan ketik, dan beberapa perintah yang Claude Code sembunyikan dari menu sampai Anda mengetik nama lengkapnya.

Perintah hanya dikenali di awal pesan Anda. Teks yang mengikuti nama perintah menjadi argumennya. Mulai dari v2.1.199, [skills](/docs/id/skills#pass-arguments-to-skills) adalah pengecualian: invokasi skill diikuti oleh lebih banyak skills, seperti `/skill-a /skill-b do XYZ`, memuat setiap skill yang dinamai di awal dan meneruskan teks yang tertinggal ke masing-masing sebagai argumen. Hingga enam skills dapat dirantai.

Jika Anda mengirim perintah saat Claude sedang merespons, Claude Code mengantreannya dan menjalankannya setelah giliran saat ini selesai. Claude Code menjalankan beberapa perintah segera tanpa mengganggu respons, seperti `/status`, `/tasks`, dan `/usage`. Dalam [fullscreen rendering](/docs/id/fullscreen), Claude Code juga membuka perintah dialog seperti `/theme` dan `/help` segera. Sebelum v2.1.234, Claude Code mengantreankan dialog tersebut sampai giliran selesai.

<h2 id="commands-across-a-typical-workflow">
  Perintah di seluruh alur kerja khas
</h2>

Sebagian besar perintah berguna pada titik tertentu dalam sesi, dari menyiapkan proyek hingga mengirimkan perubahan.

**Sesi pertama di repo.** Jalankan `/init` untuk menghasilkan `CLAUDE.md` pemula, kemudian `/memory` untuk menyempurnakannya. Gunakan `/mcp` untuk menyiapkan server apa pun yang dibutuhkan proyek, minta Claude untuk membuat [subagents](/docs/id/sub-agents) apa pun yang Anda inginkan, dan jalankan `/permissions` untuk menetapkan aturan persetujuan Anda.

**Selama tugas.** `/plan` beralih ke plan mode sebelum perubahan besar. `/model` dan `/effort` menyesuaikan model mana yang Anda gunakan dan berapa banyak penalaran yang diterapkannya. Ketika percakapan menjadi panjang, `/context` menunjukkan apa yang mengisi jendela dan `/compact` merangkumnya untuk membebaskan ruang. Gunakan `/btw` untuk pertanyaan sampingan yang tidak boleh ditambahkan ke riwayat percakapan.

**Jalankan pekerjaan secara paralel.** Claude mendelegasikan tugas sampingan ke [subagents](/docs/id/sub-agents), dan `/tasks` mencantumkan pekerjaan latar belakang sesi saat ini, termasuk subagents yang telah selesai. `/background` melepaskan seluruh sesi untuk terus berjalan sebagai [background agent](/docs/id/agent-view) dan membebaskan terminal Anda. Untuk perubahan besar yang mencakup codebase, `/batch` menguraikannya menjadi unit independen dan menjalankan masing-masing di [worktree](/docs/id/worktrees) miliknya sendiri. Lihat [Run agents in parallel](/docs/id/agents) untuk cara pendekatan ini berhubungan.

**Sebelum Anda mengirimkan.** `/diff` menunjukkan apa yang berubah. `/code-review` memeriksa diff saat ini untuk bug kebenaran dan dapat menerapkan temuan dengan `--fix`; berikan nomor PR, seperti `/code-review high 1234`, untuk meninjau pull request sebagai gantinya. `/review` adalah alias. `/code-review ultra` menjalankan tinjauan multi-agen di cloud. `/security-review` memeriksa diff untuk kerentanan keamanan.

**Antar sesi.** `/clear` memulai segar pada tugas baru sambil menyimpan memori proyek. `/resume` kembali ke percakapan sebelumnya, `/branch` membuat cabang percakapan saat ini untuk mencoba arah berbeda, dan `/fork` menyalinnya ke [background session](/docs/id/agent-view) baru. `/teleport` menarik sesi cloud ke terminal ini, dan `/remote-control` memungkinkan Anda melanjutkan sesi lokal ini dari perangkat lain.

**Ketika ada yang salah.** `/rewind` mengembalikan kode dan percakapan ke checkpoint, atau merangkum bagian dari percakapan. `/doctor` menjalankan pemeriksaan penyiapan yang mendiagnosis masalah instalasi dan konfigurasi dan dapat memperbaikinya, `/debug` mendiagnosis masalah runtime, dan `/feedback` melaporkan bug dengan konteks sesi terlampir.

<h2 id="all-commands">
  Semua perintah
</h2>

Tabel di bawah mencantumkan semua perintah yang disertakan dalam Claude Code. Sebagian besar adalah perintah bawaan yang perilakunya dikodekan ke dalam CLI. Dua jenis entri ditandai:

* **[Skill](/docs/id/skills#bundled-skills)**: sebuah skill bundel. Ini bekerja seperti skill yang Anda tulis sendiri: prompt yang diberikan kepada Claude.
  * `/verify` berjalan hanya ketika Anda menjalankannya. Sebelum v2.1.215, Claude juga bisa menjalankan `/verify` dengan sendirinya.
* **[Workflow](/docs/id/workflows#bundled-workflows)**: sebuah [dynamic workflow](/docs/id/workflows) bundel yang menyebarkan pekerjaan di banyak subagent dan berjalan di latar belakang.
  * `/deep-research` berjalan hanya ketika Anda menjalankannya. Sebelum v2.1.218, Claude juga bisa memulainya dengan sendirinya.

Untuk menambahkan perintah Anda sendiri, lihat [skills](/docs/id/skills).

Dalam tabel di bawah, `<arg>` menunjukkan argumen yang diperlukan dan `[arg]` menunjukkan argumen opsional.

<Note>
  Tidak setiap perintah muncul untuk setiap pengguna. Ketersediaan tergantung pada platform, paket, dan lingkungan Anda. Misalnya, `/desktop` hanya muncul di macOS dan Windows x64 ketika masuk dengan langganan Claude, dan `/upgrade` tidak muncul di paket Enterprise.
</Note>

<h2 id="how-the-command-menu-matches-what-you-type">
  Bagaimana menu perintah mencocokkan apa yang Anda ketik
</h2>

Claude Code memfilter menu `/` saat Anda mengetik. Setiap poin di bawah mencakup satu hal yang mungkin Anda perhatikan saat memfilter:

* **Penyorotan**: Claude Code menyoroti saran teratas hanya ketika huruf setelah `/` cocok dengan nama atau alias perintah, dari awal nama atau dari kata di dalamnya, mengabaikan pemisah `:`, `_`, dan `-`. Mengetik `/adddir` menyoroti `/add-dir`, dan mengetik `/new` menyoroti `/clear` melalui aliasnya. Tekan `Enter` untuk menjalankan saran yang disarankan. Aturan penyorotan ini memerlukan Claude Code v2.1.236 atau lebih baru.
* **Setelah kesalahan ketik**: Claude Code tidak menyoroti apa pun. Kecocokan yang dekat tetap terdaftar, dan Anda dapat memilih satu dengan `Tab` atau tombol panah, tetapi `Enter` mengirimkan teks Anda seperti yang diketik dan melaporkan [Unknown command](/docs/id/errors#unknown-command).
* **Perintah yang tidak tersedia untuk Anda**: Claude Code mengeluarkannya dari menu. Ketika tidak ada yang cocok, Claude Code menampilkan `No commands match "/name"`. Sebagian besar perintah yang tidak tersedia mengembalikan [Unknown command](/docs/id/errors#unknown-command) ketika Anda mengirimkannya; beberapa, seperti [`/schedule` pada kunci Console API](/docs/id/routines#schedule-returns-unknown-command), menjawab dengan pesan ketersediaan mereka sendiri. Beberapa perintah juga menjawab dengan pesan mereka sendiri ketika kebijakan organisasi Anda menonaktifkannya.
* **Perintah tersembunyi**: Claude Code menyimpan beberapa perintah yang tersedia, seperti `/heapdump`, keluar dari menu dengan desain. Nama parsial tidak pernah membawa perintah tersembunyi ke dalam menu: jika parsial tidak cocok dengan apa pun yang terlihat, Claude Code menampilkan pesan tanpa kecocokan yang sama. Claude Code hanya mencantumkan perintah setelah Anda mengetik nama lengkapnya, dan mengirimkan nama lengkap menjalankannya.
