# Referensi CLI

> Referensi lengkap untuk antarmuka baris perintah Claude Code, termasuk perintah dan flag.

<h2 id="cli-commands">
  Perintah CLI
</h2>

Anda dapat memulai sesi, menyalurkan konten, melanjutkan percakapan, dan mengelola pembaruan dengan perintah-perintah ini:

| Perintah                        | Deskripsi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Contoh                                                      |
| :------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| `claude`                        | Mulai sesi interaktif                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `claude`                                                    |
| `claude "query"`                | Mulai sesi interaktif dengan prompt awal                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude "explain this project"`                             |
| `claude -p "query"`             | Kueri melalui SDK, kemudian keluar                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude -p "explain this function"`                         |
| `cat file \| claude -p "query"` | Proses konten yang disalurkan                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `cat logs.txt \| claude -p "explain"`                       |
| `claude -c`                     | Lanjutkan percakapan terbaru di direktori saat ini                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude -c`                                                 |

| `claude -r "<session>" "query"` | Lanjutkan sesi berdasarkan ID atau nama                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `claude -r "auth-refactor" "Finish this PR"`                |
| `claude update`                 | Perbarui ke versi terbaru                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `claude update`                                             |
| `claude gateway`                | Mulai server [gateway aplikasi Claude](/docs/id/claude-apps-gateway) yang di-host sendiri, untuk administrator yang menerapkan SSO dan kebijakan di depan Claude Code di Amazon Bedrock, Google Cloud's Agent Platform, atau Microsoft Foundry. Memerlukan `--config` yang menunjuk ke [`gateway.yaml`](/docs/id/claude-apps-gateway-config). Tersedia di Claude Code v2.1.195 dan lebih baru.                                                                                                                                                                                                                                                                                                                                                                                                                                     | `claude gateway --config gateway.yaml`                      |
| `claude install [version]`      | Instal atau instal ulang binary asli. Menerima versi seperti `2.1.118`, atau `stable` atau `latest`. Lihat [Instal versi tertentu](/docs/id/setup#install-a-specific-version)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude install stable`                                     |
| `claude auth login`             | Masuk ke akun Anthropic Anda. Gunakan `--email` untuk mengisi email Anda sebelumnya, `--sso` untuk memaksa autentikasi SSO, dan `--console` untuk masuk dengan Anthropic Console untuk penagihan penggunaan API alih-alih langganan Claude                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude auth login --console`                               |
| `claude auth logout`            | Keluar dari akun Anthropic Anda                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `claude auth logout`                                        |
| `claude auth status`            | Tampilkan status autentikasi sebagai JSON. Gunakan `--text` untuk output yang dapat dibaca manusia. Keluar dengan kode 0 jika masuk, 1 jika tidak                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `claude auth status`                                        |
| `claude agents`                 | Buka [tampilan agen](/docs/id/agent-view) untuk memantau dan mengirim sesi latar belakang paralel. Gunakan `--cwd <path>` untuk menampilkan hanya sesi yang dimulai di bawah direktori tersebut, atau `--json` untuk mencetak sesi langsung sebagai array JSON untuk skrip (`--json --all` juga mencakup sesi latar belakang yang selesai). Lewatkan `--permission-mode`, `--model`, `--effort`, atau `--agent` untuk menetapkan [default untuk sesi yang dikirim](/docs/id/agent-view#permission-mode-model-and-effort). Menerima `--settings`, `--add-dir`, `--plugin-dir`, dan `--mcp-config` seperti perintah `claude` tingkat atas. Membuka tampilan agen memerlukan terminal interaktif                                                                                                                                      | `claude agents --json`                                      |
| `claude attach <id>`            | Lampirkan ke [sesi latar belakang](/docs/id/agent-view#manage-sessions-from-the-shell) di terminal ini                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `claude attach 7c5dcf5d`                                    |
| `claude auto-mode defaults`     | Cetak aturan pengklasifikasi [auto mode](/docs/id/permission-modes#eliminate-prompts-with-auto-mode) bawaan sebagai JSON. Gunakan `claude auto-mode config` untuk melihat konfigurasi efektif Anda dengan pengaturan yang diterapkan. `--label <prefix>` mencetak hanya aturan yang labelnya dimulai dengan awalan tersebut, cocok tanpa memperhatikan huruf besar-kecil. Memerlukan Claude Code v2.1.208 atau lebih baru                                                                                                                                                                                                                                                                                                                                                                                                     | `claude auto-mode defaults --label 'Git Destructive'`       |
| `claude auto-mode reset`        | Pulihkan konfigurasi [auto mode](/docs/id/permission-modes#eliminate-prompts-with-auto-mode) default dengan menghapus bagian `autoMode` dari file pengaturan pengguna Anda. Meminta konfirmasi sebelum menulis; lewatkan `-y`/`--yes` untuk melewati prompt. Aturan dari [pengaturan yang dikelola](/docs/id/server-managed-settings) atau flag `--settings` masih berlaku. Memerlukan Claude Code v2.1.212 atau lebih baru. Lihat [Periksa default dan konfigurasi efektif Anda](/docs/id/auto-mode-config#inspect-the-defaults-and-your-effective-config)                                                                                                                                                                                                                                                                             | `claude auto-mode reset --yes`                              |
| `claude daemon status`          | Cetak status [supervisor](/docs/id/agent-view#the-supervisor-process) sesi latar belakang, versi, direktori soket, dan jumlah pekerja untuk diagnostik. Keluar dengan 1 jika supervisor tidak berjalan                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `claude daemon status`                                      |
| `claude daemon stop --any`      | Hentikan [supervisor](/docs/id/agent-view#the-supervisor-process) sesi latar belakang dan sesi yang dihosting. Lewatkan `--keep-workers` untuk membiarkan sesi latar belakang tetap berjalan sehingga supervisor berikutnya dapat terhubung kembali ke sesi tersebut. `--any` mengonfirmasi penghentian supervisor sesuai permintaan, yang merupakan default. Gunakan ini untuk pulih dari [supervisor yang tidak responsif](/docs/id/agent-view#agent-view-says-the-background-service-did-not-respond)                                                                                                                                                                                                                                                                                                                           | `claude daemon stop --any --keep-workers`                   |
| `claude doctor`                 | Cetak diagnostik instalasi dan pengaturan hanya-baca dari terminal tanpa memulai sesi, termasuk kesehatan instalasi, kesalahan validasi file pengaturan, dan kelayakan Remote Control. Untuk pemeriksaan pengaturan dalam sesi yang juga dapat menerapkan perbaikan, jalankan [`/doctor`](/docs/id/commands#all-commands)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `claude doctor`                                             |
| `claude import [source]`        | Mulai sesi interaktif yang menjalankan [`/import`](/docs/id/commands#all-commands) untuk membawa konfigurasi dari agen pengkodean lain ke Claude Code. Menerima opsi `--dry-run` dan `--yes` yang sama dengan perintah. Tidak tersedia di Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, atau Claude Platform di AWS. Juga tidak tersedia ketika Anda mematikan [pengambilan flag fitur](/docs/id/env-vars#features-that-need-feature-flag-fetching). Memerlukan Claude Code v2.1.213 atau lebih baru                                                                                                                                                                                                                                                                                                           | `claude import codex --dry-run`                             |
| `claude logs <id>`              | Cetak output terbaru dari [sesi latar belakang](/docs/id/agent-view#manage-sessions-from-the-shell)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `claude logs 7c5dcf5d`                                      |
| `claude mcp`                    | Konfigurasi server Model Context Protocol (MCP)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Lihat [dokumentasi Claude Code MCP](/docs/id/mcp).               |
| `claude mcp login <name>`       | Jalankan alur OAuth server MCP yang dikonfigurasi tanpa membuka panel `/mcp` interaktif. Bekerja untuk server HTTP, SSE, dan konektor claude.ai. Tambahkan `--no-browser` melalui SSH untuk mencetak URL otorisasi alih-alih membuka browser, kemudian tempel URL pengalihan kembali di prompt. Lihat [Autentikasi dari baris perintah](/docs/id/mcp#authenticate-from-the-command-line)                                                                                                                                                                                                                                                                                                                                                                                                                                      | `claude mcp login sentry`                                   |
| `claude mcp logout <name>`      | Hapus kredensial OAuth yang disimpan untuk server MCP                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `claude mcp logout sentry`                                  |
| `claude plugin`                 | Kelola Claude Code [plugins](/docs/id/plugins/overview). Alias: `claude plugins`. Lihat [referensi plugin](/docs/id/plugins/cli-reference#claude-plugin-commands) untuk subperintah                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `claude plugin install code-review@claude-plugins-official` |
| `claude project purge [path]`   | Hapus semua status Claude Code lokal untuk proyek: transkrip, daftar tugas, log debug, riwayat edit file, baris riwayat prompt, dan entri proyek di `~/.claude.json`. Abaikan `[path]` untuk memilih dari daftar interaktif. Flag: `--dry-run` untuk pratinjau, `-y`/`--yes` untuk melewati konfirmasi, `-i`/`--interactive` untuk mengonfirmasi setiap item, `--all` untuk setiap proyek. Lihat [Hapus data lokal](/docs/id/claude-directory#clear-local-data)                                                                                                                                                                                                                                                                                                                                                               | `claude project purge ~/work/repo --dry-run`                |
| `claude remote-control`         | Mulai server [Remote Control](/docs/id/remote-control) untuk mengontrol Claude Code dari Claude.ai atau aplikasi Claude. Berjalan dalam mode server (tidak ada sesi interaktif lokal). Lihat [flag mode server](/docs/id/remote-control#start-a-remote-control-session). Setelah Anda menghentikan server, Anda dapat membawa kembali sesi yang sedang dilayaninya. Lihat [Lanjutkan sesi setelah menghentikan server](/docs/id/remote-control#resume-sessions-after-stopping-the-server)                                                                                                                                                                                                                                                                                                                                               | `claude remote-control --name "My Project"`                 |
| `claude respawn <id>`           | Mulai ulang [sesi latar belakang](/docs/id/agent-view#manage-sessions-from-the-shell), berjalan atau dihentikan, dengan percakapannya tetap utuh. Gunakan `--all` untuk memulai ulang setiap sesi yang berjalan, misalnya untuk mengambil binary Claude Code yang diperbarui                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `claude respawn 7c5dcf5d`                                   |
| `claude rm <id>`                | Hapus [sesi latar belakang](/docs/id/agent-view#manage-sessions-from-the-shell) dari daftar. Ketika penghapusan [ditolak melalui worktree sesi](/docs/id/agent-view#what-deleting-a-session-removes) dan `claude rm` kedua dapat menyelesaikannya, penolakan mencetak flag dan nilai yang tepat untuk dilewatkan: `--discard-unpushed <commit>@<worktree-id>` membuang worktree yang memiliki commit yang belum didorong bersama dengan commit tersebut, dan `--force-remove-worktree <worktree-id>` menghapus direktori worktree yang tidak dapat dihapus oleh git atau hook `WorktreeRemove`. `--discard-unpushed` memerlukan Claude Code v2.1.260 atau lebih baru, dan `--force-remove-worktree` memerlukan v2.1.268 atau lebih baru. Transkrip percakapan tetap berada di mesin lokal Anda, tersedia melalui `claude --resume` | `claude rm 7c5dcf5d`                                        |
| `claude self-hosted-runner`     | Mulai proses runner yang mendaftarkan mesin atau kontainer ini dengan [lingkungan yang di-host sendiri](/docs/id/self-hosted-environments) dan menghosting sesi cloud Claude Code di infrastruktur Anda. Jalankan `claude self-hosted-runner setup` untuk panduan operator interaktif, `claude self-hosted-runner doctor` untuk [mendiagnosis runner yang diterapkan](/docs/id/self-hosted-environments-deploy#troubleshooting), dan `claude self-hosted-runner orchestrator` untuk menelurkan [runner sesuai permintaan](/docs/id/self-hosted-environments-configuration#on-demand-runners). Memerlukan Claude Code v2.1.224 atau lebih baru                                                                                                                                                                                           | `claude self-hosted-runner setup`                           |
| `claude setup-token`            | Hasilkan token OAuth yang tahan lama untuk CI dan skrip. Mencetak token ke terminal tanpa menyimpannya. Memerlukan langganan Claude. Lihat [Hasilkan token yang tahan lama](/docs/id/authentication#generate-a-long-lived-token)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | `claude setup-token`                                        |
| `claude stop <id>`              | Hentikan [sesi latar belakang](/docs/id/agent-view#manage-sessions-from-the-shell). Juga menerima `claude kill`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude stop 7c5dcf5d`                                      |
| `claude ultrareview [target]`   | Jalankan [ultrareview](/docs/id/ultrareview#run-ultrareview-non-interactively) secara non-interaktif. Mencetak temuan ke stdout dan keluar dengan 0 saat berhasil atau 1 saat gagal. Gunakan `--json` untuk payload mentah dan `--timeout <minutes>` untuk mengganti default 45 menit. Gunakan `--post` pada target pull request `github.com` untuk memposting temuan yang selesai ke PR sebagai satu komentar biasa dari akun GitHub Anda. `--no-post` adalah default. `--post` dan `--no-post` memerlukan Claude Code v2.1.227 atau lebih baru. Lihat [Posting temuan ke pull request](/docs/id/ultrareview#post-findings-to-the-pull-request)                                                                                                                                                                                   | `claude ultrareview 1234 --json`                            |

Jika Anda salah mengetik subperintah, Claude Code menyarankan kecocokan terdekat dan keluar tanpa memulai sesi. Misalnya, `claude udpate` mencetak `Did you mean claude update?`.

Mulai dari v2.1.199, `claude --dangerously-skip-permissions daemon <subcommand>` menjalankan subperintah `daemon`. Versi sebelumnya memperlakukan `daemon <subcommand>` sebagai prompt untuk sesi interaktif baru, sehingga subperintah tidak pernah berjalan ketika flag datang terlebih dahulu, setup umum ketika `claude` memiliki alias untuk menyertakan flag. Hanya `--dangerously-skip-permissions` atau `--allow-dangerously-skip-permissions` yang terdepan yang merutekan ke `daemon` dengan cara ini; flag terdepan lainnya masih memulai sesi interaktif.

<h2 id="cli-flags">
  Bendera CLI
</h2>

Sesuaikan perilaku Claude Code dengan bendera baris perintah ini. `claude --help` tidak mencantumkan setiap bendera, jadi ketiadaan bendera dari `--help` tidak berarti bendera tersebut tidak tersedia.

| Bendera                                         | Deskripsi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Contoh                                                                                              |
| :---------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------- |
| `--add-dir`                                     | Tambahkan direktori kerja tambahan untuk Claude membaca dan mengedit file. Memberikan akses file; Claude Code [tidak menemukan](/docs/id/permissions#additional-directories-grant-file-access-not-configuration) sebagian besar konfigurasi `.claude/` dari direktori ini. Memvalidasi bahwa setiap jalur ada sebagai direktori. Anda tidak dapat menambahkan sebagian besar [jalur jaringan](/docs/id/errors#working-directory-is-a-network-path), seperti `\\server\share`. Untuk mempertahankan direktori ini di seluruh sesi, atur [`permissions.additionalDirectories`](/docs/id/settings-reference#permissions-additionaldirectories) dalam pengaturan                                                                                                                                                                                                                                                                                                                                                                   | `claude --add-dir ../apps ../lib`                                                                   |
| `--advisor <model>`                             | Aktifkan [alat penasihat](/docs/id/advisor) sisi server untuk sesi ini dengan alias model, `fable`, `opus`, atau `sonnet`, atau ID model lengkap. Mengambil alih pengaturan `advisorModel` untuk sesi. `fable` memerlukan [akses Fable](/docs/id/advisor#choose-an-advisor-model)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude --advisor opus`                                                                             |
| `--agent`                                       | Tentukan agen untuk sesi saat ini (menimpa pengaturan `agent`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `claude --agent my-custom-agent`                                                                    |
| `--agents`                                      | Tentukan subagen khusus secara dinamis melalui JSON. Menerima [bidang yang tercantum untuk subagen yang ditentukan CLI](/docs/id/sub-agents#choose-the-subagent-scope). Claude Code memvalidasi JSON saat startup dan keluar pada nilai yang tidak valid; lihat [`Konfigurasi --agents tidak valid`](/docs/id/errors#invalid-agents-configuration) untuk pesan dan untuk bendera dan variabel lingkungan yang melewati validasi. Validasi memerlukan Claude Code v2.1.242 atau lebih baru                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude --agents '{"reviewer":{"description":"Reviews code","prompt":"You are a code reviewer"}}'`  |
| `--allow-dangerously-skip-permissions`          | Tambahkan `bypassPermissions` ke siklus mode `Shift+Tab` tanpa memulai di dalamnya. Memungkinkan Anda memulai dalam mode berbeda seperti `plan` dan beralih ke `bypassPermissions` nanti. Lihat [mode izin](/docs/id/permission-modes#skip-all-checks-with-bypasspermissions-mode)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `claude --permission-mode plan --allow-dangerously-skip-permissions`                                |
| `--allowedTools`, `--allowed-tools`             | Alat yang dijalankan tanpa meminta izin. Lihat [sintaks aturan izin](/docs/id/settings-reference#permission-rule-syntax) untuk pencocokan pola. Untuk membatasi alat mana yang tersedia, gunakan `--tools` sebagai gantinya. Jika Anda menamai salah satu [alat pelacakan tugas](/docs/id/tools-reference#task-tool-availability) di sini, Claude Code juga memilih sesi masuk                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `"Bash(git log *)" "Bash(git diff *)" "Read"`                                                       |
| `--append-subagent-system-prompt`               | Tambahkan teks khusus ke akhir prompt sistem setiap [subagen](/docs/id/sub-agents), termasuk subagen bersarang, terlepas dari [subagen yang bercabang](/docs/id/sub-agents#fork-the-current-conversation), yang menggunakan kembali prompt percakapan sendiri. Hanya berlaku dalam mode non-interaktif dengan `-p`. Memerlukan Claude Code v2.1.205 atau lebih baru                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude -p --append-subagent-system-prompt "Cite file paths in every answer" "query"`               |
| `--append-subagent-system-prompt-file`          | Muat teks dari file dan tambahkan ke prompt sistem [subagen](/docs/id/sub-agents). Alternatif untuk `--append-subagent-system-prompt` untuk teks yang terlalu panjang untuk dilewatkan di baris perintah. Kedua bendera tidak dapat digabungkan. Hanya berlaku dalam mode non-interaktif dengan `-p`. Memerlukan Claude Code v2.1.261 atau lebih baru                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `claude -p --append-subagent-system-prompt-file ./subagent-rules.txt "query"`                       |
| `--append-system-prompt`                        | Tambahkan teks khusus ke akhir prompt sistem default                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `claude --append-system-prompt "Always use TypeScript"`                                             |
| `--append-system-prompt-file`                   | Muat teks prompt sistem tambahan dari file dan tambahkan ke prompt default                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `claude --append-system-prompt-file ./extra-rules.txt`                                              |
| `--autocompact <auto\|tokens>`                  | Atur [jendela auto-compact](/docs/id/model-config#set-the-auto-compact-window) untuk sesi ini tanpa mengubah pengaturan tersimpan Anda. Menerima nilai yang sama dengan `/autocompact`; bagian itu mencakup bentuk nilai dan apa yang menimpa bendera. Memerlukan Claude Code v2.1.221 atau lebih baru                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude --autocompact 500k`                                                                         |
| `--ax-screen-reader`                            | Render output yang ramah pembaca layar: teks datar tanpa batas dekoratif atau animasi. Memaksa renderer klasik, jadi pengaturan [`tui`](/docs/id/settings-reference#tui) tidak berpengaruh; [sesi latar belakang](/docs/id/agent-view) yang terlampir masih render layar penuh. Mengambil alih [`CLAUDE_AX_SCREEN_READER`](/docs/id/env-vars) dan pengaturan [`axScreenReader`](/docs/id/settings-reference#axscreenreader). Memerlukan Claude Code v2.1.181 atau lebih baru                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `claude --ax-screen-reader`                                                                         |
| `--bare`                                        | Mode minimal: lewati penemuan otomatis hooks, skills, perintah khusus, subagen, plugin, server MCP, memori otomatis, dan CLAUDE.md sehingga panggilan skrip dimulai lebih cepat. Skills dalam direktori yang Anda lewatkan dengan `--add-dir` masih dimuat. Claude memiliki akses ke alat Bash, pembacaan file, dan pengeditan file. Menetapkan [`CLAUDE_CODE_SIMPLE`](/docs/id/env-vars). Lihat [mode bare](/docs/id/headless#start-faster-with-bare-mode)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude --bare -p "query"`                                                                          |
| `--betas`                                       | Header beta untuk disertakan dalam permintaan API (hanya pengguna kunci API)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `claude --betas interleaved-thinking`                                                               |

<h3 id="system-prompt-flags">
  Bendera prompt sistem
</h3>

Claude Code menyediakan lima bendera untuk menyesuaikan prompt sistem. Empat menetapkan teksnya, dan dengan `--system-prompt-snapshot` Anda mengontrol apakah percakapan menyimpan teks yang dimulainya. Kelima bendera bekerja dalam mode interaktif dan non-interaktif.

| Bendera                       | Perilaku                                                                                                                                                                                                 | Contoh                                                                     |
| :---------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------- |
| `--system-prompt`             | Mengganti seluruh prompt default                                                                                                                                                                         | `claude --system-prompt "You are a Python expert"`                         |
| `--system-prompt-file`        | Mengganti dengan konten file                                                                                                                                                                             | `claude --system-prompt-file ./prompts/review.txt`                         |
| `--append-system-prompt`      | Menambahkan ke prompt default                                                                                                                                                                            | `claude --append-system-prompt "Always use TypeScript"`                    |
| `--append-system-prompt-file` | Menambahkan konten file ke prompt default                                                                                                                                                                | `claude --append-system-prompt-file ./style-rules.txt`                     |
| `--system-prompt-snapshot`    | Dengan `off`, membangun kembali prompt pada setiap permintaan. Dengan `on`, default, menggunakan kembali prompt yang dicatat di mana [pencatatan berlaku](#system-prompt-flags-in-resumed-conversations) | `claude --append-system-prompt "Draft rules" --system-prompt-snapshot off` |

`--system-prompt` dan `--system-prompt-file` saling eksklusif. Bendera append dapat digabungkan dengan bendera penggantian apa pun.

Ketika teks penggantian menggabungkan instruksi yang sama pada setiap jalankan dengan konteks yang berubah per jalankan, tambahkan baris yang berisi hanya `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__` antara instruksi dan konteks. Claude Code membagi prompt pada baris pertama seperti itu dan menghapus baris itu, jadi bagian di atasnya tetap di-cache sementara bagian di bawahnya berubah. Memerlukan Claude Code v2.1.275 atau lebih baru. [Cache bagian statis dari prompt khusus](/docs/id/agent-sdk/modifying-system-prompts#cache-the-static-part-of-a-custom-prompt) mencantumkan konfigurasi di mana pemisahan berlaku.

Pilih berdasarkan apakah identitas default Claude Code masih sesuai dengan tugas Anda. Gunakan bendera append ketika Claude harus tetap menjadi asisten pengkodean yang juga mengikuti aturan tambahan Anda: instruksi per-invokasi, pemformatan output, atau konteks domain untuk skrip `-p`. Menambahkan mempertahankan panduan alat default, instruksi keselamatan, dan konvensi pengkodean, jadi Anda hanya menyediakan apa yang berbeda. Gunakan bendera penggantian ketika permukaan, identitas, atau model izin berbeda dari Claude Code, seperti agen non-pengkodean dalam pipeline yang tidak ada manusia yang menonton. Mengganti menghilangkan seluruh prompt default, termasuk panduan alat dan instruksi keselamatan, jadi Anda bertanggung jawab atas apa pun yang masih dibutuhkan tugas Anda.

Untuk persona persisten yang dapat Anda alihkan dan bagikan di seluruh proyek, gunakan [gaya output](/docs/id/output-styles). Untuk konvensi proyek yang Claude harus selalu ikuti, gunakan [CLAUDE.md](/docs/id/memory). Panduan [Agent SDK tentang prompt sistem](/docs/id/agent-sdk/modifying-system-prompts#decide-on-a-starting-point) mencakup keputusan yang sama secara lebih mendalam.

<h4 id="system-prompt-flags-in-resumed-conversations">
  Bendera prompt sistem dalam percakapan yang dilanjutkan
</h4>

Secara default, Claude Code membangun prompt sistem sekali, pada permintaan pertama percakapan, dengan teks dari bendera prompt sistem apa pun yang diterapkan, dan mencatatnya dalam sesi. Sampai percakapan dikompak, setiap permintaan nanti menggunakan prompt yang dicatat, termasuk setelah Anda kembali ke percakapan dengan `--resume` atau `--continue`. Jika Anda melewatkan teks bendera prompt sistem yang berbeda, atau tidak ada, pada peluncuran nanti, itu berlaku setelah percakapan dikompak atau ketika Anda memulai percakapan baru.

Di luar [sesi cloud](/docs/id/cloud-environments), jika Anda memulai Claude Code dalam [mode bare](/docs/id/headless#start-faster-with-bare-mode) dengan melewatkan `--bare` atau menetapkan `CLAUDE_CODE_SIMPLE=1`, pencatatan tetap mati kecuali Anda melewatkan `--system-prompt-snapshot on`. Sebelum v2.1.268, sesi yang tidak [mengambil bendera fitur](/docs/id/env-vars#features-that-need-feature-flag-fetching), termasuk sesi di Amazon Bedrock, Google Cloud's Agent Platform, dan Microsoft Foundry, membangun kembali prompt pada setiap permintaan dan `--system-prompt-snapshot` tidak berpengaruh.

Untuk membangun kembali prompt pada setiap permintaan sebagai gantinya, misalnya saat Anda mengulangi kata-katanya di seluruh jalankan `--continue`, lewatkan `--system-prompt-snapshot off`. Sebelum v2.1.265, melewatkan salah satu bendera prompt sistem juga mematikan pencatatan kecuali Anda melewatkan `--system-prompt-snapshot on`.
