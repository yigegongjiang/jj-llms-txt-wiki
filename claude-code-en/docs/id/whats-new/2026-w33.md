<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Mode fork aktif secara default</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">Mode fork sekarang aktif secara default dalam sesi interaktif. Claude dapat meminta tipe subagent <code>fork</code>, yang mewarisi percakapan lengkap dan cache prompt alih-alih memulai dari awal, sehingga Anda tidak perlu menjelaskan ulang konteks untuk tugas sampingan. Subagent yang Claude buat dalam sesi interaktif, selain yang dibuat oleh rekan tim agent-team, juga berjalan di latar belakang secara default.</p>

  <p className="digest-feature-try">Mulai fork sendiri dengan tugas yang memerlukan semua yang telah Anda diskusikan sejauh ini:</p>

  ```text Claude Code theme={null}
  > /subtask draft unit tests for the parser changes so far
  ```

  <p className="digest-feature-try">Fork muncul di panel di bawah prompt Anda dan hasilnya tiba dalam percakapan Anda ketika selesai. Untuk mematikan mode fork, atur <code>CLAUDE\_CODE\_FORK\_SUBAGENT=0</code>.</p>

  <a className="digest-feature-link" href="/docs/id/sub-agents#turn-fork-mode-on-or-off">Aktifkan atau matikan mode fork</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Permintaan penggabungan GitLab dan marketplace</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">Marketplace plugin mengkloning URL <code>gitlab.com</code> bare, termasuk subgrup bersarang. Pada v2.1.233 atau lebih baru, teruskan URL permintaan penggabungan GitLab ke <code>--worktree</code> untuk membuat cabang darinya, dan tampilan <code>claude agents</code> memberi label sesi yang terhubung ke permintaan penggabungan sebagai <code>!N</code>. Claude Code juga menyunting keluarga token GitLab seperti <code>glpat-</code> dan <code>glrt-</code>, dan melindungi penyimpanan konfigurasi CLI <code>glab</code> dengan cara yang sama seperti melindungi <code>gh</code>.</p>

  <p className="digest-feature-try">Mulai sesi dalam worktree yang dibuat cabang dari permintaan penggabungan:</p>

  ```bash terminal theme={null}
  claude --worktree https://gitlab.com/group/project/-/merge_requests/42
  ```

  <p className="digest-feature-try">Ketika <code>origin</code> berada di gitlab.com, Claude Code mengambil <code>merge-requests/42/head</code> dan membuka sesi pada cabang tersebut di worktree-nya sendiri.</p>

  <a className="digest-feature-link" href="/docs/id/worktrees#branch-from-a-pull-request">Buat cabang worktree dari permintaan pull atau penggabungan</a>
</div>
