Jalankan <code>claude self-hosted-runner</code> di mesin atau kontainer Anda untuk mengubahnya menjadi runner. <div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Mode otomatis menjadi default</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">Mulai 14 Agustus, mode otomatis adalah mode izin default untuk sesi baru di paket Pro, Max, dan Team. Jika Anda menetapkan mode default sendiri, itu tetap berlaku kecuali Anda menerima prompt switch satu kali, dan default yang dikelola organisasi Anda tidak berubah. Anda masih dapat beralih mode kapan saja. Sudah berlaku di paket tersebut: panggilan pengklasifikasi yang dilakukan mode otomatis tidak lagi dihitung terhadap batas penggunaan Anda.</p>

  <p className="digest-feature-try">Untuk memulai setiap sesi dalam mode otomatis sebelum switch, atur sebagai default Anda di pengaturan pengguna Anda:</p>

  ```json ~/.claude/settings.json {3} theme={null}
  {
    "permissions": {
      "defaultMode": "auto"
    }
  }
  ```

  <p className="digest-feature-try">Sesi baru kemudian menampilkan <code>auto mode on</code> di bilah status.</p>

  <a className="digest-feature-link" href="/docs/id/permission-modes#eliminate-prompts-with-auto-mode">Persyaratan dan kontrol mode otomatis</a>
</div>
