  <p className="digest-feature-lede">CLI <code>claude</code> sekarang menjalankan binari asli per-platform alih-alih JavaScript yang dibundel, sehingga perintah <code>claude</code> yang diinstal tidak lagi memanggil Node. Paket npm menarik binari yang tepat melalui dependensi opsional seperti <code>@anthropic-ai/claude-code-darwin-arm64</code>, sehingga perintah instalasi Anda tidak berubah. Installer standalone sudah mengirimkan binari ini; npm sekarang cocok dengannya.</p>

  <p className="digest-feature-try">Upgrade dan periksa apa yang Anda jalankan:</p>

  ```bash theme={null}
  claude update
  claude --version
  ```
