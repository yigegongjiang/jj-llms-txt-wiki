  <p className="digest-feature-lede"><code>/skill-doctor</code> menunjukkan berapa biaya setiap skill Anda dalam konteks dan seberapa sering digunakan, sehingga Anda dapat memutuskan mana yang akan dimatikan. Setiap skill dalam <a href="/docs/id/skills#skill-descriptions-are-cut-short">daftar skill</a> menambah konteks Anda di setiap giliran, terlepas dari apakah Claude pernah menggunakannya atau tidak. Memerlukan v2.1.252 atau lebih baru dan tidak tersedia dalam sesi yang melewati <a href="/docs/id/env-vars#features-that-need-feature-flag-fetching">pengambilan feature-flag</a>.</p>

  <p className="digest-feature-try">Jalankan di sesi interaktif untuk membuka laporan di tab <strong>Stats</strong> manajer <code>/plugin</code>:</p>

  ```text Claude Code theme={null}
  > /skill-doctor
  ```

  <p className="digest-feature-try">Dalam mode non-interaktif dengan <code>-p</code>, Claude Code mencetak laporan sebagai teks sebagai gantinya.</p>
