  <p className="digest-feature-lede"><code>/doctor</code> sekarang mendiagnosis masalah dan dapat memperbaikinya, alih-alih mencetak laporan hanya-baca. Ini memeriksa kesehatan instalasi, menemukan skills, server MCP, dan plugin yang tidak digunakan versus biaya konteks mereka, menghilangkan duplikat file <code>CLAUDE.md</code> lokal terhadap file yang diperiksa, mengusulkan pemangkasan konten <code>CLAUDE.md</code> yang Claude dapat turunkan dari basis kode, dan menandai hook yang lambat. Ini melaporkan temuan terlebih dahulu dan meminta konfirmasi sebelum mengubah apa pun. <code>/checkup</code> adalah aliasnya.</p>
