  <p className="digest-feature-lede">Tekan <code>/</code> dalam mode transkrip untuk mencari percakapan Anda. <code>n</code> dan <code>N</code> melangkah melalui kecocokan. Akhirnya ada cara untuk menemukan perintah Bash itu yang Claude jalankan 400 pesan yang lalu.</p>

  <p className="digest-feature-try">Buka mode transkrip dan cari:</p>

  ```text Claude Code theme={null}
  Ctrl+O    # buka transkrip
  /migrate  # cari "migrate"
  n         # kecocokan berikutnya
  N         # kecocokan sebelumnya
  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Hooks bersyarat</span>
    <span className="digest-feature-pill">v2.1.85</span>
  </div>

  <p className="digest-feature-lede">Hooks sekarang dapat mendeklarasikan bidang <code>if</code> menggunakan sintaks aturan izin. Pemeriksaan pre-commit Anda hanya muncul untuk <code>Bash(git commit \*)</code> bukan setiap panggilan bash, mengurangi overhead proses pada sesi yang sibuk.</p>

  <p className="digest-feature-try">Batasi hook ke komit git saja:</p>

  ```json .claude/settings.json {5} theme={null}
  {
    "hooks": {
      "PreToolUse": [{
        "hooks": [{
          "if": "Bash(git commit *)",
          "type": "command",
          "command": ".claude/hooks/lint-staged.sh"
        }]
      }]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/id/docs/hooks">Referensi hooks</a>
</div>
