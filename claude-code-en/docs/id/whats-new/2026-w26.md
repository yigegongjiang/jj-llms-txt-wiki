  <p className="digest-feature-lede">Perintah baru `claude mcp login <name>` dan `claude mcp logout <name>` mengautentikasi server MCP yang dikonfigurasi dari shell Anda alih-alih menu <code>/mcp</code> interaktif. `claude mcp login` menjalankan alur OAuth server secara langsung, dan `claude mcp logout` menghapus kredensial yang disimpan.</p>

  <p className="digest-feature-try">Jalankan alur OAuth untuk server yang dikonfigurasi tanpa membuka sesi:</p>

  ```bash terminal theme={null}

  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Shell mode merespons output perintah</span>
    <span className="digest-feature-pill">v2.1.186</span>
  </div>

  <p className="digest-feature-lede">Perintah yang Anda jalankan dengan awalan <code>!</code> sekarang mendapatkan respons dari Claude setelah output masuk ke transkrip, sehingga Anda dapat menjalankan <code>! npm test</code> dan mendapatkan penjelasan tentang kegagalan tanpa prompt kedua. Respons biaya sama dengan mengirim prompt normal. Untuk mempertahankan perilaku sebelumnya, di mana output ditambahkan ke konteks tanpa respons, atur <code>respondToBashCommands</code> ke <code>false</code> dalam <code>settings.json</code>.</p>

  <p className="digest-feature-try">Jalankan perintah dan dapatkan respons terhadap outputnya:</p>

  ```text Claude Code theme={null}
  > ! npm test
  ```

  <a className="digest-feature-link" href="/docs/id/docs/interactive-mode#shell-mode-with-prefix">Shell mode dengan awalan !</a>
</div>
