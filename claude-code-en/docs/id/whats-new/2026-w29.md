  <p className="digest-feature-lede">Mode pembaca layar menggantikan antarmuka terminal visual dengan teks biasa dan linier: alih-alih kotak, spinner, dan penggambaran ulang di tempat, Claude Code mencetak baris berlabel yang dibaca pembaca layar seperti VoiceOver atau NVDA secara berurutan, sehingga Anda dapat menyetujui izin dan meninjau output dari awal hingga akhir. Aktifkan per sesi dengan bendera, per shell dengan variabel lingkungan <code>CLAUDE\_AX\_SCREEN\_READER</code>, atau di mana-mana dengan pengaturan <code>axScreenReader</code>.</p>

  <p className="digest-feature-try">Mulai sesi dalam mode pembaca layar:</p>

  ```bash terminal theme={null}
  claude --ax-screen-reader
  ```
