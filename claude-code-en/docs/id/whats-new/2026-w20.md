    <span className="digest-feature-pill">research preview</span>

  <p className="digest-feature-lede"><code>/fast</code> sekarang berjalan di Opus 4.7 secara default alih-alih Opus 4.6. Fast mode adalah konfigurasi Opus berkecepatan tinggi: kualitas model yang sama dengan kecepatan sekitar 2,5x lebih cepat untuk biaya per-token yang lebih tinggi, berguna untuk iterasi cepat dan debugging langsung. Harga tidak berubah pada $30/$150 per MTok, sama dengan mode cepat Opus 4.6. Untuk mengikat mode cepat ke Opus 4.6, atur <code>CLAUDE\_CODE\_OPUS\_4\_6\_FAST\_MODE\_OVERRIDE=1</code>.</p>

    <div><code>claude agents</code> mendapatkan flag dispatch (<code>--add-dir</code>, <code>--settings</code>, <code>--mcp-config</code>, <code>--plugin-dir</code>, <code>--permission-mode</code>, <code>--model</code>, <code>--effort</code>, <code>--dangerously-skip-permissions</code>) untuk mengonfigurasi sesi latar belakang, dan <code>claude agents --cwd \<path></code> membatasi daftar sesi ke direktori</div>
    <div>Hook baru <code>args: string\[]</code> bentuk exec menjalankan perintah secara langsung tanpa shell, jadi placeholder jalur tidak perlu dikutip</div>
    <div>Opsi konfigurasi <code>continueOnBlock</code> baru untuk hook <code>PostToolUse</code> mengirimkan alasan penolakan hook kembali ke Claude dan melanjutkan giliran alih-alih mengakhirinya</div>
    <div>Bidang <code>terminalSequence</code> baru dalam output JSON hook memungkinkan hook memancarkan notifikasi desktop, judul jendela, dan bel tanpa terminal yang mengontrol</div>
    <div>Menu Rewind menambahkan "Summarize up to here" untuk mengompresi konteks sebelumnya sambil menjaga giliran terbaru tetap utuh</div>
    <div>Remote Control, <code>/schedule</code>, konektor MCP Claude.ai, dan preferensi notifikasi sekarang dinonaktifkan ketika <code>ANTHROPIC\_API\_KEY</code>, <code>apiKeyHelper</code>, atau <code>ANTHROPIC\_AUTH\_TOKEN</code> diatur, bahkan bersama login Claude.ai; batalkan pengaturan kunci API untuk menggunakan fitur-fitur ini</div>
    <div>Server stdio MCP sekarang menerima <code>CLAUDE\_PROJECT\_DIR</code> di lingkungan mereka, mencocokkan hook, dan konfigurasi plugin dapat mereferensikan <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code> dalam perintah</div>
    <div><code>claude plugin details \<name></code> menampilkan inventaris komponen plugin dan biaya token per-sesi yang diproyeksikan, dan panel detail <code>/plugin</code> sekarang juga mencantumkan server LSP yang disediakan plugin</div>
    <div>Plugin dengan <code>SKILL.md</code> tingkat root dan tidak ada subdirektori <code>skills/</code> sekarang ditampilkan sebagai skill</div>
    <div><code>/feedback</code> sekarang dapat menyertakan sesi terbaru dari 24 jam atau 7 hari terakhir untuk masalah yang mencakup lebih dari sesi saat ini</div>
    <div>Tool agen <code>subagent\_type</code> sekarang cocok dengan huruf besar-kecil dan pemisah secara tidak sensitif, jadi <code>"Code Reviewer"</code> diselesaikan ke <code>code-reviewer</code></div>
