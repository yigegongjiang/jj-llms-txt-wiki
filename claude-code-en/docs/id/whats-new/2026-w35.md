<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Mode terbatas</span>
    <span className="digest-feature-pill">v2.1.248</span>
  </div>

  <p className="digest-feature-lede">Mode terbatas memulai Claude Code tanpa alat bawaan yang menjalankan perintah atau kode. Gunakan ketika harness evaluasi mendorong <code>claude</code> pada mesin bersama. Mulai dengan `--restricted` atau atur <code>CLAUDE\_CODE\_RESTRICTED=1</code>. Claude Code juga menghapus <code>WebFetch</code>, membatasi alat file ke direktori kerja, memuat hanya pengaturan terkelola dan `--settings`, dan menolak mode izin <code>bypassPermissions</code>.</p>

  <p className="digest-feature-try">Jalankan kueri non-interaktif tanpa alat yang menjalankan perintah:</p>

  ```bash terminal theme={null}
  claude --restricted -p "review src/ for SQL injection risks"
  ```

  <p className="digest-feature-try">Untuk memberikan Claude salah satu alat yang dihapus kembali, daftarkan di `--tools` bersama dengan alat bawaan lain yang Anda inginkan, misalnya `--tools "Bash,Read,Edit"`. `--tools` adalah daftar izin, dan preset <code>default</code> tidak mengembalikan alat yang dihapus.</p>

  <a className="digest-feature-link" href="/docs/id/cli-reference#cli-flags">Bendera CLI</a>
</div>

    <div>Organisasi dengan tarif kontrak dapat mengatur pengaturan terkelola <a href="/docs/id/costs#report-spend-at-your-contracted-rates"><code>modelPricing</code></a> sehingga <code>/usage</code>, baris status, dan OpenTelemetry melaporkan biaya pada tarif tersebut alih-alih harga daftar</div>
    <div><code>/login</code> menawarkan <strong>Masuk dengan akun Console Anda</strong> di bawah opsi <strong>Akun Konsol Anthropic</strong>, sehingga anggota organisasi Console yang tidak mengizinkan kunci API dapat masuk tanpa membuat satu</div>
    <div>Jalankan <code>/permissions</code> dan buka <a href="/docs/id/auto-mode-config#edit-rules-from-permissions">tab <strong>Auto mode</strong></a> baru untuk melihat dan mengedit aturan pengklasifikasi mode otomatis tanpa membuka file pengaturan</div>
    <div>Ketika mode otomatis tersedia, prompt izin Bash dalam mode Manual dan <code>acceptEdits</code> menawarkan opsi <a href="/docs/id/permission-modes#switch-permission-modes"><strong>Ya, dan beralih ke mode otomatis</strong></a>; pilih untuk menyetujui perintah dan beralih sesi ke mode otomatis</div>
    <div>Setelah Anda <a href="/docs/id/permissions#move-the-session-to-another-directory">memindahkan sesi dengan <code>/cd</code></a>, pengaturan proyek direktori baru, hook, server <code>.mcp.json</code>, skill, dan subagen mulai berlaku segera alih-alih pada `--resume` berikutnya</div>
    <div>Dalam sesi non-interaktif, termasuk run <code>-p</code>, run Agent SDK, dan sesi cloud, Claude Code <a href="/docs/id/errors#the-response-above-may-be-incomplete">melanjutkan respons</a> yang kesalahan server, koneksi terputus, atau stall potong di tengah aliran, ketika respons parsial berisi teks dan tidak ada panggilan alat</div>
    <div>Subagen yang berhenti pada batas <code>maxTurns</code> mengembalikan output yang ditandai sebagai parsial, dengan petunjuk bahwa Claude dapat <a href="/docs/id/sub-agents#resume-subagents">melanjutkannya dengan <code>SendMessage</code></a>, alih-alih tampak selesai</div>
    <div>Di Amazon Bedrock, Platform Agen Google Cloud, dan Microsoft Foundry, sesi pada mesin yang sama sekarang dapat <a href="/docs/id/cross-session-messaging#availability">saling berpesan</a>, <code>/loop</code> dapat <a href="/docs/id/scheduled-tasks#let-claude-choose-the-interval">memilih intervalnya sendiri</a>, dan <code>/model</code> serta <code>/effort</code> berlaku segera alih-alih setelah giliran berakhir</div>
