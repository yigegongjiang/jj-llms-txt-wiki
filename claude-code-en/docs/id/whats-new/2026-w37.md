    <span className="digest-feature-title">Uji plugin dengan claude plugin eval</span>
    <span className="digest-feature-pill">v2.1.269</span>
  </div>

  <p className="digest-feature-lede"><code>claude plugin eval</code> menjalankan plugin Anda terhadap serangkaian kasus uji, menilai hasilnya, dan secara default menjalankan setiap kasus lagi tanpa plugin sehingga Anda dapat melihat kontribusinya. <code>claude plugin eval init</code> menanyakan kepada Anda seperti apa hasil yang baik, kemudian mengusulkan kasus uji dan pemeriksaan yang menilainya, mencoba suite sekali, dan menulis file. Setiap run, dan setiap pemeriksaan yang memiliki model judge kedua untuk membalas, adalah panggilan model nyata di akun Anda.</p>

  <Frame>
    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/plugin-eval.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=913066f6d4a2a15426e98a627802f47f" alt="Output terminal dari claude plugin eval: tabel tujuh kasus dengan skor setiap kasus dengan dan tanpa plugin, delta di antara mereka, jumlah run, dan biaya, diikuti oleh baris ringkasan dengan delta rata-rata, durasi total, dan biaya total" width="1600" height="900" data-path="images/whats-new/plugin-eval.jpg" />
  </Frame>

  <p className="digest-feature-try">Dari direktori root plugin Anda, biarkan Claude membuat draft suite:</p>

  ```bash terminal theme={null}
  claude plugin eval init
  ```

  <p className="digest-feature-try">Ketika Claude memberi tahu Anda bahwa suite siap, keluar dari sesi yang dibuka <code>claude plugin eval init</code> dan jalankan <code>claude plugin eval .</code> untuk menilai setiap kasus. Tabel ringkasan dicetak di terminal Anda, dan <code>report.html</code> di bawah <code>evals/results/</code> memiliki detail per-run.</p>
