<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Correspondance par paramètre d'entrée</span>
    <span className="digest-feature-pill">v2.1.178</span>
  </div>

  <p className="digest-feature-lede">Les règles de refus et de demande de permission peuvent désormais faire correspondre les paramètres d'entrée d'un outil avec la syntaxe <code>Tool(param:value)</code>. Par exemple, <code>Agent(model:opus)</code> correspond aux générations de sous-agents qui demandent le niveau de modèle Opus. La valeur accepte `*` comme caractère générique, donc `Agent(isolation:*)` correspond à toute valeur d'isolation explicite.</p>

  <p className="digest-feature-try">Ajoutez une règle de paramètre à la liste de refus dans <code>settings.json</code> :</p>

  ```json .claude/settings.json {3} theme={null}
  {
    "permissions": {
      "deny": ["Agent(model:opus)"]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/fr/permissions#match-by-input-parameter">Correspondance par paramètre d'entrée</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Définir n'importe quel paramètre à partir de l'invite</span>
    <span className="digest-feature-pill">v2.1.181</span>
  </div>

  <p className="digest-feature-lede">Passez <code>key=value</code> à <code>/config</code> pour modifier un paramètre directement sans ouvrir l'interface Paramètres. La syntaxe fonctionne également en mode non interactif avec l'indicateur <code>-p</code> et à partir de Remote Control.</p>

  <p className="digest-feature-try">Définissez le paramètre <code>thinking</code> à partir de l'invite :</p>

  ```text Claude Code theme={null}
  > /config thinking=false
  ```

  <a className="digest-feature-link" href="/docs/fr/commands#all-commands">Référence des commandes</a>

<div className="digest-wins">
  <p className="digest-wins-title">Autres améliorations</p>

  <div className="digest-wins-grid">
    <div>Le mode Auto bloque désormais les commandes git destructrices (`git reset --hard`, `git clean -fd`, `git stash drop`) lorsque vous n'avez pas demandé à abandonner le travail local, et bloque <code>terraform destroy</code> sauf si vous avez demandé la pile spécifique</div>
    <div>Définissez le nouveau paramètre <code>attribution.sessionUrl</code> sur <code>false</code> pour omettre le lien de session claude.ai des commits et des PR dans les sessions web et Remote Control</div>
    <div>Dans l'interface <code>/config</code>, Entrée et Espace changent tous deux le paramètre sélectionné, et Échap enregistre et ferme maintenant au lieu de revenir en arrière</div>
    <div>Le nouveau paramètre d'opt-in <code>sandbox.allowAppleEvents</code> permet aux commandes en sandbox d'envoyer des Apple Events sur macOS</div>
    <div>Pointez <code>CLAUDE\_CLIENT\_PRESENCE\_FILE</code> vers un fichier marqueur pour supprimer les notifications push mobiles pendant que vous êtes à la machine</div>
    <div>Les longs paragraphes se diffusent maintenant ligne par ligne au lieu d'attendre le premier saut de ligne</div>
    <div>Les déconnexions de connexion API au milieu de la réflexion se réessaient automatiquement au lieu d'afficher « Connexion fermée pendant la réflexion »</div>
    <div>Avec <code>CLAUDE\_CODE\_EXPERIMENTAL\_AGENT\_TEAMS=1</code> défini, chaque session a une équipe implicite, vous pouvez donc générer des coéquipiers directement avec le paramètre <code>name</code> de l'outil Agent</div>
    <div>Les Skills dans les répertoires <code>.claude/skills</code> imbriqués se chargent lors du travail sur les fichiers là-bas ; en cas de conflit de nom, la skill imbriquée apparaît comme `<dir>:<name>` pour que les deux restent disponibles</div>
    <div>Correction du cache de prompt ne lisant pas sur une <code>ANTHROPIC\_BASE\_URL</code> personnalisée et sur Foundry</div>
    <div>Correction de Write et Edit produisant des fichiers de zéro octet ou tronqués sur les lecteurs réseau et les dossiers synchronisés dans le cloud</div>
  </div>
</div>
