<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Testez les plugins avec claude plugin eval</span>
    <span className="digest-feature-pill">v2.1.269</span>
  </div>

  <p className="digest-feature-lede"><code>claude plugin eval</code> exécute votre plugin par rapport à une suite de cas de test, évalue les résultats, et par défaut exécute chaque cas à nouveau sans le plugin afin que vous puissiez voir sa contribution. <code>claude plugin eval init</code> vous demande à quoi ressemble un bon résultat, puis propose des cas de test et les vérifications qui les évaluent, essaie la suite une fois, et écrit les fichiers. Chaque exécution, et chaque vérification qui a un deuxième modèle pour juger la réponse, est un vrai appel de modèle sur votre compte.</p>

  <Frame>
    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/plugin-eval.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=913066f6d4a2a15426e98a627802f47f" alt="Sortie du terminal de claude plugin eval : un tableau de sept cas avec le score de chaque cas avec et sans le plugin, la différence entre eux, le nombre d'exécutions, et le coût, suivi d'une ligne de résumé avec la différence moyenne, la durée totale, et le coût total" width="1600" height="900" data-path="images/whats-new/plugin-eval.jpg" />
  </Frame>

  <p className="digest-feature-try">À partir du répertoire racine de votre plugin, demandez à Claude de rédiger la suite :</p>

  ```bash terminal theme={null}
  claude plugin eval init
  ```

  <p className="digest-feature-try">Quand Claude vous dit que la suite est prête, quittez la session que <code>claude plugin eval init</code> a ouverte et exécutez <code>claude plugin eval .</code> pour évaluer chaque cas. Le tableau de résumé s'affiche dans votre terminal, et <code>report.html</code> sous <code>evals/results/</code> contient le détail par exécution.</p>
