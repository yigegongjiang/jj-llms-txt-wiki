<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude Fable 5.1</span>
    <span className="digest-feature-pill">nouveau modèle</span>
  </div>

  <p className="digest-feature-lede">Claude Fable 5.1 est disponible dans Claude Code avec une fenêtre de contexte de 1 M de jetons, et l'alias <code>fable</code> le sélectionne maintenant. Dans les sessions de passerelle des applications Claude, <code>fable</code> sélectionne toujours Fable 5. Si votre passerelle sert Fable 5.1, exécutez <code>/model claude-fable-5-1</code>. Nécessite v2.1.257 ou ultérieure.</p>

  <p className="digest-feature-try">Basculez la session actuelle vers Fable 5.1 et enregistrez-la comme valeur par défaut :</p>

  ```text Claude Code theme={null}
  > /model fable
  ```

  <p className="digest-feature-try">Sur l'API Anthropic, le sélecteur répertorie Fable uniquement une fois que le serveur signale qu'il est disponible pour votre organisation, mais en tapant <code>/model fable</code>, vous vérifiez directement auprès du serveur.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Panneau diff en direct dans le rendu en plein écran</span>
    <span className="digest-feature-pill">v2.1.260</span>
  </div>

  <p className="digest-feature-lede">Dans le rendu en plein écran, <code>/diff</code> ouvre maintenant un panneau à côté de la conversation au lieu d'une visionneuse que vous devez fermer. Le panneau répertorie les fichiers modifiés avec leurs nombres de lignes ajoutées et supprimées et s'actualise chaque fois que Claude modifie un fichier ou exécute une commande shell. Sélectionnez les lignes du panneau avec la souris pour les joindre à votre prochain message.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/diff-panel.mp4?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=9d7553c19e7f227891cd95f1f59d796d" data-path="images/whats-new/diff-panel.mp4" />
  </Frame>

  <p className="digest-feature-try">Avec le rendu en plein écran activé, à l'intérieur d'un référentiel git, et dans un terminal d'au moins 110 colonnes de large, basculez le panneau :</p>

  ```text Claude Code theme={null}
  > /diff
  ```

  <p className="digest-feature-try">Exécutez <code>/diff</code> à nouveau ou cliquez sur le <code>✕</code> dans son en-tête pour le fermer.</p>

  <a className="digest-feature-link" href="/docs/fr/interactive-mode#diff-panel">Panneau diff</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Trouvez les compétences inutilisées avec /skill-doctor</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede"><code>/skill-doctor</code> montre ce que chacune de vos compétences coûte en contexte et à quelle fréquence elle est utilisée, afin que vous puissiez décider lesquelles désactiver. Chaque compétence dans la <a href="/docs/fr/skills#skill-descriptions-are-cut-short">liste des compétences</a> s'ajoute à votre contexte à chaque tour, que Claude l'utilise ou non. Nécessite v2.1.252 ou ultérieure et n'est pas disponible dans les sessions qui ignorent la <a href="/docs/fr/env-vars#features-that-need-feature-flag-fetching">récupération des drapeaux de fonctionnalité</a>.</p>

  <p className="digest-feature-try">Exécutez-le dans une session interactive pour ouvrir le rapport dans l'onglet <strong>Stats</strong> du gestionnaire <code>/plugin</code> :</p>

  ```text Claude Code theme={null}
  > /skill-doctor
  ```

  <p className="digest-feature-try">En mode non interactif avec <code>-p</code>, Claude Code imprime le rapport sous forme de texte à la place.</p>

  <a className="digest-feature-link" href="/docs/fr/skills#find-unused-skills">Trouvez les compétences inutilisées</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Autres améliorations</p>

  <div className="digest-wins-grid">
    <div>Un crochet <a href="/docs/fr/hooks#premodelswitch"><code>PreModelSwitch</code></a> peut bloquer un changement de modèle que vous demandez, et un crochet <a href="/docs/fr/hooks#postmodelswitch"><code>PostModelSwitch</code></a> peut ajouter du contexte pour Claude après le changement de modèle de la session</div>
    <div><a href="/docs/fr/costs#prompt-cache-statistics"><code>/cost</code></a> ajoute une ligne <code>Prompt cache (main)</code> : la part des jetons d'entrée servis à partir du cache, les défauts de cache, si le cache est chaud, et une cause probable du dernier défaut quand Claude Code peut en nommer une. Les scripts de ligne d'état reçoivent un objet <code>prompt\_cache</code> correspondant</div>
    <div>Les organisations peuvent répertorier les serveurs MCP HTTP et SSE sous le paramètre géré <a href="/docs/fr/managed-mcp#provide-servers-through-managed-settings"><code>managedMcpServers</code></a> pour les donner à chaque utilisateur, en plus des serveurs que les utilisateurs ajoutent eux-mêmes</div>
    <div><code>/effort</code> et le sélecteur <code>/model</code> enregistrent maintenant <a href="/docs/fr/model-config#adjust-effort-level">un niveau d'effort séparé pour chaque modèle</a> ; appuyez sur <code>s</code> au lieu de <code>Entrée</code> pour appliquer un niveau à la session actuelle uniquement</div>
    <div>Par défaut, le classificateur du mode automatique <a href="/docs/fr/permission-modes#what-the-classifier-blocks-by-default">bloque maintenant aussi</a> les actions telles que la demande d'identifiants auprès du point de terminaison des métadonnées d'instance cloud ou la connexion à des conteneurs frères que Claude n'a pas démarrés</div>
    <div>En mode automatique, Claude Code vous demande avant que Claude <a href="/docs/fr/permission-modes#first-read-outside-the-working-directories">lise d'abord un fichier en dehors de vos répertoires de travail</a>, avec une option pour bloquer ces lectures à partir de ce moment</div>
    <div>Augmentez <a href="/docs/fr/settings-reference#bashoutputmaxchars"><code>bashOutputMaxChars</code></a> et <a href="/docs/fr/settings-reference#taskoutputmaxchars"><code>taskOutputMaxChars</code></a>, jusqu'à 128 000 caractères, afin que Claude reçoive plus de la sortie d'une commande réussie ou d'une tâche en arrière-plan en ligne</div>
    <div>Les raccourcis d'édition de mots du message <a href="/docs/fr/interactive-mode#make-ctrl-w-delete-back-to-whitespace">suivent readline</a> pour tout le monde, et le paramètre <code>keybindingFlavor</code> n'a plus aucun effet. <code>Ctrl+W</code> supprime jusqu'à l'espace blanc précédent, et <code>Alt+B</code>, <code>Alt+F</code>, et <code>Alt+D</code> traitent la ponctuation telle que <code>/</code> et <code>.</code> comme des séparateurs de mots</div>
    <div>Si vous définissez <code>defaultMode</code> sur <code>"bypassPermissions"</code> dans le <code>.claude/settings.json</code> ou <code>.claude/settings.local.json</code> d'un projet, cela <a href="/docs/fr/permission-modes#which-mode-a-session-starts-in">n'a plus d'effet</a> et la session démarre en mode Manuel ; définissez <code>"bypassPermissions"</code> dans les paramètres utilisateur ou gérés à la place, ou passez `--permission-mode`</div>
    <div>Les plans Enterprise basés sur les sièges <a href="/docs/fr/model-config#default-model-setting">utilisent maintenant Opus 5 par défaut</a></div>
    <div>Dans l'extension VS Code, cliquez sur le nom du modèle en bas de la boîte de message pour <a href="/docs/fr/vs-code#use-the-prompt-box">ouvrir le sélecteur de modèle</a></div>
    <div>Dans l'extension VS Code, sélectionnez <strong>Styles de sortie</strong> dans la section Personnaliser du menu de commande pour <a href="/docs/fr/vs-code#use-the-prompt-box">choisir un style de sortie</a>, y compris les vôtres personnalisés</div>
  </div>
</div>
