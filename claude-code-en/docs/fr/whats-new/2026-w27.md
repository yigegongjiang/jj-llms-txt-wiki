# Semaine 27 · 29 juin – 3 juillet 2026

> Claude Sonnet 5 devient le modèle par défaut, Claude dans Chrome atteint la disponibilité générale, les sous-agents s'exécutent en arrière-plan par défaut, Claude Desktop arrive sur Linux en bêta, et /radio se connecte à Claude FM.

  <p className="digest-feature-lede">Sonnet 5 est le nouveau modèle par défaut pour les sièges des abonnements Pro, Team Standard et Enterprise : codage de haut niveau et utilisation d'outils au prix de Sonnet, avec une fenêtre de contexte native de 1 M de jetons et la réflexion adaptative activée par défaut. La tarification de l'API est promotionnelle à 2 $/10 $ par MTok jusqu'au 31 août. Nécessite v2.1.197 ou ultérieure.</p>

  ```text Claude Code theme={null}
  > /model claude-sonnet-5
  ```

    <span className="digest-feature-pill">v2.1.198</span>
  </div>

  <p className="digest-feature-lede">L'intégration Chrome est sortie de la préversion pour tous les utilisateurs disposant d'un plan Anthropic direct. Claude Code pilote votre navigateur via l'extension Claude dans Chrome : il ouvre des onglets, navigue dans les pages, remplit les formulaires, lit les journaux de la console et partage votre état de connexion, afin qu'il puisse tester l'application qu'il crée sans que vous changiez de contexte.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Les sous-agents s'exécutent en arrière-plan par défaut</span>
    <span className="digest-feature-pill">v2.1.198</span>
  </div>

  <p className="digest-feature-lede">Claude continue maintenant de travailler pendant que les sous-agents s'exécutent et récupère leurs résultats lorsqu'ils se terminent, au lieu de mettre en pause la conversation pour attendre. Claude exécute toujours un sous-agent au premier plan lorsqu'il a besoin du résultat avant de continuer, et les sous-agents en arrière-plan affichent chaque invite de permission dans votre session principale. Épinglez le comportement d'un sous-agent avec le champ frontmatter <code>background</code>.</p>

  <a className="digest-feature-link" href="/docs/fr/docs/sub-agents#run-subagents-in-foreground-or-background">Exécuter les sous-agents au premier plan ou en arrière-plan</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude Desktop sur Linux</span>
    <span className="digest-feature-pill">Desktop</span>
  </div>

  <p className="digest-feature-lede">L'application de bureau Claude est maintenant disponible sur Ubuntu 22.04+ et Debian 12+ en bêta, sur x86\_64 et arm64. Vous obtenez la même expérience Chat, Cowork et Claude Code que sur macOS et Windows : sessions parallèles, examen des différences visuelles, un terminal et un éditeur intégrés, et aperçu en direct de l'application. S'installe à partir du référentiel apt d'Anthropic, afin que les mises à jour arrivent via les mises à jour régulières des paquets.</p>

  <a className="digest-feature-link" href="/docs/fr/docs/desktop-linux">Claude Desktop sur Linux</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Autres avancées</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/fr/docs/artifacts">Les Artifacts</a> sont maintenant généralement disponibles et inclus dans les plans Pro et Max, rejoignant Team et Enterprise</div>
    <div>Les administrateurs peuvent définir un <a href="/docs/fr/docs/model-config#organization-default-model">modèle par défaut de l'organisation</a> dans la console org ; il s'affiche comme « Org default » dans <code>/model</code> lorsque vous n'avez pas choisi de modèle vous-même</div>
    <div>Les invocations de compétences empilées comme <code>/skill-a /skill-b do XYZ</code> chargent maintenant toutes les compétences de tête (jusqu'à 5), pas seulement la première</div>
    <div>Les dialogues <code>AskUserQuestion</code> ne continuent plus automatiquement par défaut ; optez pour un délai d'inactivité via <code>/config</code></div>
    <div>Le mode de permission « default » est maintenant nommé « Manual » dans l'ensemble de la CLI, `--help`, VS Code et JetBrains ; `--permission-mode manual` est accepté aux côtés de `default`</div>
    <div>La nouvelle compétence <code>/dataviz</code> fournit des conseils de conception de graphiques et de tableaux de bord, avec un validateur de palette de couleurs exécutable</div>
    <div>L'agent Explore intégré hérite maintenant du modèle de la session principale (limité à Opus) au lieu de s'exécuter sur Haiku</div>
    <div>Les agents en arrière-plan lancés à partir de <code>claude agents</code> valident maintenant, poussent et ouvrent une PR brouillon lorsqu'ils terminent le travail de code dans un worktree, au lieu de s'arrêter pour demander</div>
    <div>Les correspondances de hook avec des identifiants avec tirets comme <code>code-reviewer</code> correspondent maintenant exactement au lieu de correspondre à une sous-chaîne ; utilisez <code>mcp\_\_brave-search\_\_.\*</code> pour correspondre à tous les outils d'un serveur MCP avec tirets</div>
    <div>Les erreurs de limite de débit du serveur transitoires non liées à votre limite d'utilisation sont maintenant automatiquement réessayées avec backoff pour les abonnés au lieu d'échouer le tour</div>
    <div>Le chien de garde d'inactivité de streaming est maintenant activé par défaut pour tous les fournisseurs : il abandonne et réessaye lorsqu'un flux de réponse ne produit aucun événement pendant 5 minutes (<code>CLAUDE\_ENABLE\_STREAM\_WATCHDOG=0</code> pour désactiver)</div>
  </div>
</div>
