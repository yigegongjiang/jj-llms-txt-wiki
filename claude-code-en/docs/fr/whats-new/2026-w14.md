<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Remplacement de taille de résultat MCP</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Les auteurs de serveurs MCP peuvent maintenant augmenter le plafond de troncature sur un outil spécifique en définissant <code>anthropic/maxResultSizeChars</code> dans l'entrée <code>tools/list</code> de l'outil, jusqu'à un plafond maximal de 500 000 caractères. Le plafond était autrefois global, donc les outils qui retournaient occasionnellement des charges utiles intrinsèquement grandes comme des schémas de base de données ou des arbres de fichiers complets atteignaient la limite par défaut et étaient persistés sur le disque avec une référence de fichier. Les remplacements par outil gardent ces résultats en ligne quand l'outil en a vraiment besoin.</p>

  <p className="digest-feature-try">Annotez l'outil dans la réponse <code>tools/list</code> de votre serveur :</p>

  ```json highlight={5} theme={null}
  {
    "name": "get_schema",
    "description": "Returns the full database schema",
    "_meta": {
      "anthropic/maxResultSizeChars": 500000
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/fr/mcp#raise-the-limit-for-a-specific-tool">Référence MCP</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Exécutables de plugin sur PATH</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Placez un exécutable dans un répertoire <code>bin/</code> à la racine de votre plugin et Claude Code ajoute ce répertoire au <code>PATH</code> de l'outil Bash pendant que le plugin est activé. Claude peut alors invoquer le binaire en tant que commande simple à partir de n'importe quel appel d'outil Bash, sans chemin absolu ni script wrapper nécessaire. Pratique pour empaqueter des assistants CLI à côté des commandes, agents et hooks qui les appellent.</p>

  <p className="digest-feature-try">Ajoutez un répertoire <code>bin/</code> à la racine du plugin :</p>

  ```text highlight={4, 5} theme={null}
  my-plugin/
  ├── .claude-plugin/
  │   └── plugin.json
  └── bin/
      └── my-tool
  ```

  <a className="digest-feature-link" href="/docs/docs/fr/plugins-reference#file-locations-reference">Référence des plugins</a>
</div>

  <div className="digest-wins-grid">
    <div>Suites en mode Auto : nouveau hook <code>PermissionDenied</code> qui se déclenche sur les refus du classificateur (retournez <code>retry: true</code> pour laisser Claude essayer une approche différente), et <code>/permissions</code> → Récemment refusé vous permet de réessayer manuellement avec <code>r</code></div>
    <div>Nouvelle valeur <code>defer</code> pour <code>permissionDecision</code> dans les hooks <code>PreToolUse</code> : les sessions <code>-p</code> s'arrêtent à un appel d'outil et se terminent avec une charge utile <code>deferred\_tool\_use</code> pour qu'une application SDK ou une interface utilisateur personnalisée puisse la présenter, puis reprendre avec <code>--resume</code></div>
    <div><code>/buddy</code> : éclosez une petite créature qui vous regarde coder. Une blague du 1er avril, plus disponible</div>
    <div>Le paramètre <code>disableSkillShellExecution</code> bloque l'exécution de shell en ligne à partir des skills, des slash commands et des commandes de plugin</div>
    <div>L'outil Edit fonctionne maintenant sur les fichiers visualisés via <code>cat</code> ou <code>sed -n</code> sans une lecture séparée</div>
    <div>La sortie du hook supérieure à 50 K est sauvegardée sur le disque avec un chemin + aperçu au lieu d'être injectée dans le contexte</div>
    <div>Les résumés de réflexion sont désactivés par défaut dans les sessions interactives (<code>showThinkingSummaries: true</code> pour restaurer)</div>
    <div>Mode voix : combinaisons de modificateurs push-to-talk, WebSocket Windows, permission du microphone Apple Silicon macOS</div>
    <div>Les liens profonds <code>claude-cli://</code> acceptent les prompts multi-lignes (encodés <code>%0A</code>)</div>
