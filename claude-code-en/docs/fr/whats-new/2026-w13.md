<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Mode auto</span>
    <span className="digest-feature-pill">aperçu de recherche</span>
  </div>

  <p className="digest-feature-lede">Le mode auto confie vos invites de permission à un classificateur. Les modifications et commandes sûres s'exécutent sans vous interrompre ; tout ce qui est destructeur ou suspect est bloqué et signalé. C'est le juste milieu entre approuver chaque écriture de fichier et exécuter avec <code>--dangerously-skip-permissions</code>.</p>

  <Frame>
    <img src="https://mintcdn.com/claude-code/CfffsX01JHFnIKvD/images/whats-new/auto-mode.png?fit=max&auto=format&n=CfffsX01JHFnIKvD&q=85&s=367c9e9d4ba5bc57ec4b935154bf1fbb" alt="Pied de page de l'invite Claude Code affichant l'indicateur ' mode auto activé (Maj+Tab pour basculer) ' en jaune" width="2400" height="691" data-path="images/whats-new/auto-mode.png" />
  </Frame>

  <p className="digest-feature-try">Basculez vers auto avec Maj+Tab, ou définissez-le comme valeur par défaut :</p>

  ```json ~/.claude/settings.json {3} theme={null}
  {
    "permissions": {
      "defaultMode": "auto"
    }
  }
  ```

  ```text Claude Code theme={null}

  n         # next match
  N         # previous match
  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Hooks conditionnels</span>
    <span className="digest-feature-pill">v2.1.85</span>
  </div>

  <p className="digest-feature-lede">Les hooks peuvent maintenant déclarer un champ <code>if</code> en utilisant la syntaxe des règles de permission. Votre vérification de pré-commit ne s'exécute que pour <code>Bash(git commit \*)</code> au lieu de chaque appel bash, réduisant la surcharge de processus sur les sessions chargées.</p>

  <p className="digest-feature-try">Limitez un hook aux commits git uniquement :</p>

  ```json .claude/settings.json {5} theme={null}
  {
    "hooks": {
      "PreToolUse": [{
        "hooks": [{
          "if": "Bash(git commit *)",
          "type": "command",
          "command": ".claude/hooks/lint-staged.sh"
        }]
      }]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/fr/docs/hooks">Référence des hooks</a>
</div>
