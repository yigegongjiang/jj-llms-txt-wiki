    <span className="digest-feature-pill">CLI</span>

  <p className="digest-feature-lede">Lorsqu'un outil continue d'échouer, que Claude ne peut pas vous aider avec une demande, ou que vous signalez une erreur, Claude rédige maintenant un rapport de commentaires pour vous avec l'outil <code>SendFeedback</code>. Une carte au-dessus de votre saisie affiche le brouillon, et vous pouvez l'examiner, l'envoyer ou le rejeter à partir de là. Rien ne parvient à Anthropic tant que vous ne l'envoyez pas. Nécessite v2.1.238 ou ultérieur.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Mode restreint</span>
    <span className="digest-feature-pill">v2.1.248</span>
  </div>

  <p className="digest-feature-lede">Le mode restreint démarre Claude Code sans les outils intégrés qui exécutent des commandes ou du code. Utilisez-le lorsqu'un harnais d'évaluation pilote <code>claude</code> sur une machine partagée. Démarrez-le avec `--restricted` ou définissez <code>CLAUDE\_CODE\_RESTRICTED=1</code>. Claude Code supprime également <code>WebFetch</code>, confine les outils de fichiers aux répertoires de travail, charge uniquement les paramètres gérés et `--settings`, et refuse le mode de permission <code>bypassPermissions</code>.</p>

  <p className="digest-feature-try">Exécutez une requête non-interactive sans les outils d'exécution de commandes :</p>

  ```bash terminal theme={null}
  claude --restricted -p "review src/ for SQL injection risks"
  ```

  <p className="digest-feature-try">Pour donner à Claude l'un des outils supprimés, listez-le dans `--tools` avec les autres outils intégrés que vous souhaitez, par exemple `--tools "Bash,Read,Edit"`. `--tools` est une liste d'autorisation, et son préréglage <code>default</code> ne restaure pas les outils supprimés.</p>

  <div className="digest-wins-grid">
    <div>Définissez le nouveau paramètre <a href="/docs/fr/settings-reference#modelpicker"><code>modelPicker</code></a> pour étendre ou remplacer la liste intégrée du sélecteur <code>/model</code> par vos propres entrées ordonnées et étiquetées, y compris les identifiants de modèle Amazon Bedrock ou Google Cloud's Agent Platform</div>
    <div>Définissez <a href="/docs/fr/prompt-caching#choose-the-ttl-yourself"><code>promptCacheTtl</code></a> sur <code>1h</code> pour conserver un cache de saisie d'une heure sur la conversation principale lorsque vous utilisez une clé API ou un fournisseur cloud ; <code>subagentPromptCacheTtl</code> définit la TTL pour les sous-agents et toutes les autres demandes en dehors de la conversation principale</div>
    <div>Sur les plans Pro, Max, Team et Enterprise, <a href="/docs/fr/costs#plan-usage-breakdown"><code>/usage</code></a> ajoute une ventilation des boucles : nombre d'exécutions, tokens totaux, tokens par exécution et dernière exécution pour les <code>/loop</code> et les tâches planifiées qui ont utilisé le plus de tokens</div>
    <div>Les organisations avec des tarifs contractuels peuvent définir le paramètre géré <a href="/docs/fr/costs#report-spend-at-your-contracted-rates"><code>modelPricing</code></a> afin que <code>/usage</code>, la ligne d'état et OpenTelemetry rapportent le coût à ces tarifs au lieu du prix catalogue</div>
    <div><code>/login</code> propose <strong>Se connecter avec votre compte Console</strong> sous l'option <strong>Compte Anthropic Console</strong>, afin que les membres des organisations Console qui n'autorisent pas les clés API puissent se connecter sans en créer une</div>
    <div>Exécutez <code>/permissions</code> et ouvrez le nouvel onglet <a href="/docs/fr/auto-mode-config#edit-rules-from-permissions"><strong>Mode automatique</strong></a> pour afficher et modifier les règles du classificateur de mode automatique sans ouvrir un fichier de paramètres</div>
    <div>Lorsque le mode automatique est disponible, les invites de permission Bash dans les modes Manual et <code>acceptEdits</code> offrent une option <a href="/docs/fr/permission-modes#switch-permission-modes"><strong>Oui, et passer au mode automatique</strong></a> ; sélectionnez-la pour approuver la commande et basculer la session en mode automatique</div>
    <div>Après avoir <a href="/docs/fr/permissions#move-the-session-to-another-directory">déplacé une session avec <code>/cd</code></a>, les paramètres du projet du nouveau répertoire, les hooks, les serveurs <code>.mcp.json</code>, les compétences et les sous-agents prennent effet immédiatement au lieu de lors du prochain `--resume`</div>
    <div>Dans les sessions non-interactives, y compris les exécutions `-p`, les exécutions Agent SDK et les sessions cloud, Claude Code <a href="/docs/fr/errors#the-response-above-may-be-incomplete">continue une réponse</a> qu'une erreur serveur, une connexion interrompue ou un blocage a coupée en cours de flux, lorsque la réponse partielle contient du texte et aucun appel d'outil</div>
    <div>Un sous-agent qui s'arrête à sa limite <code>maxTurns</code> retourne sa sortie marquée comme partielle, avec un indice que Claude peut <a href="/docs/fr/sub-agents#resume-subagents">la continuer avec <code>SendMessage</code></a>, au lieu d'apparaître terminée</div>
    <div>Sur Amazon Bedrock, Google Cloud's Agent Platform et Microsoft Foundry, les sessions sur la même machine peuvent maintenant <a href="/docs/fr/cross-session-messaging#availability">se communiquer entre elles</a>, <code>/loop</code> peut <a href="/docs/fr/scheduled-tasks#let-claude-choose-the-interval">choisir son propre intervalle</a>, et <code>/model</code> et <code>/effort</code> s'appliquent immédiatement au lieu d'après la fin du tour</div>
    <div>L'installateur natif et la mise à jour automatique téléchargent une version compressée zstd, environ 75 Mo au lieu de 340 Mo sur Linux x64, et les versions natives chargent le code à la demande, utilisant environ 40 à 70 Mo de mémoire en moins par session</div>
