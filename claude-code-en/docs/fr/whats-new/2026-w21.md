# Semaine 21 · 18–22 mai 2026

> Utilisez le mode auto sur le plan Pro et avec Sonnet 4.6, consultez les compétences, sous-agents et serveurs MCP qui limitent votre plan dans /usage, et examinez les différences avec la nouvelle commande /code-review.

  <p className="digest-feature-lede">Le mode auto est désormais disponible sur le plan Pro et prend en charge Sonnet 4.6 aux côtés d'Opus. Il remplace les invites de permission par des vérifications de sécurité en arrière-plan : les actions courantes s'exécutent sans vous interrompre, et les actions destructrices ou suspectes sont bloquées et signalées.</p>

  <p className="digest-feature-try">Mettez à jour Claude Code, puis basculez les modes avec Maj+Tab ; le mode auto apparaît une fois que votre compte remplit les conditions requises :</p>

  ```bash terminal theme={null}
  claude update
  ```

<div className="digest-wins">
  <p className="digest-wins-title">Autres améliorations</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/fr/costs#track-your-costs"><code>/usage</code></a> affiche désormais une ventilation par catégorie de ce qui limite votre plan, en attribuant l'utilisation récente aux compétences, sous-agents, plugins et serveurs MCP individuels</div>
    <div>« Extra usage » est renommé en « usage credits » dans l'ensemble de la CLI, et <code>/extra-usage</code> devient <code>/usage-credits</code>. L'ancien nom fonctionne toujours.</div>
    <div>Nouvelle commande <a href="/docs/fr/code-review"><code>/code-review</code></a> qui signale les bugs de correction à un niveau d'effort choisi comme <code>/code-review high</code>, et <code>--comment</code> publie les résultats sous forme de commentaires GitHub PR en ligne. <code>/simplify</code> reste un examen séparé de nettoyage uniquement.</div>
    <div>Les sessions en arrière-plan apparaissent désormais dans <code>/resume</code> aux côtés des sessions interactives, marquées avec <code>bg</code>, et les sessions épinglées avec <code>Ctrl+T</code> dans <code>claude agents</code> restent actives en cas d'inactivité</div>
    <div><code>claude agents --json</code> répertorie les sessions actives au format JSON pour les scripts, comme les barres d'état et les sélecteurs de session</div>
    <div>L'outil PowerShell est désormais activé par défaut sur Windows pour les utilisateurs d'Amazon Bedrock, de Google Cloud's Agent Platform et de Microsoft Foundry ; désactivez-le avec <code>CLAUDE\_CODE\_USE\_POWERSHELL\_TOOL=0</code></div>
    <div><code>claude plugin disable</code> refuse désormais quand un autre plugin activé dépend de la cible, et <code>claude plugin enable</code> force-active les dépendances transitives</div>
    <div>Le volet de navigation du marché <code>/plugin</code> affiche le coût de contexte projeté, et les écrans Découvrir et Parcourir répertorient les commandes, agents, compétences, hooks et serveurs MCP/LSP d'un plugin avant l'installation</div>
    <div>Nouveau paramètre <code>worktree.bgIsolation: "none"</code> qui permet aux sessions en arrière-plan de modifier directement la copie de travail sans <code>EnterWorktree</code>, pour les dépôts où les worktrees ne sont pas pratiques</div>
    <div>La sortie Markdown affiche les cases à cocher de la liste des tâches GFM, et la vue détaillée <code>/diff</code> se fait défiler avec le clavier</div>
    <div>L'entrée JSON de la ligne d'état inclut désormais les informations du dépôt GitHub et de la PR lorsqu'elles sont détectées</div>
    <div>Entreprise : le paramètre géré <code>allowAllClaudeAiMcps</code> charge les connecteurs MCP cloud claude.ai aux côtés de <code>managed-mcp.json</code></div>
  </div>
</div>
