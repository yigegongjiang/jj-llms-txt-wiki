    <span className="digest-feature-pill">aperçu de recherche</span>

  <p className="digest-feature-lede">Un workflow est un script d'orchestration que Claude écrit pour votre tâche et exécute sur plusieurs sous-agents en arrière-plan. Utilisez-en un lorsqu'une tâche est trop volumineuse pour qu'une seule conversation la coordonne : un audit à l'échelle de la base de code, une migration volumineuse, une question de recherche qui nécessite une vérification croisée. Gérez les exécutions avec <code>/workflows</code>.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Plugin security-guidance</span>
    <span className="digest-feature-pill">plugin</span>
  </div>

  <p className="digest-feature-lede">Le plugin security-guidance examine les modifications de code de Claude pour détecter les vulnérabilités et les corriger dans la même session. Il exécute une vérification rapide des motifs à chaque modification, un examen du modèle à la fin de chaque tour, et un examen agentique plus approfondi lors de la validation ou de la poussée. Ajoutez les règles du projet dans <code>.claude/claude-security-guidance.md</code>.</p>

    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/QsIrGXGFg6xd7joy/images/whats-new/security-guidance.mp4?fit=max&auto=format&n=QsIrGXGFg6xd7joy&q=85&s=c91d865936411586f42b24c558bcdd1d" data-path="images/whats-new/security-guidance.mp4" />

<div className="digest-wins">
  <p className="digest-wins-title">Autres améliorations</p>

  <div className="digest-wins-grid">
    <div>Dans <code>claude agents</code>, préfixez une commande shell avec <code>!</code> pour l'exécuter en tant que tâche de fond à laquelle vous pouvez vous connecter et vous déconnecter ; également disponible en tant que <code>claude --bg --exec 'pytest -x'</code></div>
    <div>Les plugins dans les répertoires <code>.claude/skills</code> sont maintenant chargés automatiquement, sans marketplace requise, et <code>claude plugin init \<name></code> crée un nouveau plugin</div>
    <div>La nouvelle commande <code>/reload-skills</code> réanalyse les répertoires de compétences sans redémarrage, et les hooks <code>SessionStart</code> peuvent retourner <code>reloadSkills: true</code> pour rendre les compétences qu'ils installent disponibles dans la même session</div>
    <div>Les compétences et les commandes peuvent définir <code>disallowed-tools</code> dans le frontmatter pour supprimer les outils du modèle tandis que la compétence est active</div>
    <div>Le nouvel événement hook <code>MessageDisplay</code> permet aux hooks de transformer ou de masquer le texte du message assistant tel qu'il s'affiche</div>
    <div>Claude Code bascule maintenant vers votre <code>--fallback-model</code> configuré pour le reste de la session lorsque le modèle principal n'est pas trouvé, au lieu d'échouer à chaque demande</div>
    <div>Les plugins peuvent déclarer <code>defaultEnabled: false</code> dans <code>plugin.json</code> ou une entrée marketplace, afin qu'ils s'installent sans s'activer jusqu'à ce que vous les activiez</div>
    <div>Mode Vim : <code>/</code> en mode NORMAL ouvre la recherche d'historique inversée, correspondant au mode vi de Bash et Zsh</div>
    <div>L'exécution d'outils en streaming est maintenant toujours activée, y compris avec la télémétrie désactivée et sur Amazon Bedrock, Google Cloud's Agent Platform, et Microsoft Foundry</div>
    <div><code>←←</code> pour ouvrir la vue agents fonctionne maintenant sur Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, et avec la télémétrie désactivée</div>
    <div>Claude dans Chrome : choisissez quel navigateur connecté utiliser via <code>/chrome</code> → « Sélectionner un navigateur… », ou dans le chat lorsqu'une action de navigateur s'exécute avec plusieurs connectés</div>
    <div><code>claude mcp list</code> et <code>claude mcp get</code> affichent maintenant les serveurs <code>.mcp.json</code> non approuvés comme en attente d'approbation au lieu d'approuver automatiquement et de se connecter lorsque la sortie est redirigée</div>
  </div>
</div>
