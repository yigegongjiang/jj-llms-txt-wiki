# Commandes

> Référence complète des commandes disponibles dans Claude Code, y compris les commandes intégrées et les compétences groupées.

Les commandes contrôlent Claude Code depuis l'intérieur d'une session. Elles offrent un moyen rapide de changer de modèle, de gérer les autorisations, d'effacer le contexte, d'exécuter un flux de travail, et bien plus encore.

Tapez `/` pour voir les commandes disponibles pour vous, ou tapez `/` suivi de lettres pour filtrer. [Comment le menu de commandes correspond à ce que vous tapez](#how-the-command-menu-matches-what-you-type) couvre la mise en évidence, les fautes de frappe, et les quelques commandes que Claude Code masque du menu jusqu'à ce que vous tapiez leur nom complet.

Une commande n'est reconnue qu'au début de votre message. Le texte qui suit le nom de la commande devient ses arguments. À partir de la v2.1.199, [les compétences](/docs/fr/skills#pass-arguments-to-skills) sont l'exception : une invocation de compétence suivie de plus de compétences, comme `/skill-a /skill-b do XYZ`, charge chaque compétence nommée au début et transmet le texte restant à chacune comme arguments. Jusqu'à six compétences peuvent être chaînées.

Si vous envoyez une commande tandis que Claude répond, Claude Code la met en file d'attente et l'exécute après la fin du tour actuel. Claude Code exécute certaines commandes immédiatement sans interrompre la réponse, comme `/status`, `/tasks`, et `/usage`. Dans le [rendu en plein écran](/docs/fr/fullscreen), Claude Code ouvre également immédiatement les commandes de dialogue comme `/theme` et `/help`. Avant la v2.1.234, Claude Code mettait ces dialogues en file d'attente jusqu'à la fin du tour.

<h2 id="commands-across-a-typical-workflow">
  Commandes au cours d'un flux de travail typique
</h2>

La plupart des commandes sont utiles à un moment spécifique d'une session, de la configuration d'un projet à la livraison d'une modification.

**Première session dans un dépôt.** Exécutez `/init` pour générer un `CLAUDE.md` de démarrage, puis `/memory` pour l'affiner. Utilisez `/mcp` pour configurer les serveurs dont le projet a besoin, demandez à Claude de créer les [sous-agents](/docs/fr/sub-agents) que vous souhaitez, et exécutez `/permissions` pour définir vos règles d'approbation.

**Pendant une tâche.** `/plan` bascule en mode plan avant une modification importante. `/model` et `/effort` ajustent le modèle que vous utilisez et le raisonnement qu'il applique. Lorsque la conversation devient longue, `/context` affiche ce qui remplit la fenêtre et `/compact` la résume pour libérer de l'espace. Utilisez `/btw` pour une question secondaire qui ne devrait pas s'ajouter à l'historique de la conversation.

**Exécuter le travail en parallèle.** Claude délègue les tâches secondaires aux [sous-agents](/docs/fr/sub-agents), et `/tasks` répertorie le travail en arrière-plan de la session actuelle, y compris les sous-agents qui ont terminé. `/background` détache la session entière pour continuer à s'exécuter en tant qu'[agent en arrière-plan](/docs/fr/agent-view) et libère votre terminal. Pour une modification importante qui s'étend sur la base de code, `/batch` la décompose en unités indépendantes et exécute chacune dans son propre [worktree](/docs/fr/worktrees). Consultez [Exécuter les agents en parallèle](/docs/fr/agents) pour comprendre comment ces approches se rapportent.

**Avant de livrer.** `/diff` affiche ce qui a changé. `/code-review` vérifie la différence actuelle pour les bogues de correction et peut appliquer les résultats avec `--fix` ; transmettez un numéro de PR, tel que `/code-review high 1234`, pour examiner une demande de tirage à la place. `/review` est un alias. `/code-review ultra` exécute un examen multi-agents dans le cloud. `/security-review` vérifie la différence pour les vulnérabilités de sécurité.

**Entre les sessions.** `/clear` commence une nouvelle tâche tout en conservant la mémoire du projet. `/resume` revient à une conversation antérieure, `/branch` crée une branche de la conversation actuelle pour essayer une direction différente, et `/fork` la copie dans une nouvelle [session en arrière-plan](/docs/fr/agent-view). `/teleport` extrait une session web dans ce terminal, et `/remote-control` vous permet de continuer cette session locale à partir d'un autre appareil.

**Quand quelque chose ne va pas.** `/rewind` restaure le code et la conversation à un point de contrôle, ou résume une partie de la conversation. `/doctor` exécute une vérification de configuration qui diagnostique les problèmes d'installation et de configuration et peut les corriger, `/debug` diagnostique les problèmes d'exécution, et `/feedback` signale un bogue avec le contexte de la session joint.

<h2 id="all-commands">
  Toutes les commandes
</h2>

Le tableau ci-dessous répertorie toutes les commandes incluses dans Claude Code. La plupart sont des commandes intégrées dont le comportement est codé dans l'interface de ligne de commande. Deux types d'entrées sont marqués :

* **[Skill](/docs/fr/skills#bundled-skills)** : une compétence groupée. Elle fonctionne comme les compétences que vous écrivez vous-même : une invite transmise à Claude.
  * `/verify` s'exécute uniquement lorsque vous l'invoquez. Avant la v2.1.215, Claude pouvait également exécuter `/verify` de lui-même.
* **[Workflow](/docs/fr/workflows#bundled-workflows)** : un [workflow dynamique](/docs/fr/workflows) groupé qui distribue le travail sur plusieurs sous-agents et s'exécute en arrière-plan.
  * `/deep-research` s'exécute uniquement lorsque vous l'invoquez. Avant la v2.1.218, Claude pouvait également le démarrer de lui-même.

Pour ajouter vos propres commandes, consultez [skills](/docs/fr/skills).

Dans le tableau ci-dessous, `<arg>` indique un argument obligatoire et `[arg]` indique un argument facultatif.

<Note>
  Toutes les commandes ne s'affichent pas pour tous les utilisateurs. La disponibilité dépend de votre plateforme, de votre plan et de votre environnement. Par exemple, `/desktop` s'affiche uniquement sur macOS et Windows x64 lorsque vous êtes connecté avec un abonnement Claude, et `/upgrade` ne s'affiche pas sur les plans Entreprise.
</Note>

<h2 id="how-the-command-menu-matches-what-you-type">
  Comment le menu de commandes correspond à ce que vous tapez
</h2>

Claude Code filtre le menu `/` au fur et à mesure que vous tapez. Chaque point ci-dessous couvre une chose que vous pourriez remarquer lors du filtrage :

* **Mise en évidence** : Claude Code met en évidence la suggestion principale uniquement lorsque les lettres après le `/` correspondent au nom ou à l'alias d'une commande, à partir du début du nom ou à partir d'un mot dans celui-ci, en ignorant les séparateurs `:`, `_` et `-`. Taper `/adddir` met en évidence `/add-dir`, et taper `/new` met en évidence `/clear` via son alias. Appuyez sur `Entrée` pour exécuter la suggestion mise en évidence. Ces règles de mise en évidence nécessitent Claude Code v2.1.236 ou version ultérieure.
* **Après une faute de frappe** : Claude Code ne met rien en évidence. Les correspondances proches restent listées, et vous pouvez en sélectionner une avec `Tab` ou les touches fléchées, mais `Entrée` soumet votre texte tel que tapé et signale [Commande inconnue](/docs/fr/errors#unknown-command).
* **Commandes qui ne vous sont pas disponibles** : Claude Code les exclut du menu. Quand rien ne correspond, Claude Code affiche `No commands match "/name"`. La plupart des commandes indisponibles retournent [Commande inconnue](/docs/fr/errors#unknown-command) lorsque vous les soumettez ; quelques-unes, comme [`/schedule` sur une clé API Console](/docs/fr/routines#schedule-returns-unknown-command), répondent plutôt avec leur propre message de disponibilité. Certaines commandes répondent également avec un message personnel lorsque la politique de votre organisation les désactive.
* **Commandes masquées** : Claude Code garde quelques commandes disponibles, comme `/heapdump`, hors du menu par conception. Un nom partiel ne ramène jamais une commande masquée dans le menu : si la correspondance partielle ne correspond à rien de visible, Claude Code affiche le même message d'absence de correspondance. Claude Code liste la commande uniquement une fois que vous avez tapé son nom complet, et soumettre le nom complet l'exécute.
