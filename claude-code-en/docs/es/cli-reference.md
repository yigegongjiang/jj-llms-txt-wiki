# Referencia de CLI

> Referencia completa de la interfaz de línea de comandos de Claude Code, incluyendo comandos y banderas.

<h2 id="cli-commands">
  Comandos CLI
</h2>

Puede iniciar sesiones, canalizar contenido, reanudar conversaciones y administrar actualizaciones con estos comandos:

| Comando                         | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Ejemplo                                                     |
| :------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| `claude`                        | Iniciar sesión interactiva                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude`                                                    |

Disponible en Claude Code v2.1.195 y posterior.                                                                                                                                                                                                                                                                                                                                                                                                                                               | `claude gateway --config gateway.yaml`                      |

Las reglas de [configuración administrada](/docs/es/server-managed-settings) o la bandera `--settings` aún se aplican. Requiere Claude Code v2.1.212 o posterior. Consulte [Inspeccionar los valores predeterminados y su configuración efectiva](/docs/es/auto-mode-config#inspect-the-defaults-and-your-effective-config)                                                                                                                                                                                                                                         | `claude auto-mode reset --yes`                              |

También no disponible cuando desactiva [obtención de banderas de características](/docs/es/env-vars#features-that-need-feature-flag-fetching). Requiere Claude Code v2.1.213 o posterior                                                                                                                                                                                                                                                                                                                | `claude import codex --dry-run`                             |
| `claude logs <id>`              | Imprimir salida reciente de una [sesión de fondo](/docs/es/agent-view#manage-sessions-from-the-shell)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `claude logs 7c5dcf5d`                                      |
| `claude mcp`                    | Configurar servidores Model Context Protocol (MCP)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Consulte la [documentación de Claude Code MCP](/docs/es/mcp).    |

Agregue `--no-browser` sobre SSH para imprimir la URL de autorización en lugar de abrir un navegador, luego pegue la URL de redirección nuevamente en el indicador. Consulte [Autenticar desde la línea de comandos](/docs/es/mcp#authenticate-from-the-command-line)                                                                                                                                                                                                                                                                                                                                                                                                               | `claude mcp login sentry`                                   |

Requiere Claude Code v2.1.224 o posterior                                                                                                                                                                                                                      | `claude self-hosted-runner setup`                           |
| `claude setup-token`            | Generar un token OAuth de larga duración para CI y scripts. Imprime el token en la terminal sin guardarlo. Requiere una suscripción a Claude. Consulte [Generar un token de larga duración](/docs/es/authentication#generate-a-long-lived-token)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `claude setup-token`                                        |
| `claude stop <id>`              | Detener una [sesión de fondo](/docs/es/agent-view#manage-sessions-from-the-shell). También acepta `claude kill`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude stop 7c5dcf5d`                                      |
| `claude ultrareview [target]`   | Ejecutar [ultrareview](/docs/es/ultrareview#run-ultrareview-non-interactively) de forma no interactiva. Imprime los hallazgos en stdout y sale con 0 en caso de éxito o 1 en caso de fallo. Use `--json` para la carga útil sin procesar y `--timeout <minutes>` para anular el valor predeterminado de 45 minutos. Use `--post` en un destino de solicitud de extracción `github.com` para publicar los hallazgos terminados en la PR como un comentario simple desde su cuenta de GitHub. `--no-post` es el predeterminado. `--post` y `--no-post` requieren Claude Code v2.1.227 o posterior. Consulte [Publicar hallazgos en la solicitud de extracción](/docs/es/ultrareview#post-findings-to-the-pull-request)                                                                                                                                 | `claude ultrareview 1234 --json`                            |

Si escribe mal un subcomando, Claude Code sugiere la coincidencia más cercana y sale sin iniciar una sesión. Por ejemplo, `claude udpate` imprime `Did you mean claude update?`.

A partir de v2.1.199, `claude --dangerously-skip-permissions daemon <subcommand>` ejecuta el subcomando `daemon`. Las versiones anteriores trataban `daemon <subcommand>` como el indicador para una nueva sesión interactiva, por lo que el subcomando nunca se ejecutaba cuando la bandera venía primero, una configuración común cuando `claude` tiene un alias que incluye la bandera. Solo un `--dangerously-skip-permissions` o `--allow-dangerously-skip-permissions` inicial enruta a `daemon` de esta manera; cualquier otra bandera inicial aún inicia una sesión interactiva.

<h2 id="cli-flags">
  Banderas CLI
</h2>

Personaliza el comportamiento de Claude Code con estas banderas de línea de comandos. `claude --help` no enumera todas las banderas, por lo que la ausencia de una bandera en `--help` no significa que no esté disponible.

| Bandera                                         | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Ejemplo                                                                                             |
| :---------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------- |
| `--add-dir`                                     | Añade directorios de trabajo adicionales para que Claude lea y edite archivos. Otorga acceso a archivos; Claude Code [no descubre](/docs/es/permissions#additional-directories-grant-file-access-not-configuration) la mayoría de la configuración de `.claude/` desde estos directorios. Valida que cada ruta exista como un directorio. No puedes añadir la mayoría de [rutas de red](/docs/es/errors#working-directory-is-a-network-path), como `\\server\share`. Para persistir estos directorios entre sesiones, establece [`permissions.additionalDirectories`](/docs/es/settings-reference#permissions-additionaldirectories) en la configuración                                                                                                                                                                                                                                                                                                                                                                                                                   | `claude --add-dir ../apps ../lib`                                                                   |
| `--advisor <model>`                             | Habilita la [herramienta advisor](/docs/es/advisor) del lado del servidor para esta sesión con un alias de modelo, `fable`, `opus`, u `sonnet`, o un ID de modelo completo. Tiene prioridad sobre la configuración `advisorModel` para la sesión. `fable` requiere [acceso a Fable](/docs/es/advisor#choose-an-advisor-model)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude --advisor opus`                                                                             |
| `--agent`                                       | Especifica un agente para la sesión actual (anula la configuración `agent`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude --agent my-custom-agent`                                                                    |
| `--agents`                                      | Define subagentes personalizados dinámicamente a través de JSON. Acepta los [campos enumerados para subagentes definidos por CLI](/docs/es/sub-agents#choose-the-subagent-scope). Claude Code valida el JSON al inicio y sale si hay un valor inválido; consulta [`Invalid --agents configuration`](/docs/es/errors#invalid-agents-configuration) para el mensaje y para las banderas y variable de entorno que omiten la validación. La validación requiere Claude Code v2.1.242 o posterior                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude --agents '{"reviewer":{"description":"Reviews code","prompt":"You are a code reviewer"}}'`  |
| `--allow-dangerously-skip-permissions`          | Añade `bypassPermissions` al ciclo de modo `Shift+Tab` sin comenzar en él. | `--allowedTools`, `--allowed-tools`             | Herramientas que se ejecutan sin solicitar permiso. Consulta [sintaxis de regla de permisos](/docs/es/settings-reference#permission-rule-syntax) para coincidencia de patrones. Si nombras una de las [herramientas de seguimiento de tareas](/docs/es/tools-reference#task-tool-availability) aquí, Claude Code también opta por la sesión                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `"Bash(git log *)" "Bash(git diff *)" "Read"`                                                       |
| `--append-subagent-system-prompt`               | Añade texto personalizado al final del indicador del sistema de cada [subagente](/docs/es/sub-agents), incluyendo subagentes anidados, excepto un [subagente bifurcado](/docs/es/sub-agents#fork-the-current-conversation), que reutiliza el indicador de la propia conversación. Solo se aplica en modo no interactivo con `-p`. Requiere Claude Code v2.1.205 o posterior                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `claude -p --append-subagent-system-prompt "Cite file paths in every answer" "query"`               |
| `--append-subagent-system-prompt-file`          | Carga texto de un archivo y lo añade a los indicadores del sistema de [subagentes](/docs/es/sub-agents). Una alternativa a `--append-subagent-system-prompt` para texto demasiado largo para pasar en la línea de comandos. Las dos banderas no se pueden combinar. Solo se aplica en modo no interactivo con `-p`. Requiere Claude Code v2.1.261 o posterior                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `claude -p --append-subagent-system-prompt-file ./subagent-rules.txt "query"`                       |
| `--append-system-prompt`                        | Añade texto personalizado al final del indicador del sistema predeterminado                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude --append-system-prompt "Always use TypeScript"`                                             |
| `--append-system-prompt-file`                   | Carga texto de indicador del sistema adicional de un archivo y lo añade al indicador predeterminado                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude --append-system-prompt-file ./extra-rules.txt`                                              |

<h3 id="system-prompt-flags">
  Banderas de indicador del sistema
</h3>

Claude Code proporciona cinco banderas para personalizar el indicador del sistema. Cuatro establecen su texto, y con `--system-prompt-snapshot` controlas si una conversación mantiene el texto con el que comenzó. Las cinco funcionan tanto en modos interactivos como no interactivos.

| Bandera                       | Comportamiento                                                                                                                                                                                     | Ejemplo                                                                    |
| :---------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------- |
| `--system-prompt`             | Reemplaza el indicador predeterminado completo                                                                                                                                                     | `claude --system-prompt "You are a Python expert"`                         |
| `--system-prompt-file`        | Reemplaza con contenido del archivo                                                                                                                                                                | `claude --system-prompt-file ./prompts/review.txt`                         |
| `--append-system-prompt`      | Añade al indicador predeterminado                                                                                                                                                                  | `claude --append-system-prompt "Always use TypeScript"`                    |
| `--append-system-prompt-file` | Añade contenido del archivo al indicador predeterminado                                                                                                                                            | `claude --append-system-prompt-file ./style-rules.txt`                     |
| `--system-prompt-snapshot`    | Con `off`, reconstruye el indicador en cada solicitud. Con `on`, el predeterminado, reutiliza un indicador registrado donde [se aplica el registro](#system-prompt-flags-in-resumed-conversations) | `claude --append-system-prompt "Draft rules" --system-prompt-snapshot off` |

`--system-prompt` y `--system-prompt-file` son mutuamente excluyentes. Las banderas de añadir se pueden combinar con cualquiera de las banderas de reemplazo.

Cuando el texto de reemplazo combina instrucciones que son iguales en cada ejecución con contexto que cambia por ejecución, añade una línea que contenga solo `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__` entre las instrucciones y el contexto. Claude Code divide el indicador en la primera línea de este tipo y elimina esa línea, por lo que la parte anterior permanece en caché mientras la parte posterior cambia. Requiere Claude Code v2.1.275 o posterior. [Cachea la parte estática de un indicador personalizado](/docs/es/agent-sdk/modifying-system-prompts#cache-the-static-part-of-a-custom-prompt) enumera las configuraciones donde se aplica la división.

Elige basándote en si la identidad predeterminada de Claude Code aún se ajusta a tu tarea. Usa una bandera de añadir cuando Claude debe permanecer como un asistente de codificación que también sigue tus reglas adicionales: instrucciones por invocación, formato de salida, o contexto de dominio para un script `-p`. Añadir preserva la orientación de herramientas predeterminada, instrucciones de seguridad y convenciones de codificación, por lo que solo suministras lo que difiere. Usa una bandera de reemplazo cuando la superficie, identidad, o modelo de permisos difiere del de Claude Code, como un agente no codificador en una canalización que ningún humano observa. Reemplazar elimina todo el indicador predeterminado, incluyendo orientación de herramientas e instrucciones de seguridad, por lo que asumes la responsabilidad de lo que tu tarea aún necesita.

Para personas persistentes que puedas cambiar entre ellas y compartir entre un proyecto, usa [estilos de salida](/docs/es/output-styles). Para convenciones de proyecto que Claude siempre debe seguir, usa [CLAUDE.md](/docs/es/memory). La [guía del Agent SDK sobre indicadores del sistema](/docs/es/agent-sdk/modifying-system-prompts#decide-on-a-starting-point) cubre la misma decisión con más profundidad.

<h4 id="system-prompt-flags-in-resumed-conversations">
  Banderas de indicador del sistema en conversaciones reanudadas
</h4>

Por defecto, Claude Code construye el indicador del sistema una vez, en la primera solicitud de una conversación, con el texto de cualquier bandera de indicador del sistema aplicada, y lo registra en la sesión. Hasta que la conversación se compacte, cada solicitud posterior usa ese indicador registrado, incluyendo después de que regreses a la conversación con `--resume` o `--continue`. Si pasas texto de bandera de indicador del sistema diferente, o ninguno, en ese lanzamiento posterior, entra en efecto una vez que la conversación se compacta o cuando comienzas una nueva conversación.

Fuera de [sesiones en la nube](/docs/es/cloud-environments), si comienzas Claude Code en [modo bare](/docs/es/headless#start-faster-with-bare-mode) pasando `--bare` o estableciendo `CLAUDE_CODE_SIMPLE=1`, el registro permanece desactivado a menos que pases `--system-prompt-snapshot on`. Antes de v2.1.268, sesiones que no [obtienen banderas de características](/docs/es/env-vars#features-that-need-feature-flag-fetching), incluyendo sesiones en Amazon Bedrock, Google Cloud's Agent Platform, y Microsoft Foundry, reconstruían el indicador en cada solicitud y `--system-prompt-snapshot` no tenía efecto.

Para reconstruir el indicador en cada solicitud en su lugar, por ejemplo mientras iteras en su redacción entre ejecuciones de `--continue`, pasa `--system-prompt-snapshot off`. Antes de v2.1.265, pasar cualquiera de las banderas de indicador del sistema también desactivaba el registro a menos que pasaras `--system-prompt-snapshot on`.
