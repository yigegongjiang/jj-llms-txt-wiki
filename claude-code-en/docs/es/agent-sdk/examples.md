# Ejemplos

> Encuentra un proyecto completo y ejecutable del Agent SDK o una receta guiada en el Claude Cookbook que coincida con lo que deseas construir.

Esta página te dirige a proyectos completos y ejecutables del Agent SDK y recetas guiadas del Claude Cookbook. Las aplicaciones TypeScript se encuentran en el repositorio [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos), y las recetas de Python se encuentran en el [Claude Cookbook](https://platform.claude.com/cookbook).

<h2 id="run-a-minimal-agent-first">
  Ejecuta un agente mínimo primero
</h2>

Si aún no has construido nada con el SDK, comienza con uno de estos antes de una aplicación completa:

* [Agent SDK quickstart](/docs/es/agent-sdk/quickstart): construye tu primer agente funcional en TypeScript o Python, con pasos de configuración incluidos. El agente encuentra y corrige errores en un archivo de ejemplo.

* [Hello World](https://github.com/anthropics/claude-agent-sdk-demos/tree/main/hello-world): un proyecto TypeScript mínimo para clonar cuando deseas comenzar desde el código del repositorio

<h2 id="explore-a-typescript-application">
  Explora una aplicación TypeScript
</h2>

Las aplicaciones TypeScript en [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos) son demostraciones para desarrollo local, desde un cliente de correo electrónico hasta un sistema de investigación multiagente. Clona la demostración cuya estructura coincida con lo que estás construyendo.

<h2 id="work-through-a-python-recipe">
  Trabaja a través de una receta de Python
</h2>

La serie Agent SDK del Claude Cookbook es una secuencia de recetas, cada una un cuaderno de Python, que progresa desde un agente de investigación simple hasta sistemas multiagente sofisticados. Cada cuaderno se basa en el anterior, introduciendo nuevos conceptos y capacidades. Comienza con [el agente de investigación de una línea](https://platform.claude.com/cookbook/claude-agent-sdk-00-the-one-liner-research-agent) y avanza.

Para recetas en todos los productos de Claude, consulta el [Claude Cookbook](https://platform.claude.com/cookbook) completo.
