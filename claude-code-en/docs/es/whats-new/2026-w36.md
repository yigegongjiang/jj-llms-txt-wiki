# Semana 36 · 31 de agosto – 4 de septiembre de 2026

> Cambia a Claude Fable 5.1, permite que el computer use se ejecute en segundo plano en Desktop, y observa las ediciones de Claude en un panel /diff en vivo.

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude Fable 5.1</span>
    <span className="digest-feature-pill">nuevo modelo</span>
  </div>

  <p className="digest-feature-lede">Claude Fable 5.1 está disponible en Claude Code con una ventana de contexto de 1M de tokens, y el alias <code>fable</code> ahora lo selecciona. En sesiones de gateway de aplicaciones Claude, <code>fable</code> sigue seleccionando Fable 5. Si tu gateway sirve Fable 5.1, ejecuta <code>/model claude-fable-5-1</code>. Requiere v2.1.257 o posterior.</p>

  <p className="digest-feature-try">Cambia la sesión actual a Fable 5.1 y guárdala como tu predeterminada:</p>

  ```text Claude Code theme={null}
  > /model fable
  ```

  <p className="digest-feature-try">En la API de Anthropic, el selector lista Fable solo una vez que el servidor informa que está disponible para tu organización, pero escribir <code>/model fable</code> verifica directamente con el servidor.</p>

  <a className="digest-feature-link" href="/docs/es/model-config#work-with-fable">Trabajar con Fable</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Panel diff en vivo en renderizado a pantalla completa</span>
    <span className="digest-feature-pill">v2.1.260</span>
  </div>

  <p className="digest-feature-lede">En renderizado a pantalla completa, <code>/diff</code> ahora abre un panel junto a la conversación en lugar de un visor que tengas que cerrar. El panel lista los archivos modificados con sus recuentos de líneas añadidas y eliminadas y se actualiza cada vez que Claude edita un archivo o ejecuta un comando shell. Selecciona líneas en el panel con el ratón para adjuntarlas a tu siguiente prompt.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/diff-panel.mp4?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=9d7553c19e7f227891cd95f1f59d796d" data-path="images/whats-new/diff-panel.mp4" />
  </Frame>

  <p className="digest-feature-try">Con renderizado a pantalla completa activado, dentro de un repositorio git, y en una terminal de al menos 110 columnas de ancho, alterna el panel:</p>

  ```text Claude Code theme={null}
  > /diff
  ```

  <p className="digest-feature-try">Ejecuta <code>/diff</code> de nuevo o haz clic en la <code>✕</code> en su encabezado para cerrarlo.</p>

  <a className="digest-feature-link" href="/docs/es/interactive-mode#diff-panel">Panel diff</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Encuentra skills no utilizadas con /skill-doctor</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede"><code>/skill-doctor</code> muestra lo que cada uno de tus skills cuesta en contexto y con qué frecuencia se usa, para que puedas decidir cuáles desactivar. Cada skill en el <a href="/docs/es/skills#skill-descriptions-are-cut-short">listado de skills</a> se suma a tu contexto en cada turno, independientemente de si Claude lo usa o no. Requiere v2.1.252 o posterior y no está disponible en sesiones que omitan <a href="/docs/es/env-vars#features-that-need-feature-flag-fetching">la obtención de banderas de características</a>.</p>

  <p className="digest-feature-try">Ejecútalo en una sesión interactiva para abrir el informe en la pestaña <strong>Stats</strong> del gestor <code>/plugin</code>:</p>

  ```text Claude Code theme={null}
  > /skill-doctor
  ```

  <p className="digest-feature-try">En modo no interactivo con <code>-p</code>, Claude Code imprime el informe como texto en su lugar.</p>

  <a className="digest-feature-link" href="/docs/es/skills#find-unused-skills">Encuentra skills no utilizadas</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Otros logros</p>

  <div className="digest-wins-grid">
    <div>Un hook <a href="/docs/es/hooks#premodelswitch"><code>PreModelSwitch</code></a> puede bloquear un cambio de modelo que solicites, y un hook <a href="/docs/es/hooks#postmodelswitch"><code>PostModelSwitch</code></a> puede añadir contexto para Claude después de que cambie el modelo de la sesión</div>
    <div><a href="/docs/es/costs#prompt-cache-statistics"><code>/cost</code></a> añade una línea <code>Prompt cache (main)</code>: la proporción de tokens de entrada servidos desde caché, los fallos de caché, si la caché está caliente, y una causa probable para el último fallo cuando Claude Code puede nombrar una. Los scripts de línea de estado obtienen un objeto <code>prompt\_cache</code> correspondiente</div>
    <div>Las organizaciones pueden listar servidores MCP HTTP y SSE bajo la <a href="/docs/es/managed-mcp#provide-servers-through-managed-settings">configuración gestionada <code>managedMcpServers</code></a> para proporcionarlos a cada usuario, además de los servidores que los usuarios añaden por su cuenta</div>
    <div><code>/effort</code> y el selector <code>/model</code> ahora <a href="/docs/es/model-config#adjust-effort-level">guardan un nivel de esfuerzo separado para cada modelo</a>; presiona <code>s</code> en lugar de <code>Enter</code> para aplicar un nivel solo a la sesión actual</div>
    <div>Por defecto, el clasificador de modo automático <a href="/docs/es/permission-modes#what-the-classifier-blocks-by-default">ahora también bloquea</a> acciones como solicitar credenciales del endpoint de metadatos de instancia en la nube o conectarse a contenedores hermanos que Claude no inició</div>
    <div>En modo automático, Claude Code te pregunta antes de que Claude <a href="/docs/es/permission-modes#first-read-outside-the-working-directories">lea por primera vez un archivo fuera de tus directorios de trabajo</a>, con una opción para bloquear tales lecturas a partir de entonces</div>
    <div>Aumenta <a href="/docs/es/settings-reference#bashoutputmaxchars"><code>bashOutputMaxChars</code></a> y <a href="/docs/es/settings-reference#taskoutputmaxchars"><code>taskOutputMaxChars</code></a>, hasta 128,000 caracteres, para que Claude reciba más de la salida de un comando exitoso o tarea en segundo plano en línea</div>
    <div>Los atajos de teclado de edición de palabras del prompt <a href="/docs/es/interactive-mode#make-ctrl-w-delete-back-to-whitespace">siguen readline</a> para todos, y la configuración <code>keybindingFlavor</code> ya no tiene ningún efecto. <code>Ctrl+W</code> elimina hacia el espacio en blanco anterior, y <code>Alt+B</code>, <code>Alt+F</code>, y <code>Alt+D</code> tratan la puntuación como <code>/</code> y <code>.</code> como separadores de palabras</div>
    <div>Si estableces <code>defaultMode</code> en <code>"bypassPermissions"</code> en el <code>.claude/settings.json</code> o <code>.claude/settings.local.json</code> de un proyecto, <a href="/docs/es/permission-modes#which-mode-a-session-starts-in">ya no tiene efecto</a> y la sesión comienza en modo Manual; establece <code>"bypassPermissions"</code> en configuración de usuario o gestionada en su lugar, o pasa `--permission-mode`</div>
    <div>Los planes Enterprise basados en asientos ahora <a href="/docs/es/model-config#default-model-setting">tienen Opus 5 como predeterminado</a></div>
    <div>En la extensión de VS Code, haz clic en el nombre del modelo en la parte inferior del cuadro de prompt para <a href="/docs/es/vs-code#use-the-prompt-box">abrir el selector de modelo</a></div>
    <div>En la extensión de VS Code, selecciona <strong>Output styles</strong> en la sección Personalizar del menú de comandos para <a href="/docs/es/vs-code#use-the-prompt-box">elegir un estilo de salida</a>, incluyendo los personalizados</div>
  </div>
</div>
