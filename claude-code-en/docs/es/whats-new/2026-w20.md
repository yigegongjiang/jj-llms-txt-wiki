  <p className="digest-feature-lede"><code>claude agents</code> abre una pantalla para cada sesión de Claude Code: qué se está ejecutando, qué está bloqueado esperando su entrada, y qué está hecho. Envíe una corrección de errores, una revisión de solicitud de extracción y una investigación de prueba inestable como tres filas, continúe trabajando en otra ventana, e intervenga solo cuando una fila lo necesite. Adjúntese a cualquier fila para acceder a su conversación completa, luego presione <code>←</code> para volver a la lista. Cada sesión en segundo plano continúa ejecutándose sin una terminal adjunta.</p>

  <p className="digest-feature-lede">Establezca una condición de finalización y Claude continúa trabajando hacia ella en todos los turnos sin que usted solicite cada paso. Después de cada turno, un modelo rápido verifica si se cumple la condición; si no, Claude inicia otro turno en lugar de devolver el control. Útil para trabajo sustancial con un estado final verificable, como migrar un módulo hasta que cada sitio de llamada se compile y las pruebas pasen. El objetivo se borra una vez que se cumple la condición, y funciona en modo interactivo, <code>-p</code>, y Control Remoto.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Modo rápido en Opus 4.7</span>
    <span className="digest-feature-pill">vista previa de investigación</span>
  </div>

  <p className="digest-feature-lede"><code>/fast</code> ahora se ejecuta en Opus 4.7 de forma predeterminada en lugar de Opus 4.6. El modo rápido es una configuración de Opus de alta velocidad: la misma calidad de modelo a aproximadamente 2.5x la velocidad por un costo más alto por token, útil para iteración rápida y depuración en vivo. El precio se mantiene sin cambios en $30/$150 por MTok, lo mismo que el modo rápido de Opus 4.6. Para fijar el modo rápido a Opus 4.6, establezca <code>CLAUDE\_CODE\_OPUS\_4\_6\_FAST\_MODE\_OVERRIDE=1</code>.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Otros logros</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code> ganó banderas de envío (<code>--add-dir</code>, <code>--settings</code>, <code>--mcp-config</code>, <code>--plugin-dir</code>, <code>--permission-mode</code>, <code>--model</code>, <code>--effort</code>, <code>--dangerously-skip-permissions</code>) para configurar sesiones en segundo plano, y <code>claude agents --cwd \<path></code> limita la lista de sesiones a un directorio</div>
    <div>Nuevo hook <code>args: string\[]</code> la forma exec genera el comando directamente sin un shell, por lo que los marcadores de posición de ruta nunca necesitan entrecomillarse</div>
    <div>Nueva opción de configuración <code>continueOnBlock</code> para hooks <code>PostToolUse</code> devuelve la razón del rechazo del hook a Claude y continúa el turno en lugar de terminarlo</div>
    <div>Nuevo campo <code>terminalSequence</code> en la salida JSON del hook permite que los hooks emitan notificaciones de escritorio, títulos de ventana y campanas sin una terminal de control</div>
    <div>El menú Rewind agregó "Resumir hasta aquí" para comprimir el contexto anterior mientras se mantienen intactos los turnos recientes</div>
    <div>Control Remoto, <code>/schedule</code>, conectores MCP de Claude.ai y preferencias de notificación ahora están deshabilitados cuando <code>ANTHROPIC\_API\_KEY</code>, <code>apiKeyHelper</code>, o <code>ANTHROPIC\_AUTH\_TOKEN</code> está establecido, incluso junto con un inicio de sesión de Claude.ai; desestablezca la clave API para usar estas características</div>
    <div>Los servidores stdio de MCP ahora reciben <code>CLAUDE\_PROJECT\_DIR</code> en su entorno, coincidiendo con hooks, y las configuraciones de plugins pueden hacer referencia a <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code> en comandos</div>
    <div><code>claude plugin details \<name></code> muestra el inventario de componentes de un plugin y el costo de token proyectado por sesión, y el panel de detalles <code>/plugin</code> ahora también enumera los servidores LSP que proporciona un plugin</div>
    <div>Los plugins con un <code>SKILL.md</code> de nivel raíz y sin subdirectorio <code>skills/</code> ahora se muestran como una skill</div>
    <div><code>/feedback</code> ahora puede incluir sesiones recientes de las últimas 24 horas o 7 días para problemas que abarquen más que la sesión actual</div>
    <div>La herramienta de agente <code>subagent\_type</code> ahora coincide sin distinción de mayúsculas y separadores, por lo que <code>"Code Reviewer"</code> se resuelve a <code>code-reviewer</code></div>
  </div>
