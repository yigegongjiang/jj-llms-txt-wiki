<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Prueba plugins con claude plugin eval</span>
    <span className="digest-feature-pill">v2.1.269</span>
  </div>

  <p className="digest-feature-lede"><code>claude plugin eval</code> ejecuta tu plugin contra un conjunto de casos de prueba, califica los resultados y, de forma predeterminada, ejecuta cada caso nuevamente sin el plugin para que puedas ver qué contribuye. <code>claude plugin eval init</code> te pregunta cómo debería verse un buen resultado, luego propone casos de prueba y las comprobaciones que los califican, prueba el conjunto una vez y escribe los archivos. Cada ejecución y cada comprobación que tiene un segundo modelo que juzga la respuesta es una llamada de modelo real en tu cuenta.</p>

  <Frame>
    <img className="w-full" src="https://mintcdn.com/claude-code/f9HTZGyMtxIFOUgt/images/whats-new/plugin-eval.jpg?fit=max&auto=format&n=f9HTZGyMtxIFOUgt&q=85&s=913066f6d4a2a15426e98a627802f47f" alt="Salida de terminal de claude plugin eval: una tabla de siete casos con la puntuación de cada caso con y sin el plugin, la diferencia entre ellos, el recuento de ejecuciones y el costo, seguido de una línea de resumen con la diferencia media, la duración total y el costo total" width="1600" height="900" data-path="images/whats-new/plugin-eval.jpg" />
  </Frame>

  <p className="digest-feature-try">Desde el directorio raíz de tu plugin, pídele a Claude que redacte el conjunto:</p>

  ```bash terminal theme={null}
  claude plugin eval init
  ```

  <p className="digest-feature-try">Cuando Claude te diga que el conjunto está listo, sal de la sesión que <code>claude plugin eval init</code> abrió y ejecuta <code>claude plugin eval .</code> para calificar cada caso. La tabla de resumen se imprime en tu terminal, y <code>report.html</code> bajo <code>evals/results/</code> tiene el detalle por ejecución.</p>

    <div>Pasa `--json` a <code>claude plugin install</code>, <code>uninstall</code>, <code>update</code>, <code>enable</code> o <code>disable</code> para imprimir el resultado como <a href="/docs/es/plugins/cli-reference#plugin-json-result">un objeto JSON en la última línea de stdout</a></div>
    <div>Cuando el clasificador del modo automático bloquea una acción, la razón que recibe Claude <a href="/docs/es/auto-mode-config#fix-a-denial-with-an-allow-rule-an-environment-entry-or-a-retry">generalmente nombra la regla que coincidió</a>, como <code>\[Data Exfiltration]</code></div>

La lista se abre mientras escribes en renderizado a pantalla completa. Una habilidad de plugin también coincide con su nombre sin el prefijo del plugin</div>
    <div>En la extensión de VS Code, haz clic en el recuento de agentes en la parte inferior del cuadro de mensaje para abrir el <a href="/docs/es/vs-code#use-the-prompt-box">mapa de agentes</a>, donde puedes abrir la transcripción de solo lectura de un subagente o detenerlo</div>
    <div>En la extensión de VS Code, selecciona <strong>Hooks</strong> o <strong>Permissions</strong> en la sección Personalizar del menú de comandos para <a href="/docs/es/vs-code#use-the-prompt-box">agregar o eliminar hooks y reglas de permisos</a> en tu configuración de usuario, proyecto y local</div>
    <div>Claude puede elegir un <a href="/docs/es/artifacts#create-an-artifact">icono de pestaña del navegador</a> para que coincida con cada artefacto que publica</div>
    <div>En Claude Code en la web, recupera un mensaje en cola en una sesión en la nube antes de que Claude lo lea: elimínalo de la cola, o presiona <code>Esc</code> o <code>Up</code>, y el texto vuelve al cuadro de mensaje</div>
