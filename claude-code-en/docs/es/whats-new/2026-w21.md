<div className="digest-wins">
  <p className="digest-wins-title">Otros logros</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/es/costs#track-your-costs"><code>/usage</code></a> ahora muestra un desglose por categoría de lo que impulsa los límites de su plan, atribuyendo el uso reciente a skills, subagentes, plugins y servidores MCP individuales</div>
    <div>"Extra usage" se renombra a "usage credits" en toda la CLI, y <code>/extra-usage</code> ahora es <code>/usage-credits</code>. El nombre anterior sigue funcionando.</div>
    <div>Nuevo comando <a href="/docs/es/code-review"><code>/code-review</code></a> que reporta errores de corrección en un nivel de esfuerzo elegido como <code>/code-review high</code>, y <code>--comment</code> publica los hallazgos como comentarios en línea de PR de GitHub. <code>/simplify</code> permanece como una revisión separada solo de limpieza.</div>
    <div>Las sesiones en segundo plano ahora aparecen en <code>/resume</code> junto con las interactivas, marcadas con <code>bg</code>, y las sesiones fijadas con <code>Ctrl+T</code> en <code>claude agents</code> permanecen activas cuando están inactivas</div>
    <div><code>claude agents --json</code> enumera sesiones activas como JSON para scripting, como barras de estado y selectores de sesión</div>
    <div>La herramienta PowerShell ahora está habilitada de forma predeterminada en Windows para usuarios de Amazon Bedrock, Google Cloud's Agent Platform y Microsoft Foundry; opte por no participar con <code>CLAUDE\_CODE\_USE\_POWERSHELL\_TOOL=0</code></div>
    <div><code>claude plugin disable</code> ahora se niega cuando otro plugin habilitado depende del destino, y <code>claude plugin enable</code> habilita forzosamente las dependencias transitivas</div>
    <div>El panel de exploración del mercado <code>/plugin</code> muestra el costo de contexto proyectado, y las pantallas Discover y Browse enumeran los comandos, agentes, skills, hooks y servidores MCP/LSP de un plugin antes de la instalación</div>
    <div>Nueva configuración <code>worktree.bgIsolation: "none"</code> permite que las sesiones en segundo plano editen la copia de trabajo directamente sin <code>EnterWorktree</code>, para repositorios donde los worktrees no son prácticos</div>
    <div>La salida Markdown renderiza las casillas de verificación de la lista de tareas GFM, y la vista de detalle <code>/diff</code> se desplaza con el teclado</div>
    <div>La entrada JSON de la línea de estado ahora incluye información del repositorio y PR de GitHub cuando se detecta</div>
    <div>Enterprise: la configuración administrada <code>allowAllClaudeAiMcps</code> carga conectores MCP en la nube de claude.ai junto con <code>managed-mcp.json</code></div>
  </div>
</div>
