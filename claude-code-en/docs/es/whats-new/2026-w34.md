<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Estilo de salida Concise</span>
    <span className="digest-feature-pill">v2.1.237</span>
  </div>

  <p className="digest-feature-lede">Concise es un nuevo estilo de salida integrado. Claude comienza con el resultado y omite el preámbulo y la narración, mientras realiza el trabajo de manera tan exhaustiva como en el estilo Default. Cuando solicita una explicación o más detalle, Claude responde completamente. Los informes de errores, advertencias de seguridad y confirmaciones para acciones destructivas mantienen su contenido completo.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/2SnAdpL4dJ18nKb3/images/whats-new/concise-output-style.mp4?fit=max&auto=format&n=2SnAdpL4dJ18nKb3&q=85&s=dfb40ec8921ed1bc82eb629042a8ec17" data-path="images/whats-new/concise-output-style.mp4" />
  </Frame>

  <p className="digest-feature-try">Actívelo en <strong>Output style</strong> en <code>/config</code>, o establézcalo en su archivo de configuración:</p>

  ```json ~/.claude/settings.json {2} theme={null}
  {
    "outputStyle": "Concise"
  }
  ```

  <p className="digest-feature-try">Ejecute <code>/clear</code> o inicie una nueva sesión, y las respuestas de Claude comenzarán con el resultado.</p>

  <p className="digest-feature-try">Inicie Remote Control en la máquina a la que desea acceder, luego abra la pestaña Code en su teléfono:</p>

  ```bash terminal theme={null}

  ```

<div className="digest-wins">
  <p className="digest-wins-title">Otros logros</p>

  <div className="digest-wins-grid">
    <div>Claude Code ahora continúa su sesión automáticamente cuando se restablece un límite de uso de claude.ai; desactívelo desde la fila <strong>Continue automatically at usage limit</strong> en <code>/config</code></div>
    <div>La configuración opcional <a href="/docs/es/interactive-mode#check-spelling-as-you-type"><code>spellcheck</code></a> subraya las palabras mal escritas en la entrada del prompt mientras escribe, utilizando su <code>aspell</code>, <code>hunspell</code> o <code>ispell</code> instalado</div>
    <div>En una rama con una solicitud de fusión de GitLab abierta, con la CLI <code>glab</code> autenticada a través de <code>glab auth login</code>, el pie de página muestra una <a href="/docs/es/interactive-mode#gitlab-merge-requests">insignia <code>MR !N</code></a> coloreada según si la solicitud de fusión es un borrador, está abierta o es fusionable</div>
    <div>Cambie el nivel de esfuerzo desde su teléfono o claude.ai/code y se <a href="/docs/es/remote-control#what-connected-devices-see">aplica a la sesión en su máquina</a>; las sesiones de Remote Control alojadas por Desktop o VS Code también muestran a los dispositivos conectados el modo de permiso actual de la sesión</div>
    <div>Puede abrir <a href="/docs/es/permissions#manage-permissions"><code>/permissions</code></a> o ejecutar <code>/add-dir \<path></code> mientras Claude está trabajando; los cambios de reglas de permisos se aplican al resto del turno actual</div>
    <div>Cuando las tareas en segundo plano mantienen un <a href="/docs/es/goal#background-work-defers-evaluation"><code>/goal</code></a> esperando, Claude verifica después de 30 minutos en lugar de esperar indefinidamente y continúa verificando, en intervalos más largos mientras la sesión está inactiva; establezca <code>CLAUDE\_CODE\_GOAL\_CHECKIN\_MINUTES=0</code> para optar por no participar</div>
    <div>Sus propios prompts ahora representan markdown en la transcripción, con bloques de código resaltados, código en línea y listas, de la misma manera que las respuestas</div>
    <div>La nueva variable de entorno <a href="/docs/es/model-config#set-a-default-model-for-new-sessions"><code>ANTHROPIC\_DEFAULT\_MODEL</code></a> establece el modelo en el que comienzan las nuevas sesiones; una selección de <code>/model</code> aún la anula y persiste entre reinicios</div>
    <div>Con la entrada <code>notify\_when\_idle</code> en <code>SendMessage</code>, Claude puede pedirle a otra sesión de Claude Code en la misma máquina que <a href="/docs/es/cross-session-messaging#get-a-notice-when-another-session-goes-idle">envíe un aviso cuando se quede inactiva a continuación</a></div>
    <div>Establezca <a href="/docs/es/interactive-mode#make-ctrl-w-delete-back-to-whitespace"><code>keybindingFlavor</code></a> en <code>"readline"</code> para hacer que <code>Ctrl+W</code> en el prompt elimine hasta el espacio en blanco anterior, como lo hace Bash, en lugar de detenerse en puntuación como <code>/</code></div>
    <div>En Windows nativo, sus sesiones de Claude Code ahora pueden <a href="/docs/es/cross-session-messaging#availability">enviarse mensajes entre sí</a> con <code>SendMessage</code> y encontrarse entre sí con <code>ListAgents</code>, como en macOS y Linux</div>
    <div>Los ejecutores autohospedados aceptan `--defer-shutdown-max-min`, que <a href="/docs/es/self-hosted-environments-deploy#defer-the-drain-past-the-first-signal">continúa sirviendo sesiones adjuntas</a> durante un número establecido de minutos después de SIGTERM</div>
    <div>Los ejecutores autohospedados aceptan `--proxy-authorization-command` o `--proxy-authorization-file` para proporcionar un encabezado <code>Proxy-Authorization</code> nuevo para <a href="/docs/es/self-hosted-environments-deploy#authenticate-to-an-egress-proxy">proxies de salida que requieran uno</a></div>
  </div>
</div>
