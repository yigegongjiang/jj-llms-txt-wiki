# Semana 33 · 10–14 de agosto de 2026

> Claude Code Desktop continúa automáticamente después de que se restablece un límite de uso, el modo fork se activa de forma predeterminada, y las solicitudes de fusión de GitLab y los marketplaces se unen a GitHub.

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Continuación automática después de un límite de uso en Desktop</span>
    <span className="digest-feature-pill">Desktop</span>
  </div>

  <p className="digest-feature-lede">Cuando alcanza su límite de sesión en la pestaña Code de Claude Code Desktop, la tarjeta de límite ahora ofrece una casilla de verificación <strong>Continuar automáticamente cuando se restablezcan los límites</strong>. Márquela y la aplicación Desktop reintentará el turno interrumpido después del restablecimiento. La tarjeta muestra la hora de reintento. La tarjeta de límite semanal no la ofrece.</p>

  <p className="digest-feature-try">La próxima vez que aparezca una tarjeta de límite de sesión, marque <strong>Continuar automáticamente cuando se restablezcan los límites</strong> y deje la sesión abierta. La tarjeta muestra <code>Auto-resuming at</code> seguido de la hora de restablecimiento, y el turno se reanuda automáticamente una vez que se restablece el límite.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Modo fork activado de forma predeterminada</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">El modo fork ahora está activado de forma predeterminada en sesiones interactivas. Claude puede solicitar el tipo de subagente <code>fork</code>, que hereda la conversación completa y la caché de prompt en lugar de comenzar desde cero, por lo que no tiene que volver a explicar el contexto para una tarea secundaria. Los subagentes que Claude genera en sesiones interactivas, aparte de los que genera un compañero de equipo de agentes, también se ejecutan en segundo plano de forma predeterminada.</p>

  <p className="digest-feature-try">Inicie un fork usted mismo con una tarea que necesite todo lo que ha discutido hasta ahora:</p>

  ```text Claude Code theme={null}
  > /subtask draft unit tests for the parser changes so far
  ```

  <p className="digest-feature-try">El fork aparece en el panel debajo de su prompt y su resultado llega a su conversación cuando finaliza. Para desactivar el modo fork, establezca <code>CLAUDE\_CODE\_FORK\_SUBAGENT=0</code>.</p>

  <a className="digest-feature-link" href="/docs/es/sub-agents#turn-fork-mode-on-or-off">Activar o desactivar el modo fork</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Solicitudes de fusión de GitLab y marketplaces</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">Los marketplaces de plugins clonan URLs de <code>gitlab.com</code> desnudas, incluidos subgrupos anidados. En v2.1.233 o posterior, pase una URL de solicitud de fusión de GitLab a <code>--worktree</code> para ramificar desde ella, y la vista <code>claude agents</code> etiqueta sesiones vinculadas a una solicitud de fusión como <code>!N</code>. Claude Code también redacta familias de tokens de GitLab como <code>glpat-</code> y <code>glrt-</code>, y protege el almacén de configuración de la CLI <code>glab</code> de la misma manera que protege <code>gh</code>.</p>

  <p className="digest-feature-try">Inicie una sesión en un worktree ramificado desde una solicitud de fusión:</p>

  ```bash terminal theme={null}
  claude --worktree https://gitlab.com/group/project/-/merge_requests/42
  ```

  <p className="digest-feature-try">Cuando <code>origin</code> está en gitlab.com, Claude Code obtiene <code>merge-requests/42/head</code> y abre la sesión en esa rama en su propio worktree.</p>

  <a className="digest-feature-link" href="/docs/es/worktrees#branch-from-a-pull-request">Ramificar un worktree desde una solicitud de extracción o fusión</a>
</div>

  <div className="digest-wins-grid">
    <div>Escriba <code>@</code> en el prompt para <a href="/docs/es/cross-session-messaging#message-another-session">mencionar otra sesión de Claude</a> por nombre, y Claude la mensajea directamente con <code>SendMessage</code>; un nombre simple que coincida exactamente con una sesión activa ahora se entrega sin un paso de confirmación</div>
    <div>Las sesiones interactivas en una máquina mantienen <a href="/docs/es/cross-session-messaging#see-which-sessions-claude-can-reach">nombres únicos</a>: si inicia o cambia el nombre de una sesión con un nombre que otra sesión activa ya usa, Claude Code le da una variante <code>name-word-word</code> y se lo comunica</div>
    <div>Los marketplaces de plugins aceptan <a href="/docs/es/plugins/marketplace-reference#command-plugin-source">fuentes de <code>command</code></a>: un comando local imprime el directorio del plugin, que Claude Code re-resuelve cada sesión y aplica sin un reinicio</div>
    <div>En Linux y WSL, establezca <a href="/docs/es/tools-reference#memory-limit-on-linux-and-wsl"><code>CLAUDE\_CODE\_TOOL\_MEMORY\_LIMIT</code></a> a un tamaño como <code>4G</code> para limitar la memoria que los comandos de herramientas Bash y PowerShell pueden usar</div>
    <div>Las herramientas de seguimiento de tareas, como <code>TaskCreate</code>, <code>TaskUpdate</code> y <code>TodoWrite</code>, <a href="/docs/es/tools-reference#task-tool-availability">ya no están disponibles en Opus 4.8, Sonnet 5, Fable 5, Mythos 5 y modelos posteriores en esas familias</a>; establezca <code>CLAUDE\_CODE\_ENABLE\_TODO\_TOOLS=1</code> para volver a habilitarlas</div>
    <div><a href="/docs/es/code-review#review-a-diff-locally"><code>/code-review</code></a> en esfuerzo alto, xhigh y máximo ahora se ejecuta en un agente de fondo como los otros niveles</div>
    <div><a href="/docs/es/plugins/install#install-a-plugin"><code>/plugin install plugin\@marketplace</code></a> actualiza primero el marketplace, por lo que los plugins recién publicados se instalan sin una actualización manual del marketplace</div>
    <div>La configuración acepta <a href="/docs/es/settings-reference#marketplace-key-aliases"><code>additionalMarketplaces</code> y <code>allowedMarketplaces</code></a> como alias para <code>extraKnownMarketplaces</code> y <code>strictKnownMarketplaces</code></div>
    <div>En modelos más nuevos, Claude puede <a href="/docs/es/tools-reference#write-tool-behavior">sobrescribir un archivo existente con la herramienta Write</a> sin leerlo primero en esta sesión, coincidiendo con las reglas de la herramienta Edit; los modelos más antiguos requieren la lectura</div>
    <div>La extensión de VS Code puede <a href="/docs/es/vs-code#organize-sessions-into-groups">organizar la lista de sesiones en grupos</a>: haga clic derecho para crear, cambiar el nombre o eliminar un grupo, y Cmd/Ctrl- o Shift-click para mover varias sesiones a la vez</div>
    <div>Si su organización enruta Claude Code a través de una <a href="/docs/es/claude-apps-gateway-spend-limits">puerta de enlace de aplicaciones Claude con límites de gasto</a>, Claude Code muestra el período de límite, su hora de restablecimiento y el mensaje del operador cuando alcanza el límite</div>
