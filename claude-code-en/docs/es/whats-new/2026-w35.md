    <span className="digest-feature-pill">CLI</span>

  <p className="digest-feature-lede">Cuando una herramienta sigue fallando, Claude no puede ayudar con una solicitud, o usted señala un error, Claude ahora redacta un informe de comentarios para usted con la herramienta <code>SendFeedback</code>. Una tarjeta encima de su solicitud muestra el borrador, y puede revisarlo, enviarlo o descartarlo desde allí. Nada llega a Anthropic hasta que lo envíe. Requiere v2.1.238 o posterior.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Modo restringido</span>
    <span className="digest-feature-pill">v2.1.248</span>
  </div>

  <p className="digest-feature-lede">El modo restringido inicia Claude Code sin las herramientas integradas que ejecutan comandos o código. Úselo cuando un arnés de evaluación ejecute <code>claude</code> en una máquina compartida. Inicie con `--restricted` o establezca <code>CLAUDE\_CODE\_RESTRICTED=1</code>. Claude Code también elimina <code>WebFetch</code>, confina las herramientas de archivo a los directorios de trabajo, carga solo la configuración administrada y `--settings`, y rechaza el modo de permiso <code>bypassPermissions</code>.</p>

  <p className="digest-feature-try">Ejecute una consulta no interactiva sin las herramientas de ejecución de comandos:</p>

  ```bash terminal theme={null}
  claude --restricted -p "review src/ for SQL injection risks"
  ```

  <p className="digest-feature-try">Para darle a Claude una de las herramientas eliminadas, enumérela en `--tools` junto con las otras herramientas integradas que desee, por ejemplo `--tools "Bash,Read,Edit"`. `--tools` es una lista de permitidos, y su preestablecimiento <code>default</code> no restaura las herramientas eliminadas.</p>

  <a className="digest-feature-link" href="/docs/es/cli-reference#cli-flags">Indicadores de CLI</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">Otros logros</p>

  <div className="digest-wins-grid">
    <div>Establezca la nueva configuración <a href="/docs/es/settings-reference#modelpicker"><code>modelPicker</code></a> para extender o reemplazar la lista integrada del selector <code>/model</code> con sus propias entradas ordenadas y etiquetadas, incluidos los ID de modelo de Amazon Bedrock o de la Plataforma de Agentes de Google Cloud</div>
    <div>Establezca <a href="/docs/es/prompt-caching#choose-the-ttl-yourself"><code>promptCacheTtl</code></a> en <code>1h</code> para mantener una caché de solicitud de una hora en la conversación principal cuando use una clave de API o un proveedor de nube; <code>subagentPromptCacheTtl</code> establece el TTL para subagentes y todas las otras solicitudes fuera de la conversación principal</div>
    <div>En los planes Pro, Max, Team y Enterprise, <a href="/docs/es/costs#plan-usage-breakdown"><code>/usage</code></a> añade un desglose de Loops: recuento de ejecuciones, tokens totales, tokens por ejecución y última ejecución para <code>/loop</code> y tareas programadas que utilizaron la mayoría de tokens</div>
    <div>Las organizaciones con tasas contratadas pueden establecer la configuración administrada <a href="/docs/es/costs#report-spend-at-your-contracted-rates"><code>modelPricing</code></a> para que <code>/usage</code>, la línea de estado y OpenTelemetry reporten el costo en esas tasas en lugar del precio de lista</div>
    <div><code>/login</code> ofrece <strong>Inicie sesión con su cuenta de Console</strong> bajo la opción <strong>Cuenta de Anthropic Console</strong>, para que los miembros de organizaciones de Console que no permiten claves de API puedan iniciar sesión sin crear una</div>
    <div>Ejecute <code>/permissions</code> y abra la nueva <a href="/docs/es/auto-mode-config#edit-rules-from-permissions">pestaña <strong>Auto mode</strong></a> para ver y editar las reglas del clasificador de modo automático sin abrir un archivo de configuración</div>
    <div>Cuando el modo automático está disponible, los mensajes de permiso de Bash en los modos Manual y <code>acceptEdits</code> ofrecen una opción <a href="/docs/es/permission-modes#switch-permission-modes"><strong>Sí, y cambiar a modo automático</strong></a>; selecciónela para aprobar el comando y cambiar la sesión al modo automático</div>
    <div>Después de <a href="/docs/es/permissions#move-the-session-to-another-directory">mover una sesión con <code>/cd</code></a>, la configuración del proyecto del nuevo directorio, hooks, servidores <code>.mcp.json</code>, skills y subagentes entran en vigor inmediatamente en lugar de en el próximo `--resume`</div>
    <div>En sesiones no interactivas, incluidas ejecuciones de <code>-p</code>, ejecuciones de Agent SDK y sesiones en la nube, Claude Code <a href="/docs/es/errors#the-response-above-may-be-incomplete">continúa una respuesta</a> que un error del servidor, una conexión perdida o un estancamiento cortó a mitad de la transmisión, cuando la respuesta parcial contiene texto y sin llamadas de herramientas</div>
    <div>Un subagente que se detiene en su límite <code>maxTurns</code> devuelve su salida marcada como parcial, con una sugerencia de que Claude puede <a href="/docs/es/sub-agents#resume-subagents">continuarla con <code>SendMessage</code></a>, en lugar de parecer terminada</div>
    <div>En Amazon Bedrock, la Plataforma de Agentes de Google Cloud y Microsoft Foundry, las sesiones en la misma máquina ahora pueden <a href="/docs/es/cross-session-messaging#availability">mensajearse entre sí</a>, <code>/loop</code> puede <a href="/docs/es/scheduled-tasks#let-claude-choose-the-interval">elegir su propio intervalo</a>, y <code>/model</code> y <code>/effort</code> se aplican inmediatamente en lugar de después de que termine el turno</div>
    <div>El instalador nativo y el actualizador automático descargan una compilación comprimida con zstd, aproximadamente 75 MB en lugar de 340 MB en Linux x64, y las compilaciones nativas cargan código bajo demanda, utilizando aproximadamente 40 a 70 MB menos de memoria por sesión</div>
