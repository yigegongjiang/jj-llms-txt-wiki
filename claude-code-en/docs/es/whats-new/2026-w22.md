<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Plugin security-guidance</span>
    <span className="digest-feature-pill">plugin</span>
  </div>

  <p className="digest-feature-lede">El plugin security-guidance revisa los cambios de código de Claude en busca de vulnerabilidades y las corrige en la misma sesión. Ejecuta una verificación de patrones rápida en cada edición, una revisión de modelo al final de cada turno, y una revisión agéntica más profunda en commit o push. Añade reglas del proyecto en <code>.claude/claude-security-guidance.md</code>.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Otros logros</p>

  <div className="digest-wins-grid">
    <div>En <code>claude agents</code>, prefija un comando de shell con <code>!</code> para ejecutarlo como un trabajo en segundo plano al que puedes conectarte y desconectarte; también disponible como <code>claude --bg --exec 'pytest -x'</code></div>
    <div>Los plugins en directorios <code>.claude/skills</code> ahora se cargan automáticamente, sin necesidad de marketplace, y <code>claude plugin init \<name></code> genera un nuevo plugin</div>
    <div>El nuevo comando <code>/reload-skills</code> vuelve a escanear directorios de skills sin reiniciar, y los hooks <code>SessionStart</code> pueden devolver <code>reloadSkills: true</code> para que los skills que instalan estén disponibles en la misma sesión</div>
    <div>Los skills y comandos pueden establecer <code>disallowed-tools</code> en frontmatter para eliminar herramientas del modelo mientras el skill está activo</div>
    <div>El nuevo evento de hook <code>MessageDisplay</code> permite que los hooks transformen u oculten el texto del mensaje del asistente mientras se muestra</div>
    <div>Claude Code ahora cambia a tu <code>--fallback-model</code> configurado para el resto de la sesión cuando el modelo principal no se encuentra, en lugar de fallar en cada solicitud</div>
    <div>Los plugins pueden declarar <code>defaultEnabled: false</code> en <code>plugin.json</code> o una entrada de marketplace, para que se instalen sin activarse hasta que los habilites</div>
    <div>Modo Vim: <code>/</code> en modo NORMAL abre la búsqueda de historial inverso, coincidiendo con el modo vi de Bash y Zsh</div>
    <div>La ejecución de herramientas en streaming ahora siempre está habilitada, incluso con telemetría deshabilitada y en Amazon Bedrock, Agent Platform de Google Cloud, y Microsoft Foundry</div>
    <div><code>←←</code> para abrir la vista de agentes ahora funciona en Amazon Bedrock, Agent Platform de Google Cloud, Microsoft Foundry, y con telemetría deshabilitada</div>
    <div>Claude en Chrome: elige qué navegador conectado usar a través de <code>/chrome</code> → "Select browser…", o en el chat cuando se ejecuta una acción del navegador con múltiples conectados</div>
    <div><code>claude mcp list</code> y <code>claude mcp get</code> ahora muestran servidores <code>.mcp.json</code> no aprobados como pendientes de aprobación en lugar de aprobar automáticamente y conectar cuando la salida se canaliza</div>
  </div>
</div>
