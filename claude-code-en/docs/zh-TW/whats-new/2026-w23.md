# 第 23 週 · 2026 年 6 月 1–5 日

> 在 Amazon Bedrock、Google Cloud 的 Agent Platform 和 Microsoft Foundry 上執行自動模式，在 acceptEdits 模式下提示寫入可執行程式碼的檔案，使用 /plugin list 列出已安裝的外掛程式，以及為受管部署要求已核准的版本範圍。

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Amazon Bedrock、Google Cloud 的 Agent Platform 和 Microsoft Foundry 上的自動模式</span>
    <span className="digest-feature-pill">v2.1.158</span>
  </div>

  <p className="digest-feature-lede">自動模式現已在 Amazon Bedrock、Google Cloud 的 Agent Platform 和 Microsoft Foundry 上提供，適用於 Opus 4.7 和 Opus 4.8，以第三方提供者的背景安全檢查取代權限提示。透過設定 <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE=1</code> 來選擇加入。</p>

  <p className="digest-feature-try">在第三方提供者上選擇加入，然後使用 Shift+Tab 切換到自動模式：</p>

  ```bash terminal theme={null}
  export CLAUDE_CODE_ENABLE_AUTO_MODE=1
  ```

  <a className="digest-feature-link" href="/docs/docs/zh-TW/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">在第三方提供者上啟用自動模式</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">更安全的自動編輯</span>
    <span className="digest-feature-pill">v2.1.160</span>
  </div>

  <p className="digest-feature-lede">Claude Code 現在會在寫入可執行程式碼的檔案前提示，即使在 <code>acceptEdits</code> 模式下也是如此。受保護的集合涵蓋 shell 啟動檔案（例如 <code>.zshenv</code> 和 <code>.bash\_login</code>）、<code>\~/.config/git/</code> 下的 git 設定，以及建置工具設定（例如 <code>.npmrc</code>、<code>.bazelrc</code> 和 <code>.pre-commit-config.yaml</code>）。除了 <code>bypassPermissions</code> 模式外，這些寫入在任何模式下都不會自動核准。</p>

  <p className="digest-feature-try">在 acceptEdits 模式下工作；Claude 現在會在寫入這些檔案前暫停：</p>

  ```bash terminal theme={null}
  claude --permission-mode acceptEdits
  ```

  <a className="digest-feature-link" href="/docs/zh-TW/docs/permission-modes#protected-paths">受保護的路徑</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">使用 /plugin list 列出已安裝的外掛程式</span>
    <span className="digest-feature-pill">v2.1.163</span>
  </div>

  <p className="digest-feature-lede">新的 <code>/plugin list</code> 命令會內聯列印已安裝的外掛程式，無需開啟 <code>/plugin</code> 選單，也可從 shell 中以 <code>claude plugin list</code> 的形式使用。在互動形式中，新增 `--enabled` 或 `--disabled` 以僅顯示處於該狀態的外掛程式。</p>

  <p className="digest-feature-try">列出目前開啟的外掛程式：</p>

  ```text Claude Code theme={null}
  > /plugin list --enabled
  ```

  <a className="digest-feature-link" href="/docs/zh-TW/docs/plugins-reference#plugin-list">外掛程式命令</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">受管部署的版本要求</span>
    <span className="digest-feature-pill">v2.1.163</span>
  </div>

  <p className="digest-feature-lede">兩個受管設定 <code>requiredMinimumVersion</code> 和 <code>requiredMaximumVersion</code> 可讓您的組織要求已核准的 Claude Code 版本範圍。超出範圍的用戶端會在啟動時退出，並告知使用者透過組織的方法進行更新。<code>claude update</code>、<code>claude install</code> 和 <code>claude doctor</code> 會繼續運作，以便使用者仍可復原。</p>

  <p className="digest-feature-try">在受管設定中新增下限，以便較舊的用戶端拒絕啟動：</p>

  ```json managed-settings.json theme={null}
  {
    "requiredMinimumVersion": "2.1.163"
  }
  ```

  <a className="digest-feature-link" href="/docs/zh-TW/docs/admin-setup#decide-what-to-enforce">決定要強制執行的項目</a>
</div>
