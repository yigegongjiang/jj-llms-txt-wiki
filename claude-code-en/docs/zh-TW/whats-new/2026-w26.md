# 第 26 週 · 2026 年 6 月 22–26 日

> 使用 claude mcp login 從您的 shell 驗證 MCP 伺服器，使用 ! 前綴取得 shell 模式命令輸出的回應，以及使用 /rewind 從 /clear 之前恢復對話。

</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">從 CLI 驗證 MCP 伺服器</span>
    <span className="digest-feature-pill">v2.1.186</span>
  </div>

  <p className="digest-feature-lede">新的 `claude mcp login <name>` 和 `claude mcp logout <name>` 命令可從您的 shell 驗證已設定的 MCP 伺服器，而不是使用互動式 <code>/mcp</code> 選單。`claude mcp login` 直接執行伺服器的 OAuth 流程，而 `claude mcp logout` 會清除儲存的認證。</p>

  <p className="digest-feature-try">在不開啟工作階段的情況下執行已設定伺服器的 OAuth 流程：</p>

  ```bash terminal theme={null}
  claude mcp login sentry
  ```

  <a className="digest-feature-link" href="/docs/docs/zh-TW/mcp#authenticate-from-the-command-line">從命令列驗證</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Shell 模式回應命令輸出</span>
    <span className="digest-feature-pill">v2.1.186</span>
  </div>

  <p className="digest-feature-lede">您使用 <code>!</code> 前綴執行的命令現在會在輸出進入文字記錄後從 Claude 獲得回應，因此您可以執行 <code>! npm test</code> 並獲得失敗的說明，而無需第二個提示。回應成本與傳送一般提示相同。若要保持較早的行為（其中輸出被新增至內容而不獲得回應），請在 <code>settings.json</code> 中將 <code>respondToBashCommands</code> 設定為 <code>false</code>。</p>

  <p className="digest-feature-try">執行命令並取得其輸出的回應：</p>

  ```text Claude Code theme={null}
  > ! npm test
  ```

  <a className="digest-feature-link" href="/docs/docs/zh-TW/interactive-mode#shell-mode-with-prefix">使用 ! 前綴的 Shell 模式</a>
</div>

  <p className="digest-wins-title">其他改進</p>

  <div className="digest-wins-grid">
    <div><code>/rewind</code> 現在可以從執行 <code>/clear</code> 之前恢復對話</div>
    <div>新的 <code>sandbox.credentials</code> 設定會阻止沙箱化命令讀取認證檔案和祕密環境變數</div>
    <div>組織設定的模型限制現在適用於模型選擇器、`--model`、<code>/model</code> 和 <code>ANTHROPIC\_MODEL</code>，當選取受限制的模型時會顯示「受您組織的設定限制」訊息</div>
    <div>新的 <code>autoMode.classifyAllShell</code> 設定會將所有 Bash 和 PowerShell 命令路由通過自動模式分類器，拒絕原因現在會顯示在文字記錄、拒絕快顯通知和 <code>/permissions</code> 中</div>
    <div>新的 <code>claude\_code.assistant\_response</code> OpenTelemetry 日誌事件會攜帶模型的回應文字；已經記錄提示內容的部署在升級時會開始接收它，因此請設定 <code>OTEL\_LOG\_ASSISTANT\_RESPONSES=0</code> 以僅保留提示</div>
    <div>背景子代理現在會在主工作階段中顯示權限提示，而不是自動拒絕；對話框會顯示哪個代理在詢問，而 Esc 只會拒絕該工具</div>
    <div><code>/install-github-app</code> 現在可以僅安裝 GitHub App，並跳過 Actions 工作流程和祕密步驟</div>
    <div>您在沙箱網路權限對話框中允許的主機會在工作階段的其餘時間內被記住，而不是在每次連線時重新提示</div>
    <div>串流回應使用的 CPU 減少約 37%，而來自終端輸出快取的長工作階段記憶體成長已減少</div>
    <div>`/review <pr>` 現在使用與 <code>/code-review medium</code> 相同的審查引擎</div>
    <div>Bash 模式 <code>!</code> 命令獲得即時檔案路徑自動完成</div>
  </div>
</div>
