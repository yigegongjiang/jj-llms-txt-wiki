  <p className="digest-feature-lede"><code>/doctor</code> 現在可以診斷問題並修復它們，而不是列印唯讀報告。它檢查安裝健康狀況、尋找未使用的技能、MCP 伺服器和外掛程式與其背景成本、對本機 <code>CLAUDE.md</code> 檔案與簽入的檔案進行重複資料刪除、建議修剪 Claude 可以從程式碼庫衍生的 <code>CLAUDE.md</code> 內容，以及標記緩慢的 hooks。它首先報告發現，並在變更任何內容之前要求確認。<code>/checkup</code> 是其別名。</p>

  <p className="digest-feature-try">從任何工作階段執行檢查：</p>

  ```text Claude Code theme={null}
  > /doctor
  ```

    <div>代理程式檢視列現在顯示彩色狀態字和分類器撰寫的標題，而不是原始工具呼叫文字，編輯、合併、評論或推送到現有 PR 的工作階段會在 <code>claude agents</code> 中連結它</div>
    <div>自動更新二進位檔案下載現在串流到磁碟，而不是在記憶體中緩衝，將更新程式的尖峰記憶體使用量減少約 400 MB</div>
    <div>背景工作通知現在明確說明沒有發生人工輸入，防止虛構的文字記錄內核准被執行</div>
