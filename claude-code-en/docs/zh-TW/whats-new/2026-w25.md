  <p className="digest-feature-lede">拒絕和詢問權限規則現在可以使用 <code>Tool(param:value)</code> 語法比對工具的輸入參數。例如，<code>Agent(model:opus)</code> 比對要求 Opus 模型層級的子代理生成。該值接受 `*` 作為萬用字元，因此 `Agent(isolation:*)` 比對任何明確的隔離值。</p>

  <p className="digest-feature-try">在 <code>settings.json</code> 中將參數規則新增到拒絕清單：</p>

  ```json .claude/settings.json {3} theme={null}
  {
    "permissions": {
      "deny": ["Agent(model:opus)"]
    }
  }
  ```

<div className="digest-wins">
  <p className="digest-wins-title">其他成果</p>

  <div className="digest-wins-grid">
    <div>自動模式現在在您未要求捨棄本機工作時會阻止破壞性 git 命令（`git reset --hard`、`git clean -fd`、`git stash drop`），並在您未要求特定堆疊時阻止 <code>terraform destroy</code></div>
    <div>將新的 <code>attribution.sessionUrl</code> 設定設為 <code>false</code> 以在網頁和遠端控制工作階段中的提交和 PR 中省略 claude.ai 工作階段連結</div>
    <div>在 <code>/config</code> 介面中，Enter 和 Space 都會變更選定的設定，Esc 現在會儲存並關閉而不是還原</div>
    <div>新的 <code>sandbox.allowAppleEvents</code> 選擇加入設定讓沙箱命令在 macOS 上傳送 Apple Events</div>
    <div>將 <code>CLAUDE\_CLIENT\_PRESENCE\_FILE</code> 指向標記檔案以在您在機器上時抑制行動推播通知</div>
    <div>長段落現在逐行串流而不是等待第一個換行符</div>
    <div>API 連線在思考中斷開現在會自動重試，而不是顯示「思考時連線已關閉」</div>
    <div>設定 <code>CLAUDE\_CODE\_EXPERIMENTAL\_AGENT\_TEAMS=1</code> 時，每個工作階段都有一個隱含的團隊，因此您可以直接使用 Agent 工具的 <code>name</code> 參數生成隊友</div>
    <div>嵌套 <code>.claude/skills</code> 目錄中的技能在處理該處的檔案時會載入；在名稱衝突時，嵌套技能顯示為 `<dir>:<name>`，因此兩者都保持可用</div>
    <div>修正了提示快取在自訂 <code>ANTHROPIC\_BASE\_URL</code> 和 Foundry 上未讀取的問題</div>
    <div>修正了 Write 和 Edit 在網路磁碟機和雲端同步資料夾上產生零位元組或截斷檔案的問題</div>
  </div>
</div>
