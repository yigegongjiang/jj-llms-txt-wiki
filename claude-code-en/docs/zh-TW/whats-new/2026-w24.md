# 第 24 週 · 2026 年 6 月 8–12 日

> 使用 /cd 將工作階段移至新目錄、讓子代理程式產生自己的子代理程式，以及使用安全模式對損壞的設定進行故障排除。

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">使用 /cd 移動工作階段</span>
    <span className="digest-feature-pill">v2.1.169</span>
  </div>

  <p className="digest-feature-lede">新的 <code>/cd</code> 命令將目前的工作階段移至不同的工作目錄，而不需重建提示快取：新目錄的 <code>CLAUDE.md</code> 會作為訊息附加，而不是取代系統提示。工作階段會重新定位到新目錄的專案儲存空間，因此 `--resume` 和 `--continue` 會在該處找到它。如果您之前未在該目錄中工作過，Claude 會提示您信任該目錄。</p>

  <p className="digest-feature-try">將工作階段移至另一個專案而不重新啟動：</p>

  ```text Claude Code theme={null}
  > /cd ../other-project
  ```

  <a className="digest-feature-link" href="/docs/zh-TW/docs/commands#all-commands">命令參考</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">子代理程式可以產生子代理程式</span>
    <span className="digest-feature-pill">v2.1.172</span>
  </div>

  <p className="digest-feature-lede">子代理程式現在可以產生自己的子代理程式。提示下方的子代理程式面板顯示完整的樹狀結構：每一列都會顯示其後代的計數以及返回 <code>main</code> 的路徑。子代理程式鏈的深度上限為五層，以防止失控的並行樹狀結構。</p>

  <p className="digest-feature-try">開啟代理程式檢視以觀看工作展開時的巢狀樹狀結構：</p>

  ```text Claude Code theme={null}
  > /agents
  ```

  <a className="digest-feature-link" href="/docs/zh-TW/docs/sub-agents#spawn-nested-subagents">產生巢狀子代理程式</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">使用安全模式進行故障排除</span>
    <span className="digest-feature-pill">v2.1.169</span>
  </div>

  <p className="digest-feature-lede">使用 `--safe-mode` 啟動 Claude Code，或設定 <code>CLAUDE\_CODE\_SAFE\_MODE</code>，以在停用所有自訂項目的情況下啟動：<code>CLAUDE.md</code>、skills、plugins、hooks、MCP 伺服器以及自訂命令和代理程式不會載入。驗證、模型選擇、內建工具和權限仍然有效。如果問題在安全模式中消失，則其中一個介面是原因。</p>

  <p className="digest-feature-try">啟動乾淨的工作階段以隔離損壞的設定：</p>

  ```bash terminal theme={null}
  claude --safe-mode
  ```

  <a className="digest-feature-link" href="/docs/zh-TW/docs/debug-your-config#test-against-a-clean-configuration">針對乾淨的設定進行測試</a>
</div>
