> Use o modo automático no plano Pro e com Sonnet 4.6, veja quais skills, subagentes e servidores MCP impulsionam seus limites de plano em /usage, e revise diffs com o novo comando /code-review.

  <p className="digest-feature-lede">O modo automático agora está disponível no plano Pro e suporta Sonnet 4.6 junto com Opus. Ele substitui prompts de permissão por verificações de segurança em segundo plano: ações rotineiras são executadas sem interrompê-lo, e as destrutivas ou suspeitas são bloqueadas e exibidas.</p>

  <p className="digest-feature-try">Atualize Claude Code, depois alterne modos com Shift+Tab; o modo automático aparece quando sua conta atende aos requisitos:</p>

  ```bash terminal theme={null}
  claude update
  ```

<div className="digest-wins">
  <p className="digest-wins-title">Outras melhorias</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/pt/costs#track-your-costs"><code>/usage</code></a> agora mostra um detalhamento por categoria do que está impulsionando seus limites de plano, atribuindo o uso recente a skills, subagentes, plugins e servidores MCP individuais</div>
    <div>"Extra usage" foi renomeado para "usage credits" em toda a CLI, e <code>/extra-usage</code> agora é <code>/usage-credits</code>. O nome antigo ainda funciona.</div>
    <div>Novo comando <a href="/docs/pt/code-review"><code>/code-review</code></a> relata bugs de correção em um nível de esforço escolhido, como <code>/code-review high</code>, e <code>--comment</code> publica descobertas como comentários inline de PR do GitHub. <code>/simplify</code> permanece como uma revisão separada apenas de limpeza.</div>
    <div>Sessões em segundo plano agora aparecem em <code>/resume</code> junto com as interativas, marcadas com <code>bg</code>, e sessões fixadas com <code>Ctrl+T</code> em <code>claude agents</code> permanecem ativas quando ociosas</div>
    <div><code>claude agents --json</code> lista sessões ativas como JSON para scripts, como barras de status e seletores de sessão</div>
    <div>A ferramenta PowerShell agora está habilitada por padrão no Windows para usuários de Amazon Bedrock, Google Cloud's Agent Platform e Microsoft Foundry; desative com <code>CLAUDE\_CODE\_USE\_POWERSHELL\_TOOL=0</code></div>
    <div><code>claude plugin disable</code> agora recusa quando outro plugin habilitado depende do alvo, e <code>claude plugin enable</code> força a habilitação de dependências transitivas</div>
    <div>O painel de navegação do marketplace <code>/plugin</code> mostra o custo de contexto projetado, e as telas Discover e Browse listam os comandos, agentes, skills, hooks e servidores MCP/LSP de um plugin antes da instalação</div>
    <div>Nova configuração <code>worktree.bgIsolation: "none"</code> permite que sessões em segundo plano editem a cópia de trabalho diretamente sem <code>EnterWorktree</code>, para repositórios onde worktrees são impraticáveis</div>
    <div>A saída Markdown renderiza caixas de seleção de lista de tarefas GFM, e a visualização de detalhes <code>/diff</code> rola com o teclado</div>
    <div>A entrada JSON da linha de status agora inclui informações de repositório GitHub e PR quando detectadas</div>
    <div>Enterprise: a configuração gerenciada <code>allowAllClaudeAiMcps</code> carrega conectores MCP em nuvem claude.ai junto com <code>managed-mcp.json</code></div>
  </div>
</div>
