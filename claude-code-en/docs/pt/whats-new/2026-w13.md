<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Hooks condicionais</span>
    <span className="digest-feature-pill">v2.1.85</span>
  </div>

  <p className="digest-feature-lede">Hooks agora podem declarar um campo <code>if</code> usando sintaxe de regra de permissão. Sua verificação de pré-commit só é gerada para <code>Bash(git commit \*)</code> em vez de cada chamada bash, reduzindo a sobrecarga de processo em sessões ocupadas.</p>

  <p className="digest-feature-try">Escope um hook apenas para commits git:</p>

  ```json .claude/settings.json {5} theme={null}
  {
    "hooks": {
      "PreToolUse": [{
        "hooks": [{
          "if": "Bash(git commit *)",
          "type": "command",
          "command": ".claude/hooks/lint-staged.sh"
        }]
      }]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/pt/docs/hooks">Referência de hooks</a>
</div>
