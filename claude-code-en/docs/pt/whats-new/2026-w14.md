<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Substituição de tamanho de resultado MCP</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Autores de servidor MCP agora podem aumentar o limite de truncamento em uma ferramenta específica definindo <code>anthropic/maxResultSizeChars</code> na entrada <code>tools/list</code> da ferramenta, até um limite máximo de 500K caracteres. O limite costumava ser global, então ferramentas que ocasionalmente retornavam payloads inerentemente grandes como esquemas de banco de dados ou árvores de arquivos completas atingiam o limite padrão e eram persistidas em disco com uma referência de arquivo. Substituições por ferramenta mantêm esses resultados inline quando a ferramenta realmente precisa deles.</p>

  <p className="digest-feature-try">Anote a ferramenta na resposta <code>tools/list</code> do seu servidor:</p>

  ```json highlight={5} theme={null}
  {
    "name": "get_schema",
    "description": "Returns the full database schema",
    "_meta": {
      "anthropic/maxResultSizeChars": 500000
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/pt/docs/mcp#raise-the-limit-for-a-specific-tool">Referência MCP</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Executáveis de plugin no PATH</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">Coloque um executável em um diretório <code>bin/</code> na raiz do seu plugin e Claude Code adiciona esse diretório ao <code>PATH</code> da ferramenta Bash enquanto o plugin está ativado. Claude pode então invocar o binário como um comando simples de qualquer chamada de ferramenta Bash, sem necessidade de caminho absoluto ou script wrapper. Útil para empacotar auxiliares CLI ao lado dos comandos, agentes e hooks que os chamam.</p>

  <p className="digest-feature-try">Adicione um diretório <code>bin/</code> na raiz do plugin:</p>

  ```text highlight={4, 5} theme={null}
  my-plugin/
  ├── .claude-plugin/
  │   └── plugin.json
  └── bin/
      └── my-tool
  ```

  <a className="digest-feature-link" href="/docs/pt/docs/plugins-reference#file-locations-reference">Referência de plugins</a>
</div>
