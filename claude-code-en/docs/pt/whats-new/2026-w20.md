    <span className="digest-feature-pill">v2.1.139</span>

  <p className="digest-feature-lede">Defina uma condição de conclusão e Claude continua trabalhando em direção a ela entre turnos sem você solicitar cada etapa. Após cada turno, um modelo rápido verifica se a condição é atendida; se não, Claude inicia outro turno em vez de devolver o controle. Útil para trabalho substancial com um estado final verificável, como migrar um módulo até que cada site de chamada seja compilado e os testes passem. O objetivo é limpo uma vez que a condição é atendida e funciona em modo interativo, <code>-p</code> e Remote Control.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Fast mode on Opus 4.7</span>
    <span className="digest-feature-pill">visualização de pesquisa</span>
  </div>

  <p className="digest-feature-lede"><code>/fast</code> agora é executado no Opus 4.7 por padrão em vez do Opus 4.6. Fast mode é uma configuração Opus de alta velocidade: a mesma qualidade de modelo em aproximadamente 2,5x a velocidade por um custo por token mais alto, útil para iteração rápida e depuração ao vivo. O preço permanece inalterado em $30/$150 por MTok, o mesmo que o modo rápido do Opus 4.6. Para fixar o modo rápido no Opus 4.6, defina <code>CLAUDE\_CODE\_OPUS\_4\_6\_FAST\_MODE\_OVERRIDE=1</code>.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Outras vitórias</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code> ganhou sinalizadores de despacho (<code>--add-dir</code>, <code>--settings</code>, <code>--mcp-config</code>, <code>--plugin-dir</code>, <code>--permission-mode</code>, <code>--model</code>, <code>--effort</code>, <code>--dangerously-skip-permissions</code>) para configurar sessões em segundo plano, e <code>claude agents --cwd \<path></code> limita a lista de sessões a um diretório</div>
    <div>Novo hook <code>args: string\[]</code> forma exec gera o comando diretamente sem um shell, portanto os espaços reservados de caminho nunca precisam de aspas</div>
    <div>Nova opção de configuração <code>continueOnBlock</code> para hooks <code>PostToolUse</code> alimenta o motivo da rejeição do hook de volta para Claude e continua o turno em vez de encerrá-lo</div>
    <div>Novo campo <code>terminalSequence</code> na saída JSON do hook permite que hooks emitam notificações de desktop, títulos de janela e sinos sem um terminal controlador</div>
    <div>O menu Rewind adicionou "Summarize up to here" para compactar contexto anterior mantendo turnos recentes intactos</div>
    <div>Remote Control, <code>/schedule</code>, conectores MCP do Claude.ai e preferências de notificação agora são desabilitados quando <code>ANTHROPIC\_API\_KEY</code>, <code>apiKeyHelper</code> ou <code>ANTHROPIC\_AUTH\_TOKEN</code> está definido, mesmo junto com um login do Claude.ai; desdefina a chave de API para usar esses recursos</div>
    <div>Servidores stdio MCP agora recebem <code>CLAUDE\_PROJECT\_DIR</code> em seu ambiente, correspondendo a hooks, e configurações de plugin podem referenciar <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code> em comandos</div>
    <div><code>claude plugin details \<name></code> mostra o inventário de componentes de um plugin e o custo de token por sessão projetado, e o painel de detalhes <code>/plugin</code> agora também lista os servidores LSP que um plugin fornece</div>
    <div>Plugins com um <code>SKILL.md</code> no nível raiz e nenhum subdiretório <code>skills/</code> agora são exibidos como uma skill</div>
    <div><code>/feedback</code> agora pode incluir sessões recentes das últimas 24 horas ou 7 dias para problemas que abrangem mais do que a sessão atual</div>
    <div>A ferramenta de agente <code>subagent\_type</code> agora corresponde sem distinção de maiúsculas e separadores, portanto <code>"Code Reviewer"</code> resolve para <code>code-reviewer</code></div>
  </div>
</div>
