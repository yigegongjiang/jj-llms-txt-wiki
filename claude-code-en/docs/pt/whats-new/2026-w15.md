  <p className="digest-feature-lede">Inicie o modo de plano na nuvem a partir do seu terminal, depois revise o resultado no seu navegador. <div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Ferramenta Monitor</span>
    <span className="digest-feature-pill">v2.1.98</span>
  </div>

  <p className="digest-feature-lede">Uma nova ferramenta integrada que gera um observador em segundo plano e transmite seus eventos para a conversa: cada evento chega como uma nova mensagem de transcrição à qual Claude reage imediatamente. Acompanhe uma execução de treinamento, cuide de um CI de PR, ou corrija automaticamente uma falha do servidor de desenvolvimento no momento em que acontece, tudo sem um loop sleep do Bash mantendo a vez aberta.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/monitor-tool.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=f4156c15a0999de5c5157f54a3117c89" data-path="images/whats-new/monitor-tool.mp4" />
  </Frame>

  <p className="digest-feature-try">Peça a Claude para observar algo enquanto você continua trabalhando:</p>

  ```text Claude Code theme={null}
  > Tail server.log in the background and tell me the moment a 5xx shows up
  ```

  <p className="digest-feature-try">Isso funciona com <code>/loop</code>, que agora tem auto-pacing: omita o intervalo e Claude agenda o próximo tick com base na tarefa, ou recorre à ferramenta Monitor para pular a sondagem completamente.</p>

  ```text Claude Code theme={null}
  > /loop check CI on my PR
  ```

  <a className="digest-feature-link" href="/docs/pt/docs/tools-reference#monitor-tool">Referência da ferramenta Monitor</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">/autofix-pr</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">A correção automática de PR chegou à web na Semana 13. Agora você pode ativá-la sem sair do seu terminal: <code>/autofix-pr</code> infere o PR aberto para sua branch atual e ativa a correção automática para ele no Claude Code na web em uma única etapa. Envie sua branch, execute o comando, saia; Claude observa CI e comentários de revisão e envia correções até que fique verde.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Outras vitórias</p>

  <div className="digest-wins-grid">
    <div>Visualização de foco: pressione <code>Ctrl+O</code> no modo sem cintilação para recolher a visualização para seu último prompt, um resumo de ferramenta de uma linha com diffstats e a resposta final de Claude</div>
    <div>Assistentes de configuração guiados <a href="/docs/pt/docs/amazon-bedrock">Amazon Bedrock</a> e <a href="/docs/pt/docs/google-vertex-ai">Plataforma de Agentes do Google Cloud</a> na tela de login: escolha "plataforma de terceiros" para autenticação passo a passo, região, verificação de credenciais e fixação de modelo</div>
    <div><code>/agents</code> recebe um layout com abas: uma aba Running mostra subagentes ao vivo com uma contagem <code>● N running</code>, além de ações Run agent e View running instance na aba Library</div>
    <div>O nível de esforço padrão agora é <code>high</code> para usuários de chave de API, Amazon Bedrock, Plataforma de Agentes do Google Cloud, Microsoft Foundry, Team e Enterprise (controle com <code>/effort</code>)</div>
    <div><code>/cost</code> mostra um detalhamento por modelo e cache-hit para usuários de assinatura</div>
    <div><code>/release-notes</code> agora é um seletor de versão interativo</div>
    <div>Linha de status: nova configuração <code>refreshInterval</code> executa o comando a cada N segundos, e <code>workspace.git\_worktree</code> na entrada JSON</div>
    <div><code>CLAUDE\_CODE\_PERFORCE\_MODE</code>: Edit/Write falham em arquivos somente leitura com uma dica <code>p4 edit</code> em vez de sobrescrever silenciosamente</div>
    <div>O armazenamento de certificados CA do SO agora é confiável por padrão, portanto proxies TLS corporativos funcionam sem configuração extra (<code>CLAUDE\_CODE\_CERT\_STORE=bundled</code> para desativar)</div>
    <div>Amazon Bedrock alimentado por Mantle: defina <code>CLAUDE\_CODE\_USE\_MANTLE=1</code></div>
    <div>Permissões de ferramenta Bash endurecidas: sinalizadores com escape de barra invertida, prefixos de variáveis de ambiente, redirecionamentos <code>/dev/tcp</code> e comandos compostos agora solicitam corretamente</div>
    <div>Hooks <code>UserPromptSubmit</code> podem definir o título da sessão via <code>hookSpecificOutput.sessionTitle</code></div>
  </div>
</div>
