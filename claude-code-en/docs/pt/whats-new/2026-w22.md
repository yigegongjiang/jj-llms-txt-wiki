Gerencie execuções com <code>/workflows</code>.</p>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Security guidance plugin</span>
    <span className="digest-feature-pill">plugin</span>
  </div>

  <p className="digest-feature-lede">O plugin security-guidance revisa as alterações de código do Claude em busca de vulnerabilidades e as corrige na mesma sessão. Ele executa uma verificação de padrão rápida em cada edição, uma revisão de modelo no final de cada turno e uma revisão agêntica mais profunda ao fazer commit ou push. Adicione regras de projeto em <code>.claude/claude-security-guidance.md</code>.</p>

<div className="digest-wins">
  <p className="digest-wins-title">Outras melhorias</p>

  <div className="digest-wins-grid">
    <div>Em <code>claude agents</code>, prefixe um comando shell com <code>!</code> para executá-lo como um trabalho em segundo plano que você pode anexar e desanexar; também disponível como <code>claude --bg --exec 'pytest -x'</code></div>
    <div>Plugins em diretórios <code>.claude/skills</code> agora são carregados automaticamente, sem necessidade de marketplace, e <code>claude plugin init \<name></code> cria um novo plugin</div>
    <div>Novo comando <code>/reload-skills</code> verifica novamente os diretórios de skills sem reiniciar, e hooks <code>SessionStart</code> podem retornar <code>reloadSkills: true</code> para disponibilizar skills que instalam na mesma sessão</div>
    <div>Skills e comandos podem definir <code>disallowed-tools</code> no frontmatter para remover ferramentas do modelo enquanto o skill está ativo</div>
    <div>Novo evento de hook <code>MessageDisplay</code> permite que hooks transformem ou ocultam o texto da mensagem do assistente conforme é exibido</div>
    <div>Claude Code agora muda para seu <code>--fallback-model</code> configurado para o resto da sessão quando o modelo primário não é encontrado, em vez de falhar em cada solicitação</div>
    <div>Plugins podem declarar <code>defaultEnabled: false</code> em <code>plugin.json</code> ou em uma entrada de marketplace, para que sejam instalados sem ativar até que você os habilite</div>
    <div>Modo Vim: <code>/</code> em modo NORMAL abre a busca de histórico reverso, correspondendo ao vi-mode do Bash e Zsh</div>
    <div>A execução de ferramentas em streaming agora está sempre ativada, incluindo com telemetria desativada e no Amazon Bedrock, Google Cloud's Agent Platform e Microsoft Foundry</div>
    <div><code>←←</code> para abrir a visualização de agentes agora funciona no Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry e com telemetria desativada</div>
    <div>Claude no Chrome: escolha qual navegador conectado usar via <code>/chrome</code> → "Select browser…", ou no chat quando uma ação do navegador é executada com múltiplos conectados</div>
    <div><code>claude mcp list</code> e <code>claude mcp get</code> agora mostram servidores <code>.mcp.json</code> não aprovados como pendentes de aprovação em vez de aprovar automaticamente e conectar quando a saída é canalizada</div>
  </div>
</div>
