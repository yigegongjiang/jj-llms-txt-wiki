  <div className="digest-wins-grid">
    <div><a href="/docs/pt/docs/interactive-mode#vim-editor-mode">Modo visual Vim</a>: pressione <code>v</code> para seleção de caracteres ou <code>V</code> para seleção de linhas na entrada de prompt, com operadores e feedback visual</div>
    <div>Hooks agora podem chamar ferramentas MCP diretamente via <a href="/docs/pt/docs/hooks#mcp-tool-hook-fields"><code>type: "mcp\_tool"</code></a>, então um hook pode acessar um servidor já conectado sem gerar um processo</div>
    <div><code>/cost</code> e <code>/stats</code> são mesclados em <a href="/docs/pt/docs/commands"><code>/usage</code></a>; os nomes antigos ainda funcionam como atalhos de digitação que abrem a aba relevante</div>
    <div>Mudanças em <code>/config</code> (tema, modo de editor, verbose e similares) agora persistem em <code>\~/.claude/settings.json</code> e seguem a mesma precedência projeto/local/política que outras <a href="/docs/pt/docs/settings">configurações</a></div>
    <div><a href="/docs/pt/docs/sub-agents#fork-the-current-conversation">Subagentes bifurcados</a> podem ser ativados em compilações externas com <code>CLAUDE\_CODE\_FORK\_SUBAGENT=1</code>: uma bifurcação herda seu contexto de conversa completo em vez de começar do zero</div>
    <div>O <a href="/docs/pt/docs/model-config#adjust-effort-level">nível de esforço</a> padrão para assinantes Pro e Max em Opus 4.6 e Sonnet 4.6 agora é <code>high</code> (era <code>medium</code>)</div>
    <div>Compilações nativas macOS e Linux substituem as ferramentas <code>Glob</code> e <code>Grep</code> por <code>bfs</code> e <code>ugrep</code> incorporados disponíveis através de Bash, para buscas mais rápidas sem uma rodada de ferramenta separada</div>
    <div><code>--from-pr</code> agora aceita URLs de solicitação de mesclagem GitLab, solicitação de pull Bitbucket e PR do GitHub Enterprise além de github.com</div>
    <div>Modo Auto: inclua <code>"\$defaults"</code> em <a href="/docs/pt/docs/auto-mode-config"><code>autoMode.allow</code>, <code>soft\_deny</code>, ou <code>environment</code></a> para adicionar regras personalizadas ao lado da lista integrada em vez de substituí-la</div>
    <div>Novo comando <a href="/docs/pt/docs/plugin-dependencies#tag-plugin-releases-for-version-resolution"><code>claude plugin tag</code></a> cria tags git de lançamento para plugins com validação de versão</div>
    <div>Sessões Opus 4.7 agora computam contra a janela de contexto nativa de 1M do modelo, corrigindo percentuais inflados de <code>/context</code> e autocompactação prematura</div>
    <div><code>/resume</code> em sessões grandes é até 67% mais rápido e agora oferece resumir sessões grandes e obsoletas antes de relê-las</div>
