# 29주차 · 2026년 7월 13–17일

  <p className="digest-feature-lede">스크린 리더 모드는 시각적 터미널 인터페이스를 일반 선형 텍스트로 바꿉니다. 상자, 스피너, 제자리 다시 그리기 대신 Claude Code는 VoiceOver 또는 NVDA와 같은 스크린 리더가 순서대로 읽을 수 있는 레이블이 지정된 줄을 인쇄하므로, 권한을 승인하고 출력을 끝에서 끝까지 검토할 수 있습니다. 플래그로 세션당, <code>CLAUDE\_AX\_SCREEN\_READER</code> 환경 변수로 셸당, 또는 <code>axScreenReader</code> 설정으로 모든 곳에서 켤 수 있습니다.</p>

  <p className="digest-feature-try">스크린 리더 모드에서 세션을 시작합니다:</p>

  ```bash terminal theme={null}
  claude --ax-screen-reader
  ```

  <a className="digest-feature-link" href="/docs/ko/accessibility#turn-on-screen-reader-mode">스크린 리더 모드 켜기</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><code>/fork</code>는 이제 대화를 <code>claude agents</code>에서 자신의 행을 가진 새로운 백그라운드 세션으로 복사하면서 계속 작업할 수 있습니다. 이전에 시작했던 세션 내 포크된 서브에이전트는 이제 <code>/subtask</code>입니다</div>
    <div><a href="/docs/ko/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">자동 모드</a>는 더 이상 Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry에서 <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE</code> 옵트인이 필요하지 않습니다. 관리자는 <code>disableAutoMode</code>로 이를 끌 수 있습니다</div>
    <div>2분 이상 실행되는 MCP 도구 호출은 이제 자동으로 백그라운드로 이동하므로 세션이 사용 가능한 상태로 유지됩니다. <code>CLAUDE\_CODE\_MCP\_AUTO\_BACKGROUND\_MS</code>로 임계값을 조정하거나 비활성화합니다</div>
    <div>새로운 <code>claude auto-mode reset</code>은 기본 자동 모드 구성을 복원하며, `--yes`는 확인 프롬프트를 건너뜁니다</div>
    <div>새로운 <a href="/docs/ko/corporate-launcher">corporate launcher</a> 지원: <code>CLAUDE\_CODE\_PROCESS\_WRAPPER</code> 또는 <code>processWrapper</code> 설정은 Claude Code가 자신의 바이너리에서 시작하는 프로세스(예: 백그라운드 서비스 및 에이전트 보기 세션)를 필수 래퍼 실행 파일을 통해 실행합니다</div>
    <div><code>vimInsertModeRemaps</code> 설정은 vim 모드에서 <code>jj</code>와 같은 2키 삽입 모드 시퀀스를 Escape에 매핑합니다</div>
    <div>`--forward-subagent-text` 및 <code>CLAUDE\_CODE\_FORWARD\_SUBAGENT\_TEXT</code>는 <a href="/docs/ko/headless">stream-json 출력</a>에 서브에이전트 텍스트 및 사고 블록을 포함합니다</div>
    <div>세션 전체 상한선은 폭주 루프를 중지합니다. WebSearch 호출 및 서브에이전트 생성은 각각 기본값 200이며, <code>CLAUDE\_CODE\_MAX\_WEB\_SEARCHES\_PER\_SESSION</code> 및 <code>CLAUDE\_CODE\_MAX\_SUBAGENTS\_PER\_SESSION</code>으로 조정 가능합니다</div>
    <div>"항상 허용" 권한 규칙은 저장소 루트에 저장되므로, git worktree에서 부여된 승인은 세션 및 worktree 전체에서 유지됩니다</div>
    <div>Amazon Bedrock, Google Cloud의 Agent Platform, AWS의 Claude Platform은 이제 기본값으로 Claude Opus 4.8을 사용합니다</div>
    <div>축소된 도구 요약 줄은 라이브 경과 시간 카운터를 표시하므로, 오래 실행되는 도구 호출이 고정된 것처럼 보이지 않고 눈에 띄게 진행됩니다</div>
  </div>
