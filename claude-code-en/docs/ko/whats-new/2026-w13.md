  <p className="digest-feature-lede">자동 모드는 권한 프롬프트를 분류기에 넘깁니다. 안전한 편집과 명령은 중단 없이 실행되고, 파괴적이거나 의심스러운 작업은 차단되어 표시됩니다. 모든 파일 쓰기를 승인하는 것과 <code>--dangerously-skip-permissions</code>로 실행하는 것 사이의 중간 지점입니다.</p>

    <img src="https://mintcdn.com/claude-code/CfffsX01JHFnIKvD/images/whats-new/auto-mode.png?fit=max&auto=format&n=CfffsX01JHFnIKvD&q=85&s=367c9e9d4ba5bc57ec4b935154bf1fbb" alt="Claude Code 프롬프트 푸터에 노란색으로 표시된 '자동 모드 켜짐(Shift+Tab으로 순환)' 표시기" width="2400" height="691" data-path="images/whats-new/auto-mode.png" />
  </Frame>

  <p className="digest-feature-try">Shift+Tab으로 자동 모드로 순환하거나 기본값으로 설정합니다:</p>

  ```json ~/.claude/settings.json {3} theme={null}
  {
    "permissions": {
      "defaultMode": "auto"
    }
  }
  ```

  <p className="digest-feature-try">트랜스크립트 모드를 열고 검색합니다:</p>

  ```text Claude Code theme={null}
  Ctrl+O    # open transcript
  /migrate  # search for "migrate"
  n         # next match
  N         # previous match
  ```

  <p className="digest-feature-lede">Windows는 Bash와 함께 기본 PowerShell 도구를 얻습니다. Claude는 cmdlet을 실행하고, 객체를 파이프하고, Git Bash를 통해 모든 것을 변환하지 않고 Windows 기본 경로로 작업할 수 있습니다.</p>

  <p className="digest-feature-try">설정에서 옵트인합니다:</p>

  ```json .claude/settings.json {3} theme={null}
  {
    "env": {
      "CLAUDE_CODE_USE_POWERSHELL_TOOL": "1"
    }
  }
  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">조건부 hooks</span>
    <span className="digest-feature-pill">v2.1.85</span>
  </div>

  <p className="digest-feature-lede">Hooks는 이제 권한 규칙 구문을 사용하여 <code>if</code> 필드를 선언할 수 있습니다. 사전 커밋 검사는 모든 bash 호출 대신 <code>Bash(git commit \*)</code>에 대해서만 생성되어 바쁜 세션에서 프로세스 오버헤드를 줄입니다.</p>

  <p className="digest-feature-try">git 커밋만으로 hook의 범위를 지정합니다:</p>

  ```json .claude/settings.json {5} theme={null}
  {
    "hooks": {
      "PreToolUse": [{
        "hooks": [{
          "if": "Bash(git commit *)",
          "type": "command",
          "command": ".claude/hooks/lint-staged.sh"
        }]
      }]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/ko/docs/hooks">Hooks 참조</a>
</div>
