# 21주차 · 2026년 5월 18–22일

> Pro 플랜에서 자동 모드를 사용하고 Sonnet 4.6을 지원하며, /usage에서 플랜 한도를 주도하는 스킬, 서브에이전트, MCP 서버를 확인하고, 새로운 /code-review 명령으로 diff를 검토합니다.

  ```bash terminal theme={null}
  claude update
  ```

  <div className="digest-wins-grid">
    <div><a href="/docs/ko/costs#track-your-costs"><code>/usage</code></a>는 이제 플랜 한도를 주도하는 요소를 카테고리별로 분류하여 표시하며, 최근 사용량을 스킬, 서브에이전트, 플러그인 및 개별 MCP 서버에 귀속시킵니다</div>
    <div>"Extra usage"는 CLI 전체에서 "usage credits"로 이름이 변경되었으며, <code>/extra-usage</code>는 이제 <code>/usage-credits</code>입니다. 이전 이름도 계속 작동합니다.</div>
    <div>새로운 <a href="/docs/ko/code-review"><code>/code-review</code></a> 명령은 <code>/code-review high</code>와 같은 선택한 노력 수준에서 정확성 버그를 보고하며, <code>--comment</code>는 결과를 인라인 GitHub PR 댓글로 게시합니다. <code>/simplify</code>는 별도의 정리 전용 검토로 유지됩니다.</div>
    <div>백그라운드 세션은 이제 <code>/resume</code>에 대화형 세션과 함께 나타나며 <code>bg</code>로 표시되고, <code>claude agents</code>에서 <code>Ctrl+T</code>로 고정된 세션은 유휴 상태일 때도 유지됩니다</div>
    <div><code>claude agents --json</code>은 상태 표시줄 및 세션 선택기와 같은 스크립팅을 위해 라이브 세션을 JSON으로 나열합니다</div>
    <div>PowerShell 도구는 이제 Amazon Bedrock, Google Cloud의 Agent Platform 및 Microsoft Foundry 사용자를 위해 Windows에서 기본적으로 활성화되며, <code>CLAUDE\_CODE\_USE\_POWERSHELL\_TOOL=0</code>으로 옵트아웃할 수 있습니다</div>
    <div><code>claude plugin disable</code>은 이제 다른 활성화된 플러그인이 대상에 의존할 때 거부하며, <code>claude plugin enable</code>은 전이적 종속성을 강제로 활성화합니다</div>
    <div><code>/plugin</code> 마켓플레이스 찾아보기 창은 예상 컨텍스트 비용을 표시하며, Discover 및 Browse 화면은 설치 전에 플러그인의 명령, 에이전트, 스킬, 훅 및 MCP/LSP 서버를 나열합니다</div>
    <div>새로운 <code>worktree.bgIsolation: "none"</code> 설정을 사용하면 백그라운드 세션이 <code>EnterWorktree</code> 없이 작업 복사본을 직접 편집할 수 있으며, worktree가 비실용적인 저장소의 경우입니다</div>
    <div>Markdown 출력은 GFM 작업 목록 체크박스를 렌더링하며, <code>/diff</code> 상세 보기는 키보드로 스크롤합니다</div>
    <div>상태 라인 JSON 입력은 이제 감지될 때 GitHub 저장소 및 PR 정보를 포함합니다</div>
    <div>엔터프라이즈: <code>allowAllClaudeAiMcps</code> 관리 설정은 <code>managed-mcp.json</code>과 함께 claude.ai 클라우드 MCP 커넥터를 로드합니다</div>
