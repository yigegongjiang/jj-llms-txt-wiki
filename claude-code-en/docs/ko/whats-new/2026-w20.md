# 20주차 · 2026년 5월 11–15일

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code>는 백그라운드 세션을 구성하기 위한 발송 플래그(<code>--add-dir</code>, <code>--settings</code>, <code>--mcp-config</code>, <code>--plugin-dir</code>, <code>--permission-mode</code>, <code>--model</code>, <code>--effort</code>, <code>--dangerously-skip-permissions</code>)를 얻었으며, <code>claude agents --cwd \<path></code>는 세션 목록을 디렉토리로 범위 지정합니다</div>
    <div>새로운 훅 <code>args: string\[]</code> exec 형식은 셸 없이 명령을 직접 생성하므로 경로 자리 표시자는 절대 따옴표가 필요하지 않습니다</div>
    <div><code>PostToolUse</code> 훅에 대한 새로운 <code>continueOnBlock</code> 구성 옵션은 훅의 거부 이유를 Claude에게 다시 피드하고 턴을 종료하는 대신 계속합니다</div>
    <div>훅 JSON 출력의 새로운 <code>terminalSequence</code> 필드를 사용하면 훅이 제어 터미널 없이 데스크톱 알림, 창 제목 및 벨을 내보낼 수 있습니다</div>
    <div>Rewind 메뉴에 "여기까지 요약"이 추가되어 최근 턴을 유지하면서 이전 컨텍스트를 압축합니다</div>
    <div>Remote Control, <code>/schedule</code>, Claude.ai MCP 커넥터 및 알림 기본 설정은 <code>ANTHROPIC\_API\_KEY</code>, <code>apiKeyHelper</code> 또는 <code>ANTHROPIC\_AUTH\_TOKEN</code>이 설정되면 Claude.ai 로그인과 함께 비활성화됩니다. API 키를 설정 해제하여 이러한 기능을 사용합니다</div>
    <div>MCP stdio 서버는 이제 훅과 일치하는 환경에서 <code>CLAUDE\_PROJECT\_DIR</code>을 수신하며, 플러그인 구성은 명령에서 <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code>을 참조할 수 있습니다</div>
    <div><code>claude plugin details \<name></code>은 플러그인의 구성 요소 인벤토리 및 예상 세션당 토큰 비용을 표시하며, <code>/plugin</code> 세부 정보 창은 이제 플러그인이 제공하는 LSP 서버도 나열합니다</div>
    <div>루트 수준 <code>SKILL.md</code>가 있고 <code>skills/</code> 하위 디렉토리가 없는 플러그인은 이제 기술로 표시됩니다</div>
    <div><code>/feedback</code>는 이제 현재 세션보다 더 오래 지속되는 문제에 대해 지난 24시간 또는 7일의 최근 세션을 포함할 수 있습니다</div>
    <div>에이전트 도구 <code>subagent\_type</code>은 이제 대소문자 및 구분 기호를 구분하지 않으므로 <code>"Code Reviewer"</code>는 <code>code-reviewer</code>로 확인됩니다</div>
  </div>
</div>
