<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Claude Security 플러그인</span>
    <span className="digest-feature-pill">플러그인</span>
  </div>

  <p className="digest-feature-lede">Claude Security 플러그인은 Claude Code 세션 내에서 코드베이스의 다중 에이전트 취약점 스캔을 실행합니다. 에이전트는 아키텍처를 매핑하고, 위협 모델을 구축하고, 취약점을 찾고, 모든 발견 사항을 독립적으로 검토한 후 보고서를 <code>CLAUDE-SECURITY-\<timestamp>/</code> 디렉토리에 작성합니다. 전체 저장소 또는 브랜치의 diff, 풀 요청 또는 단일 커밋만 스캔한 다음 선택한 발견 사항을 검토된 패치로 변환하여 직접 적용합니다.</p>

  <p className="digest-feature-try">공식 Anthropic 마켓플레이스에서 플러그인을 설치하고 <code>/reload-plugins</code>를 실행한 다음 <code>/claude-security</code>로 스캔을 시작하십시오:</p>

  ```text Claude Code theme={null}
  > /plugin install claude-security@claude-plugins-official
  ```

  <a className="digest-feature-link" href="/docs/ko/claude-security#scan-and-fix-your-codebase">코드베이스 스캔 및 수정</a>
</div>

    <div><code>/verify</code>, <code>/code-review</code> 및 <code>/deep-research</code>는 호출할 때만 실행됩니다. Claude는 더 이상 자동으로 실행하지 않습니다</div>
    <div><a href="/docs/ko/interactive-mode#emoji-shortcodes">이모지 단축코드</a>는 프롬프트 입력에서 자동 완성됩니다. <code>:heart:</code>를 입력하여 이모지를 삽입하거나 <code>:</code> 뒤에 2개 이상의 문자를 입력하여 제안을 받으십시오. <code>emojiCompletionEnabled</code>로 끌 수 있습니다</div>
    <div><code>context: fork</code>가 있는 Skills는 <a href="/docs/ko/skills#run-skills-in-a-subagent">기본적으로 백그라운드에서</a> 실행되며, 스킬의 frontmatter에서 <code>background: false</code>는 같은 턴에서 결과를 기다립니다</div>
    <div>세션은 기본적으로 최대 20개의 서브에이전트를 동시에 실행합니다. <code>CLAUDE\_CODE\_MAX\_CONCURRENT\_SUBAGENTS</code>로 <a href="/docs/ko/sub-agents#concurrent-subagent-limit">제한</a>을 변경하십시오</div>
    <div>`--max-budget-usd`는 이제 서브에이전트에 대한 상한을 적용합니다. 지출이 도달하면 Claude는 더 이상 시작할 수 없고 실행 중인 백그라운드 서브에이전트가 중지됩니다</div>
    <div>새로운 <a href="/docs/ko/sandboxing#disable-filesystem-isolation"><code>sandbox.filesystem.disabled</code></a> 설정은 네트워크 송신 제어를 유지하면서 파일 시스템 격리를 건너뜁니다</div>
    <div>자동 모드에서 위험한 <code>rm</code> 명령, 백그라운드 작업 및 의심스러운 Windows 경로에 대한 확인은 더 이상 권한 대화를 열지 않습니다. 자동 모드 분류기가 대신 판정합니다</div>
    <div>Bash 권한 확인은 파일 설명자 리디렉션, <code>\[\[ ]]</code> 비교의 Zsh 변수 첨자, 안전하지 않은 옵션을 실행할 수 있는 <code>help</code> 및 <code>man</code> 호출, 10,000자를 초과하는 명령을 포함한 더 많은 셸 형식에서 실패합니다</div>
    <div><a href="/docs/ko/fast-mode">Fast 모드</a>는 더 이상 Opus 4.7을 지원하지 않습니다. <code>/fast</code>는 이제 Opus 5 및 Opus 4.8에 적용됩니다</div>
    <div>장시간 실행되는 도구 호출은 침묵하는 대신 주기적인 진행 상황 하트비트를 내보냅니다</div>
