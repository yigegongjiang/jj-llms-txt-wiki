# 32주차 · 2026년 8월 3–7일

> Claude Code 세션이 서로 메시지를 주고받으며, 자체 호스팅 환경이 클라우드 세션을 사용자의 인프라에서 실행하고, 자동 모드가 기본 권한 모드가 됩니다.

  <p className="digest-feature-lede">Claude Code 세션이 이제 서로 메시지를 보낼 수 있습니다. Claude는 <code>ListAgents</code> 도구로 다른 세션을 발견하고 <code>SendMessage</code>로 메시지를 보냅니다. 사용자가 요청할 때 또는 한 세션의 변경 사항이 다른 세션의 작업에 영향을 미칠 때처럼 자동으로 메시지를 보낼 수 있습니다. 메시지는 Claude가 다른 세션을 위해 작성한 텍스트이며, 대화 기록이나 파일은 절대 포함되지 않습니다. macOS 및 Linux에서 사용 가능합니다. v2.1.224 이상이 필요합니다.</p>

  ```text title="Claude Code" wrap theme={null}
  Tell the session working on the payments API that users.name is now users.display_name
  ```

  <p className="digest-feature-try">다른 세션에서는 Claude가 메시지를 읽으면 <code>Message from</code> 행이 표시됩니다. <code>Ctrl+O</code>을 눌러 확장할 수 있습니다. Claude가 도달할 수 있는 세션을 확인하려면 <code>/list-agents</code>를 실행하세요.</p>

  <p className="digest-feature-lede">자체 호스팅 환경은 Claude Code 클라우드 세션을 조직의 자체 인프라에서 실행하며, Team 및 Enterprise 플랜에서 공개 베타로 제공됩니다. 머신이나 컨테이너에서 <code>claude self-hosted-runner</code>를 실행하여 이들을 러너로 변환합니다. 누군가 claude.ai, 모바일 또는 데스크톱 앱, 또는 `claude --cloud`에서 세션을 시작할 때 사용자의 환경을 선택하면, 해당 세션은 사용자의 네트워크 내에서 실행되며 내부 서비스에 액세스할 수 있습니다. Owner는 먼저 <a href="https://claude.ai/admin-settings/cloud-environments">관리자 설정</a>에서 <strong>자체 호스팅 환경 허용</strong>을 켜야 합니다.</p>

  <p className="digest-feature-try">Owner로 로그인한 상태에서 안내식 설정을 실행하면, 환경 생성을 안내하고 러너를 시작합니다:</p>

  ```bash terminal theme={null}
  claude self-hosted-runner setup
  ```

  <p className="digest-feature-try">러너가 등록되면 관리자 설정에서 환경이 <strong>정상</strong>으로 표시됩니다.</p>

  <p className="digest-feature-lede">8월 14일부터 자동 모드는 Pro, Max 및 Team 플랜의 새 세션에 대한 기본 권한 모드입니다. 기본 모드를 직접 설정한 경우, 일회성 전환 프롬프트를 수락하지 않는 한 유지되며, 조직에서 관리하는 기본값은 변경되지 않습니다. 언제든지 모드를 전환할 수 있습니다. 이미 해당 플랜에서 적용 중인 사항: 자동 모드가 수행하는 분류기 호출은 더 이상 사용량 제한에 포함되지 않습니다.</p>

  <p className="digest-feature-try">전환 전에 모든 세션을 자동 모드로 시작하려면, 사용자 설정에서 기본값으로 설정하세요:</p>

  ```json ~/.claude/settings.json {3} theme={null}
  {
    "permissions": {
      "defaultMode": "auto"
    }
  }
  ```

  <p className="digest-feature-try">새 세션은 상태 표시줄에 <code>auto mode on</code>을 표시합니다.</p>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div>VS Code 확장이 <a href="/docs/ko/vs-code#extension-settings">포커스 보기</a>를 제공하며, 이는 도구 활동을 턴당 하나의 확장 가능한 행 뒤에 숨깁니다. 명령 메뉴에서 또는 <code>Ctrl+Alt+F</code> (Mac에서는 <code>Ctrl+Option+F</code>)로 전환할 수 있습니다.</div>
    <div>샌드박스 자격 증명 파일은 Linux 및 WSL2에서 <a href="/docs/ko/sandboxing#mask-credential-files"><code>mode: "mask"</code></a>를 허용하므로, 샌드박스된 명령은 센티널 복사본을 읽고 샌드박스 프록시는 송신 시 실제 값을 대체합니다. 자격 증명 마스킹은 또한 <code>extract</code>, JWT 인식 <code>decode</code> 및 AWS SigV4 재서명 옵션을 제공합니다.</div>
    <div>마켓플레이스는 새로운 <code>archive</code> 소스를 사용하여 플러그인을 <a href="/docs/ko/plugins/marketplace-reference#archive-plugin-source">zip 아카이브</a>로 배포할 수 있으며, HTTPS를 통해 다운로드되고 선택적 SHA-256 핀을 사용하므로, git이나 npm 없이도 설치가 작동합니다.</div>
    <div><code>/review</code>는 이제 <a href="/docs/ko/code-review#review-a-diff-locally"><code>/code-review</code></a>의 별칭이며, 노력 수준 없이 <code>/code-review</code>를 사용하면 마지막으로 입력한 수준을 재사용합니다.</div>
    <div><a href="/docs/ko/agent-view#copy-the-session-with-%2Ffork"><code>/fork</code></a>로 복사한 세션은 이제 원본 세션의 체크아웃 대신 자체 worktree에서 코드 변경을 수행합니다.</div>
    <div><a href="/docs/ko/plugins/install#install-a-plugin"><code>/plugin</code></a>에서 설치한 플러그인은 안전할 때 현재 세션에서 활성화됩니다. 설치 요약은 <code>Plugin is now active.</code>를 보고하거나 <code>/reload-plugins</code>를 실행하도록 지시합니다.</div>
    <div><a href="/docs/ko/agent-view#how-file-edits-are-isolated">백그라운드 세션</a>이 worktree에서 코드를 변경한 경우, 이제 완료 전에 커밋하고 푸시하며, 작업에서 요구할 때만 초안 풀 요청을 열고, <code>CLAUDE.md</code>의 git 지시사항을 따릅니다.</div>
    <div>세션당 200개 서브에이전트 제한이 제거되었으므로, 장기 실행 세션은 더 이상 새 서브에이전트를 거부하지 않습니다. <a href="/docs/ko/sub-agents#concurrent-subagent-limit">동시성</a> 및 깊이 제한은 여전히 적용됩니다.</div>
    <div>저장소의 체크인된 설정은 더 이상 <a href="/docs/ko/remote-control#enable-remote-control-for-all-sessions">원격 제어 자동 연결</a>을 켤 수 없습니다. 대신 사용자 또는 관리 설정에서 <code>remoteControlAtStartup</code>을 설정하고, 프로젝트 및 로컬 설정은 이를 끌 수만 있습니다.</div>
    <div><a href="/docs/ko/worktrees#how-claude-code-enforces-isolation">Worktree 격리</a>는 이제 파일 편집뿐만 아니라 주 체크아웃에 도달하는 Bash 명령 및 git 리다이렉트도 차단하며, 모든 세션 유형 및 세션의 서브에이전트에서 차단합니다.</div>
    <div>Bash 명령은 더 이상 권한 확인에서 자신의 일부를 숨길 수 없으며, 탭이나 보이지 않는 유니코드 패딩은 더 이상 승인 대화에서 명령의 일부를 숨기지 않습니다.</div>
    <div>PreToolUse 자동 허용 훅은 더 이상 요약 및 압축과 같은 Claude Code의 내부 부작업에서 도구 제한을 우회하지 않습니다.</div>
    <div><a href="/docs/ko/ultraplan">Ultraplan</a> 연구 미리보기가 제거되었으며, <code>/ultraplan</code> 명령 및 <code>ultraplan</code> 키워드를 포함합니다. 대신 계획 모드 또는 웹의 Claude Code를 사용하세요.</div>
  </div>
</div>
