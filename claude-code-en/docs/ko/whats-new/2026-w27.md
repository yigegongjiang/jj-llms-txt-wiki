# 27주차 · 6월 29일 – 7월 3일, 2026

> Claude Sonnet 5가 기본 모델이 되었으며, Chrome의 Claude가 정식 출시되었고, 서브에이전트가 기본적으로 백그라운드에서 실행되며, Claude Desktop이 Linux에서 베타로 출시되었고, /radio가 Claude FM으로 튜닝됩니다.

  <p className="digest-feature-lede">Chrome 통합이 직접 Anthropic 플랜의 모든 사용자를 위해 미리보기에서 벗어났습니다. Claude Code는 Claude in Chrome 확장 프로그램을 통해 브라우저를 제어합니다: 탭을 열고, 페이지를 클릭하고, 양식을 채우고, 콘솔 로그를 읽고, 로그인 상태를 공유하므로 컨텍스트를 전환하지 않고도 빌드한 앱을 테스트할 수 있습니다.</p>

  <a className="digest-feature-link" href="/docs/ko/docs/chrome">Chrome에서 Claude Code 사용</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">서브에이전트가 기본적으로 백그라운드에서 실행됨</span>
    <span className="digest-feature-pill">v2.1.198</span>
  </div>

  <p className="digest-feature-lede">Claude는 이제 서브에이전트가 실행되는 동안 계속 작동하고 완료되면 결과를 선택하며, 대기하기 위해 대화를 일시 중지하지 않습니다. Claude는 계속하기 전에 결과가 필요할 때 여전히 포그라운드에서 서브에이전트를 실행하며, 백그라운드 서브에이전트는 주 세션에서 모든 권한 프롬프트를 표시합니다. <code>background</code> frontmatter 필드로 서브에이전트의 동작을 고정하세요.</p>

  <a className="digest-feature-link" href="/docs/ko/docs/sub-agents#run-subagents-in-foreground-or-background">서브에이전트를 포그라운드 또는 백그라운드에서 실행</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/ko/docs/artifacts">Artifacts</a>는 이제 정식 출시되었으며 Pro 및 Max 플랜에 포함되어 Team 및 Enterprise에 합류했습니다</div>
    <div>관리자는 org 콘솔에서 <a href="/docs/ko/docs/model-config#organization-default-model">조직 기본 모델</a>을 설정할 수 있습니다. 모델을 직접 선택하지 않았을 때 <code>/model</code>에서 "Org default"로 표시됩니다</div>
    <div><code>/skill-a /skill-b do XYZ</code>와 같은 스택된 스킬 호출은 이제 첫 번째만이 아니라 모든 선행 스킬(최대 5개)을 로드합니다</div>
    <div><code>AskUserQuestion</code> 대화는 더 이상 기본적으로 자동 계속되지 않습니다. <code>/config</code>를 통해 유휴 시간 초과를 선택하세요</div>
    <div>"default" 권한 모드는 이제 CLI, `--help`, VS Code 및 JetBrains 전체에서 "Manual"로 명명됩니다. `--permission-mode manual`은 `default`와 함께 허용됩니다</div>
    <div>새로운 <code>/dataviz</code> 스킬은 차트 및 대시보드 디자인 지침을 제공하며, 실행 가능한 색상 팔레트 검증기를 포함합니다</div>
    <div>기본 제공 Explore 에이전트는 이제 Haiku에서 실행되는 대신 주 세션의 모델(Opus로 제한)을 상속합니다</div>
    <div><code>claude agents</code>에서 시작된 백그라운드 에이전트는 이제 worktree에서 코드 작업을 완료할 때 커밋, 푸시 및 드래프트 PR을 열며, 묻기 위해 중지하지 않습니다</div>
    <div><code>code-reviewer</code>와 같은 하이픈이 있는 식별자를 가진 Hook 매처는 이제 부분 문자열 매칭 대신 정확히 일치합니다. 하이픈이 있는 MCP 서버의 모든 도구를 일치시키려면 <code>mcp\_\_brave-search\_\_.\*</code>를 사용하세요</div>
    <div>사용 제한과 관련 없는 일시적 서버 속도 제한 오류는 이제 구독자를 위해 백오프로 자동으로 재시도되며 턴이 실패하지 않습니다</div>
    <div>스트리밍 유휴 워치독은 이제 모든 제공자에 대해 기본적으로 활성화됩니다: 응답 스트림이 5분 동안 이벤트를 생성하지 않으면 중단하고 재시도합니다 (<code>CLAUDE\_ENABLE\_STREAM\_WATCHDOG=0</code>으로 비활성화)</div>
  </div>
</div>
