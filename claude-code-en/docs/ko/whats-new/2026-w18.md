# 18주차 · 4월 27일 – 5월 1일, 2026년

> Claude Code가 Windows에서 Git Bash 없이 실행되며, claude auth login은 브라우저 콜백이 localhost에 도달할 수 없을 때 붙여넣은 OAuth 코드를 허용하고, claude project purge는 프로젝트별 로컬 상태를 정리하며, PR URL을 /resume에 붙여넣으면 이를 생성한 세션을 찾습니다.

  <p className="digest-feature-lede"><code>claude auth login</code>은 이제 브라우저 콜백이 localhost에 도달할 수 없을 때 OAuth 코드를 터미널에 직접 붙여넣을 수 있습니다. 이는 로컬 포트로의 리다이렉트가 작동하지 않는 WSL2, SSH 세션 및 컨테이너를 지원합니다. 동일한 릴리스는 느린 또는 프록시된 연결과 IPv6 전용 devcontainer에서의 로그인 타임아웃도 수정합니다.</p>

  <p className="digest-feature-try">로그인한 후 브라우저에서 코드를 붙여넣으세요:</p>

  ```bash theme={null}
  claude auth login
  ```

  <p className="digest-feature-try">세션 선택기를 열으세요:</p>

  ```text Claude Code theme={null}

  ```

  <p className="digest-feature-try">선택기에 PR URL을 붙여넣으세요. 붙여넣기의 첫 번째 문자가 검색 모드로 전환하고, 목록이 해당 PR을 생성한 세션으로 필터링됩니다. Enter를 눌러 재개하세요. GitHub, GitHub Enterprise, GitLab 및 Bitbucket 풀 리퀘스트 및 병합 요청 URL이 모두 작동합니다.</p>

  ```text Claude Code theme={null}
  https://github.com/your-org/your-repo/pull/1234
  ```

  <p className="digest-feature-try">선택기를 건너뛰려면 대신 명령줄에서 PR 번호를 전달하세요:</p>

  ```bash theme={null}
  claude --from-pr 1234
  ```

  <div className="digest-wins-grid">
    <div>MCP 서버는 설정에서 `alwaysLoad: true`로 도구 검색 연기를 거부할 수 있으므로 해당 서버의 모든 도구가 항상 사용 가능합니다</div>
    <div>새로운 `claude plugin prune`은 고아 자동 설치 플러그인 종속성을 제거하고, `plugin uninstall --prune`은 계단식으로 작동합니다</div>
    <div>`/skills`는 이제 유형별 필터 검색 상자가 있어 긴 목록에서 스크롤 없이 기술을 찾을 수 있습니다</div>
    <div>`PostToolUse` 훅은 MCP 도구뿐만 아니라 모든 도구에 대해 `hookSpecificOutput.updatedToolOutput`을 통해 도구 출력을 대체할 수 있습니다</div>
    <div>새로운 <a href="/docs/ko/docs/ultrareview"><code>claude ultrareview</code></a> 하위 명령은 CI 또는 스크립트에서 `/ultrareview`를 비대화형으로 실행합니다: 결과를 stdout에 출력하고(`--json`으로 원본 출력), 완료 시 0으로 또는 실패 시 1로 종료합니다</div>
    <div>`--dangerously-skip-permissions`은 이제 `.claude/`, `.git/`, `.vscode/`, 셸 설정 파일 및 기타 이전에 보호된 경로에 대한 쓰기 프롬프트를 우회하며, 치명적인 제거 명령은 안전망으로 계속 프롬프트합니다</div>
    <div>`/model` 선택기는 `ANTHROPIC_BASE_URL`이 Anthropic 호환 게이트웨이를 가리킬 때 게이트웨이의 `/v1/models` 엔드포인트에서 모델을 나열할 수 있습니다. v2.1.129 이후 `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`로 옵트인하세요</div>
    <div>시작 중에 일시적 오류가 발생한 MCP 서버는 이제 연결 해제 상태로 유지되지 않고 최대 3회까지 자동으로 재시도합니다</div>
    <div>`ANTHROPIC_BEDROCK_SERVICE_TIER`는 Amazon Bedrock 서비스 계층을 선택합니다: `default`, `flex` 또는 `priority`</div>
    <div>`/terminal-setup`은 iTerm2의 클립보드 액세스 설정을 활성화하여 `/copy`가 작동하도록 합니다(tmux 포함)</div>
    <div>Google Cloud의 Agent Platform은 이제 X.509 인증서 기반 Workload Identity Federation(mTLS ADC)을 지원합니다</div>
    <div>중요한 메모리 누수 수정: 이미지가 많은 세션, 큰 트랜스크립트 히스토리에서의 `/usage`, 진행 이벤트 없는 장시간 실행 도구</div>
