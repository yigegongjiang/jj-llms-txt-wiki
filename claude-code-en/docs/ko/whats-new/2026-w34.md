# 34주차 · 2026년 8월 17–21일

    <span className="digest-feature-pill">v2.1.237</span>

  <p className="digest-feature-lede">Concise는 새로운 기본 제공 출력 스타일입니다. Claude는 결과로 시작하고 전문(preamble)과 설명을 건너뛰면서 Default 스타일만큼 철저하게 작업을 수행합니다. 설명이나 더 많은 세부 정보를 요청하면 Claude는 완전히 답변합니다. 오류 보고서, 보안 경고 및 파괴적인 작업에 대한 확인은 전체 내용을 유지합니다.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/2SnAdpL4dJ18nKb3/images/whats-new/concise-output-style.mp4?fit=max&auto=format&n=2SnAdpL4dJ18nKb3&q=85&s=dfb40ec8921ed1bc82eb629042a8ec17" data-path="images/whats-new/concise-output-style.mp4" />
  </Frame>

  <p className="digest-feature-try"><code>/config</code>의 <strong>Output style</strong> 아래에서 켜거나 설정 파일에서 설정하세요:</p>

  ```json ~/.claude/settings.json {2} theme={null}
  {
    "outputStyle": "Concise"
  }
  ```

  <p className="digest-feature-try"><code>/clear</code>를 실행하거나 새 세션을 시작하면 Claude의 답변이 결과로 시작됩니다.</p>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div>Claude Code는 이제 claude.ai 사용 한도가 재설정될 때 세션을 자동으로 계속합니다. <code>/config</code>의 <strong>Continue automatically at usage limit</strong> 행에서 끌 수 있습니다</div>
    <div>선택적 <a href="/docs/ko/interactive-mode#check-spelling-as-you-type"><code>spellcheck</code> 설정</a>은 입력할 때 프롬프트 입력에서 맞춤법이 틀린 단어에 밑줄을 그으며, 설치된 <code>aspell</code>, <code>hunspell</code> 또는 <code>ispell</code>을 사용합니다</div>
    <div>열린 GitLab 병합 요청이 있는 브랜치에서 <code>glab auth login</code>을 통해 <code>glab</code> CLI가 인증되면, 바닥글에 병합 요청이 초안, 열림 또는 병합 가능한지 여부에 따라 색상이 지정된 <a href="/docs/ko/interactive-mode#gitlab-merge-requests"><code>MR !N</code> 배지</a>가 표시됩니다</div>
    <div>휴대폰이나 claude.ai/code에서 노력 수준을 변경하면 <a href="/docs/ko/remote-control#what-connected-devices-see">머신의 세션에 적용됩니다</a>. Desktop 또는 VS Code에서 호스팅되는 Remote Control 세션도 연결된 기기에 세션의 현재 권한 모드를 표시합니다</div>
    <div>Claude가 작업 중일 때 <a href="/docs/ko/permissions#manage-permissions"><code>/permissions</code></a>를 열거나 <code>/add-dir \<path></code>를 실행할 수 있습니다. 권한 규칙 변경은 현재 턴의 나머지에 적용됩니다</div>
    <div>백그라운드 작업이 <a href="/docs/ko/goal#background-work-defers-evaluation"><code>/goal</code></a>을 대기 상태로 유지할 때, Claude는 무한정 기다리는 대신 30분 후에 확인하고 세션이 유휴 상태일 때 더 긴 간격으로 계속 확인합니다. <code>CLAUDE\_CODE\_GOAL\_CHECKIN\_MINUTES=0</code>을 설정하여 옵트아웃할 수 있습니다</div>
    <div>사용자의 프롬프트는 이제 트랜스크립트에서 마크다운을 렌더링하며, 강조된 코드 블록, 인라인 코드 및 목록이 답변과 동일한 방식으로 표시됩니다</div>
    <div>새로운 <a href="/docs/ko/model-config#set-a-default-model-for-new-sessions"><code>ANTHROPIC\_DEFAULT\_MODEL</code></a> 환경 변수는 새 세션이 시작되는 모델을 설정합니다. <code>/model</code> 선택은 여전히 이를 재정의하고 재시작 간에 유지됩니다</div>
    <div><code>SendMessage</code>의 <code>notify\_when\_idle</code> 입력을 사용하면 Claude는 같은 머신의 다른 Claude Code 세션에 <a href="/docs/ko/cross-session-messaging#get-a-notice-when-another-session-goes-idle">다음에 유휴 상태가 될 때 한 번의 알림을 보내도록</a> 요청할 수 있습니다</div>
    <div><a href="/docs/ko/interactive-mode#make-ctrl-w-delete-back-to-whitespace"><code>keybindingFlavor</code></a>를 <code>"readline"</code>으로 설정하여 프롬프트에서 <code>Ctrl+W</code>가 <code>/</code>와 같은 구두점에서 멈추는 대신 Bash처럼 이전 공백으로 돌아가도록 삭제하게 합니다</div>
    <div>네이티브 Windows에서 Claude Code 세션은 이제 macOS 및 Linux처럼 <a href="/docs/ko/cross-session-messaging#availability"><code>SendMessage</code>로 서로 메시지를 주고받을</a> 수 있으며 <code>ListAgents</code>로 서로를 찾을 수 있습니다</div>
    <div>자체 호스팅 러너는 `--defer-shutdown-max-min`을 허용하며, 이는 SIGTERM 후 설정된 분 수 동안 <a href="/docs/ko/self-hosted-environments-deploy#defer-the-drain-past-the-first-signal">연결된 세션을 계속 제공합니다</a></div>
    <div>자체 호스팅 러너는 `--proxy-authorization-command` 또는 `--proxy-authorization-file`을 허용하여 <a href="/docs/ko/self-hosted-environments-deploy#authenticate-to-an-egress-proxy">인증이 필요한 이그레스 프록시에 대한 새로운 `Proxy-Authorization` 헤더를 제공합니다</a></div>
  </div>
</div>
