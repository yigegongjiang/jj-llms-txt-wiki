<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">MCP 결과 크기 오버라이드</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">MCP 서버 작성자는 이제 도구의 <code>tools/list</code> 항목에서 <code>anthropic/maxResultSizeChars</code>를 설정하여 특정 도구의 자르기 상한을 높일 수 있으며, 최대 500K 문자까지 가능합니다. 상한은 전역이었으므로 데이터베이스 스키마 또는 전체 파일 트리와 같이 본질적으로 큰 페이로드를 반환하는 도구는 기본 제한에 도달하고 파일 참조와 함께 디스크에 저장되었습니다. 도구별 오버라이드는 도구가 정말로 필요할 때 해당 결과를 인라인으로 유지합니다.</p>

  <p className="digest-feature-try">서버의 <code>tools/list</code> 응답에서 도구에 주석을 달아주십시오:</p>

  ```json highlight={5} theme={null}
  {
    "name": "get_schema",
    "description": "Returns the full database schema",
    "_meta": {
      "anthropic/maxResultSizeChars": 500000
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/ko/docs/mcp#raise-the-limit-for-a-specific-tool">MCP 참조</a>
</div>

    <span className="digest-feature-title">PATH의 플러그인 실행 파일</span>
    <span className="digest-feature-pill">v2.1.91</span>

  <p className="digest-feature-lede">플러그인 루트의 <code>bin/</code> 디렉토리에 실행 파일을 배치하면 Claude Code는 플러그인이 활성화된 동안 해당 디렉토리를 Bash 도구의 <code>PATH</code>에 추가합니다. Claude는 절대 경로나 래퍼 스크립트 없이 모든 Bash 도구 호출에서 바이너리를 명령어로 호출할 수 있습니다. CLI 헬퍼를 호출하는 명령어, 에이전트 및 훅 옆에 패키징하는 데 편리합니다.</p>

  <p className="digest-feature-try">플러그인 루트에 <code>bin/</code> 디렉토리를 추가하십시오:</p>

  ```text highlight={4, 5} theme={null}
  my-plugin/
  ├── .claude-plugin/
  │   └── plugin.json
  └── bin/
      └── my-tool
  ```

  <a className="digest-feature-link" href="/docs/ko/docs/plugins-reference#file-locations-reference">플러그인 참조</a>
</div>
