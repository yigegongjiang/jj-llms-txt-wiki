  <div className="digest-wins-grid">
    <div>포커스 보기: 깜박임 없는 모드에서 <code>Ctrl+O</code>를 눌러 보기를 마지막 프롬프트, 한 줄 도구 요약(diffstats 포함) 및 Claude의 최종 응답으로 축소합니다</div>
    <div>로그인 화면의 가이드 <a href="/docs/ko/docs/amazon-bedrock">Amazon Bedrock</a> 및 <a href="/docs/ko/docs/google-vertex-ai">Google Cloud의 Agent Platform</a> 설정 마법사: 단계별 인증, 지역, 자격 증명 확인 및 모델 고정을 위해 "3rd-party platform"을 선택합니다</div>
    <div><code>/agents</code>는 탭 레이아웃을 가집니다. Running 탭은 <code>● N running</code> 카운트가 있는 라이브 서브에이전트를 표시하고, Library 탭에서 Run agent 및 View running instance 작업을 수행합니다</div>
    <div>기본 노력 수준은 이제 API 키, Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry, Team 및 Enterprise 사용자의 경우 <code>high</code>입니다(<code>/effort</code>로 제어)</div>
    <div><code>/cost</code>는 구독 사용자를 위한 모델별 및 캐시 히트 분석을 표시합니다</div>
    <div><code>/release-notes</code>는 이제 대화형 버전 선택기입니다</div>
    <div>상태 줄: 새로운 <code>refreshInterval</code> 설정은 N초마다 명령을 다시 실행하고, JSON 입력에서 <code>workspace.git\_worktree</code>를 사용합니다</div>
    <div><code>CLAUDE\_CODE\_PERFORCE\_MODE</code>: Edit/Write는 자동으로 덮어쓰는 대신 <code>p4 edit</code> 힌트와 함께 읽기 전용 파일에서 실패합니다</div>
    <div>OS CA 인증서 저장소는 이제 기본적으로 신뢰되므로 엔터프라이즈 TLS 프록시는 추가 설정 없이 작동합니다(<code>CLAUDE\_CODE\_CERT\_STORE=bundled</code>로 옵트아웃)</div>
    <div>Mantle에서 제공하는 Amazon Bedrock: <code>CLAUDE\_CODE\_USE\_MANTLE=1</code>을 설정합니다</div>
    <div>강화된 Bash 도구 권한: 백슬래시 이스케이프 플래그, 환경 변수 접두사, <code>/dev/tcp</code> 리다이렉트 및 복합 명령은 이제 올바르게 프롬프트합니다</div>
    <div><code>UserPromptSubmit</code> 훅은 <code>hookSpecificOutput.sessionTitle</code>을 통해 세션 제목을 설정할 수 있습니다</div>
  </div>
</div>
