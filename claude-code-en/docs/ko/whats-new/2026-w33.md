# 33주차 · 8월 10–14일, 2026년

> Claude Code Desktop이 사용량 제한 리셋 후 자동으로 계속 진행되며, 포크 모드가 기본적으로 켜지고, GitLab 병합 요청 및 마켓플레이스가 GitHub에 합류합니다.

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Desktop의 사용량 제한 후 자동 계속 진행</span>
    <span className="digest-feature-pill">Desktop</span>
  </div>

  <p className="digest-feature-lede">Claude Code Desktop의 Code 탭에서 세션 제한에 도달하면, 제한 카드는 이제 <strong>제한이 리셋될 때 자동으로 계속</strong> 체크박스를 제공합니다. 이를 선택하면 Desktop 앱이 리셋 후 중단된 턴을 다시 시도합니다. 카드는 재시도 시간을 표시합니다. 주간 제한 카드는 이 옵션을 제공하지 않습니다.</p>

    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/2SnAdpL4dJ18nKb3/images/whats-new/desktop-auto-continue.mp4?fit=max&auto=format&n=2SnAdpL4dJ18nKb3&q=85&s=1937f489695feaea715e48ecfd7e62cd" data-path="images/whats-new/desktop-auto-continue.mp4" />
  </Frame>

  <p className="digest-feature-try">다음에 세션 제한 카드가 나타나면 <strong>제한이 리셋될 때 자동으로 계속</strong>을 선택하고 세션을 열어 둡니다. 카드는 <code>Auto-resuming at</code> 뒤에 리셋 시간을 표시하며, 제한이 리셋되면 턴이 자동으로 계속됩니다.</p>

  <a className="digest-feature-link" href="/docs/ko/errors#youve-hit-your-session-limit">사용량 제한에 도달했을 때 할 일</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">포크 모드 기본적으로 켜짐</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">포크 모드는 이제 대화형 세션에서 기본적으로 켜져 있습니다. Claude는 <code>fork</code> 서브에이전트 유형을 요청할 수 있으며, 이는 처음부터 시작하는 대신 전체 대화 및 프롬프트 캐시를 상속하므로 부작업을 위해 컨텍스트를 다시 설명할 필요가 없습니다. 에이전트 팀 팀원이 생성하는 서브에이전트를 제외하고 대화형 세션에서 Claude가 생성하는 서브에이전트도 기본적으로 백그라운드에서 실행됩니다.</p>

  <p className="digest-feature-try">지금까지 논의한 모든 것이 필요한 작업으로 포크를 직접 시작합니다:</p>

  ```text Claude Code theme={null}
  > /subtask draft unit tests for the parser changes so far
  ```

  <p className="digest-feature-try">포크는 프롬프트 아래 패널에 나타나고 완료되면 결과가 대화에 도착합니다. 포크 모드를 끄려면 <code>CLAUDE\_CODE\_FORK\_SUBAGENT=0</code>을 설정합니다.</p>

  <a className="digest-feature-link" href="/docs/ko/sub-agents#turn-fork-mode-on-or-off">포크 모드 켜기 또는 끄기</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">GitLab 병합 요청 및 마켓플레이스</span>
    <span className="digest-feature-pill">v2.1.232</span>
  </div>

  <p className="digest-feature-lede">플러그인 마켓플레이스는 중첩된 서브그룹을 포함한 베어 <code>gitlab.com</code> URL을 복제합니다. v2.1.233 이상에서 GitLab 병합 요청 URL을 <code>--worktree</code>에 전달하여 이를 기반으로 분기하고, <code>claude agents</code> 보기는 병합 요청에 연결된 세션을 <code>!N</code>으로 레이블합니다. Claude Code는 또한 <code>glpat-</code> 및 <code>glrt-</code>와 같은 GitLab 토큰 패밀리를 마스킹하고, <code>glab</code> CLI의 구성 저장소를 <code>gh</code>를 보호하는 것과 동일한 방식으로 보호합니다.</p>

  <p className="digest-feature-try">병합 요청에서 분기한 worktree에서 세션을 시작합니다:</p>

  ```bash terminal theme={null}
  claude --worktree https://gitlab.com/group/project/-/merge_requests/42
  ```

  <p className="digest-feature-try"><code>origin</code>이 gitlab.com에 있으면 Claude Code는 <code>merge-requests/42/head</code>를 가져오고 자신의 worktree에서 해당 분기의 세션을 엽니다.</p>

  <a className="digest-feature-link" href="/docs/ko/worktrees#branch-from-a-pull-request">풀 또는 병합 요청에서 worktree 분기</a>
</div>

  <div className="digest-wins-grid">
    <div>프롬프트에서 <code>@</code>를 입력하여 이름으로 <a href="/docs/ko/cross-session-messaging#message-another-session">다른 Claude 세션을 언급</a>하면 Claude가 <code>SendMessage</code>로 직접 메시지를 보냅니다. 정확히 하나의 라이브 세션과 일치하는 베어 이름은 이제 확인 단계 없이 전달됩니다</div>
    <div>한 머신의 대화형 세션은 <a href="/docs/ko/cross-session-messaging#see-which-sessions-claude-can-reach">고유한 이름</a>을 유지합니다. 다른 라이브 세션이 이미 사용 중인 이름으로 세션을 시작하거나 이름을 바꾸면 Claude Code는 <code>name-word-word</code> 변형을 제공하고 알려줍니다</div>
    <div>플러그인 마켓플레이스는 <a href="/docs/ko/plugins/marketplace-reference#command-plugin-source"><code>command</code> 소스</a>를 허용합니다. 로컬 명령은 플러그인 디렉토리를 인쇄하며, Claude Code는 각 세션마다 다시 확인하고 재시작 없이 적용합니다</div>
    <div>Linux 및 WSL에서 <a href="/docs/ko/tools-reference#memory-limit-on-linux-and-wsl"><code>CLAUDE\_CODE\_TOOL\_MEMORY\_LIMIT</code></a>을 <code>4G</code>와 같은 크기로 설정하여 Bash 및 PowerShell 도구 명령이 사용할 수 있는 메모리를 제한합니다</div>
    <div><code>TaskCreate</code>, <code>TaskUpdate</code>, <code>TodoWrite</code>와 같은 작업 추적 도구는 <a href="/docs/ko/tools-reference#task-tool-availability">Opus 4.8, Sonnet 5, Fable 5, Mythos 5 및 이후 모델에서 더 이상 사용할 수 없습니다</a>. <code>CLAUDE\_CODE\_ENABLE\_TODO\_TOOLS=1</code>을 설정하여 다시 활성화합니다</div>
    <div>높음, 매우 높음, 최대 노력에서 <a href="/docs/ko/code-review#review-a-diff-locally"><code>/code-review</code></a>는 이제 다른 수준처럼 백그라운드 에이전트에서 실행됩니다</div>
    <div><a href="/docs/ko/plugins/install#install-a-plugin"><code>/plugin install plugin\@marketplace</code></a>는 먼저 마켓플레이스를 새로 고치므로 새로 게시된 플러그인이 수동 마켓플레이스 업데이트 없이 설치됩니다</div>
    <div>설정은 <a href="/docs/ko/settings-reference#marketplace-key-aliases"><code>additionalMarketplaces</code> 및 <code>allowedMarketplaces</code></a>를 <code>extraKnownMarketplaces</code> 및 <code>strictKnownMarketplaces</code>의 별칭으로 허용합니다</div>
    <div>최신 모델에서 Claude는 이 세션에서 먼저 읽지 않고 Write 도구로 <a href="/docs/ko/tools-reference#write-tool-behavior">기존 파일을 덮어쓸 수 있습니다</a>. Edit 도구의 규칙과 일치합니다. 이전 모델은 읽기가 필요합니다</div>
    <div>VS Code 확장은 <a href="/docs/ko/vs-code#organize-sessions-into-groups">세션 목록을 그룹으로 구성할 수 있습니다</a>. 마우스 오른쪽 버튼을 클릭하여 그룹을 만들거나, 이름을 바꾸거나, 삭제하고, Cmd/Ctrl- 또는 Shift-클릭으로 여러 세션을 한 번에 이동합니다</div>
    <div>조직이 Claude Code를 <a href="/docs/ko/claude-apps-gateway-spend-limits">지출 제한이 있는 Claude 앱 게이트웨이</a>를 통해 라우팅하는 경우, Claude Code는 제한에 도달했을 때 제한 기간, 리셋 시간 및 운영자의 메시지를 표시합니다</div>
