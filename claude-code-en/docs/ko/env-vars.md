# 환경 변수

> Claude Code 동작을 제어하는 환경 변수에 대한 참조입니다.

환경 변수는 모델 선택, 인증, 요청 라우팅, 기능 토글과 같은 Claude Code 동작을 제어할 수 있습니다. 동일한 동작의 대부분은 [설정 파일](/docs/ko/settings) 필드, [CLI 플래그](/docs/ko/cli-reference), 또는 `/model`과 같은 세션 내 명령을 통해서도 구성할 수 있습니다.

이 페이지에서는 다음을 다룹니다:

* [환경 변수 설정](#set-environment-variables) - 셸 또는 설정 파일에서
* [어떤 값이 적용되는지 확인](#precedence) - 동작을 여러 방법으로 설정할 수 있을 때
* [Claude Code가 읽는 변수 조회](#variables)

<h2 id="set-environment-variables">
  환경 변수 설정
</h2>

셸에서 설정한 변수는 해당 터미널 세션 동안만 지속되지만, 설정 파일의 변수는 `claude`가 실행될 때마다 적용됩니다.

<h3 id="in-your-shell">
  셸에서
</h3>

`claude`를 실행하기 전에 변수를 설정합니다:

<Tabs>
  <Tab title="macOS, Linux, WSL">
    ```bash theme={null}
    export API_TIMEOUT_MS="1200000"
    claude
    ```

    모든 세션에 대해 설정하려면 `export` 줄을 `~/.bashrc`, `~/.zshrc`, 또는 셸의 프로필 파일에 추가합니다.
  </Tab>

  <Tab title="Windows PowerShell">
    ```powershell theme={null}
    $env:API_TIMEOUT_MS = "1200000"
    claude
    ```

    모든 세션에 대해 설정하려면 `[Environment]::SetEnvironmentVariable("API_TIMEOUT_MS", "1200000", "User")`를 실행하고 새 터미널을 엽니다.
  </Tab>

  <Tab title="Windows CMD">
    ```batch theme={null}
    set API_TIMEOUT_MS=1200000
    claude
    ```

    모든 세션에 대해 설정하려면 `setx API_TIMEOUT_MS "1200000"`을 실행하고 새 터미널을 엽니다.
  </Tab>
</Tabs>

<h3 id="in-settings-files">
  설정 파일에서
</h3>

`settings.json` 파일의 `env` 키 아래에 변수를 추가합니다. Claude Code는 시작 시 파일에서 직접 읽으므로 `claude`가 어떻게 실행되었는지와 관계없이 적용됩니다.

```json ~/.claude/settings.json theme={null}
{
  "env": {
    "API_TIMEOUT_MS": "1200000",
    "BASH_DEFAULT_TIMEOUT_MS": "300000"
  }
}
```

선택한 파일이 변수가 적용되는 대상을 제어합니다:

| 파일                            | 적용 대상                                   |
| :---------------------------- | :-------------------------------------- |
| `~/.claude/settings.json`     | 모든 프로젝트에서 사용자                           |
| `.claude/settings.json`       | 프로젝트에서 작업하는 모든 사람, 소스 제어에 체크인됨          |
| `.claude/settings.local.json` | 이 프로젝트에서만 사용자 (직접 생성한 경우 gitignore에 추가) |
| 관리형 설정                        | 조직의 모든 사람, 관리자가 배포                      |

각 파일이 있는 위치는 [설정 파일](/docs/ko/settings#settings-files)을 참조하고, 둘 이상이 동일한 변수를 설정할 때 결합되는 방식은 [설정 우선순위](/docs/ko/settings#settings-precedence)를 참조합니다.

<h2 id="precedence">
  우선순위
</h2>

동일한 동작에 환경 변수와 설정 필드가 모두 있는 경우, 환경 변수가 우선합니다. 예를 들어 `ANTHROPIC_MODEL`은 `model` 설정을 재정의하고, `CLAUDE_CODE_AUTO_CONNECT_IDE`는 `autoConnectIde`를 재정의합니다. 환경 변수가 설정되지 않으면 설정 필드가 적용됩니다.

셸과 설정 파일 `env` 블록 모두에서 동일한 변수가 설정된 경우, 설정 파일 값이 적용됩니다. Claude Code는 시작 시 각 `env` 항목을 프로세스 환경에 기록하여 셸에서 상속된 값을 대체합니다. 몇 가지 변수는 특별하게 처리되며, [`env` 설정](/docs/ko/settings#available-settings)에서 예외를 나열합니다.

설정 파일 간에 `env` 값은 [설정 우선순위](/docs/ko/settings#settings-precedence)를 따르므로, 관리되는 설정 항목이 사용자 또는 프로젝트 설정의 동일한 변수를 재정의합니다.

환경 변수가 CLI 플래그 및 세션 내 명령과 상호작용하는 방식은 기능별로 다릅니다: `--model` 및 `/model`은 `ANTHROPIC_MODEL`을 재정의하지만, `CLAUDE_CODE_EFFORT_LEVEL`은 `/effort`를 재정의합니다. 변수가 다른 구성 소스와 상호작용할 때, [변수](#variables) 목록의 행에서 우선순위를 명시하거나 이를 문서화하는 페이지로 연결합니다.

Claude Code는 시작 시 환경 변수를 읽으므로 변경 사항은 다음에 `claude`를 실행할 때 적용됩니다.
