# 명령어

> Claude Code에서 사용 가능한 명령어의 완전한 참조 자료로, 기본 제공 명령어 및 번들 스킬을 포함합니다.

명령어는 세션 내에서 Claude Code를 제어합니다. 모델을 전환하고, 권한을 관리하고, 컨텍스트를 지우고, 워크플로우를 실행하는 등의 작업을 빠르게 수행할 수 있는 방법을 제공합니다.

`/`를 입력하여 사용 가능한 명령어를 확인하거나, `/` 다음에 문자를 입력하여 필터링할 수 있습니다. [명령어 메뉴가 입력한 내용과 일치하는 방식](#how-the-command-menu-matches-what-you-type)에서는 강조 표시, 오타, Claude Code가 전체 이름을 입력할 때까지 메뉴에서 숨기는 몇 가지 명령어에 대해 설명합니다.

명령어는 메시지의 시작 부분에서만 인식됩니다. 명령어 이름 다음에 오는 텍스트가 해당 인수가 됩니다. v2.1.199부터 [스킬](/docs/ko/skills#pass-arguments-to-skills)은 예외입니다. 스킬 호출 다음에 더 많은 스킬이 오는 경우(예: `/skill-a /skill-b do XYZ`), 시작 부분에서 명명된 모든 스킬을 로드하고 뒤따르는 텍스트를 각각에 인수로 전달합니다. 최대 6개의 스킬을 연결할 수 있습니다.

Claude가 응답하는 동안 명령어를 보내면 Claude Code는 이를 대기열에 넣고 현재 턴이 완료된 후 실행합니다. Claude Code는 `/status`, `/tasks`, `/usage`와 같은 일부 명령어를 응답을 중단하지 않고 즉시 실행합니다. [전체 화면 렌더링](/docs/ko/fullscreen)에서 Claude Code는 `/theme` 및 `/help`와 같은 대화 명령어도 즉시 엽니다. v2.1.234 이전에는 Claude Code가 이러한 대화를 턴이 완료될 때까지 대기열에 넣었습니다.

<h2 id="commands-across-a-typical-workflow">
  일반적인 워크플로우 전반의 명령어
</h2>

대부분의 명령어는 프로젝트 설정부터 변경 사항 배포까지 세션의 특정 시점에서 유용합니다.

**저장소의 첫 번째 세션.** `/init`을 실행하여 시작 `CLAUDE.md`를 생성한 다음, `/memory`를 실행하여 이를 개선합니다. `/mcp`를 사용하여 프로젝트에 필요한 모든 서버를 설정하고, Claude에게 원하는 [서브에이전트](/docs/ko/sub-agents)를 생성하도록 요청하고, `/permissions`을 실행하여 승인 규칙을 설정합니다.

**작업 중.** `/plan`은 큰 변경 전에 계획 모드로 전환합니다. `/model`과 `/effort`는 사용 중인 모델과 적용되는 추론의 양을 조정합니다. 대화가 길어지면 `/context`는 윈도우를 채우고 있는 항목을 표시하고 `/compact`는 이를 요약하여 공간을 확보합니다. 대화 기록에 추가되지 않아야 하는 부수적인 질문의 경우 `/btw`를 사용합니다.

**병렬로 작업 실행.** Claude는 부수 작업을 [서브에이전트](/docs/ko/sub-agents)에 위임하고, `/tasks`는 완료된 서브에이전트를 포함한 현재 세션의 백그라운드 작업을 나열합니다. `/background`는 전체 세션을 분리하여 [백그라운드 에이전트](/docs/ko/agent-view)로 계속 실행되도록 하고 터미널을 해제합니다. 코드베이스에 걸친 큰 변경의 경우 `/batch`는 이를 독립적인 단위로 분해하고 각각을 자체 [워크트리](/docs/ko/worktrees)에서 실행합니다. 이러한 접근 방식이 어떻게 관련되는지는 [병렬로 에이전트 실행](/docs/ko/agents)을 참조하세요.

**배포 전.** `/diff`는 변경된 항목을 표시합니다. `/code-review`는 현재 diff를 정확성 버그에 대해 확인하고 `--fix`로 결과를 적용할 수 있습니다. PR 번호(예: `/code-review high 1234`)를 전달하여 대신 풀 요청을 검토합니다. `/review`는 별칭입니다. `/code-review ultra`는 클라우드에서 다중 에이전트 검토를 실행합니다. `/security-review`는 diff를 보안 취약점에 대해 확인합니다.

**세션 간.** `/clear`는 프로젝트 메모리를 유지하면서 새 작업을 시작합니다. `/resume`은 이전 대화로 돌아가고, `/branch`는 현재 대화를 분기하여 다른 방향을 시도하고, `/fork`는 이를 새 [백그라운드 세션](/docs/ko/agent-view)으로 복사합니다. `/teleport`는 클라우드 세션을 이 터미널로 가져오고, `/remote-control`은 다른 장치에서 이 로컬 세션을 계속할 수 있게 합니다.

**문제가 있을 때.** `/rewind`는 코드와 대화를 체크포인트로 롤백하거나 대화의 일부를 요약합니다. `/doctor`는 설치 및 구성 문제를 진단하고 수정할 수 있는 설정 점검을 실행하고, `/debug`는 런타임 문제를 진단하고, `/feedback`은 세션 컨텍스트가 첨부된 버그를 보고합니다.

<h2 id="all-commands">
  모든 명령어
</h2>

아래 표는 Claude Code에 포함된 모든 명령어를 나열합니다. 대부분은 CLI에 코딩된 동작을 가진 기본 제공 명령어입니다. 두 가지 종류의 항목이 표시됩니다.

* **[스킬](/docs/ko/skills#bundled-skills)**: 번들로 제공되는 스킬입니다. 직접 작성한 스킬처럼 작동합니다. Claude에 전달되는 프롬프트입니다.
  * `/verify`는 호출할 때만 실행됩니다. v2.1.215 이전에는 Claude가 `/verify`를 자동으로 실행할 수도 있었습니다.
* **[워크플로우](/docs/ko/workflows#bundled-workflows)**: 번들로 제공되는 [동적 워크플로우](/docs/ko/workflows)로, 많은 서브에이전트에 걸쳐 작업을 분산하고 백그라운드에서 실행됩니다.
  * `/deep-research`는 호출할 때만 실행됩니다. v2.1.218 이전에는 Claude가 자동으로 시작할 수도 있었습니다.

자신의 명령어를 추가하려면 [스킬](/docs/ko/skills)을 참조하십시오.

아래 표에서 `<arg>`는 필수 인수를 나타내고 `[arg]`는 선택적 인수를 나타냅니다.

<Note>
  모든 명령어가 모든 사용자에게 표시되지는 않습니다. 가용성은 플랫폼, 플랜 및 환경에 따라 다릅니다. 예를 들어 `/desktop`은 Claude 구독으로 로그인했을 때 macOS 및 x64 Windows에서만 표시되고, `/upgrade`는 Enterprise 플랜에서는 표시되지 않습니다.
</Note>

| `/branch [name]`                                                                                             | 현재 대화의 이 지점에서 분기를 생성하여 대화를 잃지 않고 다른 방향을 시도할 수 있습니다. 분기로 전환하고 원본을 보존합니다. `/resume`으로 원본으로 돌아갈 수 있습니다. 분기로 전환하는 대신 별도의 [백그라운드 세션](/docs/ko/agent-view)으로 복사본을 실행하려면 `/fork`를 사용합니다. 이 대화로 보고하는 [서브에이전트](/docs/ko/sub-agents)에 부작업을 넘기려면 `/subtask`를 사용합니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `/btw [question]`                                                                                            | 대화에 추가하지 않고 현재 세션에 대한 [부가 질문](/docs/ko/interactive-mode#side-questions-with-%2Fbtw)을 합니다. 질문 없이 `/btw`를 실행하면 Claude Code가 가장 최근의 부가 질문을 표시하여 이전 답변을 검색할 수 있습니다. 아직 질문하지 않았으면 Claude Code가 사용 라인을 출력합니다. v2.1.212 이전에는 `/btw`에 질문이 필요했습니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `/bug [report]`                                                                                              | 버그를 보고하거나 대화를 공유합니다. 포함할 세션 기록의 양을 선택하고 무엇이든 전송되기 전에 동의 화면에서 확인합니다. <h2 id="how-the-command-menu-matches-what-you-type">
  명령 메뉴가 입력한 내용과 일치하는 방식
</h2>

Claude Code는 입력할 때 `/` 메뉴를 필터링합니다. 아래의 각 항목은 필터링 중에 발생할 수 있는 한 가지 사항을 다룹니다:

* **강조 표시**: Claude Code는 `/` 뒤의 문자가 명령의 이름 또는 별칭과 일치할 때만 상단 제안을 강조 표시합니다. 이는 이름의 시작 부분이나 그 안의 단어에서 일치하며, `:`, `_`, `-` 구분 기호는 무시합니다. `/adddir`을 입력하면 `/add-dir`이 강조 표시되고, `/new`를 입력하면 별칭을 통해 `/clear`가 강조 표시됩니다. `Enter`를 눌러 강조 표시된 제안을 실행합니다. 이러한 강조 표시 규칙에는 Claude Code v2.1.236 이상이 필요합니다.
* **오타 후**: Claude Code는 아무것도 강조 표시하지 않습니다. 유사한 항목들은 목록에 남아 있으며, `Tab` 또는 화살표 키로 선택할 수 있지만, `Enter`를 누르면 입력한 텍스트가 그대로 제출되고 [알 수 없는 명령](/docs/ko/errors#unknown-command)을 보고합니다.
* **사용할 수 없는 명령**: Claude Code는 메뉴에서 이러한 명령을 제외합니다. 일치하는 항목이 없으면 Claude Code는 `No commands match "/name"`을 표시합니다. 대부분의 사용할 수 없는 명령은 제출할 때 [알 수 없는 명령](/docs/ko/errors#unknown-command)을 반환합니다. 그러나 [`/schedule`(Console API 키의 경우)](/docs/ko/routines#schedule-returns-unknown-command)와 같은 일부 명령은 대신 자체 가용성 메시지로 응답합니다. 일부 명령은 조직의 정책이 이를 비활성화할 때 자체 메시지로 응답하기도 합니다.
* **숨겨진 명령**: Claude Code는 `/heapdump`와 같은 일부 사용 가능한 명령을 의도적으로 메뉴에서 제외합니다. 부분 이름은 숨겨진 명령을 메뉴에 표시하지 않습니다. 부분이 표시되는 항목과 일치하지 않으면 Claude Code는 동일한 불일치 메시지를 표시합니다. Claude Code는 전체 이름을 입력한 후에만 명령을 나열하며, 전체 이름을 제출하면 실행됩니다.
