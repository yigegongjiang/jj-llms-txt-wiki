# ClientView 开源-副屏异显解决方案
更新时间：2025-12-23 11:27:10
随着智能商用设备在零售、餐饮等行业的广泛应用，**双屏异显** 已成为提升运营效率和顾客体验的重要功能。然而，许多第三方软件开发者由于技术门槛或资源限制，难以自行实现副屏适配与内容分发。
为响应广大开发者与终端用户的需求，商米正式推出 **ClientView 开源项目** 。该项目基于商米 D3 MINI / D3 PRO 等系列设备，提供了一套**免编码、易集成、可扩展** 的副屏显示解决方案，帮助开发者和企业客户快速实现双屏异显功能，无需深度定制硬件或修改现有软件架构。
# **ClientView 的亮点**
  * **即插即用** ：无需修改现有收银或业务系统代码，通过 URL 即可将任意网页内容投屏至副屏。
  * **跨平台兼容** ：支持标准 HTTP/HTTPS 网页，适用于各类 Web 应用、数据看板、广告轮播等场景。
  * **智能记忆与自动投屏** ：支持历史记录、自动填充、开机自启动、自动投屏等人性化功能。
  * **开源可定制** ：完整源码开放，支持二次开发与功能扩展，满足个性化业务需求。
  * **多语言支持** ：内置英语等多语言界面，适用于国际化业务场景。


# **核心功能**  
| 功能模块  | 核心能力  |  
| --- | --- |  
| URL 投屏  | 输入任意网页地址，实时在副屏显示内容；自动补全 `https://` 协议前缀  |  
| 历史记录和智能联想  | 自动保存投屏记录，支持模糊搜索与一键填充，提升操作效率  |  
| 自动投票与开机自启  | 提供“显示/停止副屏显示”按钮，实时控制副屏内容；主副屏操作互不干扰  |  
| 双屏控制  | 提供“显示/停止副屏显示”按钮，实时控制副屏内容；主副屏操作互不干扰  |  
# **快速开始**
## **环境要求**
  * 商米设备（D3 MINI / D3 PRO，支持副屏输出）
  * Android 7.1+
  * 无需 root，无需系统定制
