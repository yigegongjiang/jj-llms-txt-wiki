# 价签绑定货架编号
更新时间：2025-09-25 18:00:13
说明：该功能仅在国内支持
# 准备环境
电脑：数字店铺：[store.sunmi.com](http://store.sunmi.com)
L2：价签助手App（版本号：1.2.0及以上，可在设备的应用市场里下载最新版本）
  

![](https://cdn.sunmi.com/public/image/mgt-document/ae79ca033c794af1b97defdc1c3420a9.png)
# 操作流程
  1. **数字店铺-设备管理-电子价签-价签管理 开启货架编号绑定 开关**


  

![](https://cdn.sunmi.com/public/image/mgt-document/b220ea4b324c4dd39abc3d8b354f68cb.png)
选择门店后，可以设置该门店下的价签在绑定时是否需要绑定货架编号
  * “货架编号绑定”开关默认关闭，点击可打开。打开之后，通过价签助手App绑定价签时均需要填写货架编号，填写的货架编号可以通过页面查看和搜索（搜索时，需要输入完整的货架编号）
  * 价签信息（ID、SN、商品、模板、货架编号等）可以导出为Excel文件（当前支持导出最多5000片价签的信息，若单门店下有超过5000片价签需导出，请联系商米做功能升级）
  * 关闭“货架编号绑定”开关后，通过价签助手App绑定价签时均不再需要填写货架编号。已经绑定的货架编号会保留，可以通过解绑或删除来清空货架编号（解绑会清空商品、模板、货架编号，但价签仍归属在该门店下；删除会将价签从门店里删除，同时清空商品、模板、货架编号）


  1. **价签助手App绑定货架编号**


数字店铺开启“货架编号绑定”开关后，该门店下的价签在首次绑定、再次绑定时，均需填写货架编号
  

![](https://cdn.sunmi.com/public/image/mgt-document/66ea47c3d65a49e98919afff1135b5e6.png)
  1. 绑定过程中，选择完模板、商品后，点击“绑定”，会进入下一页“绑定货架编号”
  2. 若已经绑定了货架编号，可以看到当前绑定的货架编号信息。支持手动输入货架编号，也支持点击扫描按钮读取货架编号一维码自动写入（货架编号最长可输出32个字符，支持数字、英文字母和空格、#、-、_、/等特殊字符）。
  3. 填写完后，点击“绑定”，即可完成货架编号绑定
  4. **原有功能说明**


通过价签助手App重置价签、迁移价签，均会保留已绑定的货架编号。可以通过数字店铺的解绑或删除功能来清空货架编号（解绑会清空商品、模板、货架编号，但价签仍归属在该门店下；删除会将价签从门店里删除，同时清空商品、模板、货架编号）
