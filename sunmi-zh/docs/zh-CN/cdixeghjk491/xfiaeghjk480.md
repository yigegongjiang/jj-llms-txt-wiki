# 2.注册一个合作伙伴账号（仅适用于使用了SDK_V1接口的旧设备）
更新时间：2025-11-11 15:59:13
# 说明
> 关于注册合作伙伴流程请参考：<[https://developer.sunmi.com/docs/zh-CN/cdixeghjk491/xdmqeghjk513](https://developer.sunmi.com/docs/zh-CN/cdixeghjk491/xdmqeghjk513/)>
  * a) 合作伙伴业务需基于商米云提供的安全保障前提下，所以要求合作伙伴需要拥有一个商米合作伙伴平台账户。
  * b) 要求打印机设备在商米公司出库时渠道一定要选择该账户下，否则打印机会因归属权问题无法进行下一步绑定业务。
