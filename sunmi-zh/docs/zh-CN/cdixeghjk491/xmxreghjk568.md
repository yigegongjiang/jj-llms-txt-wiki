# 8、钱箱驱动器APP使用说明
更新时间：2026-07-13 14:50:21
# 一、连接说明
钱箱驱动器是一款可以通过USB和Bluetooth连接，驱动现金抽屉打开的设备。当POS系统中没有使用打印机时，钱箱可以连接到计算机、安卓平板或iPad平板，通过软件驱动钱箱打开。此驱动器使用Type-A USB接口进行供电，可通过PC供电或5V/2A电源适配器供电。通过本APP，可以在安卓设备上出现一个悬浮按钮，快捷的操作钱箱打开。
APP适用范围：安卓设备（手机、平板等）

# 三、使用介绍
钱箱驱动器连接钱箱时，可以支持USB和蓝牙两种驱动方式，但一次只支持一个钱箱驱动器在线使用。
### 1、使用蓝牙方式驱动钱箱
获取蓝牙相应权限后，开始蓝牙搜索钱箱驱动器，选择指定的驱动器名称（名称以"CashDrawer_xxxxxx"开头）。
连接成功时，会提示相应的toast信息。
  

![](https://cdn.sunmi.com/public/image/mgt-document/e3c97a963f91415da0f04f5d33ca5994.png)
  

![](https://cdn.sunmi.com/public/image/mgt-document/d5bb84c14594413692356b61b903d14e.png)
首次使用钱箱驱动器连接时，会弹出配对PIN窗口。默认PIN码是设备名称最后的6位数字。
注意：如果设备在上电5分钟内未进行任何配对绑定，设备将退出配对模式。如果需要再次配对，请重新拔插USB进行上电操作，并在5分钟内完成绑定。
### 2、使用USB方式驱动钱箱
获取相应权限后，即可显示钱箱悬浮窗口。
注意：一台设备上仅支持一个USB钱箱驱动器设备，所以获取USB钱箱驱动器时，将直接显示第一个发现的驱动器名称。
  

![](https://cdn.sunmi.com/public/image/mgt-document/423d8e3c249f46a2a0549fb890fe90c3.png)
### 3、悬浮球操作
通过点击悬浮球打开钱箱
### 4、设置
点击识别到的钱箱驱动器，可在详情页面查看设备的相关信息。也可以通过页面删除此设备的连接。
  

![](https://cdn.sunmi.com/public/image/mgt-document/ae4af95c06ad49268aceade6d4fb4096.png)
### 5、打开关闭校准
如果点击悬浮球打开钱箱时，发现显示状态和钱箱抽屉打开状态不符，可以通过校准功能校准。
首先把钱箱关闭，点击校准按钮，提示【校准成功】完成校准动作。
注意：此功能需要钱箱本身支持状态反馈功能才校准有效。
