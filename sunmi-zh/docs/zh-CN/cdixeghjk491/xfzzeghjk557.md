# 20、云打印机Windows驱动TCP打印
更新时间：2025-12-19 22:54:06
本功能仅支持以下机型和版本：
58票据云打印机，Model：NT21x，Firmware version: 2.4.0，SUNMI APP Version：2.6.0 以上设备使用；
80后厨云打印机，Model：NT31x，Firmware version: 2.7.0，SUNMI APP Version：2.19.0以上设备使用；
80扫码打印机，Model：NT32x，Firmware version: 4.1.19，SUNMI APP Version：4.1.32以上设备使用；
如需升级请联系客服！
## 打印机Windows驱动驱动下载位置：
  1. 商米58智能云打印机 (NT211~NT21A 系列) [打印机Windows驱动下载](https://file.cdn.sunmi.com/SUNMIDOCS/58-CloudPrinter-Driver-v2.6.7.1.zip)
  2. 商米80后厨云打印机 (NT31x 系列) [打印机Windows驱动下载](https://file.cdn.sunmi.com/SUNMIDOCS/SUNMI_Cloud_Printer_Driver.zip)


# 1、安装驱动
运行【CloudPrinter Driver v2.6.7.1.exe】文件；
  

![](https://cdn.sunmi.com/public/image/mgt-document/94f1decd0cf34aa5a2f943c11dd504cc.png)
# 2、安装打印机驱动
在打印机型号下拉框中选择【TP582】（58打印机），或者【TP808】（80打印机）；
  

![](https://cdn.sunmi.com/public/image/mgt-document/c6f606f94bdb498a9c4604a55f136885.png)
选择【添加TCP/IP端口】；
  

![](https://cdn.sunmi.com/public/image/mgt-document/f49a5ca861434e618da504e2e926705c.png)
点击【下一页】；
  

![](https://cdn.sunmi.com/public/image/mgt-document/77bc52103cef413d865b05bdaa290a9f.png)
填写打印机的IP地址（同一局域网下），端口名使用默认的就好，再点击【下一页】；
  

![](https://cdn.sunmi.com/public/image/mgt-document/7a8d911c913549f6acdcf69620eda37d.png)
等待一段时间；
  

![](https://cdn.sunmi.com/public/image/mgt-document/16312ec873d242b39cb39c22bc43d9d9.png)
设备类型选择【标准】【Generic Network Card】，点击【下一页】
  

![](https://cdn.sunmi.com/public/image/mgt-document/ba28d2b7818443db8baa66388c3efc4e.png)
点击【完成】；
  

![](https://cdn.sunmi.com/public/image/mgt-document/35712ae2e4054dce9591835ae29660aa.png)
# 3、安装网络端口
选择刚才添加的IP地址，点击【下一步】
  

![](https://cdn.sunmi.com/public/image/mgt-document/3d2a2c4753744d808fe190c5a49bf87d.png)
点击【完成】
  

![](https://cdn.sunmi.com/public/image/mgt-document/77ee8496ce5049c6ae11e14b3acdc512.png)
# 4、安装完成
打印机和扫描仪设置中找到【TP582】（58打印机），或者【TP808】（80打印机），点击【管理】；
  

![](https://cdn.sunmi.com/public/image/mgt-document/1f90267154914bdc806e078335d80c8d.png)
点击【打印测试页】，打印机会打印出一张测试小票，则表示安装成功；
  

![](https://cdn.sunmi.com/public/image/mgt-document/3a7946bea44f4992a6c0eef56489e49f.png)
