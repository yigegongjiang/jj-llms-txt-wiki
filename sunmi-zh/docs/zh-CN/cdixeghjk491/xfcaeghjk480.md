# 5.数采问题FAQ

更新时间：2025-09-24 19:11:25

# 1、数采打印机与美团/二维火/客如云安卓POS机是否兼容情况？

答：数采打印机是标准USB接口的，插上去POS以后系统层是可以识别的。但由于这些POS机内部的SAAS软件可能由于适配问题，绑定了指定打印机的VID&PID，所以可能无法对打印机进行设置，导致无法使用。

# 2、采集平台针对不同格式的小票模板，是自动适配还是需要不同商户实施的时候人工调配？

答：商米数采平台采用的是云端AI算法，常见的格式微调都能自动适配，遇到个别全新的格式就需要云端调整适配。此时可以联系商米售后人员解决。

# 3、是否支持WIFI+4G全网通？

答：58数据打印机仅支持WIFI+4G CAT1，80数据打印机才能支持LAN+WIFI+4G全网通。数据打印机对于日均小于50单的数据采集业务，提供了终身免费4G流量，对于单台日均超过50单的需要收取流量费用。

# 4、解析算法是否有自我学习功能？

答：商米数采平台算法具有AI自学习能力，会自动通过大量票据样版来促进算例。

# 5、整个小票线上是否能还原，能否识别不同支付方式/优惠让利/退货？

答：商米不涉及具体经营业务，仅把小票图形识别成可读文字编码，这些解析后的文字编码可以提供给合作伙伴自行逻辑处理。

# 6、能否提供采集后台测试账号，看看有哪些报表？

答：合作伙伴自行登录【[store平台](https://store.sunmi.com/user/login)】申请开通账号即可，绑定开通数采打印机以后就可以呈现报表。

# 7、数采准确率多少？

答：只要通讯稳定，保证数据能够完整采集上云，数采解析准确率95%以上。

# 8、能否跟打二维码，加入促销推广打印？

答：产品支持数据追打功能，但此功能依据客户需求不同，是需要合作伙伴定制对接。对接需求请联系所在地区销售人员。
