# 2、开通收款音箱对接能力
更新时间：2025-11-13 15:00:10
## **特别声明：**
> 商米收款音箱对接通道为更好的保护合作伙伴的数据隐私，又能实现完整的订单播报过程，特订立以下对接规范，并需要商米与合作伙伴双方共同努力才能实现播报通道业务。
# **注册合作伙伴平台账号：**
> 关于注册合作伙伴平台账号流程请参考：<<https://developer.sunmi.com/docs/zh-CN/cicmeghjk546/xcrdeghjk524>>
  1. 合作伙伴业务基于商米云提供的安全保障前提下，所以要求合作伙伴需要拥有一个商米合作伙伴平台账户。
  2. 要求收款音箱设备在商米公司出库时，出库渠道一定要选择该账户下，否则收款音箱会因归属权问题无法进行下一步绑定业务。


# **创建应用和关联能力：**
1.登录【商米伙伴平台】，注册成为【开发者】。点击【开发服务】-【应用接入】-【创建接入能力的应用】，在创建应用界面输入“应用名称”，选择“云应用”，点击【提交】
  

![](https://cdn.sunmi.com/public/image/mgt-document/cbd44d5de0f64bc883c89aad9cee36cb.png)
  

![](https://cdn.sunmi.com/public/image/mgt-document/837b6d82c8f047c49150f5b7a1b28e12.png)
2.创建应用成功后，还需进一步关联能力，点击【收款音箱应用】卡片进入【应用详情】
  

![](https://cdn.sunmi.com/public/image/mgt-document/6e1617b0eac946edbcf9ba3ad8d85f51.png)
3.详情中提供了【AppID】【AppKey】，请复制下来备用。
点击【添加能力】，勾选【收款音箱】能力，将“收款音箱”能力添加到“关联能力列表”中
  

![](https://cdn.sunmi.com/public/image/mgt-document/adf3e9b3589544f7b45d25915b28244b.png)
4.应用关联能力后，就可以开始调用能力对应的接口。
> 具体接口请求规格请参考：<https://developer.sunmi.com/docs/zh-CN/xeghjk491/fdxeghjk491>
# **能力设置：**
1.点击【开发服务】-【应用接入】，点击应用卡片进入【应用详情】，在关联能力列表选择【收款音箱】-【设置】
  

![](https://cdn.sunmi.com/public/image/mgt-document/86f7de6b208049bf98f974a44c45105b.png)
2.收款音箱设置中，依据收款音箱的需求，设置参数。
  

![](https://cdn.sunmi.com/public/image/mgt-document/9960529da20d480d9149b761fcddf1ac.png)
3.点击【保存】完成能力设置。
# **能力列表和关联应用：**
1.点击【开发服务】-【我的能力】，开发者可以查看可对接的所有能力；
  

![](https://cdn.sunmi.com/public/image/mgt-document/ba4958c0cbe14e26a9a644401313df2f.png)
2.点击【能力信息/详情】，开发者可以查看能力的基本信息；
  

![](https://cdn.sunmi.com/public/image/mgt-document/783767aea1134eb6bb3ebef4b9d70bde.png)
3.点击【接入管理】，开发者可以查看能力已关联的应用
  

![](https://cdn.sunmi.com/public/image/mgt-document/facbbf97abef4a03903eb846343ba1b1.png)
