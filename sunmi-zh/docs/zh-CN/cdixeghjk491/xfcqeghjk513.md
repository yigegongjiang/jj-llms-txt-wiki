# 8.数采小票数据核对
更新时间：2025-09-24 19:12:44
在完成打印机的安装和一系列配置后，可以开始打印小票，核对采集小票数据准确性。
# **登录数字店铺**
商米数字店铺（<https://store.sunmi.com/>）中展示了云打印机采集到的小票数据。
# **查看小票报表**
使用和商米助手相同的账号登录后，右上角切换到门店视角，进入【数据报表>订单小票原始列表】页面，可以看到所有的原始小票。
使用收银机正常收银打印一张小票，刷新列表查看是否采集到数据，点击查看订单详情可以看到原始的小票（文字或者图片）。
如果没采集到数据，请增大订单时间筛选范围（可能打印的历史小票），检查打印机是否在线，是否进行了绑定。
如果采集到了数据，但列表中的交易金额、订单号不正确，请联系商米技术支持人员处理。
如果采集到了正确的订单数据，则测试通过，可以开始安装配置下一台打印机。
