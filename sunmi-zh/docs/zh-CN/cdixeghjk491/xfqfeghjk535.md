# 7、收款音箱DEMO for IOS
更新时间：2025-11-13 16:00:17
# 1、支持iOS 14以上
# 2、设置开发者模式信息
1）【设置】-【隐私与安全性】-【开发者模式】-开发者模式 打开
2）【设置】-【开发者】-【本地体验】-【Register Local Experience…】
3）【URL Prefix】输入【https://h5.sunmi.com】、【Bundle ID】输入【com.sunmi.demo.nfc.clip】、【Title】输入【soundbox】、【Subtitle】输入【SoundBox】、点击保存
  

![](https://cdn.sunmi.com/public/image/mgt-document/351d13c39c43414194f909274c58d778.jpg)
# 3、下载TestFlight软件
1）进入【App store】下载【TestFlight】软件
2）进入TestFlight软件主界面
# 4、打开轻APP
1）打开以下链接：[https://fir.xcxwo.com/ks2bg8xu](https://fir.xcxwo.com/ks2bg8xu?utm_source=fir&utm_medium=qr&release_id=686cb668f945486ba65a03af)
2）打开【轻APP】-【SoundBox】
  

![](https://cdn.sunmi.com/public/image/mgt-document/eeab988c3a9149ec89afe2c2a0e28703.png)
# 5、使用碰一碰功能
1）手机回到桌面，碰一下NFC天线区域，会自动弹开Soundbox应用。
2）点击【打开】进入演示界面，具体操作参考【[收款音箱DEMO演示](https://developer.sunmi.com/docs/zh-CN/cdixeghjk491/xfqdeghjk524)】说明。
