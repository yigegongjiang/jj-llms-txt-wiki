# 5、远程管理收款音箱
更新时间：2025-11-13 15:58:10
# **注册合作伙伴平台账号：**
> 关于注册合作伙伴平台账号流程请参考：<[https://developer.sunmi.com/docs/zh-CN/cicmeghjk546/xcrdeghjk524](https://developer.sunmi.com/docs/zh-CN/cicmeghjk546/xcrdeghjk524/)>
  1. 合作伙伴业务基于商米云提供的安全保障前提下，所以要求合作伙伴需要拥有一个商米合作伙伴平台账户。
  2. 要求收款音箱设备在商米公司出库时，出库渠道一定要选择该账户下，否则收款音箱会因归属权问题无法进行下一步绑定业务。


# **设备总览**
选择【设备管理】-【设备总览】-【IoT设备】，可以查看账号下的所有IoT设备简要信息。包括设备版本信息、活跃时间、地理信息等。
  

![](https://cdn.sunmi.com/public/image/mgt-document/19c134eb768b4cf9987a4c6c95a4b251.png)
# **收款音箱设置**
选择【设备管理】-【IoT设备设置】-【收款音箱】，可以查看账号下所有的收款音箱列表。
  * 状态：红色表示设备离线，绿色表示设备在线；
  * 机型：表示该收款音箱的型号；
  * SN：表示该收款音箱的SN号；
  * 固件版本：表示收款音箱固件版本；
  * 上次连入：表示收款音箱上次接入云服务器的时间；比”上次断开“更接近当前时间，说明设备在线中；
  * 上次断开：表示收款音箱上次与云服务器断开的时间；比”上次连入”更接近当前时间，说明设备离线中；
  * 操作：选择【设置】进入下一管理页面；


  

![](https://cdn.sunmi.com/public/image/mgt-document/a2f77ab7bed9468a8d64cae4dfed29e0.png)
# **设置详情页**
## 1、设备信息
选择【设置】进入【设备信息】页，该页面显示了收款音箱的基本信息，机型、SN、版本号、硬件信息等数据。
  

![](https://cdn.sunmi.com/public/image/mgt-document/92475a972dab495ca48dd84118ff4f07.png)
## 2、网络设置
选择【网络设置】，可以查看收款音箱在对应网络下的入网信息。
  

![](https://cdn.sunmi.com/public/image/mgt-document/c9d9a58056e143cfbb5d9c61d16c7641.png)
## 3、语音设置
选择【语音设置】，可以设置播报的语音语种。
  * 语音播报种类：选择对应语音包，点击【保存】后将下载语音包到设备上。


1、语音包文件较大，设置完成后下载需要一定的时间，请保持设备网络通畅。
2、语音设置后，通过接口推送的语言参数要与该设置相同才能正确播报。
  

![](https://cdn.sunmi.com/public/image/mgt-document/fd2f773316e24c6c8086320e72aa59d2.png)
## 4、播报日志
选择【播报日志】，可以查看云端订单的流转状态。
  * 播报序号：客户云推送过来的订单号；
  * 唯一标识ID：商米云唯一的消息ID，用于唯一标识；
  * 交易类型：准备支付、收款、退款、取消支付；
  * 商米云通道接收时间：商米云接收到合作伙伴推送过来订单的时间；
  * 商米云数据生成时间：商米云转换消息，并向收款音箱推送播报消息的时间；
  * 商米云消息推送时间：收款音箱获得云端播报消息的时间；时间空白表示收款音箱离线中，未接收到消息；
  * 设备播报完成时间：收款音箱消息已经播报完成的时间；时间空白表示收款音箱消息已接收到，但未能播报完成。
