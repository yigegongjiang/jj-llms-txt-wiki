# USB显示器Windows驱动
更新时间：2025-09-25 14:50:09
# 一、产品介绍
  

![](https://cdn.sunmi.com/public/image/mgt-document/2402520432114418b000f4c284d38af3.png)
SUNMI USB显示器是一种通过USB接口与计算机相连的外部显示设备，它能够直接通过USB线缆获取电能并传输图形信号，无需额外电源适配器和独立的视频信号线（如VGA、DVI、HDMI等）。USB显示器简化了硬件连接过程，尤其适用于移动办公、轻便展示和多屏扩展等场景。
SUNMI USB显示器通过更换不同长度的USB线（最长支持3米传输距离），可以将显示器放置于不同高低台面上，实现广告屏拓展效果。
SUNMI USB显示器通过Type-A USB 2.0接口，轻松实现即插即用的功能，还能实现“多屏扩展”和“多屏触控”，并且集成了NFC、人脸摄像头、刷卡器等扩展功能，为收银场景提供更多的便捷使用体验。  
| 类型  | 参数  |  
| --- | --- |  
| 屏幕尺寸  | 15.6”  |  
| 屏幕分辨率  | FHD 1920*1080  |  
| 触摸屏  | 10点触控电容屏  |  
| 信号接口  | Type-C USB 2.0，5V/2A  |  
| 连接线  | Type-A转Type-C USB连接线，长度1.5米  |  
| NFC  | 屏下NFC读卡器  |  
| 扩展接口  | Micro USB*3，可扩展人脸摄像头、读卡器等  |  
# 二、连接方式
使用Type-A转Type-C USB线，将Type-C USB口插入显示器支架上的对应接口，另一头Type-A USB接口插入PC机对应接口。

# 四、驱动安装
## 1、安装
下载并执行安装程序，选择安装程序语言，点击【确认】
  

![](https://cdn.sunmi.com/public/image/mgt-document/25aaffe6f84d44888e62fc9b29bb4b8f.png)
点击【安装】
  

![](https://cdn.sunmi.com/public/image/mgt-document/272fc94686e84cfd90951c754813b024.png)
程序安装完毕，点击【完成】
  

![](https://cdn.sunmi.com/public/image/mgt-document/004199880f4c4392a7206c5dc6b47242.png)
驱动安装完成，可以在【设备管理器】中看到安装后的驱动【显示适配器】→【SUNMI UHD Graphics】。如果没有看到驱动名称，请重新拔插一下显示器USB接口，让系统检测识别硬件驱动。
  

![](https://cdn.sunmi.com/public/image/mgt-document/52310eacb6294cc188b202c0f990acd3.png)
## 2、扩展显示器
打开【设置】→【系统】→【屏幕】，根据使用需求调整【复制显示器】、【扩展显示器】。
  

![](https://cdn.sunmi.com/public/image/mgt-document/9e6ff2b92abe4e4abec1827959836519.png)
## 3、触摸校准
USB显示器支持多屏多触控，当发现USB显示器上的触摸动作跳到了主屏上时，就需要对显示器进行触摸校准。
打开【控制面板】→【平板电脑设置】
  

![](https://cdn.sunmi.com/public/image/mgt-document/684cfde5e67e43b1b12f920031be2798.png)
在平板电脑设置串口中，选择配置【设置】
  

![](https://cdn.sunmi.com/public/image/mgt-document/fc04c7a503e74f18802c19d2c29a7d7b.png)
这时在哪个屏幕上看到以下提示，就在那个屏幕上触控点一下，然后按【Enter】跳转下一个屏幕。当把所有屏幕提示都触控完毕，就校准好了触摸屏。
  

![](https://cdn.sunmi.com/public/image/mgt-document/b62a39425bd84bf0b4ec6733d032ed92.png)
