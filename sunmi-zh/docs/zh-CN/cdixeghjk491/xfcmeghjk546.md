# USB显示器介绍
更新时间：2025-09-25 14:49:06
在商业场景中，广告屏已经成为了必不可少的宣传手段，但一般的POS机采用的都是一体化的副屏方案。如果副屏与主机需要分离时，则需要引线扩展。市场上的副屏扩展方案有4种方式：
# 1、Type-C USB to HDMI转换线
主机需要具有全功能的Type-C USB接口。目前商米仅T3 PRO支持全功能Type-C USB接口，其他老机型暂不支持。
  

![](https://cdn.sunmi.com/public/image/mgt-document/759740ade45f4dcfb1ffb8e6ed2a0249.png)
# 2、Type-A USB 3.0 to HDMI转换线
主机需要具有Type -A USB 3.0接口，并且需要安卓系统提供驱动支持。
  

![](https://cdn.sunmi.com/public/image/mgt-document/cef4b7148b71458fb600afa6d739de2b.png)
# 3、Miracast无线投屏
利用Wi-Fi进行投屏，但目前只能同显，无法异显。被投屏的显示器要求Miracast协议。
# 4、Type-A USB显示器
主机系统只要支持Type-A USB接口，安装驱动以后就可以支持商米USB显示器。
