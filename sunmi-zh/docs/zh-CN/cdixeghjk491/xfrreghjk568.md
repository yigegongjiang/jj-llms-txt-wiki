# 21、标签打印机Windows驱动
更新时间：2025-12-19 22:54:30
本功能仅支持以下机型和版本：
80扫码打印机，Model：NT32x，Firmware version: 4.1.19，SUNMI APP Version：4.1.32以上设备使用；
如需升级请联系客服！
# 一、打印模式
使用本驱动，打印机需要切换到标签打印模式下才有效。需要切换打印模式时，按住【配网键】+按下【音量减键】进行模式切换，模式切换时会伴随语音和打印内容提示当前所处的打印模式。

# 三、选择安装
双击打开安装驱动。
![](https://cdn.sunmi.com/public/image/mgt-document/51fca2b955344e0785beebbbf7da5844.png)
# 四、驱动安装
接受协议，并点击下一步。
![](https://cdn.sunmi.com/public/image/mgt-document/fe6a0fb435074e24b229fba1fd56ebbf.png)
选择安装目录（如果要指定目录，点击右边的“浏览”选择），并点击下一步。
![](https://cdn.sunmi.com/public/image/mgt-document/5d76320b7efe4ec4bff8d6c3f902bf6e.png)
勾选选项，并点击完成。
![](https://cdn.sunmi.com/public/image/mgt-document/2fe86d63b5d449078ef61e271e1309a5.png)
选择安装打印机驱动程序，并点击下一页。
![](https://cdn.sunmi.com/public/image/mgt-document/1d759ac3e3f945488a42f7e5a1d23bfe.png)
选择其他，并点击下一页。
![](https://cdn.sunmi.com/public/image/mgt-document/9e4b6191d1db44e8a53f7fa5d12b0520.png)
选择打印机型号<iDPRT SP320>，并点击下一页。
![](https://cdn.sunmi.com/public/image/mgt-document/b63b762c925049b0b21d572f1e822e4d.png)
选择端口，并点击下一页
找到已连接的80扫码打印机。80扫码打印机的端口类型显示为CloudPrint_xxxx
![](https://cdn.sunmi.com/public/image/mgt-document/3f90707aa283420aa2dbbff1b062d4b1.png)
输入打印机名称、选择"不共享此打印机"，并点击下一页
![](https://cdn.sunmi.com/public/image/mgt-document/2002cc3290b4420f896f2b2ff2e9e01e.png)
点击完成
![](https://cdn.sunmi.com/public/image/mgt-document/b3e6d1781b6045b4ae4fdd7198897daa.png)
安装完成后点击关闭
![](https://cdn.sunmi.com/public/image/mgt-document/a24f23acc4c94c5d89d4d08ec29ff5e8.png)
![](https://cdn.sunmi.com/public/image/mgt-document/e81f4490034444f5b58259c282c38280.png)
