# 9、收款音箱FAQ
更新时间：2025-10-31 15:59:13
# 1）收款音箱每月需要多少流量？
答：收款音箱开机就会一直联网使用4G流量，用于保持网络心跳，业务数据传输，每天100笔订单播报的使用情况下，流量<30MB/月。
  

# 2）QR码牌的提供方式？
答：QR码牌有多种提供方式：
1、商米可以提供QR码牌制作并整机供货的能力。客户需要提供：1) 印制的码牌样式平面矢量图稿件；2) 印刷在码牌上的QR码文本内容，可以用EXCEL表格方式提供。  
2、商米分别销售带有”空白码牌”的收款音箱和QR码牌，由客户自行粘贴。QR码牌制作时需要客户提供：1) 印制的码牌样式平面矢量图稿件；2) 印刷在码牌上的QR码文本内容，可以用EXCEL表格方式提供。  
3、商米仅销售”空白码牌”的收款音箱，由客户当地自行制作和粘贴。建议码牌材质

# 3）QR码牌材质说明？
答：材质选择：建议采用0.3mm厚度的PC或者PVC片材制作；
印刷要求：采用反面印刷，这样外表面才不易被擦拭掉漆
  

# 4）QR码制作规则的说明？
答：QR码使用原理：顾客在支付APP里打开摄像头扫码后，直接扫描音箱上的二维码，二维码在解析后相当于给APP发送了某个执行指令，至于这个指令是什么，则由软件商自行设计（有设计成字符串，也有设计成一个网址）。
客户需提供：二维码生成规则（如指令字符串/网址格式，其中需包含与设备SN号有对应关联的变量，云端具有解析这个变量转换为向指定设备发送播报的对应关系）、颜色要求等技术参数；
商米制作流程：收到规则后10-30天完成码样制作（具体时间视采购量而定）
  

# 5）码牌音箱续航时间？
答：码牌音箱充满电，可以正常使用7天（按每天播报100笔计算）。
  

# 6）电量剩余多少会提示？
答：当电量低于5%时，每5分钟会语音提示电量低。
