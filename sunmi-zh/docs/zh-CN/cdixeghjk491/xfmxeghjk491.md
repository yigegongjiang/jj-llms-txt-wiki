# 11、云打印机微信WIFI配网说明
更新时间：2025-12-19 22:49:15
本功能仅支持以下机型和版本：
58票据云打印机，Model：NT21x，Firmware version: 2.4.0，SUNMI APP Version：2.6.0 以上设备使用；
80后厨云打印机，Model：NT31x，Firmware version: 2.7.0，SUNMI APP Version：2.19.0以上设备使用；
80扫码打印机，Model：NT32x，Firmware version: 4.1.19，SUNMI APP Version：4.1.32以上设备使用；
如需升级请联系客服！
# 1、微信小程序配网
打开手机【微信】，使用【扫一扫】扫描下面的小程序二维码。
  

![](https://cdn.sunmi.com/public/image/mgt-document/d2d360ba0ec845239874262c4cc89b6a.png)
# 2、进入设置页面
1.进入微信小程序【云打印机设置】页面；
2.打开手机蓝牙功能；
蓝牙如果没有打开，将会停留在【刷新】界面，无法进行下一步操作；
3.长按打印机底部的配网按钮，直至打印机播报【开始绑定您的设备】，表示打印机已经进入配网模式；
4.点击【开始设置】；
5.如果首次使用，会提示一些位置、蓝牙权限授权，点击【允许】；
  

![](https://cdn.sunmi.com/public/image/mgt-document/bd71f412e82f47feaa81413405705520.jpg)
  

![](https://cdn.sunmi.com/public/image/mgt-document/b40fbd6cc9cf41d5a7e05f8ad7b1acce.jpg)
  

![](https://cdn.sunmi.com/public/image/mgt-document/e5a8c44ce5bb49a8abdfe8346f99ac68.jpg)
# 3、搜索附近打印机
1.开始搜索附近的云打印机，如果搜索到了，会在界面上显示【CloudPrint_xxxx】格式的打印机名称。
后面的数字表示打印机SN号的后四位，用以区分不同的打印机对应关系。
2.点击对应的打印机名称【CloudPrint_xxxx】，开始进行wifi配置。
  

![](https://cdn.sunmi.com/public/image/mgt-document/5709aba7a15b4019ae6dfc793e3c1bc8.jpg)
# 4、搜索WIFI网络
1.打印机开始搜索附近的wifi网络；
注意：仅有2.4GHz的网络才会被搜索到；
2.点击需要连接的wifi网络名称，开始连接网络；
3.如果连接的wifi网络有加密，则需要输入wifi密码；
  

![](https://cdn.sunmi.com/public/image/mgt-document/ae3c61c1fca64ba290afac8937c794ac.jpg)
  

![](https://cdn.sunmi.com/public/image/mgt-document/2a3197e902e14ed28186ff8fcc415947.jpg)
# 5、WIFI设置成功
1.wifi设置成功，点击【完成】退出。
2.观察打印机【蓝色灯】，亮蓝灯表示网络连接成功；不亮则表示网络不通，需要重新配置wifi。
  

![](https://cdn.sunmi.com/public/image/mgt-document/41d034f0a52b4b05b54823b70bcac041.jpg)
