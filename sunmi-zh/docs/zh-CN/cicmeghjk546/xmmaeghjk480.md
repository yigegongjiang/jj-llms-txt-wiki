# 配置文件常见问题

更新时间：2026-07-21 16:02:50

# 设备明明挂靠了配置文件为何没有生效？

原因：有可能是设备在子账户名下绑定的。客户主账户使用了配置文件功能，但子账户还没有使用，所以设备暂时未响应配置文件。

方法：子账户也切换成配置文件模式后，就可以响应相关设置了。

# 打印机/扫码配置为何不生效？

打印机/扫码配置一般会直接生效，不用重启。配置优先级是：用户手动配置 > 云端配置。有两种情况：

-   设备用户自主操作过打印设备的配置项，根据用户操作生效，云端配置不生效。

    -   若希望云端生效，可以点击打印设置右上角的 更多-清空打印配置

-   设备用户未操作过打印配置，根据云端生效。


# 子账户如何切换配置文件模式

需要的操作：到子账户完成配置文件的切换。

1.  开通配置文件入口：左上角进入目标子账户——进入操作员管理——Role——SystemAdmin——右下角 Edit——勾选 Profile 并保存——返回首页刷新

2.  切换配置文件模式：主菜单 Device——Profile——点击切换
