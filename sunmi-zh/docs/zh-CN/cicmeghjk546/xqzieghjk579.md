# 隐私协议内容填写规范

更新时间：2025-09-29 18:46:57

生效时间：2025年04月30日

# 1、隐私政策链接填写规范参考

### 1.1 隐私政策链接填写

开发者在创建应用或更新版本时，必须提交APP隐私政策链接，该链接的内容必须与APP内的隐私政策保证完全一致，并且当您更新了APP内的隐私政策内容时，请您及时更新隐私政策链接的文本内容。

隐私政策链接提交入口：在[伙伴平台](https://partner.sunmi.com)\--应用市场--应用上传-\-XX App--应用详情--隐私政策URL。

![](https://cdn.sunmi.com/public/image/mgt-document/0e28dad2aa1e461890b05c52edbe960b.png)

### 1.2 隐私政策URL格式参考

隐私政策自动化审核需要读取开发者提供的隐私政策，并进行自动化分析，如果提供的隐私协议链接不支持内容获取（比如PDF、图片格式等），可能会造成审核不通过，需要人工进行处理。如果希望快速通过审核，请开发者尽量提供符合规范的隐私政策链接。隐私政策链接规范如下：

1）标准url格式：如 http(s): //www.example.com/privacy/；

2）为静态html页面，用中文文字显示，统一一种字体，统一一种编码格式，无乱用符号，不需登录、点击、不需再跳转，允许对内容进行自动化分析、验证；

3）链接不能为博客、微博、Github和云笔记等；

4）不为pdf、word、图片等文件格式；

5）提交在伙伴平台的隐私链接内容必须与APP内的隐私内容一致，如您变更了隐私链接地址，需及时在伙伴平台同步更新。

## 2、 隐私政策内容规范参考

### 2.1 隐私政策内容结构大纲参考

隐私政策结构需清晰明了，有段落分层，易于用户阅读。建议您按照如下结构排版撰写隐私政策结构大纲：

一、我们如何收集和使用您的个人信息

二、我们如何使用 Cookie 和同类技术

三、我们如何共享、转让、公开披露用户的个人信息

四、我们如何存储收集的用户信息

五、我们如何使用信息

六、我们如何保证收集的用户信息安全

七、您如何管理个人信息（即，用户主体权利（管理、修改和删除等））

八、未成年人保护

九、如何联系我们

十、隐私政策变更

### 2.2 隐私政策内容要求

1）隐私政策必须单独成文，不可作为用户协议的一部分存在。

2）隐私政策中必须有明确的开发者主体，且仅需要在隐私政策中声明1次即可。如使用的隐私政策为集团或第三方隐私政策，您需要在隐私政策中明确说明集团或第三方与开发者的关联关系。

3）应用的隐私政策中如包含“将收集到的用户搜索、浏览记录、使用习惯等个人信息，用于定向推送或广告精准营销”等与“个性化推荐”、“定向推送”和“广告精准营销”相关的描述，应用内需标识定推服务和提供定推关闭按钮：

①应用内应显著区分定向推送服务，显著方式包括但不限于：标明“个性化推荐”、“定向推荐”、“猜你喜欢”等其他能显著区分的字样，或通过不同的栏目、版块、页面分别展示等。

②应在APP中提供退出或关闭个性化展示模式的选项，如拒绝接受定向推送信息，或停止、退出、关闭相应功能的机制。
