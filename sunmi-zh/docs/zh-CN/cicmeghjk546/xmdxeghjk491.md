# 时区配置
更新时间：2025-11-15 18:02:44
# **概述**
若系统未获取到正确的时区，本功能支持平台管理人员为设备系统指定时区。支持自动设置或者手动选择。
# **运行规则**  
| 规则  | 描述  | 生效时机  |  
| --- | --- | --- |  
| 设备用户自主设置  | 允许设备用户自主设定。  | 立即生效/重启后生效  |  
| 推荐设置  | 在设备用户修改之前或恢复出厂设置后，根据本配置规则生效。  | 立即生效/重启后生效  |  
| 强制控制  | 设备系统始终根据本配置执行。若用户在设备上通过其他方式修改了时区，重启后自动恢复。  | 立即生效/重启后生效  |  
# **设置步骤**
  * 创建/编辑配置文件，进入配置文件编辑状态：**系统 > 时区**
![](https://cdn.sunmi.com/public/image/mgt-document/a199472841274aeca6df5c0017d4c69f.png)


## **设备用户自由控制**
  1. 选择管控类型：**设备用户自主控制** ；
  2. 点击“保存”完成设置。


## **强制控制/推荐设置**
  1. 选择管控类型：**强制控制/推荐设置** ；
  2. 选择时区类型：自动设置时区或者手动设置时区；
  3. 若选择了 **手动设置时区** ，根据指引选择目标时区地理位置；
![](https://cdn.sunmi.com/public/image/mgt-document/8bf377887b714bd4b36a388ddb5cb14c.png)
  4. 点击“保存”完成设置。


  

配置完成后，可以继续编辑其他配置项，或发布配置文件。将配置文件应用到相关设备或组后，受管控的设备将会根据配置规则执行相应的时区设定。
