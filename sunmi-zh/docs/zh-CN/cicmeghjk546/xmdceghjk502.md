# 语言设置
更新时间：2025-11-15 18:08:38
# **概述**
支持平台管理人员为设备指定系统语言。在全球化的背景下，适用于用户来自不同的国家和地区，具有不同的语言偏好的机构。
# **运行规则**  
| 规则  | 描述  | 生效时机  |  
| --- | --- | --- |  
| 设备用户自主设置  | 允许设备用户自主设定。  | 立即生效/重启后生效  |  
| 推荐设置  | 在设备用户修改之前或恢复出厂设置后，根据本配置规则生效。  | 立即生效/重启后生效  |  
| 强制控制  | 设备系统始终根据本配置执行。若用户在设备上通过其他方式修改了设备语言，重启后自动恢复。  | 立即生效/重启后生效  |  
# **设置步骤**
  * 创建/编辑配置文件，进入配置文件编辑状态：**系统 > 语言**


## **设备用户自由控制**
  1. 选择管控类型：**设备用户自主控制** ；
  2. 点击“保存”完成设置。


## **强制控制/推荐设置**
  1. 选择管控类型：**强制控制/推荐设置** ；
  2. 点击下拉菜单，搜索、选择对应的语言
![](https://cdn.sunmi.com/public/image/mgt-document/9cc07fa51b274ad8be565049624c8d5d.png)
  3. 点击 **添加语言** 按钮，将语言添加到列表；
  4. 若需要排序，可以上下语言前方的 排序 图标完成排序；
  5. 点击“保存”完成设置。


  

配置完成后，可以继续编辑其他配置项，或发布配置文件。将配置文件应用到相关设备或组后，受管控的设备将会根据配置规则执行相应的语言设定。系统会优先显示排序第一的语言。
