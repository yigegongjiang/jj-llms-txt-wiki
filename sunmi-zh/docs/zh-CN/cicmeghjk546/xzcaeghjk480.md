# 远控-消息发送能力升级

更新时间：2026-03-31 20:09:45

-   在商米-设备分组-单选/批量设备选择，可点击【消息发送】，支持对离线设备发送。


![](https://cdn.sunmi.com/public/image/mgt-document/6ae44095f48d46e09196dee99fd3983d.png)

-   填写消息的相关信息，标题、内容、图片等

-   客户可选择指定的时区及时间进行消息发送

-   客户可选择是否弹窗显示消息


![](https://cdn.sunmi.com/public/image/mgt-document/7e405114bf324837a88d27b64d27cfc5.png)

-   已经发送的任务，可以到远程协助-使用记录中查看


![](https://cdn.sunmi.com/public/image/mgt-document/dc86ff3889dd4bb4909535d9c2209dcc.png)

-   若任务未完成，且未到结束时间，可在详情中，取消任务；取消后，任务不会继续推送。


![](https://cdn.sunmi.com/public/image/mgt-document/cb36d81c2966412ea43e7a2f75870d66.png)

-   若选择了弹窗提醒，则会在设备端弹窗查看


![](https://cdn.sunmi.com/public/image/mgt-document/551794a0e001482dae5c926ce9bbf25b.png)

-   也可以在远程协助终端-消息中查看已收到的消息。


![](https://cdn.sunmi.com/public/image/mgt-document/97891d65e94d4ede8f54343064a33fe6.png)
