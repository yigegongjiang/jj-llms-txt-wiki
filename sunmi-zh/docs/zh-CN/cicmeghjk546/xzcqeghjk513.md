# 商米投播用户手册
更新时间：2026-05-19 16:18:59
# 应用说明
商米投播（SUNMI CastPlay）是一款商米OS内置应用，可快速将你的设备屏幕转化为商业广告屏。
![](https://cdn.sunmi.com/public/image/mgt-document/caa741677df2452fa1b2cecfbbaccecb.png)
你可在局域网环境下，通过手机扫码方式，快速将手机内的图片、视频内容投放至设备，并支持设备屏幕7×24小时不间断轮播图片和视频内容。
![](https://cdn.sunmi.com/public/image/mgt-document/9d23db659f4e48009b0ea90a6683b266.png)
![](https://cdn.sunmi.com/public/image/mgt-document/3d7f0ac1cd0240ff8bb8d139a0df430c.png)
# 适用场景
适用于各类需通过屏幕长期或短期展示商业广告、菜单、新品信息、活动通知、营销内容等场景。
# 支持硬件
  * **SUNMI CPad全系列：**
    * 非GMS版本：ROM版本4.2.45及以上；
    * GMS版本：ROM版本4.5.37及以上。
  * **SUNMI FLEX全系列：**
    * 高配：
      * 非GMS版本：ROM版本XXX及以上；
      * GMS版本：ROM版本XXX及以上。
    * 标配：
      * 非GMS版本：ROM版本XXX及以上；
      * GMS版本：ROM版本XXX及以上。


# 使用说明
## 扫码投放
  1. 设备联网后，打开商米投播App；
![](https://cdn.sunmi.com/public/image/mgt-document/bae67462ec824d7eaba50b2cfc5d94ed.png)
![](https://cdn.sunmi.com/public/image/mgt-document/219a528f2dcb47da9f16b959421f2b06.png)
  2. 将手机接入与设备相同的局域网；
  3. 使用手机相机（或浏览器内置扫描功能）扫描设备屏幕上的二维码，进入手机端浏览器网页；
![](https://cdn.sunmi.com/public/image/mgt-document/4d373ca0eda548ff96df5bac232cd4d6.png)
![](https://cdn.sunmi.com/public/image/mgt-document/953c628633564d659ae8190318dde22f.png)
  4. 此时设备进入已连接状态；
![](https://cdn.sunmi.com/public/image/mgt-document/3d742880bef84516807fd63f4e00c955.png)
  5. 手机端点击“+”号，从手机相册中选择需投放的图片及视频内容；
![](https://cdn.sunmi.com/public/image/mgt-document/32b544a8ddc04999bb23ba412ea02a79.png)
  6. 点击“投放”按钮，开始内容投放。投放完后可直接关闭浏览器网页；
![](https://cdn.sunmi.com/public/image/mgt-document/6252b270673a4492a0bbb313b55ab2c9.png)
  7. 设备端将自动接收投放内容；
![](https://cdn.sunmi.com/public/image/mgt-document/1319383b85aa4b468fad1b41c09a022b.png)
  8. 投放完成后，设备将自动开启7×24小时图片及视频轮播模式。


## 调整播放顺序、添加和删除内容
  1. 内容轮播时，点击设备屏幕，右上角将显示设置按钮，点击进入应用设置界面；
![](https://cdn.sunmi.com/public/image/mgt-document/b6ef9bc717174340b962ba90ea549126.png)
  2. 在“当前播放”模块中，可查看当前播放列表，点击可进行内容预览，长按可拖动调整播放顺序；
![](https://cdn.sunmi.com/public/image/mgt-document/152529d848484b4893bf017fda2ce67b.png)
![](https://cdn.sunmi.com/public/image/mgt-document/47f7ba09fcf043a684cbfca75b46ff11.png)
  3. 点击“添加”按钮，可新增投放内容，操作流程与“扫码投放”一致；
![](https://cdn.sunmi.com/public/image/mgt-document/ddcbd5f365554a709c391280f14ac9dd.png)
    1. 也可点击弹窗右上角的文件夹图标，从设备本地文件中选择并添加新内容；
  4. 点击“选择”按钮，可批量选中需删除的内容，完成批量删除操作。


![](https://cdn.sunmi.com/public/image/mgt-document/1c7e9ba11b734621a35a5ee1cb23a50b.png)
## 修改图片播放时长
每张图片默认播放时长为5秒，可在“设置-播放设置”界面，将图片播放时长修改为5、10、15、20、25、30、35、40、45、50、55、60秒中的任意一种，修改后对所有图片均生效。
![](https://cdn.sunmi.com/public/image/mgt-document/9624486ca5434e828784454bdc8d85d6.png)
## 应用锁定
应用锁定可以强制当前屏幕始终展示商米投播应用。
开启后，屏幕底部导航栏将失效，顶部状态栏也无法下滑。无法退出投播应用，也无法切换至其他应用，确保屏幕广告的持续播放和有效展示。
  * 首次开启时，需要设置4位数字密码（请记录并妥善保存）。


![](https://cdn.sunmi.com/public/image/mgt-document/9b474d839b4c4e7b97a104fc1521ba9e.png)
### 重置/修改/清空密码
**_注意：重置/修改/清空密码会清空投放内容，需要重新投放。_**
**（1）当“应用锁定”关闭时，操作步骤：**
进入系统“设置”——“应用”——“所有应用”——“商米投播”——“存储和缓存”——“清空存储空间”——“删除”——返回到“应用信息”页面——“打开”——进入“商米投播”——再次开启“应用锁定”，设置新密码（或保持关闭“应用锁定”，密码清空）。
**（2）当“应用锁定”开启时，操作步骤：**
长按电源键——重启——开机后**直接进入** 系统“设置”——“应用”——“所有应用”——“商米投播”——“存储和缓存”——“清空存储空间”——“删除”——返回到“应用信息”页面——“打开”——进入“商米投播”——再次开启“应用锁定”，设置新密码（或保持关闭“应用锁定”，密码清空）。
### 其他问题
**（1）“应用锁定”开启后，“商米投播”异常崩溃，返回桌面，此时系统的导航栏和状态栏仍被禁用，如何修复？**
直接重新打开“商米投播”，关闭“应用锁定”即可。
（若此时已进入其他应用导致无法打开投播，可以先重启设备，重启后再直接进入“商米投播”，关闭“应用锁定”。）
**（2）“应用锁定”开启后，从“商米投播”应用内跳转进入系统“设置”连接Wi-Fi，连接完成后如何从系统“设置”返回“商米投播”？**
此时在系统“设置”里，按照：“应用”——“所有应用”——“商米投播”——“打开”，即可进入“商米投播”。
