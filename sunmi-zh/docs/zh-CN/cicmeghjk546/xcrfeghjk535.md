# 我的设备
更新时间：2024-12-24 16:25:17
# 设备总览
设备总览中可以查看您渠道下设备的SN码、ROM版本、归属账户、活跃时间等信息，由此可进行渠道下设备的基础信息统计输出，为合作伙伴提供更快捷的方式进行设备信息收集和分析。
查看步骤： 点选“设备管理”->“我的设备” -> “设备总览”
*设备的位置信息在设备重启时进行更新，5公里范围内位置信息不进行更新。
  

![](https://cdn.sunmi.com/public/image/mgt-document/f9ba838c200b41dda3d9c8803d2e9f17.png)
# 设备分组
平台提供了2种设备分组，1、普通分组 2、智能分组
普通分组：用户可以根据商户、设备位置、区域等维度灵活创建分组
  

![](https://cdn.sunmi.com/public/image/mgt-document/4c84858917814f97b547bdad47759240.png)
智能分组：用户可以通过机型、普通分组等筛选条件，动态筛选设备
  

![](https://cdn.sunmi.com/public/image/mgt-document/698e49efba4c4335bb61991d30fb6f0c.png)
# 设备地图
合作伙伴通过后台能够随时掌握渠道设备的分布状况，“设备地图”以地图的形式展示出当前区域的机器数量以及型号，帮助合作伙伴根据业务需求实现精准的市场营销活动。
查看步骤： 点选“设备管理” ->“我的设备”-> “设备地图”
注意：商米设备可通过移动网络/WiFi 或者 GPS 定位当前所能定位到的地理位置，并将采集到的数据同步到合作伙伴平台中。
在左上角可切换“地址”或者“SN”搜索设备的方式：
（1）根据“地址”搜索查看这片区域内的设备分布情况；
（2）根据“SN”搜索指定设备在地图上的位置以及这台设备周边的设备分布情况；
  

![](https://cdn.sunmi.com/public/image/mgt-document/42992e13b3154129b776d69a2ce7bb5f.png)
如果您在使用“设备地图”时出现提示信息“抱歉，暂未定位到您的设备”，可能会存在以下原因：
1、 设备没有绑定到您的合作伙伴帐号下;
2、 设备未激活使用，无法获取设备位置；
3、 获取设备位置信息有延迟，过段时间再查看。
# 设备体检
设备体检可查看您渠道下设备的硬件检测体检报告信息详情，由此知悉哪些设备体检异常以及具体异常详情，以便分析处理。
查看步骤： 点选“设备管理”-> “设备体检”
*注：
1、设备体检为设备端硬件管家的上报信息；
2、设备体检的数据需要在设备终端上完成体检之后并且在有WiFi的状态下上传，否则无法显示该项数据。

# 系统日志任务管理
此页面为设备系统日志管理界面，包括设备上报日志以及获取设备日志任务；其中设备上报日志统计了设备端主动上报日志；获取设备日志给合作伙伴提供获取设备日志的能力，下发任务之后，设备端的操作会被记录为日志上传partner平台；（此功能页面需要申请之后才可以开通，默认不显示，如需请联系您的销售沟通申请）
设备上报日志操作说明：
1.设备端上报日志之后才会产生记录，否则列表为空；
2.可以通过上方输入sn进行搜索，也可以根据机型和上报日期范围进行筛选日志；
3.点击下载日志可以下载设备上报的日志，点击设置日志任务，可以跳转至获取设备日志页面进行任务设置并抓取日志；
  

![](https://cdn.sunmi.com/public/image/mgt-document/f1d29ce62f7c4519a72504c48418941c.png)
获取设备日志操作说明：
1、云端下发日志任务之后才会产生记录，否则列表为空；
2、可以通过上方输入sn进行搜索，也可以根据机型和上报日期范围进行筛选日志；
3、点击右上角新增任务可以设置任务开始时间与结束时间，以及文件上限和sn，给设备下发日志抓取任务；
4、任务下发后可以点击强制终止结束日志任务；
