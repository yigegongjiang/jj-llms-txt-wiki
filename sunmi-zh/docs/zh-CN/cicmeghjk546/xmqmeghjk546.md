# 应用通知管理
更新时间：2025-11-15 17:56:41
# **概述**
支持平台管理人员管控设备系统的应用通知，支持针对应用设置通知开关。
# **运行规则**  
| 规则  | 描述  | 生效时机  |  
| --- | --- | --- |  
| 设备用户自主设置  | 允许设备用户自主配置应用通知策略  | 立即生效/重启后生效  |  
| 强制控制  |  设备系统始终根据本配置执行。若用户在设备上通过其他方式修改了通知策略，重启后自动恢复。
  * 开启应用通知开关：设备系统允许该应用通知
  * 关闭应用通知开关：设备系统禁止该应用通知

 | 立即生效/重启后生效  |  
# **设置步骤**
  * 创建/编辑配置文件，进入配置文件编辑状态：**应用管控 > 通知管理**
![](https://cdn.sunmi.com/public/image/mgt-document/edfa58e1577c43e39f3a0195ff07bb71.png)


## **设备用户自由控制**
  1. 选择管控类型：**设备用户自主控制** ；
  2. 点击“保存”完成设置。


## **强制控制应用通知**
  1. 选择管控类型：**强制控制**
![](https://cdn.sunmi.com/public/image/mgt-document/7f40a9b211384b919a64536bc5b21d21.png)
  2. 点击右侧 **添加应用** 按钮，弹出应用选择框，添加需要控制的应用。仅支持设置在商米应用市场上架的应用；
![](https://cdn.sunmi.com/public/image/mgt-document/1ed435d232394459a1945ae7e86a2869.png)
  3. 点击目标应用右侧的 **添加，** 返回待管控的应用列表；
  4. 针对该应用设置 **开启/关闭** 通知；
  5. 若需要删除，点击右侧 **删除** 图标，完成删除操作；
  6. 点击“保存”完成设置。


配置完成后，可以继续编辑其他配置项，或发布配置文件。将配置文件应用到相关设备或组后，受管控的设备将会根据应用开关执行相应的限制。
