# 注册企业帐号

更新时间：2026-05-21 16:46:52

1、使用您的帐号登录Partner

-   如果您是企业中的操作员，并且是通过企业管理员邀请链接注册的帐号，则在您输入帐号密码后，将直接进入企业管理页面

-   如果您是企业管理员，在您首次登录时，需要注册企业主体

    ![](https://cdn.sunmi.com/public/image/mgt-document/ed0a097ba08c4577b1b7d8c8195bfc86.png)


2、点击“立即完善资料”，跳转进入主体注册页面

选择主体所在国家和主体类型，主体类型分为“企业”和“个人”

企业：适用于运营主体为企业的客户

个人：适用于运营主体为个人的客户，如个人开发者

![](https://cdn.sunmi.com/public/image/mgt-document/967194ddde8e4abba0791fa4ff018df0.png)

3、选择企业或个人后，填写必要的信息，并提交审核。

![](https://cdn.sunmi.com/public/image/mgt-document/a01649dd30634d96ba0fa27021fdc3cd.png)

![](https://cdn.sunmi.com/public/image/mgt-document/85e18d5184c6414a8be40e484e875b62.png)

4、商米会进行资料审核，审核通过后，系统会发送审核通过邮件到您的邮箱/短信

![](https://cdn.sunmi.com/public/image/mgt-document/c2c4fe92c2a74d2f8476d9b74db8e195.png)

5、企业认证

企业注册审核后，当您登陆partner平台，您还需要进行企业账户认证

进入工作台后，您可点击“立即认证”，

（\*如果您需要管理设备，请务必要进行认证；只有公司名称和税号齐全的账户才可以申请认证）

![](https://cdn.sunmi.com/public/image/mgt-document/a15620d56ac34eb0a3a52abca2700e87.png)

认证流程

1、选择一种认证方式

企业对公打款认证：使用与注册企业一致的企业银行账户往指定商米账户打款1元进行认证

合同编号认证：使用与注册企业一致的已于商米协定并生效的企业合同编号进行认证

![](https://cdn.sunmi.com/public/image/mgt-document/836ef28441c443d795926b4a7f9d6aa8.png)

对公打款

![](https://cdn.sunmi.com/public/image/mgt-document/9fb7682f6113478b8d00d15ccb210123.png)

![](https://cdn.sunmi.com/public/image/mgt-document/4713867110ed47389d1514e54ce45a26.png)

一般转款后30分钟左右，系统即可自动完成认证。页面出现认证成功弹框，您即可获得渠道身份，对自己的设备进行管理

![](https://cdn.sunmi.com/public/image/mgt-document/fe514fb4bbf64ec681bb70273a9a1683.png)

如果您选择“合同编号认证”，填写您与商米签约的硬件销售合同、手机号、操作人员姓名，点击提交申请

![](https://cdn.sunmi.com/public/image/mgt-document/e3ee08b7aa9f4684944692b0c1232829.png)

![](https://cdn.sunmi.com/public/image/mgt-document/960225dbd6794f7faba52f862f40f0f0.png)

一般提交后30分钟左右，系统即可自动完成认证。页面出现认证成功弹框，您即可获得渠道身份，对自己的设备进行管理。

![](https://cdn.sunmi.com/public/image/mgt-document/a41225f480184cb9a6dd6f67cf4ba816.png)
