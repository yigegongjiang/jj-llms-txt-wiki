# 手册&公告概览

本文档是《软件产品手册&公告》系列资料的总括性介绍与导读，旨在为各位合作伙伴、开发者及用户提供一个清晰的阅读指南。通过本文档，您可以快速了解本系列所包含的核心内容、各类文档的定位及其所能解决的关键问题，从而更高效地获取所需信息，充分发挥商米软件生态的价值。无论您是商米生态的合作伙伴(Partner)、技术部署人员，还是使用商米设备和平台的最终用户，都可以在这里找到全面、权威、最新的技术文档、操作指南以及重要的官方公告。
# **一、文档集概述**
《软件产品手册&公告》是商米为其软件产品、平台服务及核心技术维护所建立的官方文档与公告集合。它系统化地整合了从产品使用、系统部署到安全维护、版本更新的全方位信息，体现了商米致力于提供稳定、安全、可扩展的软件解决方案的承诺。
本系列文档主要服务于以下角色:
  * **合作伙伴与集成商** : 了解产品能力，进行二次开发与系统集成。
  * **技术维护人员** : 执行系统部署、设备管理与故障排查。
  * **终端用户与管理者** : 掌握产品功能，确保业务系统平稳运行。


# **二、核心内容模块导读**
为方便您查阅，本系列文档目前包含以下几个核心模块:
## **1. 合作伙伴平台资源**
  * **《Partner手册》** : 这是**商米（SUNMI）合作伙伴平台** 的操作指南，涵盖了**账号注册、系统管理、设备管理、应用管理** 等一系列云平台相关功能。


## **2. 系统部署与管理**
  * **《TMS私有化部署手册》** : 为指导大规模、定制化的设备管理系统(TMS)部署而设计，详细说明了在私有服务器环境下的安装、配置与管理流程，满足企业对数据安全与独立管控的高要求。


## **3. 服务状态与安全体系**
  * **商米云服务健康状态平台** : 提供商米云服务平台的实时健康状态透明公示，助您随时掌握平台运行情况。
  * **商米安全中心** : 发布漏洞奖励计划、安全补丁更新计划与公告，展示了商米对产品安全性的高度重视。通过社区协作和定期更新，共同构建坚固的安全防线，保障您的业务数据安全。
  * **商米设备的安卓版本** : 集中管理与公示设备所搭载的安卓系统版本信息，确保版本可控、合规。


## **4. 专项解决方案与工具**
  * **安卓AER解决方案** : 详细介绍商米安卓设备上AER（**Android Enterprise Reseller** ）解决方案的操作方法。
  * **SUNMI Windows软件说明** : 针对SuperPOS设备提供的Windows系统的操作使用指南和操作手册。

  1. 首先通读本文档，建立对整体内容的认知框架。

  3. 定期关注“公告”部分（如安全补丁更新、服务状态），以确保您的系统始终处于最佳和安全的状态。
