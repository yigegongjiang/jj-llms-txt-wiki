# 注册个人帐号
更新时间：2025-03-11 18:46:55
1、选择partner站点，输入域名，点击“立即注册”
partner站点域名[了解更多](https://developer.sunmi.com/docs/preview/zh-CN/xqfieghjk579)  
| 站点  | 域名  |   
 |  
| --- | --- | --- |  
| 全球站  | partner.sunmi.com  |   
 |  
| 欧洲站点  | partner.eu.sunmi.com  |   
 |  
| 北美站点  | partner.us.sunmi.com  |   
 |  
  

![](https://cdn.sunmi.com/public/image/mgt-document/058a272796d34ce588a08c1c3f6d2d01.png)
2、点击立即注册后会跳出对话框，输入信息后，点击“立即注册”按钮
  

![](https://cdn.sunmi.com/public/image/mgt-document/c4aed304d1f446a4b864d73c89fa8702.png)
3、系统将发送激活邮件/短信。请在您的邮箱/短信中查收激活信息，并点击激活链接。激活信息有效期为发送后24小时，请在有效期内及时处理
  

![](https://cdn.sunmi.com/public/image/mgt-document/5a2598a69278468696c1c1d25c4085a2.png)
3、激活完成后，您的个人帐号就创建完成。
  

![](https://cdn.sunmi.com/public/image/mgt-document/38b5c5409fc3489690aaa2d3bd928f26.png)
