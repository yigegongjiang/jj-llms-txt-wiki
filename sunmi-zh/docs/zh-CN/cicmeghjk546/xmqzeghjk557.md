# WLAN 配置

更新时间：2025-11-15 17:57:41

# 概述

平台管理人员可以配置需要分发给设备的 Wi-Fi 信息。可以将所有必须的 Wi-Fi 添加到同一个配置文件中。

# 运行规则

-   设备添加 Wi-Fi 的 SSID、密码等信息，配置完成并绑定到设备后立即生效，但不会立即自动连接；

-   不同的配置文件如果包含不同的 SSID。所有 SSID 都会添加到设备中；

-   删除 Wi-Fi 的配置文件，只会影响新绑定的设备，已完成配置的设备不受影响。


# 设置步骤

## 添加 Wi-Fi 信息

1.  创建/编辑配置文件，进入配置文件编辑状态：**Network > WLAN 配置**；

    ![](https://cdn.sunmi.com/public/image/mgt-document/a859089f48cf4d6fbd949b4ef59a4391.png)

2.  点击 **新增 Wi-Fi** 按钮，弹出 Wi-Fi 设置弹框；

    ![](https://cdn.sunmi.com/public/image/mgt-document/fde21c3e21054415b57038d9c59d7831.png)

3.  填写 SSID、安全类型、密码等信息；

4.  点击“保存”完成设置。已保存的 Wi-Fi 信息，支持编辑修改。


## 删除 Wi-Fi 信息

注意：删除配置文件的 Wi-Fi 信息后，仅代表配置文件后续不会再下发本 Wi-Fi，已经配置过本 Wi-Fi 的设备不会受影响。

1.  创建/编辑配置文件，进入配置文件编辑状态：**Network > WLAN 配置** 查看已经添加的 Wi-Fi 列表；

2.  点击需要删除的 Wi-Fi 条目右侧的 **删除** 图标，并再次确认；

3.  删除操作完成。


配置完成后，可以继续编辑其他配置项，或发布配置文件。将配置文件应用到相关设备或组后，受管控的设备将会出现系统桌面切换弹框确认或者在重启后生效系统桌面。
