# 打印机设置
更新时间：2025-11-15 17:52:54
# **概述**
平台管理人员可针对设备所搭载的打印机，灵活设定差异化的打印规则。该配置仅对配备打印机的机型产生作用，对于未配备打印机的设备，即便关联了此配置文件，系统也将自动忽略其中涉及打印机的相关限制 。
# **运行规则**  
| 规则  | 描述  | 生效时机  |  
| --- | --- | --- |  
| 设备用户自主设置  | 云端不管控，允许设备用户自主设定  | 立即生效/重启后生效  |  
| 默认推荐配置  | 在用户更改配置前，以本配置生效  | 立即生效/重启后生效  |  
# **设置步骤**
  * 创建/编辑配置文件，进入配置文件编辑状态：**配件 > 打印机设置**


## **设备用户自由控制**
  1. 选择管控类型：**设备用户自主控制** ；
  2. 点击“保存”完成设置。


## **为设备推荐配置**
  1. 选择管控类型：**默认推荐配置；**
![](https://cdn.sunmi.com/public/image/mgt-document/f71f5c6623b04bbf987a85a60b0111cc.png)
  2. 依次设置**打印效果、打印纸张、其他打印设置；**
  3. 点击底部 **保存** 按钮，完成配置。


# **配置与执行效果**
## **打印字体设置**  
| 配置规则  | 效果说明  |  
| --- | --- |  
| 字体倍高  | 开启后，打印字体高度加倍。  |  
| 字体倍宽  | 开启后，打印字体宽度加倍。将会影响打印输出排版，请谨慎选择。  |  
| 字体加粗  | 开启后，字体自动加粗打印。  |  
| 自动行高  | 当行高小于字符高度时，行高将会被自动设为字符高度。支持按照像素修改。  |  
| 字体反白  | 开启后，字体自动加黑背景并反白打印。  |  
| 下划线  | 开启后，字体自动会加下划线打印。  |  
| 打印浓度  | 支持调整打印机字体的浓度。调整范围 70%～130%  |  
| 字体兼容  | 指定打印字体版本（1.0～3.0）打印机服务会对字体做不同的兼容处理。  |  
## **打印纸张设置**
  1. 开启 **强制纸张规格** 按钮
  2. 选择打印模式。支持：**普通热敏纸、黑标热敏纸、标签打印纸** 三种

  
| 打印纸类型  | 设置  | 支持范围  |  
| --- | --- | --- |  
| 普通热敏纸  | 选择纸张规格  | 设备默认、58mm、80mm  |  
| 黑标热敏纸  | 选择纸张规格  | 设备默认、58mm、80mm  |  
|   
 | 调校切刀位置  | -10mm～15mm  |  
| 标签打印纸  | 选择纸张规格  | 设备默认、25mm～60mm  |  
|   
 | 指定打印速度  | 高速、中速、低速。  |  
## **打印机其他设置**  
| 配置规则  | 效果说明  |  
| --- | --- |  
| 二维码行打印  | 开启后，两个二维码会合并到一行打印。  |  
| 系统弹框报警  | 开启后，允许弹框或者提醒打印机硬件状况。  |  
| 自动切刀/走纸  | 开启后，打印机会执行商米的自动切刀/走纸算法。  |  
  

配置完成后，需要保存。保存后可以继续编辑其他配置项，或发布配置文件。将配置文件应用到相关设备或组后，受管控的设备将会根据应用开关执行相应的限制。
