# 商米设备的安卓版本

更新时间：2025-11-20 17:36:03

尊敬的商米生态开发者伙伴：

您好！

伴随商米硬件产品的持续迭代，商米OS系统已完成从早期Android 7到当前Android 14的版本升级，并规划在未来支持更多Android系统版本。

随着安卓系统版本的不断演进，对商米平台应用的功能适配与技术兼容性提出了更高要求。为进一步保障终端应用市场的兼容性水平，提升用户对应用的使用体验与评价，现诚邀广大开发者提前开展针对商米OS对应安卓系统版本的技术适配工作。

以下为商米硬件产品所支持的安卓版本列表，供各位开发者参考规划适配计划。
