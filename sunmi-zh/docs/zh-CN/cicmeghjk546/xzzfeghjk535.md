# 网络端口映射图解

更新时间：2026-07-04 23:33:22

在部署和配置企业防火墙规则时，请参考本章节提供的端口定义及不同部署架构下的网络通信拓扑端口图解。

---

## 1\. 核心端口说明

端口解释：

`81`: TMS管理平台 WEB 前端端口（HTTP，供管理员浏览器访问）

`8088`: TMS API 核心业务与 WebSocket/Socket.io 服务端口（HTTPS/WSS）

`8883`: 终端 MQTT 消息队列加密长连接端口（MQTT/SSL，供 POS 设备长连接通信）

`1883`: 终端 MQTT 消息队列非加密长连接端口（MQTT/TCP，通常仅限于内网测试使用）

`3478`: 远程桌面控制数据传输及穿透服务端口（TCP/UDP，WebRTC coturn 服务使用）

---

## 2\. 部署架构端口图解

### 图解 A：负载均衡器到后端应用（Nginx 内部端口转发与 SSL 卸载关系）

此图展示了当前置 Nginx（Load Balancer）充当反向代理时，对外的安全端口与容器内部端口的的映射与转发关系。Nginx 负责接收外部的加密 HTTPS/MQTTS 流量并卸载 SSL 证书，解密为明文的 HTTP/TCP 流量后，再分发给后端的应用容器：

-   **443** (HTTPS)转发至 Web 容器的 **81** 端口 (HTTP)

-   **8088** (HTTPS)转发至 API 容器的 **8088** 端口 (HTTP)

-   **8883** (MQTTS)四层转发至 EMQX 容器的 **1883** 端口 (MQTT TCP)

-   **3478** (TCP/UDP)透传至 coturn 容器的 **3478** 端口


![](https://cdn.sunmi.com/public/image/mgt-document/0cfa583d70cc47f78ba1d86b587c5bec.png)

---

### 图解 B：防火墙直连单机部署（无前置 Nginx 反向代理）

此图展示了在没有配置前置 Nginx 反向代理的极简单机部署模式下，防火墙与容器端口的直接映射关系。此时，SSL 证书的卸载或加解密（若有配置）必须直接在各容器内部处理：

-   防火墙的公网 **443** 端口直接映射至容器 Web 端的 **81** 端口

-   防火墙的公网 **8088** 端口直接映射至容器 API 端的 **8088** 端口

-   防火墙的公网 **8883** 端口直接映射至 EMQX 的 **1883** 端口

-   防火墙的公网 **3478** 端口直接映射至 Coturn 服务的 **3478** 端口


![](https://cdn.sunmi.com/public/image/mgt-document/cbf82207788b4357a8670b23fe950f2a.png)

---

### 图解 C：公网防火墙到负载均衡器（前置反向代理的外部接口关系）

此图展示了在使用前置负载均衡器（Nginx LB 或云服务商 SLB）时的最外层端口映射规则。防火墙将公网所有的请求原封不动地转发到负载均衡器上，由负载均衡器统一进行证书管理、访问控制和流量分发：

-   防火墙 **443** 端口对应负载均衡器 **443** 端口

-   防火墙 **8088** 端口对应负载均衡器 **8088** 端口

-   防火墙 **8883** 端口对应负载均衡器 **8883** 端口

-   防火墙 **3478** 端口对应负载均衡器 **3478** 端口
