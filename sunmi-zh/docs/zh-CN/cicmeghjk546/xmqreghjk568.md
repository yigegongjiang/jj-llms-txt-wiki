# 自定义桌面

更新时间：2025-11-15 17:58:40

# 概述

支持平台管理人员管控设备系统桌面（Launcher）。可以通过配置文件为设备指定系统桌面。包括：系统原桌面、自定义桌面。更好的保证整个设备群保持一致的品牌形象或者交互体验。

# 运行规则

<!-- prettier-ignore -->
| 规则 | 描述 | 生效时机 |
| --- | --- | --- |
| 设备用户自主控制 | 允许设备用户修改系统桌面 | 立即生效/重启后生效 |
| 强制显示指定系统桌面（Launcher） | 设备始终显示指定的系统桌面。若用户在设备上通过其他方式修改了桌面，重启后自动恢复。 | 立即生效/重启后生效 |

# 设置步骤

-   创建/编辑配置文件，进入配置文件编辑状态：**风格管理 > 自定义桌面**；


## 设备用户自由控制

1.  选择管控类型：**设备用户自主控制**；

2.  点击“保存”完成设置。


## 强制设备显示指定桌面（Luncher）

1.  选择管控类型：强制指定桌面 > **系统默认桌面/自定义桌面**

    ![](https://cdn.sunmi.com/public/image/mgt-document/cf369048f0184494852f35e798b554cb.png)

2.  根据应用的格式要求，上传自定义桌面 APK。（若选择了系统默认桌面，则不需要上传）；

3.  上传后的桌面若需要修改，可以点击右侧的切换图标，重新上传；

    ![](https://cdn.sunmi.com/public/image/mgt-document/92fd9b9863ed44f193201aeed642a352.png)

4.  点击“保存”完成设置。


配置完成后，可以继续编辑其他配置项，或发布配置文件。将配置文件应用到相关设备或组后，受管控的设备将会出现系统桌面切换弹框确认或者在重启后生效系统桌面。
