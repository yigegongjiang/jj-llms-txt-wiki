# 自定义开机动画

更新时间：2025-11-15 17:59:55

# 概述

支持平台管理人员管控设备的开机动画。可以通过配置文件为设备指定开机动画并下发到设备。包括：系统原开机动画、自定义开机动画。更好的保证整个设备群保持一致的品牌形象。

# 运行规则

<!-- prettier-ignore -->
| 规则 | 描述 | 生效时机 |
| --- | --- | --- |
| 设备用户自主控制 | 允许设备通过其他方式修改开机动画 | 重启后生效 |
| 强制显示指定开机动画 | 系统始终执行已经指定的开机动画，无论设备如何修改或重启 | 重启后生效 |

# 设置步骤

-   创建/编辑配置文件，进入配置文件编辑状态：**风格管理 > 自定义开机动画**；


![](https://cdn.sunmi.com/public/image/mgt-document/461284094fd04862870a33fd795d98fa.png)

## 设备用户自由控制

1.  选择管控类型：设备用户自主控制；

2.  点击“保存”完成设置。


## 强制指定开机动画

1.  选择管控类型：**强制指定开机动画** 可以看到所有机型的开机动画列表。开机动画是按照分辨率区分的，不同的机型分辨率相同，在列表中会被合并；

    ![](https://cdn.sunmi.com/public/image/mgt-document/2112863b142842b096d5af7b71f4e78a.png)

2.  点击右边的编辑按钮，进入编辑状态。选择 **商米默认开机动画 / 自定义开机动画** ；

    ![](https://cdn.sunmi.com/public/image/mgt-document/b95b82358d4a442ba9cd64f6cb2fcd8b.png)

    ![](https://cdn.sunmi.com/public/image/mgt-document/ae8723eea98e4a38b5fe3b50f4780075.png)

3.  根据文件格式要求，上传开机动画文件（若选择了商米默认开机动画，则不需要上传）。支持图片上传或 ZIP 包上传。鼠标滑过 **制作帮助** 可以看到开机动画文件制作帮助，包括图片和 ZIP 包以及 Demo 文件；

4.  点击“保存”完成设置。


配置完成后，可以继续编辑其他配置项，或保存并发布配置文件。将配置文件应用到相关设备或组后，受管控的设备将在重启后生效设置。配置虽然生效，但开机动画文件下载需要一定时间。若首次重启下载尚未完成，则需要再次重启才可以生效。
