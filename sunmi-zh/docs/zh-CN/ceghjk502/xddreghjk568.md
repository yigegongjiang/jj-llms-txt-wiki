# 89键商用键盘

更新时间：2025-09-18 13:03:52

# 89键商用键盘编程操作说明

# 1.接入外设键盘

-   用户将外设键盘插入商米的设备。设备接入外设键盘后，界面上弹出“设备已连接”的提示弹窗，提醒用户进行键盘快捷键设置操作。

-   提示弹窗会提醒用户“是否创建桌面快捷方式”，用户可根据需要自行选择。

-   弹窗底部有两个按钮，分别是“取消”和“编辑”。点击“取消”按钮，提示弹窗关闭，用户未进行键盘快捷键设置。

-   点击“编辑”按钮，进入键盘快捷键设置详细界面。


![](https://cdn.sunmi.com/public/image/mgt-document/3747a70609a345fb976e3ef36fe2a1c0.png)

# 2.设置键盘快捷键

-   在键盘快捷键设置详细界面，点击“编辑”按钮，对键盘中的“ESC”、“F1”、“F2”等按键进行设置。


![](https://cdn.sunmi.com/public/image/mgt-document/e987132000f6402bb80e95c08d0d2ba7.png)

-   用户使用界面上的虚拟键盘，在每个按键对应的输入框中输入自定义的快捷键。


![](https://cdn.sunmi.com/public/image/mgt-document/e304d89b1e5e45d797232af8d03fcc08.png)

-   用户可根据实际应用场景的需要来设置键盘的快捷键。 说明：若用户输入时点击的是外设键盘任意的一个按键，此时界面将由编辑状态变成完成查看状态。

    例如：在“Esc”键的输入框中点击虚拟键盘上的“M”按键。 点击“下一个”按钮，进入“F1”键的设置。

    例如：在“F1”键的输入框中点击“A”按键。


![](https://cdn.sunmi.com/public/image/mgt-document/5cda73363e7247a282fa5b4b067ddd8a.png)

-   以此类推，“F5”键的输入框中点击“Enter”按键；“F6”键的输入框中点击“2”按键；“F0”键的输入框中点击“，”按键等等，设置键盘快捷键。


![](https://cdn.sunmi.com/public/image/mgt-document/6e46124eb374445e96ad544ab68fb6d5.png)

-   点击“全部清除”按钮，弹出清除所有快捷键配置的提示弹窗。

-   点击“取消”按钮，提示弹窗关闭；点击“确定”按钮，所有快捷键配置信息清空。


![](https://cdn.sunmi.com/public/image/mgt-document/98e8f7c470344cc3ba2c3fc8284a0a02.png)

-   点击“全部保存”按钮，键盘快捷键设置完毕，回到设置界面。


![](https://cdn.sunmi.com/public/image/mgt-document/5cda73363e7247a282fa5b4b067ddd8a.png)

![](https://cdn.sunmi.com/public/image/mgt-document/712db2cce5354350a116f84e70bd3088.png)

# 3.使用键盘快捷键

-   打开一个可以输入文本的界面。

-   示例：比如打开“用户反馈”应用的“我要反馈”功能页面，在填写反馈信息时使用键盘快捷键进行操作。详细内容可见下图。


![](https://cdn.sunmi.com/public/image/mgt-document/f68416ae83b447978fc41658ae2ec1fc.png)

按照步骤2中上设置，用户在外设键盘依次点击“Esc”、“F1”、“F2”、“Esc”、“F3”、“F4”、“F10”、“F5”、“F6”、“F7”“F6”、“F6”、“F7”、“F8”、“F7”、“F9”、“F10”、“F5”、“Delete”、“Home”、“End”、“PgUp”和“PgDn”。

快捷按键映射说明：“Esc”（“M”键）、“F1”（“A”键）、“F2”（“Y”键）、“F3”（“E”键）、“F4”（“I”键）、“F5”（“Enter”键）、“F6”（“0”键）、“F7”（“0”键）、 “F8”（“8”键）、“F9”（“9”键）、“F10”（“.”键）、“Delete”（“C”键）、“Home”（“H”键）、“End”（“I”键）、“PgUp”（“N”键）和“PgDn”（“A”键）。

括号内为按键的映射按键，如点击“Esc”按键，实际上是点击“M”键的结果
